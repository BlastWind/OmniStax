回复力引起振动

牛顿第一定律意味着，来回振动的物体正受到力的作用。没有力，物体就会沿直线以恒定的速率运动，而不会振动。例如，考虑像图 16.2 所示那样，把一把塑料直尺向左拨开。直尺的形变会产生一个力，其方向相反，称为回复力。一经释放，回复力就使直尺朝它的稳定平衡位置运动回去，在那里它所受的合力为零。然而，等直尺到达那里时，它已获得动量，继续向右运动，产生相反的形变。它随即被迫向左，回头穿过平衡位置，如此反复，直到耗散力使运动衰减。这些力把机械能从系统中带走，使运动逐渐减弱，直到直尺停下来。

胡克定律：力与位移成正比

最简单的振动出现在回复力与位移成正比的时候。在“牛顿第三定律”中讨论应力和应变时，力与位移之间的这种关系有了一个名称，叫作胡克定律：

$$\kF = -\kk\kx.$$

这里，$\kF$ 是回复力，$\kx$ 是偏离平衡位置的位移，即形变，$\kk$ 是与使系统发生形变的难易程度有关的常量。负号表示回复力的方向与位移相反。

劲度系数 $\kk$ 与系统的刚性（或刚度）有关——劲度系数越大，回复力越大，系统的刚度也越大。$\kk$ 的单位是牛顿每米（N/m）。例如，当我们拉伸一根细绳时，$\kk$ 与杨氏模量直接相关。图 16.4 画出了回复力的绝对值随位移变化的图像，所对应的系统可以用胡克定律描述——这里是一个简单的弹簧。图像的斜率等于以牛顿每米为单位的劲度系数 $\kk$。一项常见的物理学实验练习是：测量弹簧产生的回复力，判断它们是否遵循胡克定律，若遵循，就计算它们的劲度系数。

例题 16.1 · 汽车弹簧的刚度有多大？

当一个 80.0 kg 的人上车时，车身下沉 1.20 cm，这辆汽车悬架系统的劲度系数是多少？

思路

设人上车之前，汽车处于平衡位置 $\kx = 0$。随后汽车下沉 1.20 cm，这意味着它被移到了一个位置 $\kx = -1.20 \times 10^{-2}\ \text{m}$。此时，弹簧提供一个回复力 $\kF$，它等于人的重力 $w = \km g = (80.0\ \text{kg})(9.80\ \text{m/s}^2) = 784\ \text{N}$。我们把这个力当作胡克定律中的 $\kF$。已知 $\kF$ 和 $\kx$，就可以求出劲度系数 $\kk$。

解

  1. 由胡克定律 $\kF = -\kk\kx$ 解出 $\kk$： $$\kk = -\frac{\kF}{\kx}.$$
  2. 代入已知数值，求出 $\kk$： $$\kk = -\frac{784\ \text{N}}{-1.20 \times 10^{-2}\ \text{m}} = 6.53 \times 10^{4}\ \text{N/m}.$$

讨论

注意，$\kF$ 和 $\kx$ 的符号相反，因为它们的方向相反——回复力向上，而位移向下。另外还要注意，如果没有减震器提供的阻尼（由摩擦力引起），人上车时汽车会上下振动。上下颠簸的汽车是减震器已坏的确凿标志。

形变中储存的能量

要产生形变，就必须做功。也就是说，无论是拨一根吉他弦还是压缩汽车的弹簧，都必须有力作用一段距离。如果唯一的结果是形变，没有功转变为热能、声能或动能，那么所有的功最初都以某种势能的形式储存在发生形变的物体中。弹簧中储存的势能为 $\text{PE}_{\text{s}} = \tfrac{1}{2}\kk\kx^2$。在这里，我们把这一想法推广为适用于任何可用胡克定律描述的系统发生形变时的弹性势能。因此，

$$\kPE = \tfrac{1}{2}\kk\kx^2,$$

其中 $\kPE$ 是储存在任何遵循胡克定律的形变系统中的弹性势能，该系统自平衡位置起有一个位移 $\kx$，并有一个劲度系数 $\kk$。

为了求出储存的能量，可以去求使系统发生形变时所做的功。这个功由一个外加力 $\kFa$ 完成。外加力与回复力恰好相反（作用与反作用），所以 $\kFa = \kk\kx$。图 16.6 画出了外加力随形变 $\kx$ 变化的图像，所对应的系统可以用胡克定律描述。对系统所做的功等于力乘以距离，也就等于曲线下的面积，即 $(1/2)\kk\kx^2$（图中的方法 A）。确定这个功的另一种方法是注意到，这个力从 0 线性增大到 $\kk\kx$，因此平均力为 $(1/2)\kk\kx$，移动的距离为 $\kx$，于是 $\kW = \kFa d = [(1/2)\kk\kx](\kx) = (1/2)\kk\kx^2$（图中的方法 B）。

例题 16.2 · 计算储存的能量：玩具枪的弹簧

我们可以借助玩具枪的弹簧机构提出并回答两个简单的问题：（a）一把玩具枪的弹簧，其劲度系数为 50.0 N/m，被压缩了 0.150 m，其中储存了多少能量？（b）如果忽略摩擦力和弹簧的质量，一个 2.00 g 的抛体将以多大的速率从枪中射出？

（a）的思路

（a）：储存在弹簧中的能量可以直接由弹性势能公式求出，因为 $\kk$ 和 $\kx$ 已经给出。

（a）的解

代入 $\kk$ 和 $\kx$ 的已知值，得到

$$\kPE = \tfrac{1}{2}\kk\kx^2 = \tfrac{1}{2}(50.0\ \text{N/m})(0.150\ \text{m})^2 = 0.563\ \text{N}\cdot\text{m} = 0.563\ \text{J}$$

（b）的思路

因为没有摩擦力，这份势能全部转化为动能。动能的表达式可以用来解出该抛体的速率。

（b）的解

  1. 找出已知量： $$\kKE_{\text{f}} = \kPE \quad \text{或} \quad \tfrac{1}{2}\km\kv^2 = \tfrac{1}{2}\kk\kx^2 = \kPE = 0.563\ \text{J}$$
  2. 解出 $\kv$： $$\kv = \left(\frac{2\kPE}{\km}\right)^{1/2} = \left(\frac{2(0.563\ \text{J})}{0.002\ \text{kg}}\right)^{1/2} = 23.7\ (\text{J/kg})^{1/2}$$
  3. 换算单位：$23.7\ \text{m/s}$

讨论

（a）和（b）：对一把玩具枪来说，这个抛体的速率令人印象深刻（超过 80 km/h）。这道题里的数值看起来是合理的。压缩弹簧所需的力小到成年人可以应付，传给飞镖的能量也小到足以限制它可能造成的伤害，尤其是因为这类枪的许多飞镖是用带橡胶头的软材料制成的。然而，飞镖的速率又大到足以让它飞出一段可以接受的距离。
