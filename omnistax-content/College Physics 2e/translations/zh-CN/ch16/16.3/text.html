简谐运动及其振幅

合力可以用胡克定律描述的系统所做的振动尤为重要，因为它们非常常见。它们也是最简单的振动系统。简谐运动（SHM）是对这样一种振动运动的称呼：系统所受的合力可以用胡克定律描述；这样的系统称为简谐振子。如果合力可以用胡克定律描述，并且没有阻尼（由摩擦力或其他非保守力引起），那么简谐振子将在平衡位置两侧以相等的位移振动，如图 16.9 中弹簧上的物体所示。偏离平衡的最大位移称为振幅 $\kX$。振幅和位移的单位相同，但取决于振动的类型。对于弹簧上的物体，振幅和位移的单位是米；而对于声振动，它们的单位是压强的单位（其他类型的振动还有别的单位）。由于振幅是最大位移，它与振动中的能量有关。

居家实验：简谐运动与弹珠

找一只内侧呈半球形的碗或盆。把一颗弹珠放进碗里，周期性地倾斜碗，使弹珠从碗底滚到碗壁两侧同样高的位置。体会一下维持这种周期运动所需的力。回复力是什么？你施加的力在弹珠的简谐运动（SHM）中起什么作用？

周期取决于质量和刚度，而与振幅无关

简谐运动为什么如此重要？一个特别之处在于，简谐振子的周期 $\kT$ 和频率 $\kf$ 与振幅无关。例如，吉他的弦无论是轻拨还是重拨，都会以相同的频率振动。由于周期是恒定的，简谐振子可以用作时钟。

有两个重要因素确实会影响简谐振子的周期。周期与系统的刚度有关。刚度很大的物体具有很大的劲度系数 $\kk$，这使系统的周期较小。例如，你可以调节跳板的刚度——跳板的刚度越大，振动得越快，其周期也越短。周期还取决于振动系统的质量。系统的质量越大，周期越长。例如，体重大的人在跳板上比体重小的人上下弹跳得更慢。

事实上，只有质量 $\km$ 和劲度系数 $\kk$ 会影响简谐运动的周期和频率。

简谐振子的周期

简谐振子的周期为

$$\kT = 2\pi\sqrt{\frac{\km}{\kk}}$$

又因为 $\kf = 1/\kT$，简谐振子的频率为

$$\kf = \frac{1}{2\pi}\sqrt{\frac{\kk}{\km}}.$$

注意，$\kT$ 和 $\kf$ 都与振幅无关。

居家实验：质量与直尺的振动

找两把相同的木质或塑料直尺。把每把直尺的一端牢牢粘在桌边，使每把直尺伸出桌面的长度相同。在其中一把直尺的自由端粘上一件较重的物体，例如几枚大硬币。同时拨动两把直尺的端部，观察哪一把在一段时间内经历的循环更多，并测量每把直尺的振动周期。

例题 16.4 · 计算振动的频率和周期：汽车上失效的减震器

如果汽车的减震器失效，汽车稍受一点扰动就会振动，例如驶过路面颠簸处时，以及停车之后（见图 16.10）。对于这样一辆汽车，如果汽车的质量（包括其载荷）为 900 kg，其悬架系统的劲度系数（$\kk$）为 $6.53 \times 10^{4}\ \text{N/m}$，求这些振动的频率和周期。

思路

汽车振动的频率就是简谐振子的频率，由方程 $\kf = \frac{1}{2\pi}\sqrt{\frac{\kk}{\km}}$ 给出。质量和劲度系数都已给出。

解

  1. 代入 $\kk$ 和 $\km$ 的已知值： $$\kf = \frac{1}{2\pi}\sqrt{\frac{\kk}{\km}} = \frac{1}{2\pi}\sqrt{\frac{6.53 \times 10^{4}\ \text{N/m}}{900\ \text{kg}}}.$$
  2. 计算频率： $$\frac{1}{2\pi}\sqrt{72.6/\text{s}^{2}} = 1.3656/\text{s} \approx 1.36/\text{s} = 1.36\ \text{Hz}.$$
  3. 你可以用 $\kT = 2\pi\sqrt{\frac{\km}{\kk}}$ 来计算周期，但更简单的做法是使用关系 $\kT = 1/\kf$，并代入刚才求得的 $\kf$ 值： $$\kT = \frac{1}{\kf} = \frac{1}{1.356\ \text{Hz}} = 0.738\ \text{s}.$$

讨论

对于一辆上下颠动的汽车，$\kT$ 和 $\kf$ 的值看起来都大致合理。如果你用力按下汽车的一端然后松手，就可以观察到这些振动。

简谐运动与波的联系

如果在这辆上下颠动的汽车驶过时拍一张长时间曝光的照片，前照灯会留下一道波状的光迹，如图 16.10 所示。类似地，图 16.11 显示了弹簧上跳动的一个物体，它在移动的纸带上留下自身位置的波状“轨迹”。这两种波都是正弦函数。所有简谐运动都与正弦波和余弦波密切相关。

在任何简谐运动中——也就是合回复力可以用胡克定律描述的运动——位移作为时间 $\kt$ 的函数，由下式给出：

$$\kx(\kt) = \kX\cos\frac{2\pi\kt}{\kT},$$

其中 $\kX$ 为振幅。在 $\kt = 0$ 时，初始位置为 $\kxo = \kX$，而位移以周期 $\kT$ 来回振动。（当 $\kt = \kT$ 时，我们再次得到 $\kx = \kX$，因为 $\cos 2\pi = 1$。）此外，由 $\kx$ 的这一表达式可知，速度 $\kv$ 作为时间的函数为：

$$\kv(\kt) = -\kvmax\sin\left(\frac{2\pi\kt}{\kT}\right),$$

其中 $\kvmax = 2\pi\kX/\kT = \kX\sqrt{\kk/\km}$。物体在最大位移处速度为零——例如，$\kt = 0$ 时 $\kv = 0$，而在那一时刻 $\kx = \kX$。$\kv(\kt)$ 的第一个方程中的负号给出了速度的正确方向。例如，在运动刚开始之后，速度为负，因为系统正向平衡点运动回去。最后，我们可以利用牛顿第二定律得到加速度的表达式。[于是我们就有了 $\kx(\kt)$、$\kv(\kt)$、$\kt$ 和 $\ka(\kt)$，即运动学以及描述简谐运动所需的量。]根据牛顿第二定律，加速度为 $\ka = \kF/\km = \kk\kx/\km$。因此，$\ka(\kt)$ 也是余弦函数：

$$\ka(\kt) = -\frac{\kk\kX}{\km}\cos\frac{2\pi\kt}{\kT}.$$

因此，$\ka(\kt)$ 与 $\kx(\kt)$ 成正比，且方向相反。

图 16.12 显示了弹簧上一个物体的简谐运动，并给出了 $\kx(\kt)$、$\kv(\kt)$ 和 $\ka(\kt)$ 随时间变化的图线。

这里最重要的一点是，这些方程在数学上很直接，并且对所有简谐运动都成立。它们非常有助于直观地呈现与简谐运动相关的波，包括呈现波如何相互叠加。
