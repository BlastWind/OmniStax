摩擦力是什么，沿哪个方向作用

摩擦力是一种无时无刻不在我们周围的力，它阻碍相互接触的表面之间的相对运动，但也让我们得以行动（如果你曾试图在冰上行走，就已经体会到了）。虽然是一种常见的力，摩擦力的行为其实非常复杂，至今仍未被完全理解。我们要得到任何认识，都得在很大程度上依赖观察。不过，我们仍然可以处理它较为基本的一般特性，并弄清它在什么情形下表现出这些特性。

摩擦力

摩擦力是一种阻碍相互接触的表面之间相对运动的力。

摩擦力较为简单的特性之一，是它平行于各表面之间的接触面，并且总是沿着阻碍各系统之间相对运动或运动趋势的方向。如果两个表面相互接触并且彼此之间有相对运动，那么它们之间的摩擦力称为滑动摩擦力。例如，摩擦力使在冰面上滑行的冰球减速。但当物体静止时，它们之间可以有静摩擦力作用；静摩擦力通常大于这两个表面之间的滑动摩擦力。

滑动摩擦力

如果两个表面相互接触并且彼此之间有相对运动，那么它们之间的摩擦力称为滑动摩擦力。

例如，设想你试图让一只沉重的木箱滑过混凝土地面——你可能对木箱越推越用力，却完全推不动它。这意味着，静摩擦力会对你的所作所为作出响应——它增大到与你的推力大小相等、方向相反。但如果你终于推得足够用力，木箱似乎会突然打滑并开始运动。一旦处于运动状态，要让它保持运动比让它开始运动更容易，这表明滑动摩擦力小于静摩擦力。如果你给木箱增加质量，比如在它上面放一个箱子，那么无论是让它开始运动，还是让它保持运动，你都需要推得更用力。此外，如果你给混凝土涂上油，你会发现更容易让木箱开始运动并保持它运动（正如你可能预料的那样）。

图 5.2 是一幅粗略的示意图，表示摩擦力是如何在两个物体的界面处产生的。近距离观察这些表面，会发现它们是粗糙的。因此，当你推一个物体使其运动（这里是一只木箱）时，你必须把这个物体抬高，直到它只靠表面的尖端相碰便能跳跃着前进，或者使这些尖点断裂，或者两者兼而有之。一个相当大的力可以被摩擦力抵抗，而没有明显的运动。表面被压得越紧（比如在木箱上再放一个箱子），移动它们所需的力就越大。摩擦力的一部分来自两个物体表面分子之间的附着力，这解释了摩擦力对物质性质的依赖。黏附随相接触的物质而变化，是表面物理学中一个复杂的方面。物体一旦运动，接触点就减少了（黏附的分子减少），因此保持物体运动所需的力也就更小。在较小但不为零的速率下，摩擦力几乎与速率无关。

静摩擦力和滑动摩擦力的大小

摩擦力的大小有两种形式：一种用于静止的情形（静摩擦力），另一种用于存在运动的情形（滑动摩擦力）。

当物体之间没有运动时，静摩擦力的大小 $\kfs$ 为

$$\kfs \le \mu_{\text{s}}\kN,$$

其中 $\mu_{\text{s}}$ 是静摩擦因数，$\kN$ 是法向力（垂直于表面的力）的大小。

静摩擦力的大小

静摩擦力的大小 $\kfs$ 为

$$\kfs \le \mu_{\text{s}}\kN,$$

其中 $\mu_{\text{s}}$ 是静摩擦因数，$\kN$ 是法向力的大小。

符号 $\le$ 的意思是小于或等于，这意味着静摩擦力可以有最小值，也可以有最大值 $\mu_{\text{s}}\kN$。静摩擦力是一种响应式的力，它会增大到与所施加的任何力大小相等、方向相反，直至其最大限度。一旦所施加的力超过 $\kfsmax$，物体就会运动。因此

$$\kfsmax = \mu_{\text{s}}\kN.$$

物体一旦运动起来，滑动摩擦力的大小 $\kfk$ 为

$$\kfk = \mu_{\text{k}}\kN,$$

其中 $\mu_{\text{k}}$ 是动摩擦因数。满足 $\kfk = \mu_{\text{k}}\kN$ 的系统，被描述为其中摩擦力遵循简单规律的系统。

滑动摩擦力的大小

滑动摩擦力的大小 $\kfk$ 为

$$\kfk = \mu_{\text{k}}\kN,$$

其中 $\mu_{\text{k}}$ 是动摩擦因数。

如表 5.1 所示，动摩擦因数小于相应的静摩擦因数。表 5.1 中 $\mu$ 的值只给到一位或至多两位数字，这表明上面两个方程对摩擦力的描述是近似的。

前面给出的方程包含了摩擦力对材料和法向力的依赖。摩擦力的方向总是与运动的方向相反，平行于物体之间的表面，并垂直于法向力。例如，如果你试图推动的木箱（所用的力平行于地面）质量为 100 kg，那么法向力就等于它所受的重力 $W = \km\kg = (100\ \text{kg})(9.80\ \text{m/s}^2) = 980\ \text{N}$，方向垂直于地面。如果静摩擦因数为 0.45，你就必须施加一个力，平行于地面，大于 $\kfsmax = \mu_{\text{s}}\kN = (0.45)(980\ \text{N}) = 440\ \text{N}$，才能推动木箱。一旦有了运动，摩擦力就变小，动摩擦因数可能是 0.30，于是只要仅 290 N 的力（$\kfk = \mu_{\text{k}}\kN = (0.30)(980\ \text{N}) = 290\ \text{N}$）就能使它以恒定速率保持运动。如果地面被润滑，两个摩擦因数都会比没有润滑时小得多。摩擦因数是一个无单位的量，其大小通常在 0 到 1.0 之间。摩擦因数取决于相接触的两个表面。

关节及其他润滑表面中的摩擦

许多人都体验过在冰上行走时的湿滑程度。然而，身体的许多部位，尤其是关节，摩擦因数要小得多——常常比冰小三四倍。关节由两块骨的端部构成，两块骨由厚实的组织相连。膝关节由小腿骨（胫骨）和大腿骨（股骨）构成。髋关节是球（位于股骨末端）和窝（骨盆的一部分）构成的球窝关节。关节中各骨的端部覆盖着软骨，它提供了光滑得近乎玻璃般的表面。关节还会产生一种液体（滑液），减少摩擦力和磨损。受损的关节或关节炎患病关节可以用人工关节替换（图 5.3）。这些替代物可以由金属（不锈钢或钛）或塑料（聚乙烯）制成，它们的摩擦因数也非常小。

其他天然润滑剂包括我们口腔中分泌的、有助于吞咽过程的唾液，以及存在于体内器官之间的滑腻黏液，它使器官在心跳、呼吸和人体活动时能够彼此自由滑过。人工润滑剂在医院和诊所中也很常见。例如，进行超声成像时，把换能器与皮肤耦合起来的凝胶也起到润滑换能器与皮肤之间表面的作用——从而减小这两个表面之间的摩擦因数。这使得换能器能够在皮肤上自由移动。

斜坡上的摩擦

例题 5.1 · 滑雪练习

一位滑雪者，质量为 62 kg，正沿着积雪的斜坡下滑。求这位滑雪者的动摩擦因数，已知摩擦力为 45.0 N。

思路

滑动摩擦力的大小已经给出，为 45.0 N。滑动摩擦力与法向力 $\kN$ 的关系为 $\kfk = \mu_{\text{k}}\kN$；因此，只要能求出滑雪者在斜坡上所受的法向力，就能求出动摩擦因数。法向力总是垂直于表面，并且由于垂直于表面的方向上没有运动，法向力应等于滑雪者的重力垂直于斜坡的分量。（见图 5.4 中的滑雪者和受力图。）

即，

$$\kN = \kwperp = \kwgt\ \text{cos}\ 25^\circ = \km\kg\ \text{cos}\ 25^\circ.$$

把它代入我们的滑动摩擦力表达式，得到

$$\kfk = \mu_{\text{k}}\km\kg\ \text{cos}\ 25^\circ,$$

现在即可由它解出动摩擦因数 $\mu_{\text{k}}$。

解

解出 $\mu_{\text{k}}$，得

$$\mu_{\text{k}} = \frac{\kfk}{\kN} = \frac{\kfk}{\kwgt\ \text{cos}\ 25^\circ} = \frac{\kfk}{\km\kg\ \text{cos}\ 25^\circ}.$$

把已知值代入方程右边，

$$\mu_{\text{k}} = \frac{45.0\ \text{N}}{(62\ \text{kg})(9.80\ \text{m/s}^2)(0.906)} = 0.082.$$

讨论

这个结果比表 5.1 中给出的涂蜡木材对雪的因数略小，但仍然是合理的，因为摩擦因数的值可以有很大变化。在这样的情形中，即质量为 $\km$ 的物体沿着与水平方向成 $\ktheta$ 角的斜坡下滑时，摩擦力为 $\kfk = \mu_{\text{k}}\km\kg\ \text{cos}\ \ktheta$。在这些情况下，所有物体都将以恒定加速度沿斜坡下滑。对此的证明留给本章的习题。

摩擦的原子起源

我们已经讨论过，当物体静置在水平表面上时，有一个法向力支撑着它，其大小等于它的重力。此外，遵循简单规律的摩擦力总是与法向力成正比。

建立联系：摩擦的亚微观解释

到目前为止所讨论的摩擦力较为简单的方面，是它的宏观（大尺度）特性。在过去几十年里，对摩擦力的原子尺度解释已经取得了长足的进展。研究人员发现，摩擦力的原子本质似乎有几个基本特征。这些特征不仅解释了摩擦力的一些较简单的方面——它们还有可能促成近乎无摩擦环境的发展，这样的环境可以节省数千亿美元的能量，而这些能量目前正（不必要地）被转化为热量。

图 5.5 说明了摩擦力的一个宏观特性，它可以由微观（小尺度）研究加以解释。我们已经指出，摩擦力与法向力成正比，却与接触面积无关，这是一个多少有些违反直觉的观念。当两个粗糙表面接触时，实际接触面积只是总面积的极小一部分，因为只有凸起处才接触。当施加更大的法向力时，实际接触面积增大，并且发现摩擦力与这个面积成正比。

但原子尺度的观点有望解释的，远不止摩擦力的那些较简单的特征。热量是如何产生的机理，现在正在被确定。换句话说，表面摩擦时为什么会变热？本质上，原子彼此相连，形成晶格。表面摩擦时，表面原子相互黏附，并使原子晶格振动——本质上是产生了穿透材料的声波。声波随距离衰减，其能量转化为热量。与摩擦磨损有关的化学反应也可以发生在表面的原子和分子之间。图 5.6 显示了探针的针尖划过另一种材料时，如何被原子尺度的摩擦力弄得发生形变。拖动针尖所需的力可以测量，并且发现它与切应力有关，这将在本章后面讨论。切应力的变化范围十分惊人（相差超过 $10^{12}$ 倍），难以从理论上预测，但切应力正在使我们对一种自古就为人所知的大尺度现象——摩擦力——获得基本的认识。
