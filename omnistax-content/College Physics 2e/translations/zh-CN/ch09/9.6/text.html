作为杠杆的肌肉、骨骼与关节

肌肉、骨骼和关节是静力学一些最有趣的应用。其中有一些出人意料之处。例如，肌肉施加的力要比我们想象的大得多。图 9.25 显示了一条前臂托着一本书，以及与之类似的杠杆系统的示意图。该示意图是对前臂的良好近似，而前臂看上去比实际情形复杂；通过分析它，我们可以对典型肌肉系统的运作方式获得一些认识。

肌肉只能收缩，所以它们成对出现。在手臂中，肱二头肌是屈肌——也就是说，它使肢体弯曲。肱三头肌是伸肌，使肢体伸展。这种配置是人类和其他脊椎动物的骨骼肌、骨骼和关节的典型情形。大多数骨骼肌在体内施加的力，要比肢体对外界施加的大得多。一旦我们认识到大多数肌肉是通过靠近关节的肌腱附着在骨骼上的，原因就清楚了，这使得这些系统的机械利益远小于 1。把它们看作简单机械，输入力远大于输出力，如图 9.25 所示。

肱二头肌中的力

例题 9.4 · 肌肉施加的力比你想象的更大

计算肱二头肌为托住如图 9.25 所示的前臂及其载荷所必须施加的力，并将这个力与前臂加其载荷的重力相比较。你可以认为图中的数据精确到三位有效数字。

思路

作用在前臂及其载荷（所研究的系统）上的共有四个力。肱二头肌所施力的大小为 $\kFB$；肘关节所施力的大小为 $\kFE$；前臂的重力的大小为 $\kwarm$，其载荷的重力的大小为 $\kwbook$。其中两个是未知的（$\kFB$ 和 $\kFE$），所以仅靠平衡的第一条件无法求出 $\kFB$。但是，如果我们利用第二条件并选取支点在肘，那么 $\kFE$ 产生的力矩为零，唯一的未知量就成了 $\kFB$。

解

重力产生的力矩相对于支点是顺时针的，而肱二头肌产生的力矩是逆时针的；因此，平衡的第二条件 $(\text{合力矩}\ \ktau = 0)$ 成为

$$\krtwo\kwarm + \krthree\kwbook = \krone\kFB.$$

注意，对所有力都有 $\sin\ktheta = 1$，因为对所有力都有 $\ktheta = 90^\circ$。这个方程很容易用已知量解出 $\kFB$，得到

$$\kFB = \frac{\krtwo\kwarm + \krthree\kwbook}{\krone}.$$

代入已知数值，得到

$$\kFB = \frac{(0.160\ \text{m})(2.50\ \text{kg})(9.80\ \text{m/s}^2) + (0.380\ \text{m})(4.00\ \text{kg})(9.80\ \text{m/s}^2)}{0.0400\ \text{m}}$$

即得

$$\kFB = 470\ \text{N}.$$

现在，手臂与其载荷合在一起的重力是 $(6.50\ \text{kg})(9.80\ \text{m/s}^2) = 63.7\ \text{N}$，所以肱二头肌所施力与总重力之比为

$$\frac{\kFB}{\kwarm + \kwbook} = \frac{470}{63.7} = 7.38.$$

讨论

这意味着肱二头肌所施加的力是所承受的重力的 7.38 倍。

在上面肱二头肌的例子中，前臂与上臂之间的夹角是 90°。如果这个夹角改变，肱二头肌所施力也会随之改变。此外，肱二头肌的长度也会改变。肱二头肌所能施加的力取决于它的长度；它缩短时的力比拉伸时的小。

关节中的力

关节中也会产生非常大的力。在前面的例题中，肱骨在肘关节处施加的向下的力 $\kFE$ 等于 407 N，是所承受的总重力的 6.38 倍。（$\kFE$ 的计算很简单，留作章末习题。）由于肌肉能够收缩，却不能伸长到超过其静息长度，关节和肌肉所施加的力往往作用在相反的方向上，因而相减。（在上面的例题中，肌肉向上的力减去关节向下的力，等于所承受的重力——即 $470\ \text{N} - 407\ \text{N} = 63\ \text{N}$，近似等于所承受的重力。）当载荷离关节的距离很远时，肌肉和关节中的力最大，就像前面例题中的书那样。

在网球等球拍类运动中，比赛时手臂不断伸展，就这样产生了很大的力。网球拍的质量乘以力臂是一个重要因素，许多球员使用他们能驾驭的最重的球拍。毫不奇怪，在这类运动中，重复性运动、过大的力矩以及可能不当的球拍选择，会导致关节退化和肘部肌腱受损，例如“网球肘”。各种久经检验的握持和使用球拍、球棒或球杆的技巧，不仅能提高运动水平，还能把疲劳和对身体的长期损伤降到最低。例如，网球若正好击中球拍上的“最佳击球点”，球拍和身体感受到的振动或冲击力就很小——正如“有限大小物体的二维碰撞”中所解释的，力矩也更小。扭动手以使球产生上旋，或在反手击球时使用伸直而僵硬的肘，也会加重肘部肌腱的负担。

训练教练和物理治疗师在治疗肌肉和关节时，运用力与力矩之间关系的知识。在物理治疗中，一套锻炼程序可以施加特定的力和力矩，经过一段时间，可使肌肉和关节恢复活力。有些锻炼被设计成在水下进行，因为这需要施加更大的力，从而进一步增强肌肉。然而，肢体中的结缔组织，例如肌腱和软骨，以及关节，有时会因所承受的大力而受损。这往往是由于意外，但肌肉发达的运动员，例如举重运动员，仅凭用力就可能撕裂肌肉和结缔组织。

姿势与背部劳损

背部比手臂或腿复杂得多，椎骨之间有各种肌肉和关节，它们的机械利益都小于 1。因此，背部肌肉必须施加非常大的力，这些力由脊柱承担。仅因用力就被压坏的椎间盘十分常见。颌有些例外——使颌闭合的咬肌对后牙而言机械利益大于 1，使我们能用后牙施加非常大的力。紧张性头痛的一个成因是持续咬紧牙齿，持续的大力会转化为颅骨周围肌肉的疲劳。

图 9.26 表明了不良姿势如何造成背部劳损。在（a）图中，我们看到一个人姿势良好。请注意，她上身的重心位于髋部支点的正上方，而髋部支点又位于她双脚处支撑面的正上方。因此，她上身的重力对髋部不产生力矩。所需要的唯一的力是髋部处一个竖直方向的力，它等于所承受的重力。不需要肌肉活动，因为骨骼是刚性的，会把这个力从地面传递上来。这是一个不稳定平衡的位置，但如果上身稍有偏离，只需很小的力就能把它带回竖直位置。（b）图表示不良姿势；我们看到上身的重心在髋部支点的前方。这在髋部周围产生一个顺时针力矩，由下背部的肌肉来抵消。这些肌肉必须施加很大的力，因为它们的机械利益通常很小。（换句话说，肌肉的垂直力臂比重心的小得多。）不良姿势还会使坐在桌前使用电脑的人肌肉劳损。有一种特制的椅子，能让身体的重心更容易位于座位的上方，以减轻背痛。肌肉长时间活动会造成肌肉劳损。请注意，在图 9.26 的（b）图中，整个身体的重心仍然位于支撑面的正上方。这是必须的；否则这个人就不会处于平衡。出于同样的原因，我们背着重物时身体前倾，一只手臂提着重物时身体向侧面倾斜，而重物抱在身前时身体后仰，如图 9.27 所示。

你大概被告诫过不要用背部搬举物体。这个动作甚至比不良姿势更容易造成肌肉劳损，并损伤椎间盘和椎骨，因为背部肌肉和脊柱中会产生异常大的力。

用背部搬举

例题 9.5 · 不要用背部搬举

考虑图 9.28 所示的这个人，他用背部搬举一个很重的箱子。（a）计算背部肌肉中支撑上身加箱子所需的力的大小 $\kFB$，并将它与他的重力相比较。上身的质量是 55.0 kg，箱子的质量是 30.0 kg。（b）计算在图中标出的支点处，椎骨对脊柱所施力 $\kFV$ 的大小和方向。同样，图中的数据可认为精确到三位有效数字。

思路

到现在，我们感觉到从平衡的第二条件入手是个好办法，检查已知数值也证实，如果选取支点在髋部，就可以用它来求解 $\kFB$。$\kwub$ 和 $\kwbox$ 产生的力矩是顺时针的，而 $\kFB$ 产生的力矩是逆时针的。

（a）的解

利用图中给出的垂直力臂，平衡的第二条件 $(\text{合力矩}\ \ktau = 0)$ 成为

$$(0.350\ \text{m})(55.0\ \text{kg})(9.80\ \text{m/s}^2) + (0.500\ \text{m})(30.0\ \text{kg})(9.80\ \text{m/s}^2) = (0.0800\ \text{m})\kFB.$$

解出 $\kFB$，得

$$\kFB = 4.20 \times 10^{3}\ \text{N}.$$

背部肌肉所施力与上身加其载荷的重力之比为

$$\frac{\kFB}{\kwub + \kwbox} = \frac{4200\ \text{N}}{833\ \text{N}} = 5.04.$$

这个力比没有载荷时大得多。

（b）的解

就其造成损伤的可能性而言，更重要的是椎骨上的力 $\kFV$。平衡的第一条件 $(\text{合力}\ \kF = 0)$ 可用来求它的大小和方向。用 $y$ 表示竖直方向，$x$ 表示水平方向，沿这两个轴的合外力为零的条件是

$$\text{合力}\ \kFy = 0\ \text{且}\ \text{合力}\ \kFx = 0.$$

先看竖直（$y$）分量，得

$$\kFVy - \kwub - \kwbox - \kFB \sin 29.0^\circ = 0.$$

于是，

$$\begin{aligned}\kFVy &= \kwub + \kwbox + \kFB \sin 29.0^\circ\\ &= 833\ \text{N} + (4200\ \text{N})\sin 29.0^\circ\end{aligned}$$

得

$$\kFVy = 2.87 \times 10^{3}\ \text{N}.$$

同样，对于水平（$x$）分量，

$$\kFVx - \kFB \cos 29.0^\circ = 0$$

得

$$\kFVx = 3.67 \times 10^{3}\ \text{N}.$$

$\kFV$ 的大小由勾股定理给出：

$$\kFV = \sqrt{\kFVx^{2} + \kFVy^{2}} = 4.66 \times 10^{3}\ \text{N}.$$

$\kFV$ 的方向为

$$\ktheta = \tan^{-1}\left(\frac{\kFVy}{\kFVx}\right) = 38.0^\circ.$$

注意，$\kFV$ 与所承受的重力之比为

$$\frac{\kFV}{\kwub + \kwbox} = \frac{4660\ \text{N}}{833\ \text{N}} = 5.59.$$

讨论

这个力约为此人直立站着时的 5.6 倍。背部的问题与其说在于力大——因为我们的髋、膝和踝也会产生类似的力——不如说在于我们的脊柱相对脆弱。正确的搬举方式是保持背部挺直，用腿来抬起身体和载荷，这会使背部产生小得多的力——在这个例子中约为原来的 1/5.6。

肌肉为什么附着在靠近关节处

大多数骨骼肌附着得离关节如此之近，有什么好处？一个好处是速度，因为肌肉的小幅收缩能在很短的时间内使肢体产生大幅度的运动。另一些好处是灵活性和敏捷性，这得益于关节数量众多以及它们的活动范围。例如，很难想象肱二头肌附着在手腕上的系统能够具备我们脊椎动物所拥有的宽广运动范围。

真实系统中的复杂情形

由肌肉、骨骼和关节组成的真实系统中有一些有趣的复杂情况。例如，许多关节的支点位置会随着关节的弯曲而改变，因此垂直力臂和系统的机械利益也随之改变。于是，肱二头肌托住一本书所必须施加的力会随着前臂的弯曲而变化。类似的机制也在腿部起作用，例如，这就解释了为什么自行车座位设在合适的高度时腿部劳损较小。只要对系统的尺寸了解得足够多，本节所用的方法就能对真实系统作出合理的描述。身体中还有许多其他关于力和力矩的有趣例子——其中几个是章末习题的主题。
