改变转动需要力

如果你曾让自行车车轮转起来，或推过旋转木马，你就知道需要力才能改变角速度，如图 10.10 所示。事实上，你的直觉在预测所涉及的许多因素时是可靠的。例如，我们知道，如果推门的位置离铰链太近，门就会开得很慢。此外，我们还知道，门的质量越大，开得越慢。第一个例子意味着，力的作用点离支点越远，角加速度就越大；另一个含义是，角加速度与质量成反比。这些关系应该看起来与力、质量和加速度之间我们熟悉的关系非常相似，后者体现在牛顿第二定律中。事实上，力和质量都有精确的转动类比。

质点的牛顿第二定律的转动类比

为了建立力、质量、半径和角加速度之间的精确关系，考虑如图 10.11 所示的情形：对一个质点 $\km$ 施加一个力 $\kF$，该质点与支点相距一段距离 $\kr$。

最后这个方程是牛顿第二定律（$\kF = \km\ka$）的转动类比，其中力矩类比于力，角加速度类比于平动加速度，而 $\km\kr^2$ 类比于质量（或惯性）。量 $\km\kr^2$ 称为与转动中心相距距离 $\kr$ 的质点 $\km$ 的转动惯量或转动惯量。

建立联系：转动动力学

转动运动的动力学与线性的或平动的动力学完全类似。动力学关注的是力和质量及其对运动的影响。对于转动运动，我们将找到与力和质量直接对应的类比量，它们的表现正如我们根据以往经验所预期的那样。

转动惯性与转动惯量

在我们能够考虑除了像图 10.11 中的那个质点以外的任何物体的转动之前，我们必须把转动惯量的概念推广到所有类型的物体。为了扩展我们的转动惯量概念，我们把物体的转动惯量 $\kI$ 定义为组成它的所有质点的 $\km\kr^2$ 之和。也就是说，$\kI = \sum \km\kr^2$。这里 $\kI$ 类比于平动运动中的 $\km$。由于有距离 $\kr$，任何物体的转动惯量都取决于所选的转轴。实际上，计算 $\kI$ 超出了本教材的范围，只有一种简单的情形除外——细圆环，它的全部质量都与转轴相距同样的距离。因此，细圆环绕其转轴的转动惯量为 $\kM\kR^2$，其中 $\kM$ 是它的总质量，$\kR$ 是它的半径。（我们用 $\kM$ 和 $\kR$ 表示整个物体，以便与表示质点的 $\km$ 和 $\kr$ 区分开来。）在所有其他情形中，我们必须查阅图 10.12（注意，该表是一件既有形状又有公式的艺术作品），其中的 $\kI$ 公式是对连续物体积分导出的。注意，$\kI$ 的单位是质量乘以距离的平方（$\text{kg}\cdot\text{m}^2$），正如我们根据它的定义所预期的那样。

转动的牛顿第二定律

力矩、转动惯量和角加速度之间的一般关系是

$$\text{合力矩}\;\ktau = \kI\kalpha$$

或

$$\kalpha = \frac{\text{合力矩}\;\ktau}{\kI},$$

其中合力矩 $\ktau$ 是所有力相对于选定转轴的总力矩。为简单起见，我们只考虑转动平面内的力所施加的力矩。这样的力矩不是正的就是负的，并且像普通的数一样相加。$\ktau = \kI\kalpha, \kalpha = \frac{\text{合力矩}\;\ktau}{\kI}$ 中的关系是牛顿第二定律的转动类比，适用范围非常广。这个方程实际上对施加在任何物体上的任何力矩、相对于任何转轴都成立。

正如我们所预期的，力矩越大，角加速度就越大。例如，孩子推旋转木马推得越用力，它加速得就越快。此外，旋转木马的质量越大，在同样的力矩下它加速得就越慢。转动惯量与角加速度之间的基本关系是：转动惯量越大，角加速度越小。但还有一个额外的转折。转动惯量不仅取决于物体的质量，还取决于质量相对于它所绕转轴的分布。例如，如果孩子们都站在靠近旋转木马转轴的地方，要让坐满孩子的旋转木马加速，就会比他们都站在外缘时容易得多。两种情形下质量是一样的，但孩子们在边缘时，转动惯量要大得多。

居家实验

用硬纸板剪出一个半径约为 10 cm 的圆。在圆的边缘附近，像钟面上的小时那样写上数字 1 到 12。摆放这个圆，使它能像车轮一样绕一根穿过圆心的水平转轴自由转动。（你可以把圆松松地钉在墙上。）让圆保持静止，数字 12 位于顶部，在数字 3 处贴上一团蓝色油灰（用来把海报固定在墙上的粘性材料）。这团油灰需要多大，才刚好能使圆转动？描述你可以怎样改变圆的转动惯量。这一改变如何影响在数字 3 处刚好使圆转动所需的蓝色油灰的量？改变圆的转动惯量，然后用不同量的蓝色油灰试着转动圆。把这个过程重复几次。

求解转动动力学问题

转动动力学的解题策略
  1. 审视情形，确定力矩和质量参与了转动。仔细画出情形的草图。
  2. 确定所研究的系统。
  3. 画出受力图。也就是说，画出并标注作用在所研究系统上的所有外力。
  4. 应用 $\text{合力矩}\;\ktau = \kI\kalpha, \kalpha = \frac{\text{合力矩}\;\ktau}{\kI}$，即牛顿第二定律的转动等价形式，来解决问题。必须注意使用正确的转动惯量，并考虑对转动点的力矩。
  5. 一如既往，检验解是否合理。
建立联系

在静力学中，合力矩为零，没有角加速度。在转动运动中，合力矩是角加速度的原因，这与适用于转动的牛顿第二定律完全一样。

父亲推旋转木马

例题 10.7 · 计算质量分布对旋转木马的影响

请看图 10.13 中父亲推游乐场旋转木马的情形。他在50.0 kg 的旋转木马边缘施加250 N 的力，该旋转木马的半径为 1.50 m。求（a）旋转木马上没有人时和（b）一个 18.0 kg 的孩子坐在距中心 1.25 m 处时产生的角加速度。把旋转木马本身看作均匀圆盘，阻碍转动的摩擦力可忽略不计。

思路

角加速度由表达式 $\kalpha = \frac{\text{合力矩}\;\ktau}{\kI}$ 直接给出：

$$\kalpha = \frac{\ktau}{\kI}.$$

要求 $\kalpha$，我们必须先计算力矩 $\ktau$（两种情形下相同）和转动惯量 $\kI$（第二种情形中更大）。为求力矩，我们注意到所施加的力垂直于半径，且摩擦力可忽略，因此

$$\ktau = \kr\kF\sin\ktheta = (1.50\ \text{m})(250\ \text{N}) = 375\ \text{N}\cdot\text{m}.$$

（a）的解

实心圆盘绕此转轴的转动惯量在图 10.12 中给出为

$$\frac{1}{2}\kM\kR^2,$$

其中 $\kM = 50.0\ \text{kg}$，$\kR = 1.50\ \text{m}$，所以

$$\kI = (0.500)(50.0\ \text{kg})(1.50\ \text{m})^2 = 56.25\ \text{kg}\cdot\text{m}^2.$$

现在，代入已知数值后，我们求得角加速度为

$$\kalpha = \frac{\ktau}{\kI} = \frac{375\ \text{N}\cdot\text{m}}{56.25\ \text{kg}\cdot\text{m}^2} = 6.67\ \frac{\text{rad}}{\text{s}^2}.$$

（b）的解

我们预期这一部分中该系统的角加速度会更小，因为孩子在旋转木马上时，转动惯量更大。为求总转动惯量 $\kI$，我们先求孩子的转动惯量 $\kIc$，方法是把孩子看作等效于位于距转轴距离为 1.25 m 处的质点。于是，

$$\kIc = \kM\kR^2 = (18.0\ \text{kg})(1.25\ \text{m})^2 = 28.13\ \text{kg}\cdot\text{m}^2.$$

总转动惯量是旋转木马和孩子的转动惯量之和（绕同一转轴）。要自己验证这个求和，请考察 $\kI$ 的定义：

$$\kI = 28.13\ \text{kg}\cdot\text{m}^2 + 56.25\ \text{kg}\cdot\text{m}^2 = 84.38\ \text{kg}\cdot\text{m}^2.$$

把已知数值代入 $\kalpha$ 的方程，得到

$$\kalpha = \frac{\ktau}{\kI} = \frac{375\ \text{N}\cdot\text{m}}{84.38\ \text{kg}\cdot\text{m}^2} = 4.44\ \frac{\text{rad}}{\text{s}^2}.$$

讨论

正如预期的那样，孩子在旋转木马上时的角加速度比旋转木马空着时小。求得的角加速度相当大，部分原因是摩擦力被认为可以忽略。例如，如果父亲持续垂直推 2.00 s，他会使旋转木马在它空着时获得 13.3 rad/s 的角速度，而孩子在它上面时只有 8.89 rad/s。以转每秒计，这些角速度分别为 2.12 rev/s 和 1.41 rev/s。在第一种情形中，父亲最终将以约 50 km/h 的速度奔跑。夏季奥运会，他来了！对这些数值的验证留给读者作为练习。
