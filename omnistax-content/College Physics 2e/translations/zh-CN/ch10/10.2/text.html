转动运动学及其与直线运动的类比

仅凭直觉，我们就能开始看出 $\ktheta$、$\kw$ 和 $\kalpha$ 这样的转动量是如何相互联系的。例如，如果一个摩托车车轮在相当长的时间里具有很大的角加速度，它最终就会转得很快，并转过许多圈。说得更专业一些，如果车轮的角加速度 $\kalpha$ 很大，且持续了很长一段时间 $\kt$，那么末角速度 $\kw$ 和转角 $\ktheta$ 都很大。车轮的转动运动恰好类似于这样一个事实：摩托车较大的平动加速度会产生较大的末速度，而路程也会很大。

运动学是对运动的描述。转动运动学描述转角、角速度、角加速度和时间之间的关系。让我们先来求一个联系 $\kw$、$\kalpha$ 和 $\kt$ 的方程。

请注意，在转动运动中 $\ka = \kat$，从现在起，我们将用符号 $\ka$ 表示切向加速度或线加速度。

这里 $\kwo$ 是初角速度。最后这个方程是 $\kw$、$\kalpha$ 和 $\kt$ 之间的一个运动学关系——也就是说，它描述它们之间的关系，而不涉及可能影响转动的力或质量。它在形式上也与其平动对应量恰好类似。

建立联系

转动运动的运动学与平动运动学完全类似，后者最早在“一维运动学”中介绍。运动学关注的是不考虑力或质量的运动描述。我们将会发现，诸如位移、速度和加速度这些平动运动学量，在转动运动中都有直接的类比量。

四个转动运动学方程

从我们在“一维运动学”中得出的四个运动学方程出发，我们可以推导出下面四个转动运动学方程（与它们的平动对应量一并给出）：

表 10.2转动运动学方程
转动平动
$\ktheta = \kwb\kt$$\kx = \kvb\kt$
$\kw = \kwo + \kalpha\kt$$\kv = \kvo + \ka\kt$（$\kalpha$、$\ka$ 恒定）
$\ktheta = \kwo\kt + \tfrac{1}{2}\kalpha\kt^2$$\kx = \kvo\kt + \tfrac{1}{2}\ka\kt^2$（$\kalpha$、$\ka$ 恒定）
$\kw^2 = \kwo^2 + 2\kalpha\ktheta$$\kv^2 = \kvo^2 + 2\ka\kx$（$\kalpha$、$\ka$ 恒定）

在这些方程中，下标 0 表示初始值（$\kthetao$、$\kxo$ 和 $\kto$ 是初始值），平均角速度 $\kwb$ 和平均速度 $\kvb$ 的定义如下：

$$\kwb = \frac{\kwo + \kw}{2} \quad\text{和}\quad \kvb = \frac{\kvo + \kv}{2}.$$

上面表 10.2 中给出的方程可用于求解任何 $\ka$ 和 $\kalpha$ 恒定的转动或平动运动学问题。

转动运动学的解题策略

转动运动学的解题策略
  1. 审视情境，确定涉及的是转动运动学（转动运动）。必须涉及转动，但无需考虑影响运动的力或质量。
  2. 准确找出题目中需要求出的量（确定未知量）。画一张情境草图会有帮助。
  3. 列出题目所述情境中已给出或可以推断的量（确定已知量）。
  4. 针对要求的量（未知量），解出合适的一个或几个方程。可以从平动类比的角度来思考，因为到目前为止你已经熟悉这种运动了。
  5. 把已知值连同它们的单位一起代入合适的方程，得到带有单位的数值结果。务必使用弧度作为角的单位。
  6. 检查你的答案是否合理：你的答案说得通吗？

例题 10.3 · 计算渔线轮的加速度

一位深海垂钓者钓到了一条大鱼，大鱼游离渔船，把鱼线从他的渔线轮上拉出。整个系统起初静止，鱼线从渔线轮上放出，放出处距其转轴的半径为 4.50 cm。如图 10.7 所示，渔线轮在 2.00 s 内获得 $110\ \text{rad/s}^2$ 的角加速度。

（a）渔线轮的末角速度是多少？

（b）经过 2.00 s 后，鱼线离开渔线轮的速率是多少？

（c）渔线轮转过多少圈？

（d）在这段时间内，有多少米的鱼线从渔线轮上放出？

思路

在本例的每一部分中，思路都与求解直线运动学问题时相同。具体来说，先确定已知值，然后寻找可用来求解未知量的关系式。

（a）的解

这里已知 $\kalpha$ 和 $\kt$，需要求 $\kw$。最直接可用的方程是 $\kw = \kwo + \kalpha\kt$，因为未知量已经在方程的一边，而其他各项都是已知的。该方程表明

$$\kw = \kwo + \kalpha\kt.$$

我们还知道 $\kwo = 0$（它由静止开始），因此

$$\kw = 0 + (110\ \text{rad/s}^2)(2.00\ \text{s}) = 220\ \text{rad/s}.$$

（b）的解

既然 $\kw$ 已知，速率 $\kv$ 最容易利用下列关系求得

$$\kv = \kr\kw,$$

其中渔线轮的半径 $\kr$ 已知为 4.50 cm；因此，

$$\kv = (0.0450\ \text{m})(220\ \text{rad/s}) = 9.90\ \text{m/s}.$$

再次提醒，在任何联系线量与角量的计算中，都必须使用弧度。另外，由于弧度是无量纲的，所以有 $\text{m} \times \text{rad} = \text{m}$。

（c）的解

这里要求的是圈数。因为 $1\ \text{rev} = 2\pi\ \text{rad}$，我们可以通过求出以弧度为单位的 $\ktheta$ 来得到圈数。已知 $\kalpha$ 和 $\kt$，并且我们知道 $\kwo$ 为零，因此可以用 $\ktheta = \kwo\kt + \tfrac{1}{2}\kalpha\kt^2$ 求得 $\ktheta$。

$$\begin{array}{lll}\ktheta & = & \kwo\kt + \tfrac{1}{2}\kalpha\kt^2 \\ & = & 0 + (0.500)(110\ \text{rad/s}^2)(2.00\ \text{s})^2 = 220\ \text{rad}.\end{array}$$

把弧度换算成圈数，得

$$\ktheta = (220\ \text{rad})\frac{1\ \text{rev}}{2\pi\ \text{rad}} = 35.0\ \text{rev}.$$

（d）的解

鱼线的米数就是 $\kx$，它可以通过与 $\ktheta$ 的关系求得：

$$\kx = \kr\ktheta = (0.0450\ \text{m})(220\ \text{rad}) = 9.90\ \text{m}.$$

讨论

本例说明，转动量之间的关系与线量之间的关系高度类似。我们还在本例中看到了线量与转动量是如何联系起来的。各问的答案是符合实际的。放线两秒后，渔线轮的转速为 220 rad/s，即 2100 转每分。（难怪渔线轮有时会发出尖锐的声音。）放出的鱼线量为 9.90 m，与大鱼上钩时的情形大致相符。

例题 10.4 · 计算渔线轮减速直至停止所用的时间

现在设想垂钓者对转动的渔线轮施加刹车，使其获得 $-300\ \text{rad/s}^2$ 的角加速度。渔线轮需要多长时间才能停下来？

思路

我们要求的是渔线轮停下来所用的时间 $\kt$。初始条件和最终条件与上一题不同，上一题涉及的是同一个渔线轮。现在我们看到，初角速度为 $\kwo = 220\ \text{rad/s}$，末角速度 $\kw$ 为零。角加速度给定为 $\kalpha = -300\ \text{rad/s}^2$。检查可用的方程，我们发现在 $\kw = \kwo + \kalpha\kt,$ 中除 $\kt$ 外的所有量都是已知的，因此最容易使用这个方程。

解

该方程表明

$$\kw = \kwo + \kalpha\kt.$$

我们先对 $\kt$ 代数求解该方程，然后像往常一样代入已知值，得

$$\kt = \frac{\kw - \kwo}{\kalpha} = \frac{0 - 220\ \text{rad/s}}{-300\ \text{rad/s}^2} = 0.733\ \text{s}.$$

讨论

请注意，必须小心处理表示各量方向的正负号。另外还要注意，由于加速度相当大，让渔线轮停下来的时间相当短。鱼线有时会因为所涉及的加速度而绷断，垂钓者往往让鱼游一会儿再对渔线轮刹车。疲惫的鱼会游得更慢，所需的加速度也较小。

例题 10.5 · 计算列车及其车轮的缓慢加速

大型货运列车的加速非常缓慢。假设一列这样的列车由静止开始加速，使其半径为 0.350 m 的车轮获得 $0.250\ \text{rad/s}^2$ 的角加速度。在车轮转过 200 圈后（假设不打滑）：（a）列车沿轨道前进了多远？（b）车轮的末角速度和列车的线速度各是多少？

思路

在（a）部分，要求的是 $\kx$，在（b）部分，要求的是 $\kw$ 和 $\kv$。已知圈数 $\ktheta$、车轮的半径 $\kr$ 和角加速度 $\kalpha$。

（a）的解

距离 $\kx$ 很容易由距离与转角之间的关系求得：

$$\ktheta = \frac{\kx}{\kr}.$$

由该方程解出 $\kx$，得

$$\kx = \kr\ktheta.$$

在使用这个方程之前，我们必须先把圈数换算成弧度，因为我们处理的是线量与转动量之间的关系：

$$\ktheta = (200\ \text{rev})\frac{2\pi\ \text{rad}}{1\ \text{rev}} = 1257\ \text{rad}.$$

现在我们可以把已知值代入 $\kx = \kr\ktheta$，求出列车沿轨道前进的距离：

$$\kx = \kr\ktheta = (0.350\ \text{m})(1257\ \text{rad}) = 440\ \text{m}.$$

（b）的解

我们不能用任何含有 $\kt$ 的方程来求 $\kw$，因为这样的方程至少会有两个未知量。方程 $\kw^2 = \kwo^2 + 2\kalpha\ktheta$ 可以用，因为除 $\kw$ 外，所有变量的值我们都知道：

$$\kw^2 = \kwo^2 + 2\kalpha\ktheta$$

对该方程取平方根并代入已知值，得

$$\begin{array}{lll}\kw & = & [0 + 2(0.250\ \text{rad/s}^2)(1257\ \text{rad})]^{1/2} \\ & = & 25.1\ \text{rad/s}.\end{array}$$

我们可以通过列车的线速度 $\kv$ 与 $\kw$ 的关系求出它：

$$\kv = \kr\kw = (0.350\ \text{m})(25.1\ \text{rad/s}) = 8.77\ \text{m/s}.$$

讨论

路程相当大，而末速度相当慢（略低于 32 km/h）。

原地旋转物体的平动

即使是原地旋转的物体也存在平动运动，下面的例题就说明了这一点。图 10.8 显示了一只苍蝇位于一个旋转的微波炉转盘的边缘。下面的例题计算它走过的总距离。

例题 10.6 · 计算微波炉转盘边缘上的苍蝇所走过的距离

一个人决定用微波炉加热一些午餐。在此过程中，一只苍蝇意外地飞进微波炉，落在旋转的转盘的外缘并留在那里。如果转盘的半径为 0.15 m，以 6.0 转每分转动，求苍蝇在 2.0 min 的加热期间走过的总距离。（忽略启动和减速的时间。）

思路

首先求出总圈数 $\ktheta$，然后求出走过的线距离 $\kx$。因为已知 $\kwb$ 为 6.0 转每分，所以可以用 $\ktheta = \kwb\kt$ 求出 $\ktheta$。

解

把已知值代入 $\ktheta = \kwb\kt$，得

$$\ktheta = \kwb\kt = (6.0\ \text{rpm})(2.0\ \text{min}) = 12\ \text{rev}.$$

和以往一样，在由 $\ktheta$ 这样的角量计算 $\kx$ 这样的线量之前，必须先把圈数换算成弧度：

$$\ktheta = (12\ \text{rev})\left(\frac{2\pi\ \text{rad}}{1\ \text{rev}}\right) = 75.4\ \text{rad}.$$

现在，利用 $\kx$ 与 $\ktheta$ 之间的关系，我们可以求出走过的路程：

$$\kx = \kr\ktheta = (0.15\ \text{m})(75.4\ \text{rad}) = 11\ \text{m}.$$

讨论

这趟旅程可真不短（如果它能活下来的话）！请注意，这段距离是苍蝇走过的总路程。对于完整的转圈，位移实际上为零，因为转完整圈会把苍蝇带回它的原来的位置。总路程与位移之间的区别，最早是在“一维运动学”中指出的。
