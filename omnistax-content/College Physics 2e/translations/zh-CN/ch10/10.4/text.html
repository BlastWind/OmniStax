转动圆盘所做的功

在本模块中，我们将学习与转动相联系的功和能量。图 10.16 展示了一名工人正在使用由电动机驱动的电动砂轮。随着一层层钢从杆上被磨去，火花四溅，并产生噪声和振动。即使电动机关闭之后，砂轮仍继续转动，但最终在摩擦力的作用下停了下来。显然，要让砂轮转起来，电动机必须做功。这些功转化成了热量、光、声、振动，以及相当可观的转动动能。

要使砂轮或旋转木马之类的物体转动，必须做功。功已在“匀速圆周运动与引力”中针对平动作了定义，在考虑转动中所做的功时，我们可以在这些知识的基础上继续推进。最简单的转动情形是：合力垂直于圆盘的半径作用（如图 10.17 所示），并且在圆盘开始转动后仍保持垂直。

这个方程就是力矩的功的表达式。它与我们熟悉的平动功的定义——力乘以距离——非常相似。在这里，力矩类比于力，角度类比于距离。方程 $\text{合外力的功}\;\kW = (\text{合力矩}\;\ktau)\ktheta$ 普遍成立，尽管它是针对一种特殊情形推导出来的。

建立联系

转动中的功和能量与平动中的功和能量完全类似，后者首先在“匀速圆周运动与引力”中介绍。

转动动能与动能定理

要得到转动动能的表达式，我们必须再次进行一些代数运算。

这个方程是仅适用于转动的动能定理。你可能还记得，合外力的功会改变系统的动能。通过与平动的类比，我们把 $(\frac{1}{2})\kI\kw^2$ 这一项定义为转动动能 $\kKErot$，其中物体的转动惯量为 $\kI$、角速度为 $\kw$：

$$\kKErot = \frac{1}{2}\kI\kw^2.$$

转动动能的表达式与平动动能的表达式完全类似，其中 $\kI$ 类比于 $\km$，$\kw$ 类比于 $\kv$。转动动能有重要的效应。例如，飞轮可用来在车辆中储存大量的转动动能，如图 10.18 所示。

转动砂轮

例题 10.8 · 计算转动砂轮所做的功和所需的能量

设想一个人转动一个大砂轮：她把手放在砂轮的边缘，并在转过一圈的一部分的过程中施加一个力，如图 10.19 所示。在本例题中，我们验证她施加的力矩所做的功等于转动能量的变化。（a）如果她施加200 N 的力，使砂轮产生 $1.00\ \text{rad}\ (57.3^\circ)$ 的转角，要做多少功？该力在作用点处始终垂直于砂轮的0.320 m 半径，且摩擦力的影响可以忽略。（b）如果砂轮的质量为 85.0 kg，末角速度是多少？（c）末转动动能是多少？（它应当等于所做的功。）

思路

要求功，可以使用方程 $\text{合外力的功}\;\kW = (\text{合力矩}\;\ktau)\ktheta$。我们有足够的信息来计算力矩，并且已知转角。在第二问中，可以利用其中一个运动学关系求出末角速度。在最后一问中，可以根据 $\kKErot = \frac{1}{2}\kI\kw^2$ 中的表达式来计算转动动能。

（a）的解

合外力的功由下面的方程表示

$$\text{合外力的功}\;\kW = (\text{合力矩}\;\ktau)\ktheta,$$

其中合力矩 $\ktau$ 等于外加力乘以半径 $(\kr\kF)$，因为没有阻碍转动的摩擦力，并且力垂直于 $\kr$。角度 $\ktheta$ 已给出。把已知值代入上面的方程，得

$$\begin{aligned}\text{合外力的功}\;\kW &= \kr\kF\ktheta = (0.320\ \text{m})(200\ \text{N})(1.00\ \text{rad})\\ &= 64.0\ \text{N}\cdot\text{m.}\end{aligned}$$

注意到 $1\ \text{N}\cdot\text{m} = 1\ \text{J}$，

$$\text{合外力的功}\;\kW = 64.0\ \text{J}.$$

（b）的解

要由已知信息求出 $\kw$，需要不止一步。我们从下面方程中的运动学关系出发

$$\kw^2 = {\kwo}^2 + 2\kalpha\ktheta.$$

注意 $\kwo = 0$，因为我们从静止开始。对所得方程取平方根，得

$$\kw = (2\kalpha\ktheta)^{1/2}.$$

现在需要求出 $\kalpha$。一种可能的做法是

$$\kalpha = \frac{\text{合力矩}\;\ktau}{\kI},$$

其中力矩为

$$\text{合力矩}\;\ktau = \kr\kF = (0.320\ \text{m})(200\ \text{N}) = 64.0\ \text{N}\cdot\text{m}.$$

圆盘转动惯量的公式见图 10.12：

$$\kI = \frac{1}{2}\kM\kR^2 = 0.5(85.0\ \text{kg})(0.320\ \text{m})^2 = 4.352\ \text{kg}\cdot\text{m}^2.$$

把力矩和转动惯量的值代入 $\kalpha$ 的表达式，得

$$\kalpha = \frac{64.0\ \text{N}\cdot\text{m}}{4.352\ \text{kg}\cdot\text{m}^2} = 14.7\ \frac{\text{rad}}{\text{s}^2}.$$

现在，把这个值和 $\ktheta$ 的已知值代入上面 $\kw$ 的表达式：

$$\kw = (2\kalpha\ktheta)^{1/2} = \left[2\left(14.7\ \frac{\text{rad}}{\text{s}^2}\right)(1.00\ \text{rad})\right]^{1/2} = 5.42\ \frac{\text{rad}}{\text{s}}.$$

（c）的解

末转动动能为

$$\kKErot = \frac{1}{2}\kI\kw^2.$$

$\kI$ 和 $\kw$ 都已在上面求出。因此，

$$\kKErot = (0.5)(4.352\ \text{kg}\cdot\text{m}^2)(5.42\ \text{rad/s})^2 = 64.0\ \text{J}.$$

讨论

末转动动能等于力矩所做的功，这证实了所做的功变成了转动动能。事实上，我们本可以用能量的表达式代替运动学关系来求解（b）问。我们将在后面的例题中这样做。

直升机桨叶中的能量

直升机飞行员对转动动能相当熟悉。例如，他们知道，如果在飞行中让桨叶慢到低于某个临界角速度，就会到达无法挽回的地步。桨叶会失去升力，而要让桨叶立刻转得足够快以重新获得升力是不可能的。必须向桨叶输入转动动能才能使它们转得更快，而在避免坠毁所要求的时间内，无法提供足够的能量。由于重量的限制，直升机的发动机太小，无法既提供升力所需的能量，又在桨叶慢下来之后补充桨叶的转动动能。转动动能是在起飞前输入桨叶的，而且不得让它降到这个关键水平以下。避免坠毁的一种可能办法是，利用直升机的重力势能来补充桨叶的转动动能：降低高度，并调整桨叶的方位，使直升机在下降中被带动旋转起来。当然，如果直升机的高度太低，那么在到达地面之前，桨叶就没有足够的时间重新获得升力。

转动能的解题策略
  1. 确定转动过程中涉及能量或功。
  2. 确定所研究的系统。画一张草图通常有帮助。
  3. 分析情形，确定所涉及的功和能量的类型。
  4. 对于封闭系统，机械能守恒。也就是说，$\kKEi + \kPEi = \kKEf + \kPEf.$ 注意，$\kKEi$ 和 $\kKEf$ 各自都可能包含平动和转动的贡献。
  5. 对于开放系统，机械能可能不守恒，其他形式的能量（前面称为 $\kOE$），例如热传递，可能进入或离开系统。确定它们是什么，并按需要计算它们。
  6. 尽可能消去各项，以简化代数运算。
  7. 检查答案是否合理。

例题 10.9 · 计算直升机的各种能量

一架典型的小型救援直升机，类似图 10.20 中的那架，有四片桨叶，每片长 4.00 m，质量为 50.0 kg。桨叶可以近似看作绕一端、垂直于其长度的转轴转动的细杆。该直升机的满载总质量为 1000 kg。（a）当桨叶以300 转每分转动时，求它们具有的转动动能。（b）当直升机以20.0 m/s 飞行时，计算它的平动动能，并将其与桨叶中的转动能量作比较。（c）如果全部转动动能都能用来提升直升机，则它可被升高到多大的高度？

思路

转动和平动动能可以根据它们的定义计算。最后一问涉及这样一个观念：能量可以改变形式，在这里是由转动动能变为重力势能。

（a）的解

转动动能为

$$\kKErot = \frac{1}{2}\kI\kw^2.$$

在求 $\kKErot$ 之前，我们必须把角速度换算为弧度每秒，并计算转动惯量。角速度 $\kw$ 为

$$\kw = \frac{300\ \text{rev}}{1.00\ \text{min}}\cdot\frac{2\pi\ \text{rad}}{1\ \text{rev}}\cdot\frac{1.00\ \text{min}}{60.0\ \text{s}} = 31.4\ \frac{\text{rad}}{\text{s}}.$$

一片桨叶的转动惯量就是绕端点转动的细杆的转动惯量，见图 10.12。总的 $\kI$ 是这个转动惯量的四倍，因为共有四片桨叶。因此，

$$\kI = 4\frac{\kM\ell^2}{3} = 4\times\frac{(50.0\ \text{kg})(4.00\ \text{m})^2}{3} = 1067\ \text{kg}\cdot\text{m}^2.$$

把 $\kw$ 和 $\kI$ 代入转动动能的表达式，得

$$\begin{aligned}\kKErot &= 0.5(1067\ \text{kg}\cdot\text{m}^2)(31.4\ \text{rad/s})^2\\ &= 5.26\times 10^5\ \text{J}\end{aligned}$$

（b）的解

平动动能已在“匀速圆周运动与引力”中定义。代入质量和速度的已知值，得

$$\kKEtrans = \frac{1}{2}\km\kv^2 = (0.5)(1000\ \text{kg})(20.0\ \text{m/s})^2 = 2.00\times 10^5\ \text{J}.$$

为了比较动能，我们取平动动能与转动动能之比。这个比值为

$$\frac{2.00\times 10^5\ \text{J}}{5.26\times 10^5\ \text{J}} = 0.380.$$

（c）的解

在最大高度处，全部转动动能都已转化为重力势能。要求出这个高度，我们令这两种能量相等：

$$\kKErot = \kPEgrav$$

即

$$\frac{1}{2}\kI\kw^2 = \km\kg\kh.$$

现在解出 $\kh$，并把已知值代入所得方程

$$\kh = \frac{\frac{1}{2}\kI\kw^2}{\km\kg} = \frac{5.26\times 10^5\ \text{J}}{(1000\ \text{kg})(9.80\ \text{m/s}^2)} = 53.7\ \text{m}.$$

讨论

平动能量与转动动能之比仅为 0.380。这个比值告诉我们，直升机的大部分动能都在它的旋转桨叶中——这很可能是你想不到的。利用转动动能可将直升机升高的53.7 m 高度同样令人印象深刻，再次强调了桨叶中转动动能的数量之多。

建立联系

能量守恒也包括转动，因为转动动能是 $\kKE$ 的另一种形式。“匀速圆周运动与引力”对能量守恒有详细的论述。

汤有多浓？或者说，为什么并非所有物体都以同样的快慢滚下斜坡？

番茄汤工厂的质量控制之一，就是让装满的罐头沿一个斜坡滚下。如果它们滚得太快，汤就太稀。为什么大小和质量都相同的罐头沿斜面滚下的快慢会不同？为什么最浓的汤滚得最慢？

回答这些问题最简单的办法是考虑能量。假设每只罐头都从静止开始沿斜坡滚下。每只罐头从静止开始，意味着每只起初都具有相同的重力势能 $\kPEgrav$，只要每只都是纯滚动，这份重力势能就完全转化为 $\kKE$。然而，$\kKE$ 可以取 $\kKEtrans$ 或 $\kKErot$ 的形式，总的 $\kKE$ 是二者之和。如果罐头沿斜坡滚下，它就会把一部分能量用于转动，留给平动的就少了。因此，罐头比它滑下来时要慢。此外，稀汤不转动，而浓汤则会转动，因为它黏在罐头上。因此，浓汤比稀汤把更多的罐头的原有重力势能用于转动，所以罐头滚得更慢，如图 10.21 所示。

假设没有摩擦力造成的损失，则做功的力只有一个——重力。因此所做的总功就是动能的变化。罐头开始运动时，势能正在转变为动能。

所以，起初的 $\km\kg\kh$ 在平动动能和转动动能之间分配；$\kI$ 越大，用于平动的能量就越少。如果罐头无摩擦地滑下，则 $\kw = 0$，所有能量都用于平动；因此罐头滑得更快。

居家实验

找几只罐头，每只装有不同种类的食物。首先，预测哪只罐头会在沿斜面滚下的竞赛中获胜，并解释原因。看看你的预测是否正确。你也可以这样做这个实验：收集几个大小相同的空圆柱形容器，用湿沙或干沙等不同的材料把它们装满。
