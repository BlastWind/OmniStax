电感器与感抗

许多电路除了电阻器和交流电压源之外，还含有电容器和电感器。我们已经看到，在直流电压接通和断开时，电容器和电感器是如何响应的。现在我们来探讨电感器和电容器对正弦交流电压如何反应。

假设一个电感器直接接到一个交流电压源上，如图 23.43 所示。可以合理地假设电阻可忽略，因为在实际中，我们可以把电感器的电阻做得很小，使它对电路的影响可以忽略不计。图中还画出了电压和电流随时间变化的图像。

图 23.43（b）中的图像从电压的最大值开始。请注意，电流从零开始，在驱动它的电压之后才升到峰值，这与上一节中直流电压接通时的情形一样。当电压在 a 点变为负值时，电流开始减小；它在 b 点变为零，此时电压负得最多。随后电流变为负值，又一次跟随电压。电压在 c 点变为正值，开始使电流的负值变小。在 d 点，电流经过零，而此时电压恰好达到正的峰值，开始又一个周期。这一行为概括如下：

电感器中的交流电压

当正弦电压加在电感器上时，电压超前电流四分之一个周期，即超前 $90^\circ$ 的相位角。

电流滞后于电压，因为电感器阻碍电流的变化。变化的电流会感应出反电动势 $\kV = -\kLind(\kdIcur/\kdt)$。这被视为电感器对交流的有效电阻。通过电感器 $\kLind$ 的方均根电流 $\kIcur$ 由欧姆定律的一种形式给出：

$$\kIcur = \frac{\kV}{\kXL}\text{,}$$

其中 $\kV$ 是电感器两端的方均根电压，$\kXL$ 定义为

$$\kXL = 2\pi \kf\kLind\text{,}$$

式中 $\kf$ 是交流电压源的频率，单位为赫兹（用基尔霍夫回路定则和微积分对电路进行分析，确实可以得出这一表达式）。$\kXL$ 称为感抗，因为电感器会做出反应（react）以阻碍电流。$\kXL$ 的单位是欧姆（$1\ \text{H} = 1\ \Omega\cdot\text{s}$，所以频率乘以电感的单位是 $(\text{周期/s})(\Omega\cdot\text{s}) = \Omega$），这与它作为有效电阻的作用相一致。$\kXL$ 与 $\kLind$ 成正比是合理的，因为感应越大，它对变化的阻碍就越大。$\kXL$ 与频率 $\kf$ 成正比也是合理的，因为频率越高，意味着电流的变化越大。也就是说，对于大的频率，$\kdIcur/\kdt$ 很大（$\kf$ 大，$\kdt$ 小）。变化越大，电感器的阻碍就越大。

例题 23.10 · 先计算感抗，再计算电流

（a）当加上 60.0 Hz 和 10.0 kHz 的交流电压时，计算一个 3.00 mH 的电感器的感抗。（b）若所加的方均根电压为 120 V，则每个频率下的方均根电流是多少？

思路

感抗可直接由表达式 $\kXL = 2\pi \kf\kLind$ 求出。求出每个频率下的 $\kXL$ 后，就可以用式 $\kIcur = \kV/\kXL$ 所表述的欧姆定律，求出每个频率下的电流。

（a）的解

把频率和电感代入式 $\kXL = 2\pi \kf\kLind$，得

$$\kXL = 2\pi \kf\kLind = 6.28(60.0/\text{s})(3.00\ \text{mH}) = 1.13\ \Omega\ \text{(60 Hz 时)}.$$

同样，在 10 kHz 时，

$$\kXL = 2\pi \kf\kLind = 6.28(1.00\times {10}^{4}/\text{s})(3.00\ \text{mH}) = 188\ \Omega\ \text{(10 kHz 时)}.$$

（b）的解

已知所加的方均根电压为 120 V，现在用式 $\kIcur = \kV/\kXL$ 中欧姆定律的形式求方均根电流。对于第一个频率，得

$$\kIcur = \frac{\kV}{\kXL} = \frac{120\ \text{V}}{1.13\ \Omega} = 106\ \text{A (60 Hz 时)}.$$

同样，在 10 kHz 时，

$$\kIcur = \frac{\kV}{\kXL} = \frac{120\ \text{V}}{188\ \Omega} = 0.637\ \text{A (10 kHz 时)}.$$

讨论

电感器在两个不同的频率下的反应截然不同。在较高的频率下，它的电抗很大，电流很小，这与电感器阻碍快速变化的方式相一致。因此高频率受到的阻碍最大。电感器可用来滤除高频率；例如，可以把一个大电感器串联到声音重放系统中，或串联到你的家用计算机上，以减少扬声器输出的高频声音，或减少进入计算机的高频功率尖峰。

请注意，虽然所考虑的电路中的电阻可以忽略，但交流电流并不会极大，因为感抗阻碍了它的流动。对于交流，电流没有时间变得极大。

电容器与容抗

考虑电容器直接接到一个交流电压源上，如图 23.44 所示。这样一个电路的电阻可以做得很小，以致与电容器相比，它的影响可以忽略，因此我们可以假设电阻可忽略。图中画出了电容器两端的电压和电流随时间变化的图像。

图 23.44 中的图像从电容器两端的电压取最大值开始。此时电流为零，因为电容器已充满电，阻止了电流的流动。随后电压下降，电容器放电，电流变为负值。在 a 点，电容器已完全放电（其上 $\kQch = 0$），它两端的电压为零。在 a 点和 b 点之间，电流保持为负，使电容器上的电压反向。这一过程在 b 点完成，此时电流为零，而电压取其负得最多的值。过了 b 点，电流变为正值，中和电容器上的电荷，并使电压在 c 点降为零，这使得电流达到最大值。在 c 点和 d 点之间，电压升到峰值，电流降为零，然后这一过程开始重复。在整个周期中，电压都比电流的变化滞后四分之一个周期：

电容器中的交流电压

当正弦电压加在电容器上时，电压滞后于电流四分之一个周期，即滞后 $90^\circ$ 的相位角。

电容器在影响电流，它在充满电时甚至能完全阻止电流。由于所加的是交流电压，所以存在方均根电流，但它受到电容器的限制。这被视为电容器对交流的有效电阻，因此仅含电容器 $\kCap$ 的电路中的方均根电流 $\kIcur$ 由欧姆定律的另一种形式给出：

$$\kIcur = \frac{\kV}{\kXC}\text{,}$$

其中 $\kV$ 是方均根电压，$\kXC$ 定义（与 $\kXL$ 一样，$\kXC$ 的这一表达式是用基尔霍夫定律和微积分分析电路得到的）为

$$\kXC = \frac{1}{2\pi \kf\kCap}\text{,}$$

其中 $\kXC$ 称为容抗，因为电容器会做出反应（react）以阻碍电流。$\kXC$ 的单位是欧姆（验证留给读者作为练习）。$\kXC$ 与电容 $\kCap$ 成反比；电容器越大，能储存的电荷越多，能流动的电流也越大。它也与频率 $\kf$ 成反比；频率越高，给电容器充满电的时间就越少，因此它对电流的阻碍就越小。

例题 23.11 · 先计算容抗，再计算电流

（a）当加上 60.0 Hz 和 10.0 kHz 的交流电压时，计算一个 5.00 µF 的电容器的容抗。（b）若所加的方均根电压为 120 V，则方均根电流是多少？

思路

容抗可直接由表达式 $\kXC = \frac{1}{2\pi \kf\kCap}$ 求出。求出每个频率下的 $\kXC$ 后，就可以用 $\kIcur = \kV/\kXC$ 所表述的欧姆定律，求出每个频率下的电流。

（a）的解

把频率和电容代入 $\kXC = \frac{1}{2\pi \kf\kCap}$，得

$$\begin{array}{lll}\kXC & = & \frac{1}{2\pi \kf\kCap} \\ & = & \frac{1}{6.28(60.0/\text{s})(5.00\ \mu\text{F})} = 531\ \Omega\ \text{(60 Hz 时)}\text{.}\end{array}$$

同样，在 10 kHz 时，

$$\begin{array}{lll}\kXC & = & \frac{1}{2\pi \kf\kCap} = \frac{1}{6.28(1.00\times {10}^{4}/\text{s})(5.00\ \mu\text{F})} \\ & = & 3.18\ \Omega\ \text{(10 kHz 时)}\end{array}\text{.}$$

（b）的解

已知所加的方均根电压为 120 V，现在用 $\kIcur = \kV/\kXC$ 中欧姆定律的形式求方均根电流。对于第一个频率，得

$$\kIcur = \frac{\kV}{\kXC} = \frac{120\ \text{V}}{531\ \Omega} = 0.226\ \text{A (60 Hz 时)}.$$

同样，在 10 kHz 时，

$$\kIcur = \frac{\kV}{\kXC} = \frac{120\ \text{V}}{3.18\ \Omega} = 37.7\ \text{A (10 kHz 时)}.$$

讨论

电容器在两个不同的频率下的反应截然不同，而且与电感器的反应恰好相反。在较高的频率下，它的电抗很小，电流很大。电容器顺应变化，而电感器阻碍变化。电容器对低频率的阻碍最大，因为低频率使它们有时间被充电并截断电流。电容器可用来滤除低频率。例如，把一个电容器串联到声音重放系统中，就能消除其中 60 Hz 的交流声。

虽然电容器基本上是开路，但在对电容器加上交流电压的电路中，存在方均根电流。这是因为电压不断反向，使电容器不断充电和放电。如果频率趋于零（直流），$\kXC$ 趋于无穷大，一旦电容器充满电，电流即为零。在很高的频率下，电容器的电抗趋于零——它的电抗可以忽略，不阻碍电流（它的作用就像一根普通导线）。电容器对交流电路的作用与电感器的作用相反。
