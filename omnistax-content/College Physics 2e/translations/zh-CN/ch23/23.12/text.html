阻抗

单独处于交流电路中时，电感器、电容器和电阻器都会阻碍电流。三者同时出现时，它们的表现如何？有意思的是，它们各自以欧姆为单位的电阻并不是简单相加。由于电感器和电容器的表现方式相反，它们会部分乃至完全抵消彼此的效应。图 23.46 画出了一个带有一个交流电压源的 RLC 串联电路，它的表现就是本节的主题。分析 RLC 电路的关键，是 $\kXL$ 和 $\kXC$ 对频率的依赖，以及它们对电压与电流之间相位的影响（上一节已经建立）。这些使电路的表现依赖于频率，并带来重要的“共振”特征，它们是许多应用的基础，例如收音机调谐器。

电阻 $\kRes$、感抗 $\kXL$ 和容抗 $\kXC$ 的合成效应被定义为阻抗，它是直流电路中电阻的交流对应量。RLC 电路中的电流、电压和阻抗通过欧姆定律的交流形式相联系：

$$\kIocur = \frac{\kVo}{\kZimp}\;\text{或}\;\kIrms = \frac{\kVrms}{\kZimp}\text{.}$$

这里 $\kIocur$ 是峰值电流，$\kVo$ 是电源的峰值电压，$\kZimp$ 是电路的阻抗。阻抗的单位是欧姆，它对电路的影响正如你所预料的：阻抗越大，电流越小。为了得到用 $\kRes$、$\kXL$ 和 $\kXC$ 表示 $\kZimp$ 的表达式，我们现在来考察各个元件两端的电压与电源电压是怎样联系的。这些电压在图 23.46 中标记为 $\kVR$、$\kVL$ 和 $\kVC$。

电荷守恒要求电流在任何时刻在电路的各部分都相同，因此可以说 $\kRes$、$\kLind$ 和 $\kCap$ 中的电流相等且同相。但我们从上一节知道，电感器两端的电压 $\kVL$ 超前电流四分之一周期，电容器两端的电压 $\kVC$ 滞后电流四分之一周期，而电阻器两端的电压 $\kVR$ 与电流恰好同相。图 23.47 在一幅图中表示了这些关系，也表示了绕电路一周的总电压 $\kV = \kVR + \kVL + \kVC$，其中四个电压都是瞬时值。根据基尔霍夫回路定则，绕电路一周的总电压 $\kV$ 也就是电源的电压。

从图 23.47 可以看出，$\kVR$ 与电流同相，$\kVL$ 超前 $90^\circ$，$\kVC$ 滞后 $90^\circ$。因此 $\kVL$ 和 $\kVC$ 相差 $180^\circ$（波峰对波谷），倾向于相互抵消，不过除非二者有相同的大小，否则不会完全抵消。由于各峰值电压没有对齐（不同相），电源的峰值电压 $\kVo$ 不等于 $\kRes$、$\kLind$ 和 $\kCap$ 两端峰值电压之和。

这就是 RLC 串联交流电路的阻抗。对于没有电阻器的电路，取 $\kRes = 0$；对于没有电感器的电路，取 $\kXL = 0$；对于没有电容器的电路，取 $\kXC = 0$。

例题 23.12 · 计算阻抗和电流

一个 RLC 串联电路有一个 $40.0\;\Omega$ 的电阻器、一个 3.00 mH 的电感器和一个 $5.00\;\mu\text{F}$ 的电容器。（a）求电路的阻抗，频率为 60.0 Hz 和 10.0 kHz，注意这两个频率以及 $\kLind$ 和 $\kCap$ 的值，与“电抗：感抗与容抗”中的两个例题相同。（b）如果电压源的 $\kVrms = 120\;\text{V}$，在每个频率上 $\kIrms$ 是多少？

思路

对于每个频率，我们用 $\kZimp = \sqrt{\kRes^{2} + (\kXL - \kXC)^{2}}$ 求出阻抗，再用欧姆定律求电流。我们可以利用前两个例题的结果，而不必重新计算电抗。

（a）的解

在 60.0 Hz 时，在“电抗：感抗与容抗”中求得电抗的值为 $\kXL = 1.13\;\Omega$ 和 $\kXC = 531\;\Omega$。把它们和作为电阻的已知值 $40.0\;\Omega$ 代入 $\kZimp = \sqrt{\kRes^{2} + (\kXL - \kXC)^{2}}$，得到

$$\begin{array}{lll}\kZimp & = & \sqrt{\kRes^{2} + (\kXL - \kXC)^{2}} \\ & = & \sqrt{(40.0\;\Omega)^{2} + (1.13\;\Omega - 531\;\Omega)^{2}} \\ & = & 531\;\Omega\;\text{在 60.0 Hz 时.}\end{array}$$

同样，在 10.0 kHz 时，$\kXL = 188\;\Omega$，$\kXC = 3.18\;\Omega$，所以

$$\begin{array}{lll}\kZimp & = & \sqrt{(40.0\;\Omega)^{2} + (188\;\Omega - 3.18\;\Omega)^{2}} \\ & = & 190\;\Omega\;\text{在 10.0 kHz 时.}\end{array}$$

（a）的讨论

两种情况下，结果都与较大的那个值几乎相同，而且阻抗显然不是各个值之和。很明显，在高频率下 $\kXL$ 起主导作用，在低频率下 $\kXC$ 起主导作用。

（b）的解

电流 $\kIrms$ 可以用方程 $\kIrms = \kVrms/\kZimp$ 中欧姆定律的交流形式求得：

$\kIrms = \frac{\kVrms}{\kZimp} = \frac{120\;\text{V}}{531\;\Omega} = 0.226\;\text{A}$，60.0 Hz 时

最后，在 10.0 kHz 时，我们求得

$\kIrms = \frac{\kVrms}{\kZimp} = \frac{120\;\text{V}}{190\;\Omega} = 0.633\;\text{A}$，10.0 kHz 时

（b）的讨论

60.0 Hz 时的电流，与在“电抗：感抗与容抗”中单独只有电容器时求得的相同（精确到三位数字）。在低频率下，电容器起主导作用。10.0 kHz 时的电流，与单独只有电感器时求得的只有微小差别。在高频率下，电感器起主导作用。

RLC 串联交流电路中的共振

RLC 电路的表现与驱动它的电压源的频率有什么函数关系？把欧姆定律 $\kIrms = \kVrms/\kZimp$ 与由 $\kZimp = \sqrt{\kRes^{2} + (\kXL - \kXC)^{2}}$ 给出的阻抗 $\kZimp$ 的表达式结合起来，得到

$$\kIrms = \frac{\kVrms}{\sqrt{\kRes^{2} + (\kXL - \kXC)^{2}}}\text{.}$$

电抗随频率变化，$\kXL$ 在高频率下大，$\kXC$ 在低频率下大，这一点我们在前面三个例题中已经看到。在某个中间频率 $\kfo$ 处，两个电抗相等并相互抵消，得到 $\kZimp = \kRes$——这是阻抗的最小值，因而 $\kIrms$ 取得最大值。

这里 $\kfo$ 是 RLC 串联电路的共振频率。它也是电路不受电压源驱动时会振荡的固有频率。在 $\kfo$ 处，电感器和电容器的效应相互抵消，因而 $\kZimp = \kRes$，$\kIrms$ 最大。

交流电路中的共振类似于机械共振，共振被定义为以系统的固有频率发生的受迫振动——在这里是由电压源驱动的。收音机中的接收器是一个 RLC 电路，它在 $\kfo$ 处振荡得最好。常用一个可变电容器来调节 $\kfo$，以接收想要的频率而排除其他频率。图 23.48 是电流随频率变化的图线，表明 $\kIrms$ 在 $\kfo$ 处有一个共振峰。这两条曲线对应两个不同的电路，它们只在所含电阻的大小上有所不同。电阻较大的电路，其峰更低也更宽。因此电阻较大的电路不会那样强烈地共振，例如在收音机接收器中，它的选择性就不会那么好。

例题 23.13 · 计算共振频率和电流

仍是那个 RLC 串联电路，有一个 $40.0\;\Omega$ 的电阻器、一个 3.00 mH 的电感器和一个 $5.00\;\mu\text{F}$ 的电容器：（a）求共振频率。（b）如果 $\kVrms$ 为 120 V，计算共振时的 $\kIrms$。

思路

共振频率用 $\kfo = \frac{1}{2\pi\sqrt{\kLind\kCap}}$ 中的表达式求得。该频率下的电流，与电路中只有电阻器时相同。

（a）的解

把 $\kLind$ 和 $\kCap$ 的已知值代入 $\kfo = \frac{1}{2\pi\sqrt{\kLind\kCap}}$ 中给出的 $\kfo$ 的表达式，得到

$$\begin{array}{lll}\kfo & = & \frac{1}{2\pi\sqrt{\kLind\kCap}} \\ & = & \frac{1}{2\pi\sqrt{(3.00\times {10}^{-3}\;\text{H})(5.00\times {10}^{-6}\;\text{F})}} = 1.30\;\text{kHz.}\end{array}$$

（a）的讨论

我们看到，共振频率介于 60.0 Hz 和 10.0 kHz 之间，这是前面例题中选用的两个频率。这是可以预料的，因为在低频率下电容器起主导作用，在高频率下电感器起主导作用。在这个中间频率下，二者的效应相同。

（b）的解

电流由欧姆定律给出。在共振时，两个电抗相等并抵消，所以阻抗等于单独的电阻。因此，

$$\kIrms = \frac{\kVrms}{\kZimp} = \frac{120\;\text{V}}{40.0\;\Omega} = 3.00\;\text{A.}$$

（b）的讨论

在共振时，电流大于上一个例题中对同一电路考虑的较高和较低频率下的电流。

RLC 串联交流电路中的功率

如果 RLC 电路中的电流随频率变化，那么输送给它的功率也随频率变化。但是平均功率并不像在纯电阻电路中那样，简单地等于电流乘以电压。正如图 23.47 所示，在 RLC 电路中电压和电流不同相。电源电压 $\kV$ 与电流 $\kIcur$ 之间有一个相位角 $\kphi$，可由下式求得

$$\cos\;\kphi = \frac{\kRes}{\kZimp}\text{.}$$

例如，在共振频率处，或在纯电阻电路中，$\kZimp = \kRes$，所以 $\cos\;\kphi = 1$。这意味着 $\kphi = 0^\circ$，电压和电流同相，正如电阻器所预期的那样。在其他频率下，平均功率比共振时小。这既是因为电压和电流不同相，也是因为 $\kIrms$ 较小。电源电压和电流不同相这一事实，影响输送给电路的功率。可以证明，平均功率为

$$\kPave = \kIrms\kVrms\cos\;\kphi,$$

因此 $\cos\;\kphi$ 称为功率因数，它的取值范围为 0 到 1。例如，在设计高效的电动机时，希望功率因数接近 1。在共振频率处，$\cos\;\kphi = 1$。

例题 23.14 · 计算功率因数和功率

仍是那个 RLC 串联电路，有一个 $40.0\;\Omega$ 的电阻器、一个 3.00 mH 的电感器、一个 $5.00\;\mu\text{F}$ 的电容器，以及一个 $\kVrms$ 为 120 V 的电压源：（a）计算 $\kf = 60.0\;\text{Hz}$ 时的功率因数和相位角。（b）60.0 Hz 时的平均功率是多少？（c）求电路共振频率下的平均功率。

（a）的思路与解

60.0 Hz 时的功率因数由下式求得

$$\cos\;\kphi = \frac{\kRes}{\kZimp}\text{.}$$

由例题 23.12 知 $\kZimp = 531\;\Omega$，所以

$$\cos\;\kphi = \frac{40.0\;\Omega}{531\;\Omega} = 0.0753\;\text{在 60.0 Hz 时.}$$

这个很小的值表明，电压和电流明显不同相。实际上，相位角为

$$\kphi = \cos^{-1}\;0.0753 = 85.7^\circ\;\text{在 60.0 Hz 时.}$$

（a）的讨论

相位角接近 $90^\circ$，这与在这个低频率下电容器在电路中起主导作用相一致（纯 RC 电路的电压和电流相差 $90^\circ$）。

（b）的思路与解

60.0 Hz 时的平均功率为

$$\kPave = \kIrms\kVrms\cos\;\kphi.$$

在例题 23.12 中求得 $\kIrms$ 为 0.226 A。代入已知值，得到

$$\kPave = (0.226\;\text{A})(120\;\text{V})(0.0753) = 2.04\;\text{W 在 60.0 Hz 时.}$$

（c）的思路与解

在共振频率处，我们知道 $\cos\;\kphi = 1$，并且在例题 23.13 中求得 $\kIrms$ 为 3.00 A。因此，

$\kPave = (3.00\;\text{A})(120\;\text{V})(1) = 360\;\text{W}$，共振时（1.30 kHz）

讨论

电流和功率因数在共振时都更大，产生的功率也就明显大于较高和较低频率时的功率。

输送给 RLC 串联交流电路的功率，只由电阻耗散。电感器和电容器有能量输入和输出，但并不把它耗散到电路之外。相反，它们在彼此之间来回传递能量，而电阻器恰好耗散掉电压源输入电路的那部分。这里假定电感器和电容器没有明显的电磁辐射，例如无线电波。这样的辐射是可以发生的，甚至可能是人们想要的，我们将在下一章关于电磁辐射的内容中看到，但它也可以被抑制，本章就是如此。这个电路类似于汽车的车轮驶过搓板状路面，如图 23.49 所示。路面上等间距的颠簸类似于电压源，驱动车轮上下运动。减震器类似于电阻，起阻尼作用并限制振动的振幅。系统内的能量在动能（类似于最大电流，以及储存在电感器中的能量）和储存在汽车弹簧中的势能（类似于无电流，以及储存在电容器的电场中的能量）之间来回转换。如果在共振频率下碰上路面的颠簸，车轮的运动振幅就最大。

电阻可以忽略的纯 LC 电路在 $\kfo$ 处振荡，这与 RLC 电路的共振频率相同。它可以用作频率标准或时钟电路——例如，用在数字手表中。电阻很小时，只需要很小的能量输入就能维持振荡。这个电路类似于一辆没有减震器的汽车。一旦开始振动，它就会以其固有频率持续一段时间。图 23.50 表示了 LC 电路与弹簧上质量块之间的类比。
