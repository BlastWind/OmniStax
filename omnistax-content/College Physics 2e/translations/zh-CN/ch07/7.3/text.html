克服重力所做的功

爬楼梯和举起物体，无论从科学意义上还是日常意义上说，都是功——它是克服重力所做的功。有功，就有能量的转化。克服重力所做的功变成了一种重要的储存能量的形式，我们将在本节中探讨它。

我们来计算在地球表面附近将质量为 $\km$ 的物体举起高度 $\kh$（如图 7.5 所示）所做的功。如果物体以恒定速率竖直向上举起，那么举起它所需的力等于它的重力 $\km\kg$。于是对该质量所做的功为 $\kW = \kF\kd = \km\kg\kh$。我们把它定义为放入物体-地球系统（或由该系统获得）的重力势能 $(\kPEg)$。这种能量与通过引力相互吸引的两个物体之间的分离状态有关。为方便起见，我们把它称为物体所获得的 $\kPEg$，同时认识到这是储存在地球引力场中的能量。我们为什么要用“系统”这个词？势能是系统而不是单个物体的性质——这是由其物理位置所决定的。物体的重力势能取决于它在地球-物体系统内相对于周围环境的位置。施加在物体上的力是外力，来自系统之外。当它做正功时，就增加了系统的重力势能。由于重力势能取决于相对位置，我们需要一个参考平面，在该平面上把势能设为 0。我们通常选取地球表面作为这一点，但这一点是任意的；重要的是重力势能的差，因为这个差与所做的功有关。物体（在地球-物体系统中）在梯子的两个梯级之间的重力势能之差，对最下面两级和最上面两级是相同的。

势能与动能的相互转化

重力势能可以转化为其他形式的能量，例如动能。如果我们释放该质量，重力就会对它做等于 $\km\kg\kh$ 的功，从而使它的动能增加同样的量（根据动能定理）。我们会发现，只考虑 $\kPEg$ 向 $\kKE$ 的转化，而不明确考虑功这一中间步骤，会更有用。（见例题 7.7。）这条捷径使得用能量（如果可能的话）而不是明确地用力来解题更加容易。

更准确地说，我们把重力势能的变化量 $\kdPEg$ 定义为

$$\kdPEg = \km\kg\kh,$$

其中，为简便起见，我们用 $\kh$ 而不是通常的 $\Delta \kh$ 表示高度的变化量。注意，当末高度大于初高度时 $\kh$ 为正，反之亦然。例如，如果把挂在布谷鸟钟上的 0.500 kg 重物举起 1.00 m，那么它的重力势能变化量为

$$\begin{aligned} \km\kg\kh &= (0.500\ \text{kg})(9.80\ \text{m/s}^2)(1.00\ \text{m})\\ &= 4.90\ \text{kg}\cdot\text{m}^2\text{/s}^2 = 4.90\ \text{J.}\end{aligned}$$

注意，重力势能的单位结果是焦耳，与功和其他形式的能量相同。钟走动时，重物被放低。我们可以认为重物在逐渐放出它的 4.90 J 重力势能，而不必直接考虑做功的重力。

用势能简化计算

方程 $\kdPEg = \km\kg\kh$ 适用于任何高度变化为 $\kh$ 的路径，而不只是质量被竖直向上举起的情形，只要 $\kh$ 与地球半径相比很小。注意，正如我们在“匀速圆周运动与引力”中所学到的，地球重力确实随着离地球的距离增大而减小。对于距离的微小变化，这一变化可以忽略，但如果你想在涉及前往月球甚至更远处的问题中使用势能，就必须考虑牛顿万有引力定律。这种更完整的处理超出了本教材的范围，对于我们在这里考虑的问题也并非必要。（见图 7.6。）计算 $\km\kg\kh$（一个简单的乘法）比计算沿复杂路径所做的功要容易得多。重力势能这一概念有双重好处：它的适用范围非常广，而且使计算更容易。从现在起，我们将认为，质量 $\km$ 的竖直位置的任何变化 $\kh$ 都伴随着重力势能的变化 $\km\kg\kh$，并且我们将避免去做那件等价但更困难的任务：计算功，无论是由重力所做的，还是克服它所做的。

使下落停止的力

例题 7.6 · 使人停止下落所需的力

一个 60.0 kg 的人从 3.00 m 的高度跳到地板上。如果他僵直着地（他的膝关节压缩 0.500 cm），求膝关节所受的力。

思路

这个人的能量在这种情形中被降为零，靠的是地板在他停下时对他所做的功。初始的 $\kPEg$ 在他下落时转化为 $\kKE$。地板所做的功使这份动能降为零。

解

地板在他停下时对这个人所做的功由下式给出

$$\kW = \kF\kd\cos\ktheta = -\kF\kd,$$

带负号，是因为停下过程中的位移与地板所施的力的方向相反 $(\cos\ktheta = \cos 180^\circ = -1)$。地板从系统中带走能量，所以它做负功。

这个人到达地板时具有的动能，等于下落高度 $\kh$ 所损失的势能的量：

$$\kKE = -\kdPEg = -\km\kg\kh,$$

这个人的膝盖弯曲的距离 $\kd$ 远小于下落的高度 $\kh$，所以膝盖弯曲期间额外的重力势能变化被忽略。

地板对这个人所做的功 $\kW$ 使这个人停下，并使这个人的动能降为零：

$$\kW = -\kKE = \km\kg\kh.$$

把这个方程与 $\kW$ 的表达式合并，得到

$$-\kF\kd = \km\kg\kh.$$

回想 $\kh$ 为负，因为这个人是向下落下的，膝关节所受的力为

$$\kF = -\frac{\km\kg\kh}{\kd} = -\frac{(60.0\ \text{kg})(9.80\ \text{m/s}^2)(-3.00\ \text{m})}{5.00\times 10^{-3}\ \text{m}} = 3.53\times 10^{5}\ \text{N}.$$

讨论

在很短的着地时间内，如此大的力（是这个人的重力的 500 倍）足以使骨折断。缓冲冲击的好得多的办法是弯曲双腿或在地上翻滚，从而延长力作用的时间。用这种方式作 0.5 m 的弯曲运动，得到的是比例题中小 100 倍的力。袋鼠的蹦跳显示了这种方法的实际运用。袋鼠是唯一用蹦跳来移动的大型动物，但蹦跳时的冲击被每次跳跃中后腿的弯曲所缓冲。（见图 7.7。）

由高度求速率

例题 7.7 · 由高度求过山车的速率

（a）图 7.8 所示的过山车的末速率是多少，如果它从 20.0 m 高的山坡顶由静止开始，且摩擦力所做的功可以忽略？（b）如果它的初速率为 5.00 m/s，它的末速率（同样假设摩擦力可忽略）是多少？

思路

过山车在它下山时失去势能。我们忽略摩擦力，于是轨道所施的其余力就是法向力，它垂直于运动的方向，不做功。于是，过山车所受的合外力的功完全由重力所做。向下移动距离 $\kh$ 所损失的重力势能等于动能的增加量。这可以写成方程的形式 $-\kdPEg = \kdKE$。利用 $\kPEg$ 和 $\kKE$ 的方程，我们可以解出末速率 $\kv$，这就是所要求的量。

（a）的解

这里初动能为零，所以 $\kdKE = \tfrac{1}{2}\km\kv^2$。势能变化的方程为 $\kdPEg = \km\kg\kh$。由于在这种情形下 $\kh$ 为负，我们把它改写成 $\kdPEg = -\km\kg|\kh|$，以清楚地显示负号。因此，

$$-\kdPEg = \kdKE$$

变为

$$\km\kg|\kh| = \tfrac{1}{2}\km\kv^2.$$

解出 $\kv$，我们发现质量被消去，并且

$$\kv = \sqrt{2\kg|\kh|}.$$

代入已知值，

$$\begin{aligned}\kv &= \sqrt{2(9.80\ \text{m/s}^2)(20.0\ \text{m})}\\ &= 19.8\ \text{m/s.}\end{aligned}$$

（b）的解

同样 $-\kdPEg = \kdKE$。在这种情形下存在初动能，所以 $\kdKE = \tfrac{1}{2}\km\kv^2 - \tfrac{1}{2}\km\kvo^2$。因此，

$$\km\kg|\kh| = \tfrac{1}{2}\km\kv^2 - \tfrac{1}{2}\km\kvo^2.$$

整理得

$$\tfrac{1}{2}\km\kv^2 = \km\kg|\kh| + \tfrac{1}{2}\km\kvo^2.$$

这意味着末动能是初动能与重力势能之和。质量再次被消去，并且

$$\kv = \sqrt{2\kg|\kh| + \kvo^2}.$$

这个方程与运动学方程 $\kv = \sqrt{\kvo^2 + 2\ka\kd}$ 非常相似，但它更为普遍——运动学方程只在加速度恒定时成立，而我们上面的方程对任何路径都成立，无论物体是否以恒定加速度运动。现在，代入已知值得到

$$\begin{aligned}\kv &= \sqrt{2(9.80\ \text{m/s}^2)(20.0\ \text{m}) + (5.00\ \text{m/s})^2}\\ &= 20.4\ \text{m/s.}\end{aligned}$$

讨论与推论

首先，注意到质量被消去。这与“落体”中所作的观察完全一致：如果摩擦力可以忽略，所有物体都以相同的快慢下落。其次，只考虑了过山车的速率；没有关于它在任何一点的方向的信息。这揭示了另一个普遍的真理。当摩擦力可以忽略时，下落物体的速率只取决于它的初速率和高度，而与它的质量或所经路径无关。例如，过山车将具有相同的末速率，无论它是竖直落下 20.0 m，还是沿着像图中那样更复杂的路径。第三，也许出乎意料的是，（b）部分的末速率比（a）部分的大，但增大的量远小于 5.00 m/s。最后，注意速率可以在沿途的任何高度求出，只需在所关心的点上使用适当的 $\kh$ 值。

我们已经看到，功（无论是由重力所做的，还是克服它所做的）只取决于起点和终点，而与二者之间的路径无关，这使我们能够定义重力势能这一起简化作用的概念。对其他少数几种力，我们也可以这样做，并且我们将看到，这会导出能量守恒定律的正式定义。
