热力学第一定律

如果我们关心热传递如何转化为做功，那么能量守恒原理就很重要。热力学第一定律把能量守恒原理应用于这样的系统：热传递和做功是能量传入和传出系统的方式。热力学第一定律指出，系统的内能变化等于传入系统的净热传递量减去系统所做的净功。用方程表示，热力学第一定律为

$$\kdEint = \kQh - \kW.$$

这里 $\kdEint$ 是系统内能 $\kEint$ 的变化。$\kQh$ 是传入系统的净热传递量——也就是说，$\kQh$ 是传入和传出系统的所有热传递之和。$\kW$ 是系统所做的净功——也就是说，$\kW$ 是系统所做的或外界对它所做的所有功之和。我们采用如下符号约定：若 $\kQh$ 为正，则有净热传递传入系统；若 $\kW$ 为正，则有系统所做的净功。所以，正的 $\kQh$ 为系统增加能量，正的 $\kW$ 则从系统取走能量。于是 $\kdEint = \kQh - \kW$。还要注意，如果传入系统的热传递多于所做的功，二者之差就作为内能储存起来。热机就是这方面的一个很好的例子——热传递传入热机，为的是让它们做功。（见图 15.3。）接下来我们将进一步考察 $\kQh$、$\kW$ 和 $\kdEint$。

建立联系：热力学定律与能量守恒定律

热力学第一定律实际上就是以在热力学中最有用的形式表述的能量守恒定律。第一定律给出了热传递、所做的功和系统内能变化之间的关系。

热量 $\kQh$ 与功 $\kW$

热传递（$\kQh$）和做功（$\kW$）是把能量带入系统或从其中取走能量的两种日常方式。这两个过程大不相同。热传递是一个有序程度较低的过程，由温差驱动。功是一个相当有序的过程，涉及一个宏观的力作用一段距离。然而，热量和功可以产生相同的结果。例如，二者都能使温度升高。热传递传入系统，例如太阳加热自行车轮胎里的空气时，可以使它的温度升高；对系统做功也可以，例如骑自行车者给轮胎打气时。温度升高一旦发生，就不可能分辨它是由热传递引起的，还是由做功引起的。这种不确定性是很重要的一点。热传递和功都是传递中的能量——二者都不以其本身的形式储存在系统中。然而，二者都能改变系统的内能 $\kEint$。内能是一种与热量或功都完全不同的能量形式。

内能 $\kEint$

我们可以用两种不同而又一致的方式来考虑系统的内能。第一种是原子和分子的观点，在原子和分子的尺度上考察系统。系统的内能 $\kEint$ 是其原子和分子的动能与势能之和。回想一下，动能加势能称为机械能。因此，内能就是原子和分子机械能之和。由于不可能追踪每一个原子和分子，我们必须处理平均值和分布。看待系统内能的第二种方式，是从它的宏观特征出发，这些特征与原子和分子的平均值非常相似。

从宏观上，我们把内能变化 $\kdEint$ 定义为由热力学第一定律给出的量：

$$\kdEint = \kQh - \kW.$$

许多详细的实验已经证实 $\kdEint = \kQh - \kW$，其中 $\kdEint$ 是系统中所有原子和分子的总动能与势能的变化。实验还确定，系统的内能 $\kEint$ 只取决于系统的状态，而与它如何达到该状态无关。更具体地说，发现 $\kEint$ 是少数几个宏观量（例如压强、体积和温度）的函数，与过去的历史无关，比如是否发生过热传递或做过功。这种独立性意味着，如果我们知道系统的状态，就可以根据少数几个宏观变量计算其内能 $\kEint$ 的变化。

建立联系：宏观与微观

在热力学中，我们在计算系统的行为时常常采用宏观图像，而原子和分子的图像则以平均值和分布为依据给出其背后的解释。本章后面的几节中我们还会再次看到这一点。例如，在熵这一主题中，计算将采用原子和分子的观点。

经由两条不同路径产生的同一内能变化

为了更好地理解该如何考虑系统的内能，我们来考察一个从状态 1 变到状态 2 的系统。无论系统是怎样到达这两个状态的，它在状态 1 时具有内能 $\kEintone$，在状态 2 时具有内能 $\kEinttwo$。所以内能变化 $\kdEint = \kEinttwo - \kEintone$ 与引起这一变化的原因无关。换句话说，$\kdEint$ 与路径无关。所谓路径，指的是从起点到终点的方式。为什么这种独立性很重要？注意 $\kdEint = \kQh - \kW$。$\kQh$ 和 $\kW$ 都依赖于路径，但 $\kdEint$ 不依赖。这种与路径无关的性质意味着，内能 $\kEint$ 比热传递或所做的功都更容易考虑。

例题 15.1 · 计算内能的变化：两种不同过程产生同一个 $\kEint$ 变化

（a）假设有 40.00 J 的热传递传给一个系统，同时该系统做了 10.00 J 的功。后来，有 25.00 J 的热传递从该系统传出，同时外界对该系统做了 4.00 J 的功。该系统的内能净变化是多少？

（b）当共有 150.00 J 的热传递从系统传出（来自系统），而外界对系统做了 159.00 J 的功时，系统的内能变化是多少？（见图 15.4。）

思路

在（a）部分，我们必须先根据已知信息求出净热传递量和所做的净功。然后就可以用热力学第一定律 $(\kdEint = \kQh - \kW)$ 求出内能变化。在（b）部分，净热传递量和所做的功是已知的，所以可以直接使用这个方程。

（a）的解

净热传递量等于传入系统的热传递量减去传出系统的热传递量，即

$$\kQh = 40.00\ \text{J} - 25.00\ \text{J} = 15.00\ \text{J}.$$

类似地，总功等于系统所做的功减去外界对系统所做的功，即

$$\kW = 10.00\ \text{J} - 4.00\ \text{J} = 6.00\ \text{J}.$$

于是，内能变化由热力学第一定律给出：

$$\kdEint = \kQh - \kW = 15.00\ \text{J} - 6.00\ \text{J} = 9.00\ \text{J}.$$

我们还可以求出这两个步骤各自的内能变化。首先，考虑传入 40.00 J 的热传递和传出 10.00 J 的功，即

$$\Delta\kEintone = \kQheatone - \kWone = 40.00\ \text{J} - 10.00\ \text{J} = 30.00\ \text{J}.$$

现在考虑传出 25.00 J 的热传递和传入 4.00 J 的功，即

$$\Delta\kEinttwo = \kQheattwo - \kWtwo = -25.00\ \text{J} - (-4.00\ \text{J}) = -21.00\ \text{J}.$$

总变化是这两个步骤之和，即

$$\kdEint = \Delta\kEintone + \Delta\kEinttwo = 30.00\ \text{J} + (-21.00\ \text{J}) = 9.00\ \text{J}.$$

（a）的讨论

无论是看整个过程，还是把它分成几个步骤，内能变化都是一样的。

（b）的解

这里净热传递量和总功是直接给出的，分别为 $\kQh = -150.00\ \text{J}$ 和 $\kW = -159.00\ \text{J}$，所以

$$\kdEint = \kQh - \kW = -150.00\ \text{J} - (-159.00\ \text{J}) = 9.00\ \text{J}.$$

（b）的讨论

（b）部分中一个很不相同的过程产生了与（a）部分中相同的 9.00 J 内能变化。注意，两部分中系统的变化都与 $\kdEint$ 有关，而与所涉及的各个 $\kQh$ 或 $\kW$ 无关。在（a）和（b）两部分中，系统最终都处于相同的状态。（a）和（b）两部分给出了系统在相同的起点和终点之间所遵循的两条不同路径，而各自的内能变化是相同的——它与路径无关。

人体代谢与热力学第一定律

人体代谢是把食物转化为热传递、功和储存的脂肪。代谢是热力学第一定律实际起作用的一个有趣的例子。我们现在通过热力学第一定律对这些主题再看一遍。把人体当作所关心的系统，我们就可以用第一定律来考察从睡眠到剧烈运动的各种活动中的热传递、做功和内能。人体中的热传递、做功和能量有哪些主要特征？首先，体温通常靠向周围环境的热传递保持恒定。这意味着 $\kQh$ 为负。另一个事实是，人体通常对外界做功。这意味着 $\kW$ 为正。这样，在这些情形中，人体失去内能，因为 $\kdEint = \kQh - \kW$ 为负。

现在来考虑进食的影响。进食通过增加化学势能（这是对一块上好牛排的一种毫不浪漫的看法）而增加人体的内能。人体会代谢我们摄入的所有食物。基本上，代谢是一个氧化过程，食物的化学势能在其中被释放出来。这意味着食物的输入具有功的形式。食物能量用一个特殊的单位来表示，称为大卡。这种能量是通过在量热器中燃烧食物来测量的，单位就是这样确定的。

在化学和生物化学中，一卡（calorie，英文拼写为小写 c）被定义为使一克纯水的温度升高一摄氏度所需的能量（或热传递量）。营养学家和注意控制体重的人往往使用食物大卡，它常被称为 Calorie（英文拼写为大写 C）。一个食物大卡是使一千克水的温度升高一摄氏度所需的能量。这意味着，一个食物大卡等于化学家所说的一千卡，必须小心，避免把两者混淆。

再来考虑人体已失去的内能。这份内能有三个去处——去往热传递、去往做功，以及去往储存的脂肪（还有极小一部分去往细胞修复和生长）。热传递和做功把内能从人体中带走，而食物把它补回来。如果你吃的食物恰到好处，那么你的平均内能保持不变。你因热传递和做功而失去的一切都由食物补回，所以从长远来看 $\kdEint = 0$。如果你反复吃得过多，那么 $\kdEint$ 总是为正，你的身体就把这份多余的内能储存为脂肪。吃得太少则相反。如果 $\kdEint$ 连续几天为负，那么人体就会代谢自身的脂肪，以维持体温并做那些从人体中取走能量的功。节食之所以能带来减重，就是这个过程。

正如任何节食者都知道的，生活并不总是这么简单。只有当能量摄入的变化持续数日时，人体才会储存脂肪或代谢脂肪。一旦你经历过一次严格节食，下一次就不那么成功了，因为你的身体改变了它对低能量摄入的反应方式。你的基础代谢率（BMR）是身体完全静止时食物转化为热传递和所做功的速率。人体会调整自己的基础代谢率，以部分补偿吃得过多或过少。人体会降低代谢率，而不是消耗自身的脂肪来补充减少的食物摄入。由于较低的代谢率，你会更容易感到冷，也会觉得没有那么精力充沛，而且你不会像以前那样快地减重。锻炼有助于减重，因为它既使你的身体产生热传递，又产生功，并且即使在你静止的时候也提高你的代谢率。人体把内能转化为功的效率相当低，这也有助于减重，因为做功所造成的内能损失要比所做的功大得多。不过应当指出，生物系统并不处于热平衡。

人体为我们提供了一个极好的迹象，表明许多热力学过程是不可逆的。不可逆过程在给定的一组条件下可以沿一个方向进行，却不能反向进行。例如，虽然体内脂肪可以转化为做功和产生热传递，但对人体所做的功和传入人体的热传递却不能转化为体脂。否则，我们就可以靠晒太阳或走下楼梯来省掉午饭了。热力学不可逆过程的另一个例子是光合作用。这一过程是植物摄取一种形式的能量——光——并把它转化为化学势能。图 15.5 展示了热力学第一定律的这两种应用。像热力学第一定律这样的守恒定律有一个很大的优点，就是它们能准确地描述代谢和光合作用这类复杂过程的起点和终点，而不必考虑二者之间的种种复杂情况。表 15.1 概括了与热力学第一定律有关的各项。
