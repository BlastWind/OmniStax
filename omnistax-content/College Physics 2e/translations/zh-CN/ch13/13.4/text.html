分子碰撞产生的压强

我们已经建立了压强和温度的宏观定义。压强是力除以该力所作用的面积，而温度用温度计测量。从气体动理论（它假设原子和分子处于连续的随机运动之中）出发，我们可以更好地理解压强和温度。

图 13.21 表示一个气体分子与容器器壁的弹性碰撞，因此（根据牛顿第三定律）它对器壁施加一个力。由于大量分子会在很短的时间内与器壁碰撞，我们观察到的是单位面积上的平均力。这些碰撞就是气体压强的来源。随着分子数增加，碰撞次数增加，压强也随之增大。同样，如果分子的平均速度较大，气体压强也较大。实际的关系式将在下面的“大与小”栏目中推导。得到如下关系：

$$\kPr \kvol = \frac{1}{3}N\km\overline{v^2},$$

其中 $\kPr$ 是压强（单位面积上的平均力），$\kvol$ 是容器中气体的体积，$N$ 是容器中的分子数，$\km$ 是一个分子的质量，$\overline{v^2}$ 是分子速率平方的平均值。

由分子推出理想气体定律

从这个原子和分子形式的理想气体定律中，我们能学到什么？我们可以推导出气体中温度与分子平均平动动能之间的关系。

建立联系：大与小：气体压强的原子与分子起源

图 13.22 表示一个充满气体的盒子。我们从前面的讨论中知道，向盒中充入更多气体会产生更大的压强，升高气体的温度也会产生更大的压强。但是，为什么升高气体的温度会使盒中的压强增大呢？从原子和分子的尺度来看，可以得到一些答案，也能得到理想气体定律的另一种表达式。

该图给出了弹性碰撞的放大图，碰撞发生在一个气体分子与容器器壁之间。计算这类分子所施加的平均力，将引出理想气体定律，以及温度与分子动能之间的联系。我们假设分子与气体中分子之间的间距相比很小，且它与其他分子的相互作用可以忽略。我们还假设器壁是刚性的，分子的方向改变，但其速率保持不变（因此其动能和其动量的大小也保持不变）。这一假设并不总是成立，但是对分子与器壁之间能量和动量交换作更详细的描述，也会得到相同的结果。

这个方程是理想气体定律的另一种表达式。

温度与分子的平均动能

这一计算得出：分子的平均动能与热力学温度直接相关。

分子的平均平动动能 $\kKEbar$ 称为热能。方程 $\kKEbar = \frac{1}{2}\km\overline{v^2} = \frac{3}{2}k\kTemp$ 是对温度的分子解释，已发现它对气体成立，对液体和固体也相当准确。它是温度的另一种定义，基于分子能量的表达式。

有时把 $\kKEbar = \frac{1}{2}\km\overline{v^2} = \frac{3}{2}k\kTemp$ 重新整理，求解气体中分子的平均速率，并用温度表示，是很有用的：

$$\sqrt{\overline{v^2}} = \kvrms = \sqrt{\frac{3k\kTemp}{\km}},$$

其中 $\kvrms$ 表示方均根（rms）速率。

例题 13.8 · 计算气体分子的动能和速率

（a）在 $20.0^\circ\text{C}$（室温）时，气体分子的平均动能是多少？（b）求此温度下氮分子的方均根速率 $(\text{N}_2)$。

（a）的思路

平均动能方程中的已知量是温度。

$$\kKEbar = \frac{1}{2}\km\overline{v^2} = \frac{3}{2}k\kTemp$$

在把数值代入此方程之前，必须先把给定的温度换算成开尔文。换算得 $\kTemp = (20.0 + 273)\ \text{K} = 293\ \text{K}.$

（a）的解

温度本身就足以求出平均平动动能。把温度代入平动动能方程，得

$$\kKEbar = \frac{3}{2}k\kTemp = \frac{3}{2}(1.38\times10^{-23}\ \text{J/K})(293\ \text{K}) = 6.07\times10^{-21}\ \text{J}.$$

（b）的思路

求氮分子的方均根速率只需用下列方程做一个简单的计算：

$$\sqrt{\overline{v^2}} = \kvrms = \sqrt{\frac{3k\kTemp}{\km}},$$

但我们必须先求出氮分子的质量。利用元素周期表中氮 $\text{N}_2$ 的分子质量，

$$\km = \frac{2(14.0067)\times10^{-3}\ \text{kg/mol}}{6.02\times10^{23}\ \text{mol}^{-1}} = 4.65\times10^{-26}\ \text{kg}.$$

（b）的解

把这个质量和 $k$ 的值代入 $\kvrms$ 的方程，得

$$\kvrms = \sqrt{\frac{3k\kTemp}{\km}} = \sqrt{\frac{3(1.38\times10^{-23}\ \text{J/K})(293\ \text{K})}{4.65\times10^{-26}\ \text{kg}}} = 511\ \text{m/s}.$$

讨论

请注意，分子的平均动能与分子的种类无关。平均平动动能只取决于热力学温度。这个动能与宏观能量相比非常小，所以当一个空气分子撞到我们的皮肤上时，我们并不会感觉到。氮分子的方均根速度大得惊人。这些很大的分子速度并不会使空气产生宏观的移动，因为分子向各个方向运动的可能性相等。空气中分子的平均自由程（分子在两次碰撞之间平均能运动的距离）非常小，因此分子运动得很快，却在一秒内走不了多远。然而，方均根速率的高数值体现在声速上，在室温下约为 340 m/s。空气分子的方均根速率越大，声振动在空气中的传递就越快。声速随温度升高而增大，在分子质量较小的气体（例如氦）中更大。（见图 13.23。）

建立联系：历史注记——气体动理论

气体动理论由丹尼尔·伯努利（1700–1782）建立，他在物理学中最为人知的是关于流体流动（流体动力学）的工作。伯努利的工作早于道尔顿确立的物质原子论观点。

分子速率分布

气体中单个分子的运动在大小和方向上都是随机的，但是由大量分子组成的气体具有可预测的分子速率分布。这一分布称为麦克斯韦-玻尔兹曼分布，以其提出者命名，他们基于气体动理论计算出了它，此后它已被实验证实。（见图 13.24。）该分布有一条长长的尾巴，因为少数分子的速率可能达到方均根速率的几倍。最概然速率 $\kvp$ 小于方均根速率 $\kvrms$。图 13.25 表明，温度越高，曲线越向高速率移动，速率范围也越宽。

热运动速率的分布强烈依赖于温度。随着温度升高，速率向较高的值移动，分布变宽。

图 13.25 所示的分布随温度的变化对人类有什么含义？在其他条件相同的情况下，如果一个人发热，他很可能会失去更多的水分子，特别是从肺和口腔等湿润腔体的内壁失去，从而在口中产生干燥的感觉。

逃逸速度与大气的流失

例题 13.9 · 计算温度：氦原子的逃逸速度

为了摆脱地球的引力，大气层顶附近（100 km 的高度处）的物体必须以 11.1 km/s 的速率离开地球。这一速率称为逃逸速度。温度为多少时，氦原子的方均根速率才等于逃逸速度？

思路

找出已知量和未知量，并确定用哪些方程来解这个问题。

解

  1. 找出已知量：$\kv$ 是该逃逸速度，即 11.1 km/s。
  2. 找出未知量：我们需要求温度 $\kTemp$。我们还需要求氦原子的质量 $\km$。
  3. 确定需要哪些方程。
    • 为了求氦原子的质量 $\km$，我们可以利用元素周期表中的信息： $$\km = \frac{\text{摩尔质量}}{\text{每摩尔的原子数}}.$$
    • 为了求温度 $\kTemp$，我们可以重新整理下面两个方程中的任何一个 $$\kKEbar = \frac{1}{2}\km\overline{v^2} = \frac{3}{2}k\kTemp$$ 或 $$\sqrt{\overline{v^2}} = \kvrms = \sqrt{\frac{3k\kTemp}{\km}}$$ 得到 $$\kTemp = \frac{\km\overline{v^2}}{3k},$$ 其中 $k$ 是玻尔兹曼常量，$\km$ 是氦原子的质量。
  4. 把已知值代入方程，求解未知量。 $$\km = \frac{\text{摩尔质量}}{\text{每摩尔的原子数}} = \frac{4.0026\times10^{-3}\ \text{kg/mol}}{6.02\times10^{23}\ \text{mol}} = 6.65\times10^{-27}\ \text{kg}$$ $$\kTemp = \frac{(6.65\times10^{-27}\ \text{kg})(11.1\times10^{3}\ \text{m/s})^2}{3(1.38\times10^{-23}\ \text{J/K})} = 1.98\times10^{4}\ \text{K}$$

讨论

这个温度远高于大气温度，后者在高空约为 250 K（$-25^\circ\text{C}$ 或 $-10^\circ\text{F}$）。大气中剩下的氦原子很少，但在大气形成时有很多。氦原子流失的原因是，有少数氦原子的速率高于地球的逃逸速度，即使在正常温度下也是如此。氦原子的速率从一个时刻到下一个时刻都在变化，所以在任一时刻，其速率大于逃逸速度、从而分子逃离地球引力的概率虽小，但不为零。较重的分子，例如氧、氮和水（其中只有极少数能到达很高的高度），方均根速率较小，因此它们中任何一个的速率大于逃逸速度的可能性要小得多。事实上，速率超过逃逸速度的分子如此之少，以致要经过数十亿年才会损失大量的大气。图 13.26 表明月球上缺少大气的影响。由于月球的引力弱得多，它几乎失去了全部大气。地球与月球的比较在本章的“习题”中讨论。
