抛体运动及其相互独立的分量

抛体运动是指物体被抛出或射向空中后，仅受重力加速度作用的运动。该物体称为抛体，它的路径称为它的轨迹。落体的运动（如“一维运动学的解题基础”中所述）是一种简单的一维抛体运动，其中没有水平方向的移动。在本节中，我们考虑二维抛体运动，例如橄榄球或其他空气阻力可以忽略的物体的运动。

这里要记住的最重要的事实是：沿相互垂直的坐标轴的运动是相互独立的，因此可以分别分析。这一事实已在“二维运动学：引言”中讨论过，在那里我们看到，竖直和水平运动是相互独立的。分析二维抛体运动的关键，是把它分解为两个运动，一个沿水平轴，另一个沿竖直轴。（这样选取坐标轴最为合理，因为重力加速度是竖直的——因此，当空气阻力可以忽略时，沿水平轴不存在加速度。）按照惯例，我们把水平轴称为 x 轴，把竖直轴称为 y 轴。图 3.34 表示了位移的记号，其中 $\mathbf{s}$ 定义为总位移，$\mathbf{x}$ 和 $\mathbf{y}$ 分别是它沿水平轴和竖直轴的分量。这些矢量的大小为 $\ks$、$\kx$ 和 $\ky$。（请注意，在上一节中，我们用记号 $\mathbf{A}$ 表示矢量，其分量为 $A_x$ 和 $A_y$。如果沿用这种格式，我们就应把位移记作 $\mathbf{s}$，其分量为 $\mathbf{s}_x$ 和 $\mathbf{s}_y$。不过，为了简化记号，我们将直接把分矢量表示为 $\mathbf{x}$ 和 $\mathbf{y}$。）

当然，要描述运动，我们必须处理速度和加速度，也要处理位移。我们同样必须求出它们沿 x 轴和 y 轴的分量。我们将假定除重力以外的所有力（例如空气阻力和摩擦力）都可以忽略。于是加速度的分量就非常简单：$\kay = -\kg = -9.80\ \text{m/s}^2$。（请注意，这一定义假设向上的方向被定义为正方向。如果你把坐标系布置成向下的方向为正，那么重力加速度就取正值。）由于重力是竖直的，所以 $\kax = 0$。这两个加速度都是恒定的，因此可以使用运动学方程。

运动学方程回顾（恒定 $\ka$）
$$\kx = \kxo + \kvb\kt$$ $$\kvb = \frac{\kvo + \kv}{2}$$ $$\kv = \kvo + \ka\kt$$ $$\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$$ $$\kv^2 = \kvo^2 + 2\ka(\kx - \kxo).$$

在这些假设下，按以下步骤分析抛体运动：

分解运动：水平方程和竖直方程

步骤 1。沿 x 轴和 y 轴，把运动分解或拆分为水平分量和竖直分量。这两条坐标轴相互垂直，所以使用 $A_x = A\cos\ktheta$ 和 $A_y = A\sin\ktheta$。位移 $\mathbf{s}$ 沿这两条坐标轴的分量的大小为 $\kx$ 和 $\ky$。速度 $\mathbf{v}$ 的分量的大小为 $\kvx = \kv\cos\ktheta$ 和 $\kvy = \kv\sin\ktheta$，其中 $\kv$ 是速度的大小，$\ktheta$ 是它的方向，如图 3.35 所示。初值照例用下标 0 表示。

步骤 2。把运动看作两个相互独立的一维运动，一个沿水平方向，另一个沿竖直方向。水平运动和竖直运动的运动学方程具有如下形式：

水平运动（$\kax = 0$）
$$\kx = \kxo + \kvx\kt$$ $$\kvx = \kvox = \kvx = \text{速度是恒定的。}$$
竖直运动（设向上为正，$\kay = -\kg = -9.80\ \text{m/s}^2$）
$$\ky = \kyo + \tfrac{1}{2}(\kvoy + \kvy)\kt$$ $$\kvy = \kvoy - \kg\kt$$ $$\ky = \kyo + \kvoy\kt - \tfrac{1}{2}\kg\kt^2$$ $$\kvy^2 = \kvoy^2 - 2\kg(\ky - \kyo).$$

求解与重新合成

步骤 3。分别求出两个独立运动——一个水平、一个竖直——中的未知量。请注意，两个运动之间唯一共同的变量是时间 $\kt$。这里的解题方法与一维运动学相同，并在下面的例题中加以演示。

步骤 4。把两个运动重新合成，求出总位移 $\mathbf{s}$ 和速度 $\mathbf{v}$。由于 x 方向和 y 方向的运动相互垂直，我们利用“矢量的加法和减法：解析法”中概述的方法，并采用如下形式的 $A = \sqrt{A_x^2 + A_y^2}$ 和 $\ktheta = \tan^{-1}(A_y / A_x)$，来确定这些矢量，其中 $\ktheta$ 是位移 $\mathbf{s}$ 的方向，$\kthetav$ 是速度 $\mathbf{v}$ 的方向：

总位移和速度
$$\ks = \sqrt{\kx^2 + \ky^2}$$ $$\ktheta = \tan^{-1}(\ky / \kx)$$ $$\kv = \sqrt{\kvx^2 + \kvy^2}$$ $$\kthetav = \tan^{-1}(\kvy / \kvx).$$

抛体的最大高度

例题 3.4 · 烟花弹在高处远处爆炸

在一场烟花表演中，一枚烟花弹以 70.0 m/s 的初速率、高于水平方向 $75.0^\circ$ 的角度射向空中，如图 3.36 所示。引信经过定时，使烟花弹恰好在它到达离地面的最高点时被点燃。（a）求烟花弹爆炸处的高度。（b）从烟花弹发射到爆炸，经过了多少时间？（c）当它爆炸时，烟花弹的水平位移是多少？

思路

因为对未爆炸的烟花弹而言空气阻力可以忽略，所以可以使用上面概述的分析方法。运动可以分解为水平和竖直两个运动，其中 $\kax = 0$，$\kay = -\kg$。然后我们可以把 $\kxo$ 和 $\kyo$ 定义为零，并求出所需的量。

（a）的解

我们所说的“高度”，是指高于起点的海拔或竖直位置 $\ky$。任何轨迹的最高点称为顶点，在 $\kvy = 0$ 时到达。由于我们知道初、末速度以及初位置，所以用下面的方程求 $\ky$：

现在我们必须求出 $\kvoy$，即初速度在 y 方向上的分量。它由 $\kvoy = \kvo\sin\ktheta$ 给出，其中 $\kvoy$ 是70.0 m/s 的初速度，$\kthetao = 75.0^\circ$ 是初始角度。因此，

$$\kvoy = \kvo\sin\kthetao = (70.0\ \text{m/s})(\sin 75^\circ) = 67.6\ \text{m/s}.$$

而 $\ky$ 为

$$\ky = \frac{(67.6\ \text{m/s})^2}{2(9.80\ \text{m/s}^2)},$$

所以

$$\ky = 233\ \text{m}.$$

（a）的讨论

请注意，由于向上为正，所以初速度为正，最大高度也为正，而重力加速度为负。还请注意，最大高度只取决于初速度的竖直分量，因此，任何抛体，只要初速度的竖直分量为 67.6 m/s，就将达到233 m 的最大高度（忽略空气阻力）。这个例题中的数值对于大型烟花表演来说是合理的，其烟花弹在爆炸前确实能达到这样的高度。实际上，空气阻力并非完全可以忽略，所以要达到同样的高度，初速度必须比题中给出的略大一些。

（b）的解

与许多物理学问题一样，求到达最高点的时间有不止一种方法。在这里，最简单的方法是使用 $\ky = \kyo + \tfrac{1}{2}(\kvoy + \kvy)\kt$。由于 $\kyo$ 为零，这个方程就简化为

$$\ky = \tfrac{1}{2}(\kvoy + \kvy)\kt.$$

请注意，最高点处的竖直末速度 $\kvy$ 为零。因此，

$$\begin{aligned}\kt &= \frac{2\ky}{(\kvoy + \kvy)} = \frac{2(233\ \text{m})}{(67.6\ \text{m/s})}\\ &= 6.90\ \text{s}.\end{aligned}$$

（b）的讨论

这个时间对于大型烟花来说也是合理的。当你能看到烟花发射时，你会注意到烟花弹爆炸之前要过几秒钟。（求时间的另一种方法是使用 $\ky = \kyo + \kvoy\kt - \tfrac{1}{2}\kg\kt^2$，并对 $\kt$ 解二次方程。）

（c）的解

由于空气阻力可以忽略，所以 $\kax = 0$，并且如上所述，水平速度是恒定的。水平位移等于水平速度乘以时间，即 $\kx = \kxo + \kvx\kt$，其中 $\kxo$ 等于零：

$$\kx = \kvx\kt,$$

其中 $\kvx$ 是速度的 x 分量，由 $\kvx = \kvo\cos\kthetao$ 给出。现在，

$$\kvx = \kvo\cos\kthetao = (70.0\ \text{m/s})(\cos 75.0^\circ) = 18.1\ \text{m/s}.$$

两个运动的时间 $\kt$ 相同，所以 $\kx$ 为

$$\kx = (18.1\ \text{m/s})(6.90\ \text{s}) = 125\ \text{m}.$$

（c）的讨论

在没有空气阻力的情况下，水平运动的速度是恒定的。这里求得的水平位移，可以用来避免烟花碎片落到观众身上。烟花弹一旦爆炸，空气阻力就会产生重大影响，许多碎片将直接落在正下方。

在求解上面例题的（a）部分时，我们得到的 $\ky$ 的表达式对任何空气阻力可以忽略的抛体运动都成立。把最大高度记为 $\ky = \kh$，那么，

$$\kh = \frac{\kvoy^2}{2\kg}.$$

这个方程定义了抛体的最大高度，它只取决于初速度的竖直分量。

建立坐标系

分析抛体运动时，建立坐标系很重要。定义坐标系的一部分工作，是为 $\kx$ 和 $\ky$ 位置定义一个原点。通常，选取物体的初始位置作为原点，使 $\kxo = 0$、$\kyo = 0$，是很方便的。同样重要的是，要定义 $\kx$ 和 $\ky$ 方向上的正、负方向。通常，我们把竖直方向的正方向定为向上，而水平方向的正方向通常是物体运动的方向。在这种情况下，竖直加速度 $\kay = -\kg$ 取负值（因为它向下指向地球）。不过，有时用不同的方式定义坐标会更有用。例如，如果你在分析从悬崖顶部向下抛出的球的运动，那么由于球的运动完全沿向下的方向，把正方向定为向下可能更合理。在这种情况下，$\kay = \kg$ 取正值。

飞行时间与着地速度

例题 3.5 · 计算抛体运动：炽热的岩石

夏威夷的基拉韦厄火山是世界上活动最为持续不断的火山。非常活跃的火山的特点是喷出炽热的岩石和熔岩，而不是烟和灰。假设一块大岩石从火山喷出，速率为 25.0 m/s，以高于水平方向 $35.0^\circ$ 的角度喷出，如图 3.37 所示。岩石在海拔比其起点低 20.0 m 的位置撞上火山的侧面。（a）求岩石沿这条路径运动所需的时间。（b）岩石在着地时的速度的大小和方向各是多少？

思路

同样，把这个二维运动分解为两个相互独立的一维运动，就能求出所需的量。抛体在空中的时间完全由其竖直运动决定。我们先求 $\kt$。在岩石竖直上升和下落的同时，水平运动以恒定的速度继续进行。这个例题要求的是末速度。因此，要把竖直方向和水平方向的结果重新合成，以得到在例题第一部分所确定的末时刻 $\kt$ 的 $\kv$ 和 $\kthetav$。

（a）的解

岩石在空中时，它先上升，然后下落到比起始海拔低 20.0 m 的末位置。我们可以用下式求出这一过程所需的时间：

$$\ky = \kyo + \kvoy\kt - \tfrac{1}{2}\kg\kt^2.$$

如果取初位置 $\kyo$ 为零，则末位置为 $\ky = -20.0\ \text{m}$。现在，竖直初速度就是初速度的竖直分量，由 $\kvoy = \kvo\sin\kthetao$ = ($25.0\ \text{m/s}$)($\sin 35.0^\circ$) = $14.3\ \text{m/s}$ 求得。代入已知值得

$$-20.0\ \text{m} = (14.3\ \text{m/s})\kt - (4.90\ \text{m/s}^2)\kt^2.$$

整理各项，得到关于 $\kt$ 的二次方程：

$$(4.90\ \text{m/s}^2)\kt^2 - (14.3\ \text{m/s})\kt - (20.0\ \text{m}) = 0.$$

这个表达式是形如 $at^2 + bt + c = 0$ 的二次方程，其中常数为 $a = 4.90$，$b = -14.3$，$c = -20.0$。它的解由二次方程求根公式给出：

$$t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$

这个方程有两个解：$\kt = 3.96$ 和 $\kt = -1.03$。（验证这两个解留给读者作为练习。）时间为 $\kt = 3.96\ \text{s}$ 或 $-1.03\ \text{s}$。时间取负值，意味着这是运动开始之前的事件，所以我们把它舍去。因此，

$$\kt = 3.96\ \text{s}.$$

（a）的讨论

抛体运动的时间完全由竖直运动决定。因此，任何抛体，只要竖直初速度为 14.3 m/s，并且落在比起始海拔低 20.0 m 处，就会在空中停留 3.96 s。

（b）的解

根据现在掌握的信息，我们可以求出水平和竖直方向的末速度 $\kvx$ 和 $\kvy$，并把它们合成，求出合速度 $\kv$，以及它与水平方向所成的角度 $\kthetao$。当然，$\kvx$ 是恒定的，所以可以在任何水平位置求它。在这里，我们选择起点，因为我们知道初速度和初始角度。因此：

$$\kvx = \kvo\cos\kthetao = (25.0\ \text{m/s})(\cos 35^\circ) = 20.5\ \text{m/s}.$$

竖直末速度由下面的方程给出：

$$\kvy = \kvoy - \kg\kt,$$

其中 $\kvoy$ 在（a）部分中求得为 $14.3\ \text{m/s}$。因此，

$$\kvy = 14.3\ \text{m/s} - (9.80\ \text{m/s}^2)(3.96\ \text{s})$$

所以

$$\kvy = -24.5\ \text{m/s}.$$

为了求出末速度的大小 $\kv$，我们用下面的方程合成它相互垂直的分量：

$$\kv = \sqrt{\kvx^2 + \kvy^2} = \sqrt{(20.5\ \text{m/s})^2 + (-24.5\ \text{m/s})^2},$$

得到

$$\kv = 31.9\ \text{m/s}.$$

方向 $\kthetav$ 由下面的方程求得：

$$\kthetav = \tan^{-1}(\kvy / \kvx)$$

所以

$$\kthetav = \tan^{-1}(-24.5 / 20.5) = \tan^{-1}(-1.19).$$

因此，

$$\kthetav = -50.1^\circ.$$

（b）的讨论

负角度表示速度在水平方向以下 $50.1^\circ$。这一结果与竖直末速度为负、因而向下这一事实一致——这正是你所预料的，因为最终海拔比初始海拔低 20.0 m。（见图 3.37。）

抛体的射程

抛体运动所说明的最重要的一点是：竖直和水平运动相互独立。伽利略是第一个充分理解这一特性的人。他用它来预测抛体的射程。在水平地面上，我们把射程定义为抛体所经过的水平距离 $\kR$。伽利略和许多其他人关心抛体的射程，主要出于军事目的——例如瞄准火炮。不过，研究抛体的射程，可以帮助我们理解其他有趣的现象，例如卫星绕地球的轨道。让我们进一步考虑抛体射程。

抛体的初速度如何影响它的射程？显然，初速率 $\kvo$ 越大，射程越大，如图 3.38（a）所示。初始角度 $\kthetao$ 对射程的影响也很显著，如图 3.38（b）所示。对于固定的初速率（例如火炮所能产生的初速率），最大射程在 $\kthetao = 45^\circ$ 时取得。这只在忽略空气阻力的条件下成立。如果考虑空气阻力，最大角度约为 $38^\circ$。有趣的是，除 $45^\circ$ 外，对每一个初始角度，都有两个角度给出相同的射程——这两个角度之和为 $90^\circ$。射程还取决于重力加速度 $\kg$ 的值。登月航天员艾伦·谢泼德之所以能在月球上把一个高尔夫球击出很远的距离，是因为那里的重力较弱。在水平地面上，抛体的射程 $\kR$（空气阻力可以忽略时）由下式给出

$$\kR = \frac{\kvo^2 \sin 2\kthetao}{\kg},$$

其中 $\kvo$ 是初速率，$\kthetao$ 是相对于水平方向的初始角度。这个方程的证明留作本章末的习题（给出了提示），但它确实符合前面所述抛体射程的主要特征。

从射程到轨道

当我们谈到水平地面上的抛体的射程时，我们假定 $\kR$ 与地球的周长相比非常小。然而，如果射程很大，地球就会在抛体下方弯曲离去，重力加速度的方向也沿路径变化。这时的射程比上面给出的射程方程所预测的更大，因为抛体要下落的距离比它在水平地面上更远。（见图 3.39。）如果初速率足够大，抛体就会进入轨道。这种可能性在能够实现的几个世纪之前就已被认识到。当物体在轨道上时，地球从物体下方弯曲离去的速率与物体下落的速率相同。因此物体不断下落，却永远不会撞到地表。轨道运动的这些方面和其他方面，例如地球的自转，将在本书后面做更深入的解析讨论。

我们再一次看到，思考一个话题，例如抛体的射程，可以把我们引向其他话题，例如地球轨道。在“速度的合成”中，我们将考察速度的合成，这是二维运动学的另一个重要方面，也将带来超出当前话题的见解。
