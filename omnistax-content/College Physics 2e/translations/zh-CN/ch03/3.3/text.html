解析法

解析法求矢量加法和减法时，使用的是几何和简单的三角学，而不是图解法中的直尺和量角器。图解技术的一部分得以保留，因为矢量仍然用箭头表示，以便形象化。然而，解析法比图解法更简明、更准确、更精密，而图解法受限于作图所能达到的准确度。解析法只受限于物理量已知的准确度和精密度。

把矢量分解为相互垂直的分量

解析技术与直角三角形在物理学中密不可分，原因之一是沿相互垂直方向的运动是相互独立的。我们经常需要把一个矢量分成相互垂直的分量。例如，给定图 3.24 中的矢量 $\mathbf{A}$，我们可能希望求出哪两个相互垂直的矢量 $\mathbf{A}_x$ 和 $\mathbf{A}_y$ 相加得到它。

$\mathbf{A}_x$ 和 $\mathbf{A}_y$ 被定义为 $\mathbf{A}$ 沿x 轴和y 轴的分量。三个矢量 $\mathbf{A}$、$\mathbf{A}_x$ 和 $\mathbf{A}_y$ 构成一个直角三角形：

$$\mathbf{A}_x + \mathbf{A}_y = \mathbf{A}.$$

请注意，矢量分量与合矢量之间的这一关系只适用于矢量（它们既包括大小也包括方向）。这一关系不适用于单独的大小。例如，若 $\kAx = 3\ \text{m}$ 向东，$\kAy = 4\ \text{m}$ 向北，$\kA = 5\ \text{m}$ 向东北，则确有矢量 $\mathbf{A}_x + \mathbf{A}_y = \mathbf{A}$。然而，说这些矢量的大小之和也相等，却并非事实。也就是说，

$$3\ \text{m} + 4\ \text{m} \neq 5\ \text{m}$$

因此，

$$\kAx + \kAy \neq \kA$$

如果矢量 $\mathbf{A}$ 已知，那么它的大小 $\kA$（即它的长度）和角 $\ktheta$（即它的方向）也就已知。要求 $\kAx$ 和 $\kAy$，即它的 x 分量和 y 分量，我们使用直角三角形的下列关系。

$$\kAx = \kA\cos\ktheta$$

和

$$\kAy = \kA\sin\ktheta.$$

例如，假设 $\mathbf{A}$ 是表示“二维运动学：引言”和“矢量的加法和减法：图解法”中所考虑的在城市中行走的人的总位移的矢量。

于是 $\kA = 10.3$ 个街区，$\ktheta = 29.1^\circ$，因此

$$\kAx = \kA\cos\ktheta = (10.3\ \text{街区})(\cos 29.1^\circ) = 9.0\ \text{街区}$$ $$\kAy = \kA\sin\ktheta = (10.3\ \text{街区})(\sin 29.1^\circ) = 5.0\ \text{街区}.$$

计算合矢量

如果矢量 $\mathbf{A}$ 的相互垂直的分量 $\mathbf{A}_x$ 和 $\mathbf{A}_y$ 已知，那么 $\mathbf{A}$ 也可以用解析的方法求出。要由矢量的相互垂直的分量 $\mathbf{A}_x$ 和 $\mathbf{A}_y$ 求出它相对于x 轴的大小 $\kA$ 和方向 $\ktheta$，我们使用下列关系：

$$\kA = \sqrt{\kAx^2 + \kAy^2}$$ $$\ktheta = \tan^{-1}(\kAy / \kAx).$$

请注意，方程 $\kA = \sqrt{\kAx^2 + \kAy^2}$ 恰是勾股定理，它把直角三角形的两条直角边与斜边的长度联系起来。例如，若 $\kAx$ 和 $\kAy$ 分别为9 个和 5 个街区，则 $\kA = \sqrt{9^2 + 5^2} = 10.3$ 个街区，这与在城市中行走的人的例子再次一致。最后，方向为 $\ktheta = \tan^{-1}(5/9) = 29.1^\circ$，与前面相同。

用解析法确定矢量及其分量

方程 $\kAx = \kA\cos\ktheta$ 和 $\kAy = \kA\sin\ktheta$ 用来求矢量的相互垂直的分量——即由 $\kA$ 和 $\ktheta$ 求 $\kAx$ 和 $\kAy$。方程 $\kA = \sqrt{\kAx^2 + \kAy^2}$ 和 $\ktheta = \tan^{-1}(\kAy / \kAx)$ 用来由相互垂直的分量求矢量——即由 $\kAx$ 和 $\kAy$ 求 $\kA$ 和 $\ktheta$。这两个过程对于解析法的矢量加法和减法都至关重要。

用解析法求矢量和

要了解如何用相互垂直的分量来相加矢量，请看图 3.28，其中矢量 $\mathbf{A}$ 和 $\mathbf{B}$ 相加，得到合矢量 $\mathbf{R}$。

如果 $\mathbf{A}$ 和 $\mathbf{B}$ 表示一次行走的两段路（两个位移），那么 $\mathbf{R}$ 就是总位移。行走的人最终停在 $\mathbf{R}$ 的矢端处。到达同一点有很多种方式。特别是，这个人可以先沿 x 方向走，再沿 y 方向走。这两段路径就是合矢量的 x 分量和 y 分量，即 $\mathbf{R}_x$ 和 $\mathbf{R}_y$。如果我们知道 $\kRx$ 和 $\kRy$，就可以用方程 $\kA = \sqrt{\kAx^2 + \kAy^2}$ 和 $\ktheta = \tan^{-1}(\kAy / \kAx)$ 求出 $\kR$ 和 $\ktheta$。使用矢量加法的解析法时，你可以确定一个矢量的分量，或者确定它的大小和方向。

步骤 1。确定题目中要使用的x 轴和y 轴。然后，求出要相加的每个矢量沿所选相互垂直轴的分量。使用方程 $\kAx = \kA\cos\ktheta$ 和 $\kAy = \kA\sin\ktheta$ 求分量。在图 3.29 中，这些分量是 $\kAx$、$\kAy$、$\kBx$ 和 $\kBy$。矢量 $\mathbf{A}$ 和 $\mathbf{B}$ 与x 轴所成的角分别为 $\kthetaA$ 和 $\kthetaB$。

步骤 2。把各个矢量沿某个轴的分量相加，得到合矢量沿每个轴的分量。也就是说，如图 3.30 所示，

$$\kRx = \kAx + \kBx$$

和

$$\kRy = \kAy + \kBy.$$

沿同一个轴（比如x 轴）的分量是沿同一直线的矢量，因此可以像普通的数一样彼此相加。沿y 轴的分量也是如此。（例如，向东走 9 个街区可以分两段走，第一段向东 3 个街区，第二段向东 6 个街区，总共 9 个街区，因为它们沿相同的方向。）所以把矢量分解为沿共同轴的分量，会使它们更容易相加。既然 $\mathbf{R}$ 的分量已知，就可以求出它的大小和方向。

步骤 3。要得到合矢量的大小 $\kR$，使用勾股定理：

$$\kR = \sqrt{\kRx^2 + \kRy^2}.$$

步骤 4。要得到合矢量相对于x 轴的方向：

$$\ktheta = \tan^{-1}(\kRy / \kRx).$$

下面的例题说明了用相互垂直的分量相加矢量的这种方法。

例题 3.3 · 用解析法求矢量和

利用沿x 轴和y 轴的相互垂直的分量，把图 3.31 中所示的矢量 $\mathbf{A}$ 与矢量 $\mathbf{B}$ 相加。x 轴和y 轴分别沿东西和南北方向。矢量 $\mathbf{A}$ 表示一次行走的第一段，其中一个人沿东偏北 $20.0^\circ$ 的方向走 $53.0\ \text{m}$。矢量 $\mathbf{B}$ 表示第二段，是沿东偏北 $63.0^\circ$ 的方向、大小为 $34.0\ \text{m}$ 的位移。

思路

$\mathbf{A}$ 和 $\mathbf{B}$ 沿x 轴和y 轴的分量，表示为到达同一终点而向正东和向正北行走。求出之后，把它们合起来，得到合矢量。

解

按照上面概述的方法，我们首先求出 $\mathbf{A}$ 和 $\mathbf{B}$ 沿x 轴和y 轴的分量。请注意 $\kA = 53.0\ \text{m}$，$\kthetaA = 20.0^\circ$，$\kB = 34.0\ \text{m}$，$\kthetaB = 63.0^\circ$。我们用 $\kAx = \kA\cos\ktheta$ 求 x 分量，得到

$$\begin{aligned}\kAx &= \kA\cos\kthetaA = (53.0\ \text{m})(\cos 20.0^\circ)\\ &= (53.0\ \text{m})(0.940) = 49.8\ \text{m}\end{aligned}$$

和

$$\begin{aligned}\kBx &= \kB\cos\kthetaB = (34.0\ \text{m})(\cos 63.0^\circ)\\ &= (34.0\ \text{m})(0.454) = 15.4\ \text{m}.\end{aligned}$$

类似地，用 $\kAy = \kA\sin\kthetaA$ 求 y 分量：

$$\begin{aligned}\kAy &= \kA\sin\kthetaA = (53.0\ \text{m})(\sin 20.0^\circ)\\ &= (53.0\ \text{m})(0.342) = 18.1\ \text{m}\end{aligned}$$

和

$$\begin{aligned}\kBy &= \kB\sin\kthetaB = (34.0\ \text{m})(\sin 63.0^\circ)\\ &= (34.0\ \text{m})(0.891) = 30.3\ \text{m}.\end{aligned}$$

合矢量的 x 分量和 y 分量因此为

$$\kRx = \kAx + \kBx = 49.8\ \text{m} + 15.4\ \text{m} = 65.2\ \text{m}$$

和

$$\kRy = \kAy + \kBy = 18.1\ \text{m} + 30.3\ \text{m} = 48.4\ \text{m}.$$

现在我们可以用勾股定理求出合矢量的大小：

$$\kR = \sqrt{\kRx^2 + \kRy^2} = \sqrt{(65.2)^2 + (48.4)^2}\ \text{m}$$

于是

$$\kR = 81.2\ \text{m}.$$

最后，我们求出合矢量的方向：

$$\ktheta = \tan^{-1}(\kRy / \kRx) = +\tan^{-1}(48.4 / 65.2).$$

因此，

$$\ktheta = \tan^{-1}(0.742) = 36.6^\circ.$$

讨论

这个例题说明了用相互垂直的分量相加矢量。用相互垂直的分量做矢量减法与此非常相似——它只是加上一个负矢量。

用解析法求矢量差

矢量的减法是通过加上一个负矢量来完成的。也就是说，$\mathbf{A} - \mathbf{B} \equiv \mathbf{A} + (-\mathbf{B})$。因此，用相互垂直的分量做矢量减法的方法与加法完全相同。$-\mathbf{B}$ 的分量是 $\mathbf{B}$ 的分量的负值。因此，合矢量 $\mathbf{A} - \mathbf{B} = \mathbf{R}$ 的 x 分量和 y 分量为

$$\kRx = \kAx + (-\kBx)$$

和

$$\kRy = \kAy + (-\kBy)$$

而上面概述的其余方法与加法完全相同。（见图 3.33。）

用相互垂直的分量分析矢量在物理学的许多领域都非常有用，因为相互垂直的量往往彼此独立。下一节抛体运动是许多这样的小节之一，其中使用相互垂直的分量有助于使图景清晰，并使其中的物理学问题变得简单。
