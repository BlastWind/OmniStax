相对于介质和相对于观察者的速度

如果一个人划着小船横渡一条水流湍急的河，并试图径直驶向对岸，小船反而会相对于河岸斜向运动，如图 3.40 所示。小船并不沿着它所指向的方向运动。原因当然是河水把小船带向了下游。同样，如果一架小型飞机在强侧风中从头顶飞过，你有时可以看到飞机并不沿着它所指向的方向运动，如图 3.41 所示。飞机相对于空气是笔直向前飞行的，但气团相对于地面的运动把它带向了一侧。

在上述每种情形中，物体相对于一种介质（如河流）都有一个速度，而该介质相对于坚实地面上的观察者也有一个速度。物体相对于观察者的速度就是这些速度矢量之和，如图 3.40 和图 3.41 所示。这两种情形只是需要把速度相加的许多情形中的两种。在本节中，我们先重新审视如何把速度相加，然后再探讨相对速度的含义的某些方面。

用分量求速度之和

我们如何把速度相加？速度是矢量（它既有大小又有方向）；“矢量的加法和减法：图解法”以及“矢量的加法和减法：解析法”中讨论过的矢量加法法则，同样适用于速度的合成，就像适用于任何其他矢量一样。在一维运动中，速度的合成很简单——它们像普通数那样相加。例如，如果一名曲棍球运动员以 $5\ \text{m/s}$ 的速度径直朝球门跑去，并沿相同方向击球，球相对于她身体的速度为 $30\ \text{m/s}$，那么球的速度相对于站在球门前、静止不动而又汗流浃背的守门员为 $35\ \text{m/s}$。

在二维运动中，既可以用图解法，也可以用解析法把速度相加。我们将着重讨论解析法。下列方程给出了速度的大小和方向（$\kv$ 和 $\ktheta$）与它沿适当选取的坐标系的 x 轴和 y 轴的分量（$\kvx$ 和 $\kvy$）之间的关系：

$$\kvx = \kv\cos\ktheta$$ $$\kvy = \kv\sin\ktheta$$ $$\kv = \sqrt{\kvx^2 + \kvy^2}$$ $$\ktheta = \tan^{-1}(\kvy / \kvx).$$

这些方程对任何矢量都成立，这里是专门针对速度改写的。前两个方程用于在已知速度的大小和方向时求它的分量。后两个方程用于在已知速度的分量时求它的大小和方向。

居家实验：小船的相对速度

在浴缸里放半缸水。取一只玩具小船或其他能浮在水面上的物体。拔掉排水塞，让水开始排出。试着把小船从浴缸的一侧推向另一侧，并使推的方向垂直于水流。你需要朝哪个方向推小船，它才会正好到达正对面？比较水流的方向、小船的航向和小船的实际速度。

河上的小船

例题 3.6 · 速度的合成：河上的小船

参见图 3.43，图中是一条小船正试图径直驶过这条河。我们来计算小船相对于岸上观察者的速度 $\mathbf{v}_{\text{tot}}$ 的大小和方向。小船的速度 $\mathbf{v}_{\text{boat}}$ 相对于河水沿 $y$ 方向，为 0.75 m/s；河水的速度 $\mathbf{v}_{\text{river}}$ 向右，为 1.20 m/s。

思路

我们首先选取一个 $x$ 轴平行于河水的速度的坐标系，如图 3.43 所示。因为小船的船头正对着对岸，所以它的速度相对于水平行于 $y$ 轴，并垂直于河水的速度。因此，我们可以直接利用方程 $\kvtot = \sqrt{\kvx^2 + \kvy^2}$ 和 $\ktheta = \tan^{-1}(\kvy / \kvx)$ 把这两个速度相加。

解

合速度的大小为

$$\kvtot = \sqrt{\kvx^2 + \kvy^2},$$

其中

$$\kvx = \kvriver = 1.20\ \text{m/s}$$

且

$$\kvy = \kvboat = 0.750\ \text{m/s}.$$

因此，

$$\kvtot = \sqrt{(1.20\ \text{m/s})^2 + (0.750\ \text{m/s})^2}$$

得出

$$\kvtot = 1.42\ \text{m/s}.$$

合速度的方向 $\ktheta$ 由下式给出：

$$\ktheta = \tan^{-1}(\kvy / \kvx) = \tan^{-1}(0.750 / 1.20).$$

该方程给出

$$\ktheta = 32.0^\circ.$$

讨论

合速度的大小 $\kv$ 和方向 $\ktheta$ 都与图 3.43 一致。请注意，因为河水的速度比小船的速度大，所以它被迅速冲向下游。合速度相对于河岸的夹角很小（只有 $32.0^\circ$），这印证了上述结果。

风中的飞机

例题 3.7 · 计算速度：风速使飞机偏航

计算图 3.44 所示情形中风的速度。已知飞机相对于气团以 45.0 m/s 的速度向正北运动，而它的速度相对于地面（它的合速度）为 38.0 m/s，方向为北偏西 $20.0^\circ$。

思路

在这个问题中，与上一个例题有些不同，我们知道合速度 $\mathbf{v}_{\text{tot}}$，并且知道它是另外两个速度之和，即 $\mathbf{v}_{\text{w}}$（风）和 $\mathbf{v}_{\text{p}}$（飞机相对于气团）。量 $\mathbf{v}_{\text{p}}$ 是已知的，要求我们求出 $\mathbf{v}_{\text{w}}$。这些速度都不相互垂直，但可以求出它们沿同一组相互垂直的坐标轴的分量。如果能求出 $\mathbf{v}_{\text{w}}$ 的分量，就可以把它们合成起来，求出它的大小和方向。如图 3.44 所示，我们选取 x 轴指向正东、y 轴指向正北（平行于 $\mathbf{v}_{\text{p}}$）的坐标系。（你不妨回头看看“矢量的加法和减法：解析法”中关于用相互垂直的分量求矢量和的讨论。）

解

因为 $\mathbf{v}_{\text{tot}}$ 是 $\mathbf{v}_{\text{w}}$ 与 $\mathbf{v}_{\text{p}}$ 的矢量和，所以它的 x 分量和 y 分量分别是风和飞机的速度的 x 分量之和与 y 分量之和。请注意，飞机的速度只有竖直分量，所以 $\kvpx = 0$，$\kvpy = \kvp$。也就是说，

$$\kvtotx = \kvwx$$

且

$$\kvtoty = \kvwy + \kvp.$$

我们可以用这两个方程中的第一个来求 $\kvwx$：

$$\kvwx = \kvtotx = \kvtot\cos 110^\circ.$$

因为 $\kvtot = 38.0\ \text{m/s}$，且 $\cos 110^\circ = -0.342$，所以有

$$\kvwx = (38.0\ \text{m/s})(-0.342) = -13\ \text{m/s}.$$

负号表示运动向西，这与图示一致。

现在，为了求 $\kvwy$，我们注意到

$$\kvtoty = \kvwy + \kvp$$

这里 $\kvtoty = \kvtot\sin 110^\circ$；因此，

$$\kvwy = (38.0\ \text{m/s})(0.940) - 45.0\ \text{m/s} = -9.29\ \text{m/s}.$$

这个负号表示运动向南，这与图示一致。

既然风的速度的相互垂直的分量 $\kvwx$ 和 $\kvwy$ 已经知道，我们就可以求出 $\mathbf{v}_{\text{w}}$ 的大小和方向。首先，大小为

$$\begin{aligned}\kvw &= \sqrt{\kvwx^2 + \kvwy^2}\\ &= \sqrt{(-13.0\ \text{m/s})^2 + (-9.29\ \text{m/s})^2}\end{aligned}$$

所以

$$\kvw = 16.0\ \text{m/s}.$$

方向为：

$$\ktheta = \tan^{-1}(\kvwy / \kvwx) = \tan^{-1}(-9.29 / -13.0)$$

得出

$$\ktheta = 35.6^\circ.$$

讨论

风的速率和方向，与风对飞机的合速度所产生的显著影响是一致的，如图 3.44 所示。因为飞机是在与侧风和逆风的强烈组合相抗衡，所以它最终的合速度明显小于它的速度（相对于气团），而且前进的方向也不同。

请注意，在最近的这两个例题中，我们都通过选取一个其中一根轴平行于某一个速度的坐标系，使数学运算变得更容易。我们将反复发现，选取合适的坐标系会使解题更加容易。例如，在抛体运动中，我们总是使用一根轴平行于重力的坐标系。

相对速度与经典相对性原理

在把速度相加时，我们一直小心地指明：速度是相对于某个参考系的。这些速度称为相对速度。例如，飞机相对于气团的速度不同于它相对于地面的速度。这两者又都与飞机相对于其乘客的速度（它应当接近于零）大不相同。相对速度是相对论的一个方面，其定义是：研究彼此相对运动的不同观察者如何测量同一现象。

几乎每个人都听说过相对论，并立刻把它与 20 世纪最伟大的物理学家阿尔伯特·爱因斯坦（1879–1955）联系在一起。爱因斯坦以他的近代相对论这一理论彻底改变了我们对自然的看法，我们将在后面的章节中学习它。本节中的相对速度实际上是经典相对性原理的各个方面，该原理最早由伽利略和艾萨克·牛顿正确地论述。经典相对性原理仅限于速率小于光速约 1% 的情形——也就是说，小于 $3{,}000\ \text{km/s}$。我们在日常生活中遇到的大多数事物的运动都比这个速率慢。

让我们考虑一个例子，看看两个不同的观察者在伽利略很久以前分析过的一种情形中会看到什么。假设一艘行驶中的船的桅杆顶端有一名水手，掉落了他的双筒望远镜。它会落在甲板的什么位置？它会落在桅杆的底部，还是它会因为船在向前行驶而落在桅杆的后方？答案是：如果空气阻力可以忽略，双筒望远镜将落在桅杆的底部，即其释放点的正下方。现在让我们考虑，当双筒望远镜掉落时，两个不同的观察者会看到什么。一个观察者在船上，另一个在岸上。双筒望远镜相对于船上的观察者没有水平速度，所以他看到它们沿着桅杆笔直下落。（见图 3.45。）对岸上的观察者来说，双筒望远镜和船具有相同的水平速度，所以在双筒望远镜下落的过程中，二者都向前移动了相同的距离。这位观察者看到的是图 3.45 中所示的弯曲路径。尽管对不同的观察者来说路径看上去不同，但每个人看到的结果都相同——双筒望远镜落在桅杆的底部，而不是落在它的后方。要得到正确的描述，关键在于正确地指明相对于观察者的速度。

客机中掉落的硬币

例题 3.8 · 计算相对速度：航班乘客掉落硬币

一名航班乘客在飞机以 260 m/s 的速度飞行时掉落了一枚硬币。当硬币撞击到释放点下方 1.50 m 处的地板时，它的速度是多少：（a）相对于飞机测量？（b）相对于地球测量？

思路

这两个问题都可以用处理落体和抛体的方法来解决。在（a）问中，硬币相对于飞机的初速度为零，所以这个运动就是落体（一维）运动。在（b）问中，相对于地球，初速度为水平方向的 260 m/s，而重力是竖直的，所以这个运动是抛体运动。在两问中，最好都使用一个具有竖直轴和水平轴的坐标系。

（a）的解

利用已知信息，我们注意到初速度和初位置都为零，末位置为 1.50 m。末速度可以用下式求出：

$$\kvy^2 = \kvoy^2 - 2\kg(\ky - \kyo).$$

把已知量代入方程，我们得到

$$\kvy^2 = 0^2 - 2(9.80\ \text{m/s}^2)(-1.50\ \text{m} - 0\ \text{m}) = 29.4\ \text{m}^2\text{/s}^2$$

得出

$$\kvy = -5.42\ \text{m/s}.$$

我们知道 29.4 的平方根有两个根：5.42 和 −5.42。我们取负根，因为我们知道该速度是向下的，而我们已把正方向定义为向上。相对于飞机，没有水平方向的初速度，也没有水平加速度，所以运动相对于飞机是笔直向下的。

（b）的解

因为相对于地面，初始竖直速度为零，而且竖直运动与水平运动相互独立，所以相对于地面，硬币的末竖直速度为 $\kvy = -5.42\ \text{m/s}$，与（a）问中求得的相同。与（a）问不同，现在速度有了水平分量。然而，由于没有水平加速度，初、末水平速度相同，且 $\kvx = 260\ \text{m/s}$。速度的 x 分量和 y 分量可以合成起来，求出末速度的大小：

$$\kv = \sqrt{\kvx^2 + \kvy^2}.$$

因此，

$$\kv = \sqrt{(260\ \text{m/s})^2 + (-5.42\ \text{m/s})^2}$$

得出

$$\kv = 260.06\ \text{m/s}.$$

方向由下式给出：

$$\ktheta = \tan^{-1}(\kvy / \kvx) = \tan^{-1}(-5.42 / 260)$$

所以

$$\ktheta = \tan^{-1}(-0.0208) = -1.19^\circ.$$

讨论

在（a）问中，相对于飞机的末速度，与硬币在地球上从静止释放并下落 1.50 m 时的末速度相同。这个结果符合我们的经验：飞机水平飞行时，机内物体的下落方式与飞机静止在地面上时相同。这个结果对行驶中的汽车同样成立。在（b）问中，地面上的观察者看到的硬币的运动大不相同。飞机一开始水平运动得如此之快，以致它的末速度仅仅比初速度稍大一点。我们再一次看到，在二维中，矢量不像普通的数那样相加——（b）问中的末速度 v 并不是 $(260 - 5.42)\ \text{m/s}$，而是 $260.06\ \text{m/s}$。速度的大小必须算到五位数字，才能看出它与飞机的速度有任何差别。在这个例题中，不同观察者（一个在飞机上，一个在地面上）所看到的运动，类似于前面讨论过的双筒望远镜从一艘行驶中的船的桅杆上掉落的情形，不同之处在于飞机的速度要大得多，所以两个观察者看到的路径非常不同。（见图 3.46。）此外，两个观察者都看到硬币竖直下落了 1.50 m，但地面上的那位还看到它向前运动了 144 m（这一计算留给读者）。因此，一个观察者看到的是竖直路径，另一个看到的是近乎水平的路径。

建立联系：相对论与爱因斯坦

由于爱因斯坦能够清楚地定义测量是如何进行的（有些测量涉及光），也由于光速对所有观察者都相同，其结果出人意料得令人惊叹。时间因观察者而异，能量以增加的质量的形式储存，还有更多的惊奇在等待着我们。
