量子数

量子化的物理特性——例如能量、电荷和角动量——如此重要，以至于它们都被赋予了名称和符号。量子化的实体的取值用量子数来表示，而支配它们的规则，对于确定自然界是什么、做什么，具有至关重要的意义。本节介绍一些较为重要的量子数和规则——它们都适用于化学、材料科学，并且远远超出了它们最初被发现时所在的原子物理学领域。我们再一次看到，物理学如何做出发现，使其他领域得以发展。

束缚系统的能态是量子化的，因为粒子的波长只能以某些特定的方式嵌入系统的边界之内。这一点在氢原子中得到了详细阐述，其允许的能量表示为 $\kEn\propto 1/n^{2}$，其中 $n = 1, 2, 3, \ldots$。我们把 $n$ 定义为主量子数，它标记系统的基本状态。能量最低的状态对应 $n = 1$，第一激发态对应 $n = 2$，依此类推。因此，主量子数的允许值为

$$n = 1, 2, 3, \ldots.$$

这不仅仅是一种编号方案，因为系统（例如氢原子）的能量可以表示为 $n$ 的某个函数，其他特性（例如氢原子的轨道半径）也是如此。

角动量的大小

角动量的大小是量子化的，这一事实最早是玻尔在研究氢原子时认识到的；现在已知它在一般情况下都成立。随着量子力学的发展，人们发现，角动量的大小 $\kL$ 只能取下列值

$$\kL = \sqrt{l(l+1)}\frac{h}{2\pi}\;(l = 0, 1, 2, \ldots, n-1)\text{,}$$

其中 $l$ 被定义为角量子数。原子中 $l$ 所遵循的规则写在括号中。给定 $n$，$l$ 的值可以是从零到 $n-1$ 的任意整数。例如，若 $n = 4$，则 $l$ 可以是 0、1、2 或 3。

请注意，当 $n = 1$ 时，$l$ 只能为零。这意味着氢的基态角动量实际上为零，而不是玻尔所提出的 $h/2\pi$。圆轨道的图景是不成立的，因为任何圆轨道都会有角动量。更为合理的图景是图 30.46 中给出的氢基态的概率云。电子实际上会在原子核内部及其附近度过一段时间。电子不会留在原子核内的原因，与海森伯不确定性原理有关——电子的能量必须过于巨大，才能被限制在原子核那么小的空间内。现在，氢的第一激发态为 $n = 2$，所以按照 $\kL = \sqrt{l(l+1)}\frac{h}{2\pi}$ 中的规则，$l$ 可以是 0 或 1。同样，对于 $n = 3$，$l$ 可以是 0、1 或 2。通常，说出 $l$ 的值（一个简单的整数），要比根据 $\kL = \sqrt{l(l+1)}\frac{h}{2\pi}$ 计算 $\kL$ 的值方便得多。例如，对于 $l = 2$，我们看到

$$\kL = \sqrt{2(2+1)}\frac{h}{2\pi} = \sqrt{6}\frac{h}{2\pi} = 0.390h = 2.58\times 10^{-34}\;\text{J}\cdot\text{s}.$$

直接说 $l = 2$ 要简单得多。

角动量的方向

正如塞曼效应中所认识到的，角动量的方向是量子化的。我们现在知道，这在所有情况下都成立。人们发现，角动量沿空间中某一方向（通常称为 $z$ 轴）的分量 $\kLz$ 只能取某些特定的值。空间中的这个方向必须与某种物理的东西相关联，例如该处磁场的方向。这是相对论的一个方面。如果没有任何东西像磁力那样随方向而变化，方向就没有意义。$\kLz$ 的允许值为

$$\kLz = m_l\frac{h}{2\pi}\;(m_l = -l, -l+1, \ldots, -1, 0, 1, \ldots, l-1, l)\text{,}$$

其中 $\kLz$ 是角动量的 $z$ 分量，$m_l$ 是磁量子数。括号中关于 $m_l$ 取值的规则是：它可以从 $-l$ 到 $l$，以 1 为间隔取值。例如，若 $l = 2$，则 $m_l$ 可以取五个值：–2、–1、0、1 和 2。每个 $m_l$ 对应的能量在有磁场存在时各不相同，因此它们与谱线分裂为分立的几部分有关，如上一节所讨论的。如果角动量的 $z$ 分量只能取某些特定的值，那么角动量就只能有某些特定的方向，如图 30.52 所示。

例题 30.3 · 允许的方向有哪些？

计算当 $l = 1$ 时，角动量矢量 $\kL$ 与 $z$ 轴之间可以形成的夹角，如图 30.52 所示。

思路

图 30.52 如往常一样表示矢量 $\kL$ 和 $\kLz$，箭头的长度与它们的大小成正比，并指向正确的方向。$\kL$ 和 $\kLz$ 构成一个直角三角形，$\kL$ 是斜边，$\kLz$ 是邻边。这意味着 $\kLz$ 与 $\kL$ 的比值就是所求的角的余弦。我们可以利用 $\kL = \sqrt{l(l+1)}\frac{h}{2\pi}$ 和 $\kLz = m\frac{h}{2\pi}$ 求出 $\kL$ 和 $\kLz$。

解

已知 $l = 1$，所以 $m_l$ 可以是 +1、0 或 −1。于是 $\kL$ 的值由 $\kL = \sqrt{l(l+1)}\frac{h}{2\pi}$ 给出。

$$\kL = \frac{\sqrt{l(l+1)}h}{2\pi} = \frac{\sqrt{2}h}{2\pi}$$

$\kLz$ 可以有三个值，由 $\kLz = m_l\frac{h}{2\pi}$ 给出。

$$\kLz = m_l\frac{h}{2\pi} = \begin{cases} \frac{h}{2\pi}, & m_l = +1 \\ 0, & m_l = 0 \\ -\frac{h}{2\pi}, & m_l = -1 \end{cases}$$

由图 30.52 可以看出，$\cos\ktheta = \kLz/\kL$，所以对于 $m_l = +1$，我们有

$$\cos\kthetaone = \frac{\kLz}{\kL} = \frac{\frac{h}{2\pi}}{\frac{\sqrt{2}h}{2\pi}} = \frac{1}{\sqrt{2}} = 0.707.$$

因此，

$$\kthetaone = \cos^{-1}0.707 = 45.0^\circ.$$

同样，对于 $m_l = 0$，我们求得 $\cos\kthetatwo = 0$；因此，

$$\kthetatwo = \cos^{-1}0 = 90.0^\circ.$$

而对于 $m_l = -1$，

$$\cos\kthetathree = \frac{\kLz}{\kL} = \frac{-\frac{h}{2\pi}}{\frac{\sqrt{2}h}{2\pi}} = -\frac{1}{\sqrt{2}} = -0.707,$$

所以

$$\kthetathree = \cos^{-1}(-0.707) = 135.0^\circ.$$

讨论

这些角度与图一致。只有相对于 $z$ 轴的角度是量子化的。只要 $\kL$ 与 $z$ 轴所成的角度合适，它就可以指向任何方向。因此，角动量矢量位于如图所示的圆锥上。这种行为在大尺度上是观察不到的。要看出对应原理在这里是如何成立的，请考虑：最小的角度（例题中的 $\kthetaone$）对应于 $m_l = 0$ 的最大值，即 $m_l = l$。对于这个最小的角度，

$$\cos\ktheta = \frac{\kLz}{\kL} = \frac{l}{\sqrt{l(l+1)}}\text{,}$$

当 $l$ 变得很大时，它趋近于 1。如果 $\cos\ktheta = 1$，则 $\ktheta = 0^\circ$。此外，对于大的 $l$，$m_l$ 有许多个值，所以当 $l$ 变得非常大时，所有的角度都成为可能。

内禀自旋角动量的大小和方向都是量子化的

还有两个需要立即关注的量子数。它们最初都是在研究原子光谱的精细结构时，针对电子发现的。现在已经确认，电子和其他基本粒子具有内禀自旋，大致类似于行星绕自身的轴旋转。这种自旋是粒子的基本特性，对于给定种类的粒子，只允许有一种大小的内禀自旋。内禀角动量是独立于轨道角动量而量子化的。此外，自旋的方向也是量子化的。已经发现，电子的内禀（内部）自旋角动量的大小 $s$ 由下式给出

$$\kSspin = \sqrt{s(s+1)}\frac{h}{2\pi}\;\text{(}s = 1/2\;\text{对电子而言),}$$

其中 $s$ 被定义为自旋量子数。这与 $\kL = \sqrt{l(l+1)}\frac{h}{2\pi}$ 中给出的 $\kL$ 的量子化非常相似，只是对于电子，$s$ 唯一允许的值是 1/2。

内禀自旋的方向是量子化的，正如轨道角动量的方向那样。自旋角动量的方向，沿空间中的某一方向（仍称为 $z$ 轴），只能取下列值

$$\kSz = m_s\frac{h}{2\pi}\;\left(m_s = -\frac{1}{2}, +\frac{1}{2}\right)$$

这适用于电子。$\kSz$ 是自旋角动量的 $z$ 分量，$m_s$ 是自旋磁量子数。对于电子，$s$ 只能为 1/2，而 $m_s$ 可以是 +1/2 或 –1/2。自旋磁量子数 $m_s = +1/2$ 称为自旋向上，而 $m_s = -1/2$ 称为自旋向下。这些如图 30.51 所示。

内禀自旋

在后面的章节中，我们将看到内禀自旋是所有亚原子粒子的一种特性。对某些粒子，$s$ 是半整数，而对另一些粒子，$s$ 是整数——半整数自旋粒子与整数自旋粒子之间存在着关键的差别。质子和中子与电子一样，$s = 1/2$，而光子的 $s = 1$，另一些称为 π 介子的粒子 $s = 0$，等等。

总结一下，系统的状态，例如一个电子在原子中的确切性质，是由它特定的量子数决定的。这些量子数以 $(n, l, m_l, m_s)$ 的形式表示——见表 30.1。对于原子中的电子，主量子数可以取值 $n = 1, 2, 3, \ldots$。一旦知道了 $n$，角量子数的取值就限定为 $l = 1, 2, 3, \ldots, n-1$。对于给定的 $l$ 值，磁量子数只能取值 $m_l = -l, -l+1, \ldots, -1, 0, 1, \ldots, l-1, l$。电子自旋与 $n$、$l$ 和 $m_l$ 无关，总是 $s = 1/2$。自旋磁量子数可以有两个值，$m_s = 1/2\;\text{或}\;-1/2$。

我们将会看到，本节讨论的量子数对范围很广的粒子和其他系统（例如原子核）都是有效的。有些量子数，例如内禀自旋，与亚原子粒子的基本分类有关，它们遵循的定律将使我们对物质的子结构及其相互作用有进一步的认识。
