玻尔与行星模型

伟大的丹麦物理学家尼尔斯·玻尔（1885–1962）立即利用了卢瑟福的原子的行星模型。（图 30.13。）玻尔确信它是正确的，并在 1912 年的部分时间待在卢瑟福的实验室。1913 年，回到哥本哈根后，他开始发表他关于最简单的原子——氢——的理论，该理论以原子的行星模型为基础。几十年来，人们提出了许多关于原子特性的问题。从大小到光谱，人们对原子已有许多了解，但用物理学定律加以解释的却很少。玻尔的理论解释了氢的原子光谱，并在量子力学中确立了新的、应用广泛的原理。

原子光谱之谜

如“能量的量子化”一节所述，一些小系统的能量是量子化的。一个多世纪以来，人们已经知道原子和分子的发射光谱与吸收光谱是分立的（或量子化的）。（见图 30.14。）麦克斯韦等人曾意识到，原子的光谱与其结构之间一定存在某种联系，类似于乐器的共振频率。但是，尽管许多伟大的头脑多年来不断努力，却没有人提出可行的理论。（当时有一个流传已久的笑话：任何关于原子光谱和分子光谱的理论，只要朝它扔一本数据书就会被推翻，光谱就是这么复杂。）爱因斯坦提出光子具有与其波长成正比的量子化的能量之后，就更加明显了：原子中的电子只能存在于分立的轨道上。

在某些情况下，人们已经能够设计出描述发射光谱的公式。正如你可能预料的那样，最简单的原子——只有一个电子的氢——具有相对简单的光谱。人们已在红外（IR）、可见光和紫外（UV）区观察到氢光谱，并观察到了几个线系的谱线。（见图 30.15。）这些线系以早期对它们作过特别深入研究的研究者命名。

所观测到的氢光谱波长可以用下面的公式计算：

$$\frac{1}{\klam} = R\left(\frac{1}{n_{\text{f}}^{2}} - \frac{1}{n_{\text{i}}^{2}}\right),$$

其中 $\klam$ 是所发射的电磁辐射的波长，$R$ 是里德伯常量，由实验测定为

$$R = 1.097\times 10^{7}/\text{m}\;(\text{或 m}^{-1}).$$

常量 $n_{\text{f}}$ 是与某个特定线系相联系的正整数。对于莱曼系，$n_{\text{f}} = 1$；对于巴耳末系，$n_{\text{f}} = 2$；对于帕邢系，$n_{\text{f}} = 3$；依此类推。莱曼系完全位于紫外区，而巴耳末系的一部分是可见光，其余部分在紫外区。帕邢系及其余所有线系都完全位于红外区。线系显然有无限多个，不过随着 $n_{\text{f}}$ 增大，它们越来越深入红外区，也变得难以观测。常量 $n_{\text{i}}$ 是正整数，但它必须大于 $n_{\text{f}}$。因此，对于巴耳末系，$n_{\text{f}} = 2$，$n_{\text{i}} = 3, 4, 5, 6, \ldots$。注意 $n_{\text{i}}$ 可以趋于无穷大。虽然波长方程中的公式只是为拟合数据而设计的一种“配方”，并不以物理原理为基础，但它确实暗含着更深层的意义。巴耳末最初只为他的线系设计了这个公式，后来人们发现，取不同的 $n_{\text{f}}$ 值，它就能描述所有其他线系。玻尔是第一个领悟这更深层意义的人。我们再次看到物理学中实验与理论之间的相互作用。在实验上，光谱已经确立无疑，人们找到了拟合实验数据的方程，但理论基础却缺失了。

例题 30.1 · 计算氢谱线的波干涉

对于第二条巴耳末线，在 $15^\circ$ 的角度上产生一级极大的光栅，其缝间距离是多少？

思路与概念

对于综合概念题，我们必须首先确定所涉及的物理原理。在本例中，我们需要知道（a）光的波长，以及（b）双缝图样出现干涉极大的条件。（a）部分涉及本章的一个主题，而（b）部分考虑的是“波动光学”中的波干涉内容。

（a）的解

氢光谱波长。巴耳末系要求 $n_{\text{f}} = 2$。该线系的第一条谱线取为 $n_{\text{i}} = 3$，因此第二条谱线的 $n_{\text{i}} = 4$。

这个计算只是对波长方程的直接应用。代入 $n_{\text{f}}$ 和 $n_{\text{i}}$ 的已定值，得

$$\begin{aligned}\frac{1}{\klam} &= R\left(\frac{1}{n_{\text{f}}^{2}} - \frac{1}{n_{\text{i}}^{2}}\right)\\ &= (1.097\times 10^{7}\;\text{m}^{-1})\left(\frac{1}{2^{2}} - \frac{1}{4^{2}}\right)\\ &= 2.057\times 10^{6}\;\text{m}^{-1}.\end{aligned}$$

取倒数求 $\klam$，得

$$\begin{aligned}\klam &= \frac{1}{2.057\times 10^{6}\;\text{m}^{-1}} = 486\times 10^{-9}\;\text{m}\\ &= 486\;\text{nm}.\end{aligned}$$

（a）的讨论

这确实是实验观测到的波长，对应于巴耳末系中第二条（蓝绿色）谱线。更令人印象深刻的是，同样简单的“配方”预言了氢光谱的所有谱线，包括后来的实验中观测到的新谱线。大自然在告诉我们什么？

（b）的解

双缝干涉（“波动光学”）。要获得双缝相长干涉，来自两条缝的波程差必须是波长的整数倍。这个条件由下面的方程表示：

$$\kd\sin\ktheta = m\klam,$$

其中 $\kd$ 是缝间距离，$\ktheta$ 是与光束原来方向的夹角。数 $m$ 是干涉的级次；在本例中 $m = 1$。解出 $\kd$ 并代入已知值，得

$$\kd = \frac{(1)(486\;\text{nm})}{\sin 15^\circ} = 1.88\times 10^{-6}\;\text{m}.$$

（b）的讨论

这个数与“量子物理学导论”一章的干涉例题中所用的数相近（也接近常用的衍射眼镜中的缝间距）。

玻尔对氢原子的解

玻尔能够利用基本的物理学、原子的行星模型以及一些非常重要的新假设，推导出氢光谱的公式。他的第一个假设是只有某些轨道是允许的：我们说原子中电子的轨道是量子化的。每个轨道的能量各不相同，电子吸收能量可以移到较高的轨道，发射能量则可以降到较低的轨道。如果轨道是量子化的，那么吸收或发射的能量也是量子化的，从而产生分立光谱。光子的吸收和发射是向原子输入和输出能量的主要方式之一。光子的能量是量子化的，其能量被解释为等于电子从一个轨道移到另一个轨道时的能量变化。写成方程，即

$$\kdE = h\kf = \kEini - \kEfin.$$

这里，$\kdE$ 是初、末轨道之间的能量变化，$h\kf$ 是被吸收或发射的光子的能量。改变轨道要涉及能量，这是相当合乎逻辑的（也就是说，是我们的日常经验所预期的）。例如，航天飞机要爬升到较高的轨道，就需要一股强大的能量。出乎预料的是，原子轨道竟然是量子化的。卫星或行星并不如此，只要有合适的能量，它们可以处于任何轨道。（见图 30.16。）

图 30.17 显示了一幅能级图，这是显示能态的一种方便方法。在目前的讨论中，我们把这些状态看作电子的允许能级。能量画在竖直方向上，最低的状态即基态在最下方，激发态在其上方。已知原子光谱中各谱线的能量，就有可能（尽管有时非常困难）确定原子的能级。能级图用于许多系统，包括分子和原子核。关于原子或任何其他系统的理论，必须根据该系统的物理学预言其能量。

量子化的角动量

玻尔足够聪明，找到了计算氢中电子轨道能量的方法。这是重要的第一步，后来已有所改进，但在这里重述一遍很有价值，因为它确实正确地描述了氢的许多特性。假定轨道是圆形的，玻尔提出，轨道上电子的角动量 $\kL$ 是量子化的，也就是说，它只有特定的分立的值。$\kL$ 的值由下式给出

$$\kL = \kme\kv\krn = n\frac{h}{2\pi}\;(n = 1, 2, 3, \ldots),$$

其中 $\kL$ 是角动量，$\kme$ 是电子的质量，$\krn$ 是第 $n$ 个轨道的半径，$h$ 是普朗克常量。注意角动量为 $\kL = \kI\kw$。对于半径 $\krad$ 处的小物体，$\kI = \km\krad^{2}$，$\kw = \kv/\krad$，所以 $\kL = (\km\krad^{2})(\kv/\krad) = \km\kv\krad$。量子化要求 $\km\kv\krad$ 的这个值只能等于 $h/2,\;2h/2,\;3h/2$等。当时玻尔自己也不知道角动量为什么应该是量子化的，但利用这一假设，他能够算出氢光谱中的能量，这是当时没有其他人做到过的。

从玻尔的假设出发，我们现在利用本书中已讲过的经典物理学，推导出氢原子的若干重要性质。我们首先注意到，使电子沿圆形路径运动的向心力由库仑力提供。为了更具一般性，我们指出这一分析对任何单电子原子都成立。所以，如果一个原子核有 $Z$ 个质子（氢的 $Z = 1$，氦的 $Z = 2$，等等）而只有一个电子，这种原子就称为类氢原子。类氢离子的光谱与氢相似，但由于电子与原子核之间的吸引力更大，而移向更高的能量。向心力的大小为 $\kme\kv^{2}/\krn$，而库仑力为 $k(Z\kqe)(\kqe)/\krn^{2}$。这里隐含的假设是，原子核比静止的电子质量更大，电子绕它运动。这与原子的行星模型一致。令二者相等，

$$k\frac{Z\kqe^{2}}{\krn^{2}} = \frac{\kme\kv^{2}}{\krn}\;(\text{库仑力} = \text{向心力}).$$

允许轨道的半径

角动量量子化已在前面的方程中给出。我们由该方程解出 $\kv$，代入上式，并整理表达式，得到轨道的半径。这样得到：

$$\krn = \frac{n^{2}}{Z}\kaB,\ \text{对于允许的轨道}\;(n = 1, 2, 3, \ldots),$$

其中 $\kaB$ 定义为玻尔半径，因为对于最低的轨道 $(n = 1)$ 和氢 $(Z = 1)$，$r_{1} = \kaB$。证明玻尔半径为下式，留待本章的“习题”去完成：

$$\kaB = \frac{h^{2}}{4\pi^{2} \kme k \kqe^{2}} = 0.529\times 10^{-10}\;\text{m}.$$

最后这两个方程可用来计算任何类氢原子中允许的（量子化的）电子轨道的半径。令人印象深刻的是，这个公式给出了氢的正确大小，实验测得氢的大小非常接近玻尔半径。前面的方程还告诉我们，轨道半径与 $n^{2}$ 成正比，如图 30.18 所示。

轨道能量

要得到电子轨道能量，先注意到电子的能量等于它的动能与势能之和。

动能就是我们熟悉的 $\kKE = (1/2)\kme\kv^{2}$，假定电子不是以相对论性的速率运动。电子的势能是电势能，即 $\kPEtot = \kqe\kV$，其中 $\kV$ 是电势，由看起来像点电荷的原子核产生。原子核带正电荷 $Z\kqe$；因此 $\kV = kZ\kqe/\krn$，这是回想前面关于点电荷产生的电势的方程。由于电子的电荷为负，我们看到 $\kPEtot = -kZ\kqe/\krn$。

这是类氢原子的轨道能量的公式。这里，$\kEobohr$ 是氢 $(Z = 1)$ 的基态能量 $(n = 1)$，由下式给出

$$\kEobohr = \frac{2\pi^{2}\kqe^{4} \kme k^{2}}{h^{2}} = 13.6\;\text{eV}.$$

因此，对于氢，

$$\kEn = -\frac{13.6\;\text{eV}}{n^{2}}\;(n = 1, 2, 3, \ldots).$$

图 30.19 显示了氢的能级图，它还说明了氢的各种光谱线系与能级之间的跃迁是怎样联系的。

电子的总能量是负的，因为电子束缚在原子核上，类似于身处坑中而没有足够的动能逃出。当 $n$ 趋于无穷大时，总能量变为零。这对应于没有动能的自由电子，因为 $n$ 很大时 $\krn$ 变得很大，电势能因而变为零。因此，使氢电离（从 –13.6 eV 变到 0，即成为非束缚的）需要 13.6 eV，这是一个经实验证实的数值。若给予更多的能量，电子就成为非束缚的并带有一些动能。例如，给氢基态中的电子 15.0 eV，就会把它从原子中剥离出来，并使它留有 1.4 eV 的动能。

玻尔的光谱公式

最后，我们来考虑在向下跃迁中发射的光子的能量。

常量 $R$ 就是里德伯常量。这样，我们利用玻尔的假设推导出了巴耳末多年前作为拟合实验数据的“配方”首先提出的公式。

我们看到，玻尔的氢原子理论回答了为什么这个先前已知的公式能描述氢光谱。这是因为能级与 $1/n^{2}$ 成正比，其中 $n$ 是非负整数。向下的跃迁释放能量，所以 $n_{\text{i}}$ 必须大于 $n_{\text{f}}$。各个线系由终止于同一能级的跃迁构成。对于莱曼系，$n_{\text{f}} = 1$——也就是说，所有的跃迁都终止于基态（另见图 30.19）。对于巴耳末系，$n_{\text{f}} = 2$，即所有的跃迁都终止于第一激发态；依此类推。曾经的“配方”如今有了物理学基础，而且有新东西正在浮现——角动量是量子化的。

玻尔理论的成就与局限

玻尔做到了此前没有人能做到的事。他不仅解释了氢的光谱，还从基本物理学出发正确地算出了原子的大小。他的一些想法具有广泛的适用性。在所有原子和分子中，电子的轨道能量都是量子化的。角动量是量子化的。电子不会像经典理论所预期的那样螺旋式地落入原子核（加速运动的电荷会辐射，因此按经典理论，电子的轨道会迅速衰减，电子会落在原子核上——物质将会坍缩）。这些都是重大的成就。

但是，玻尔的理论也有局限。它不能应用于多电子原子，即使是像双电子氦原子那样简单的原子也不行。玻尔的模型就是我们所说的半经典的。轨道是量子化的（非经典的），但被假定为简单的圆形路径（经典的）。随着量子力学的发展，人们清楚地认识到不存在定义明确的轨道；相反，存在的是概率云。玻尔的理论也没有解释为什么仔细观察时一些谱线是双重线（分裂为两条）。我们将更详细地研究量子力学的许多这些方面，但应当记住，玻尔并没有失败。相反，他在通往更多知识的道路上迈出了非常重要的几步，并为此后发展起来的全部原子物理学奠定了基础。
