来自 X 射线管的 X 射线

每种原子（或元素）都有其自身特有的电磁波谱。X 射线位于原子谱的高频端，同样也是该原子的特征。在本节中，我们探讨特征 X 射线及其若干重要应用。

我们此前把 X 射线作为电磁波谱的一部分，在“光子能量与电磁波谱”中讨论过。那一节说明了 X 射线管（一种专用的 CRT）如何产生 X 射线。从热灯丝发射出的电子被高电压加速，获得可观的动能，然后撞击阳极。

在 X 射线管的阳极中，有两种过程产生 X 射线。其一，电子减速时产生 X 射线，这种 X 射线称为轫致辐射，即制动辐射。其二是本质上属于原子层面的过程，产生特征 X 射线，之所以这样称呼，是因为它们是阳极材料所特有的。图 30.20 中的 X 射线谱是 X 射线管所产生者的典型，显示出一条宽阔的轫致辐射曲线，其上叠有特征 X 射线峰。

图 30.20 中的谱是在一段时间内收集的，其间有许多电子撞击阳极，每次撞击都可能有多种结果。轫致辐射中 X 射线能量的范围很宽，这表明入射电子的能量通常并不全部转化为光子能量。所产生的能量最高的 X 射线，是电子的全部能量都转化为光子能量的那一个。因此，加速电压与最大 X 射线能量由能量守恒联系起来。电势能转化为动能，然后再转化为光子能量，因此 $\kEmax = hf_{\text{max}} = \kqe\kV\text{.}$ 以电子伏为单位很方便。例如，100 kV 的加速电压所产生的 X 射线光子，其最大能量为 100 keV。

特征 X 射线

有些电子激发阳极中的原子。通过与原子的碰撞，它们沉积的能量中有一部分，使该原子的一个或多个内层电子被击入更高的轨道，或使该原子被电离。当阳极的原子退激发时，它们发射特征电磁辐射。其中能量最高的，是在内层空位被填充时产生的——也就是说，当一个 $n=1$ 或 $n=2$ 壳层电子被激发到更高能级，而另一个电子落入这个空位时。特征 X 射线（见“光子能量与电磁波谱”）是原子在内层空位被填充时发射的电磁（EM）辐射。图 30.21 给出一幅有代表性的能级图，说明了特征 X 射线的标记方式。当一个电子落入 $n=1$ 壳层空位而产生的 X 射线，如果来自相邻的更高能级，就称为 $K_{\alpha}$；也就是说，是 $n=2$ 到 $n=1$ 的跃迁。标记 $K, L, M, \ldots$ 来自较早的以字母标记壳层的做法，它从 $K$ 开始，而不是使用主量子数 1, 2, 3, …。当一个电子从 $n=3$ 壳层落入 $n=1$ 壳层空位时，产生能量更高的 $K_{\beta}$ X 射线；也就是说，是 $n=3$ 到 $n=1$ 的跃迁。类似地，当一个电子从 $n=3$ 壳层落入 $n=2$ 壳层时，就产生一条 $L_{\alpha}$ X 射线。这些 X 射线的能量取决于特定原子中电子态的能量，因而是该元素所特有的：每种元素都有它自己的一组 X 射线能量。这一性质可用来鉴别元素，例如，用来在环境样品或生物样品中查出某种元素的痕量（少量）。

例题 30.2 · 特征 X 射线能量

计算 X 射线管中钨阳极所发出的 $K_{\alpha}$ X 射线的近似能量。

思路

如何计算多电子原子中的能量？对于特征 X 射线，下面的近似计算是合理的。特征 X 射线是在内层空位被填充时产生的。内层电子比原子中的其他电子更靠近原子核，因而所受其他电子的净效应很小。这与带电导体内部发生的情形类似，其多余的电荷分布在表面上，因此在内部不产生电场。可以合理地假设内层电子具有类氢的能量，由 $\kEn=-\frac{Z^{2}}{n^{2}}\kEobohr\;(n=1, 2, 3, \ldots)$ 给出。如前所述，$K_{\alpha}$ X 射线由 $n=2$ 到 $n=1$ 的跃迁产生。由于填满的 $K$ 壳层中有两个电子，出现空位后会剩下一个电子，因此有效电荷将是 $Z-1$ 而不是 $Z$。对于钨，$Z=74$，所以有效电荷为 73。

解

$\kEn=-\frac{Z^{2}}{n^{2}}\kEobohr\;(n=1, 2, 3, \ldots)$ 给出类氢原子的轨道能量为 $\kEn=-(Z^{2}/n^{2})\kEobohr$，其中 $\kEobohr=13.6\;\text{eV}$。如前所述，有效的 $Z$ 为 73。现在，$K_{\alpha}$ X 射线能量由下式给出

$$E_{K_{\alpha}}=\kdE=\kEini-\kEfin=E_{2}-E_{1},$$

其中

$$E_{1}=-\frac{Z^{2}}{1^{2}}\kEobohr=-\frac{73^{2}}{1}(13.6\;\text{eV})=-72.5\;\text{keV}$$

且

$$E_{2}=-\frac{Z^{2}}{2^{2}}\kEobohr=-\frac{73^{2}}{4}(13.6\;\text{eV})=-18.1\;\text{keV.}$$

因此，

$$E_{K_{\alpha}}=-18.1\;\text{keV}-(-72.5\;\text{keV})=54.4\;\text{keV}.$$

讨论

如此大的光子能量，是重元素特征 X 射线的典型特征。与其他原子发射相比它很大，因为它是在内层空位被填充时产生的，而内层电子束缚得很紧。特征 X 射线能量随元素变重而逐渐增大，因为它们的能量近似按 $Z^{2}$ 增大。要产生这些内层空位，需要相当大的加速电压。就钨而言，至少需要 72.5 kV，因为其他壳层都已填满，不能简单地把一个电子撞到更高的已填满壳层上。钨是 X 射线管中常用的阳极材料；撞击电子的能量有如此之多被吸收，使其温度升高，以致需要钨这样的高熔点材料。

X 射线的医学及其他诊断用途

我们每个人都能说出 X 射线光子的诊断用途。其中包括牙科和医学上普遍使用的 X 射线，它们已成为医学诊断中不可或缺的一部分。（见图 30.23 和图 30.24。）X 射线还用于在机场检查我们的行李，如图 30.22 所示，也用于及早发现关键航空器部件中的裂纹。X 射线不仅是指高能光子的名词，它也指由 X 射线产生的图像，并且已成为一个人们熟悉的动词——被 X 射线检查（to be x-rayed）。

最常见的 X 射线图像是简单的影子。由于 X 射线光子具有很高的能量，它们能穿透对可见光不透明的材料。X 射线光子的能量越大，穿透的材料就越多。因此，拍胸部 X 射线时，X 射线管可在 50.0 kV 下工作，而要检查打着石膏的断腿，可能需要在 100 kV 下工作。穿透深度既与材料的密度有关，也与光子的能量有关。材料的密度越大，通过的 X 射线光子越少，影子就越暗。因此，X 射线擅长检测骨折，以及对其他生理结构成像，例如某些肿瘤，这些结构的密度与周围材料不同。由于它们很高的光子能量，X 射线会在材料中产生显著的电离，并损伤生物有机体中的细胞。现代的使用方式把患者受到的照射降到最低，并使他人完全不受照射。X 射线的生物效应将在下一章与其他类型的电离辐射（如由原子核产生的那些）一起探讨。

随着 X 射线能量的增大，康普顿效应（见“光子动量”）在 X 射线的衰减中变得更重要。此时，X 射线从原子的外层电子壳层上散射，使被逐出的电子获得一些动能，而自身损失能量。X 射线的衰减概率取决于存在的电子数（即材料的密度），也取决于材料的厚度。介质的化学成分（以其原子序数 $Z$ 表征）在这里并不重要。低能 X 射线提供更好的衬度（更清晰的图像）。然而，由于衰减更大、散射更少，它们更多地被较厚的材料所吸收。注入原子序数大的物质，如钡或碘，可获得更大的衬度。这样就能轻易看清含有该物质的身体部位（如胃肠道或腹部）的结构。

乳腺癌是全球女性死亡的第二大原因。早期发现可以非常有效，因此 X 射线诊断很重要。乳腺 X 射线照片不能诊断恶性肿瘤，只能提供乳房内有肿块或密度增大区域的证据。不同类型软组织对 X 射线的吸收非常相近，所以很难获得衬度；对较年轻的女性尤其如此，她们的乳房通常更致密。对于患乳腺癌风险更大的年长女性，乳房中较多的脂肪使肿块或肿瘤有更大的衬度。MRI（磁共振成像）近来被用作传统 X 射线的补充，以改进检测并消除假阳性。受检者所受 X 射线的辐射剂量将在后面的章节中讨论。

标准的 X 射线只给出物体的二维视图。致密的骨骼可能会遮住软组织或器官的图像。如果再从人的侧面拍一张 X 射线（第一张是从正面拍的），你就会获得更多信息。虽然在许多应用中影子图像就够用了，但借助现代技术可以产生精密得多的图像。图 30.25 显示了计算机断层扫描（CT）扫描仪的使用，它也称为计算机轴向断层扫描（CAT）扫描仪。X 射线沿一系列方向穿过患者身体（或身体某部位）的一个狭窄截面（称为层面）。患者另一侧由许多探测器组成的阵列记录这些 X 射线。然后，整个系统绕患者旋转，再拍摄另一幅图像，如此继续。X 射线管与探测器阵列机械地连接在一起，因此一起转动。对沿不同方向的 X 射线相对吸收量进行复杂的计算机图像处理，便产生细节极为丰富的图像。患者在一张台子上移动穿过扫描仪时，拍摄不同的层面。也可以用计算机分析不同层面的多幅图像，得到三维信息，有时还能突出特定类型的组织，如图 30.26 所示。G. 豪恩斯菲尔德（英国）和 A. 科马克（美国）因发展了计算机断层扫描，于 1979 年获得诺贝尔生理学或医学奖。

X 射线衍射与晶体学

由于 X 射线光子的能量很高，它们的波长相对较短。例如，例题 30.2 中 54.4 keV 的 $K_{\alpha}$ X 射线，其波长为 $\klam=h\kc/\kE=0.0228\;\text{nm}$。因此，典型的 X 射线光子遇到牙齿这样的宏观物体时，行为像光线一样，并产生清晰的影子；然而，由于原子的尺寸约为 0.1 nm，X 射线可用来探测原子和分子的位置、形状和大小。这一过程称为 X 射线衍射，因为它涉及 X 射线的衍射和干涉，产生的图样可经分析得到有关散射这些 X 射线的结构的信息。也许 X 射线衍射最著名的例子，是 1953 年一个在卡文迪什实验室工作的国际科学家团队发现了 DNA 的双螺旋结构——美国人詹姆斯·沃森、英国人弗朗西斯·克里克和出生于新西兰的莫里斯·威尔金斯。他们利用罗莎琳德·富兰克林获得的 X 射线衍射数据，率先辨明了对生命至关重要的 DNA 结构。为此，沃森、克里克和威尔金斯被授予 1962 年诺贝尔生理学或医学奖。对于罗莎琳德·富兰克林没有被列入获奖者这一问题，存在许多争论和争议。

图 30.27 显示了 X 射线被一块晶体散射所产生的衍射图样。这一过程称为 X 射线晶体学，因为它能给出有关晶体结构的信息，罗莎琳德·富兰克林为沃森和克里克提供的关于 DNA 的数据正属于这一类型。X 射线不仅证实了原子的大小和形状，还提供材料中原子排列的信息。例如，目前对高温超导体的研究涉及一些复杂的材料，其晶格排列对于获得超导材料至关重要。这些可以用 X 射线晶体学来研究。

从历史上看，X 射线被晶体的散射曾被用来证明 X 射线是高能的电磁波。自 1895 年发现 X 射线起，人们就怀疑如此，但直到 1912 年，德国人马克斯·冯·劳厄（1879–1960）才说服他的两位同事让 X 射线在晶体上散射。他推断，如果得到了衍射图样，那么 X 射线就一定是波，并且可以测定它们的波长。（当时，根据阿伏伽德罗常量的良好数值，各种晶体中原子的间距已相当清楚。）实验很有说服力，1914 年诺贝尔物理学奖授予了冯·劳厄，以表彰他提出的、导致证明 X 射线是电磁波的建议。1915 年，独一无二的父子组合——威廉·亨利·布拉格爵士和他的儿子威廉·劳伦斯·布拉格爵士——因发明 X 射线谱仪和当时新兴的 X 射线分析科学而共同获得诺贝尔奖。老布拉格在数学专业毕业后不久，就从英国移居澳大利亚。他在阿德莱德大学任职期间学习了物理学和化学。小布拉格出生在阿德莱德，但回到英国的卡文迪什实验室，从事 X 射线和中子晶体学的研究；他为沃森、克里克和威尔金斯解开 DNA 奥秘的工作提供了支持，也为马克斯·佩鲁茨获得 1962 年诺贝尔奖的血红蛋白结构研究提供了支持。在这里，我们再次看到物理学的赋能性质——建立仪器、设计实验，以及解开生物医学科学中的奥秘。

X 射线的其他一些用途将在后面的章节中学习。X 射线可用于治疗癌症，因为它们对细胞增殖有抑制作用。观测到的来自外层空间的 X 射线，有助于确定其来源的性质，这些来源如中子星，也许还有黑洞。核弹爆炸中产生的 X 射线，也可用来探测对这类武器进行的秘密大气层试验。X 射线可使原子激发，这些原子随后发荧光（发射特征电磁辐射），这使 X 射线荧光成为从艺术到考古等一系列领域中一种有价值的分析工具。
