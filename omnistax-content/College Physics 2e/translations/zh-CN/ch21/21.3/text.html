适用于任何电路的两条定则

许多复杂电路，例如图 21.21 中的电路，无法用“电阻器的串联与并联”和“电动势：端电压”中建立的串并联方法来分析。不过，有两条电路分析定则，可以用来分析任何电路，无论简单还是复杂。这两条定则是电荷守恒和能量守恒这两条定律的特例。它们称为基尔霍夫定律，以其提出者古斯塔夫·基尔霍夫（1824–1887）的名字命名。

基尔霍夫定律
  • 基尔霍夫第一定律——节点定则。流入一个节点的所有电流之和必须等于流出该节点的所有电流之和。
  • 基尔霍夫第二定律——回路定则。沿任一闭合电路路径（回路）一周，电势的变化的代数和必须为零。

下面先对这两条定则作出解释，然后给出应用基尔霍夫定律的解题提示，以及一道运用它们的例题。

基尔霍夫第一定律

基尔霍夫第一定律（节点定则）是电荷守恒在节点上的应用；图 21.22 对它作了说明。电流就是电荷的流动，而电荷是守恒的；因此，流入节点的电荷必定全部流出。基尔霍夫第一定律要求 $\kIcurone = \kIcurtwo + \kIcurthree$（见图）。这样的方程可以用来、也将会用来分析电路和求解电路问题。

建立联系：守恒定律

基尔霍夫定律用于电路分析，是守恒定律在电路中的应用。第一条定则是电荷守恒的应用，而第二条定则是能量守恒的应用。守恒定律即使用在某个具体应用中，例如电路分析，也是如此基本，以至于构成了该应用的基础。

基尔霍夫第二定律

基尔霍夫第二定律（回路定则）是能量守恒的应用。回路定则是用电势 $\kV$ 而不是势能来表述的，但二者是相关的，因为 $\text{PE}_{\text{elec}} = \kq\kV$。回想一下，电动势是电源在没有电流流动时的电势差。在闭合回路中，电动势所提供的任何能量，都必须由回路中的器件转化为其他形式，因为再没有别的方式能使能量转移进入或离开电路。图 21.23 说明了一个简单串联电路回路中的电势的变化。

基尔霍夫第二定律要求 $\kemf - \kIcur\krint - \kIcur\kResone - \kIcur\kRestwo = 0$。整理后为 $\kemf = \kIcur\krint + \kIcur\kResone + \kIcur\kRestwo$，这意味着电动势等于回路中各 $\kIcur\kRes$（电压）降之和。

应用基尔霍夫定律

应用基尔霍夫定律，我们得到一些方程，用它们可以求出电路中的未知量。未知量可以是电流、电动势或电阻。每应用一次定则，就得到一个方程。如果独立方程的个数与未知量的个数一样多，问题就可以求解。应用基尔霍夫定律时，你必须做出两个选择。这些选择决定了你应用定则所得方程中各个量的正负号。

  1. 应用基尔霍夫第一定律，即节点定则时，你必须标出每条支路中的电流，并确定它沿什么方向流动。例如，在图 21.21、图 21.22 和图 21.23 中，电流分别标为 $\kIcurone$、$\kIcurtwo$、$\kIcurthree$ 和 $\kIcur$，箭头表示它们的方向。这里没有风险，因为即使你选错了方向，求得的电流大小也是正确的，只是为负。
  2. 应用基尔霍夫第二定律，即回路定则时，你必须确定一个闭合回路，并决定沿哪个方向绕行，是顺时针还是逆时针。例如，在图 21.23 中，回路是沿与电流相同的方向（顺时针）绕行的。这里同样没有风险；沿相反的方向绕电路一周，会使方程中每一项的符号反转，这就像把方程两边都乘以 $-1$。

图 21.24 和下面几点，将帮助你在应用回路定则时把正负号取对。请注意，电阻器和电动势都是沿从 a 到 b 的方向绕行的。在许多电路中，需要构造不止一个回路。绕行每个回路时，电势的变化的符号必须前后一致。（见例题 21.5。）

  • 当沿与电流相同的方向绕行电阻器时，电势的变化为 $-\kIcur\kRes$。（见图 21.24。）
  • 当沿与电流相反的方向绕行电阻器时，电势的变化为 $+\kIcur\kRes$。（见图 21.24。）
  • 当沿从 $-$ 到 $+$ 的方向绕行电动势时（与它推动正电荷运动的方向相同），电势的变化为 $+\kemf$。（见图 21.24。）
  • 当沿从 $+$ 到 $-$ 的方向绕行电动势时（与它推动正电荷运动的方向相反），电势的变化为 $-\kemf$。（见图 21.24。）

例题 21.5 · 计算电流：运用基尔霍夫定律

求图 21.25 的电路中流动的各电流。

思路

这个电路相当复杂，无法用欧姆定律和串并联方法求出各电流——必须使用基尔霍夫定律。图中已将电流标为 $\kIcurone$、$\kIcurtwo$ 和 $\kIcurthree$，并对它们的方向作了假定。图上的各个位置已用字母 a 到 h 标出。在解中，我们将应用节点定则和回路定则，寻求三个独立方程，以便解出三个未知电流。

解

我们先在 a 点应用基尔霍夫第一定律，即节点定则。得

$$\kIcurone = \kIcurtwo + \kIcurthree,$$

因为 $\kIcurone$ 流入节点，而 $\kIcurtwo$ 和 $\kIcurthree$ 流出节点。在 e 点应用节点定则得到的恰是同一个方程，所以没有得到新的信息。这是含三个未知量的一个方程——需要三个独立方程，因此必须应用回路定则。

现在考虑回路 abcdea。从 a 到 b，我们沿与电流 $\kIcurtwo$ 相同的（假定）方向绕行 $\kRestwo$，所以电势的变化为 $-\kIcurtwo\kRestwo$。然后从 b 到 c，我们是从 $-$ 到 $+$，所以电势的变化为 $+\kemfone$。从 c 到 d 绕行内阻 $\krintone$，得到 $-\kIcurtwo\krintone$。从 d 回到 a 完成整个回路时，又是沿与其电流相同的方向绕行一个电阻器，得到一个电势的变化 $-\kIcurone\kResone$。

回路定则指出，电势的变化之和为零。因此，

$$-\kIcurtwo\kRestwo + \kemfone - \kIcurtwo\krintone - \kIcurone\kResone = -\kIcurtwo(\kRestwo + \krintone) + \kemfone - \kIcurone\kResone = 0.$$

把电路图中各电阻和电动势的值代入，并约去安培单位，得

$$-3\kIcurtwo + 18 - 6\kIcurone = 0.$$

现在把回路定则应用于 aefgha（我们也可以选 abcdefgha），同样得到

$$+\;\kIcurone\kResone + \kIcurthree\kResthree + \kIcurthree\krinttwo - \kemftwo = +\kIcurone\kResone + \kIcurthree(\kResthree + \krinttwo) - \kemftwo = 0.$$

注意，与另一个回路相比，符号是相反的，因为各元件是沿相反的方向绕行的。代入数值后，成为

$$+\;6\kIcurone + 2\kIcurthree - 45 = 0.$$

这三个方程足以解出三个未知电流。首先，由第二个方程解出 $\kIcurtwo$：

$$\kIcurtwo = 6 - 2\kIcurone.$$

再由第三个方程解出 $\kIcurthree$：

$$\kIcurthree = 22.5 - 3\kIcurone.$$

把这两个新方程代入第一个方程，就可以求出 $\kIcurone$ 的值：

$$\kIcurone = \kIcurtwo + \kIcurthree = (6 - 2\kIcurone) + (22.5 - 3\kIcurone) = 28.5 - 5\kIcurone.$$

合并各项，得

$$6\kIcurone = 28.5,$$

并且

$$\kIcurone = 4.75\ \text{A}.$$

把 $\kIcurone$ 的这个值代回第四个方程，得

$$\kIcurtwo = 6 - 2\kIcurone = 6 - 9.50$$ $$\kIcurtwo = -3.50\ \text{A}.$$

负号表示 $\kIcurtwo$ 的流动方向与图 21.25 中所假定的相反。

最后，把 $\kIcurone$ 的值代入第五个方程，得

$$\kIcurthree = 22.5 - 3\kIcurone = 22.5 - 14.25$$ $$\kIcurthree = 8.25\ \text{A}.$$

讨论

作为检验，我们注意到确有 $\kIcurone = \kIcurtwo + \kIcurthree$。也可以把所有数值代入 abcdefgha 回路的方程，来检验这些结果。

运用基尔霍夫定律的解题策略
  1. 务必画出一张清晰的电路图，以便在图上标出所有已知和未知的电阻、电动势和电流。如果某个电流未知，你必须为它指定一个方向。这对确定电势的变化取何种符号是必要的。如果你指定的方向不正确，求得的电流将是负值——并无妨碍。
  2. 对电路中的任一节点应用节点定则。每次应用节点定则，你得到的方程中都应含有一个在先前应用中未出现过的电流——否则，这个方程就是多余的。
  3. 对需要的若干个回路应用回路定则，以解出问题中的未知量。（独立方程的个数必须与未知量的个数一样多。）应用回路定则时，你必须选定绕回路的方向。然后，结合图 21.24，运用上面讨论的四条要点，仔细而前后一致地确定每个元件处电势的变化的符号。
  4. 解联立方程，求出未知量。这可能涉及许多代数步骤，需要仔细地反复检查。
  5. 检查答案是否合理、前后一致。数值应具有正确的数量级，既不能大得离谱，也不能小得几乎为零。符号应当合理——例如，任何电阻都不应为负。检查所得的值是否满足应用定则所得到的各个方程。例如，各电流应当满足节点定则。

本节的内容在理论上是正确的。我们应当能够通过测量电流和电压来验证它。事实上，用于进行这类测量的一些仪器，正是对迄今所学原理的直接应用，将在后面的几节中探讨。我们将会看到，由此得出一个非常基本、甚至意义深远的事实——测量会改变被测量的量。
