两种最简单的连接

大多数电路含有不止一个元件，称为电阻器，它限制电路中电荷的流动。对电荷流动的这种限制的度量称为电阻。电阻器最简单的组合是图 21.2 所示的串联和并联。电阻器组合的总电阻既取决于各个电阻器自身的阻值，也取决于它们的连接方式。

电阻器的串联

电阻器何时是串联的？只要电荷的流动（称为电流）必须依次流过各个器件，电阻器就是串联的。例如，若电流流过一个手持螺丝刀的人而进入地球，则图 21.2 中的 $\kResone$ 可以是螺丝刀杆的电阻，$\kRestwo$ 是其手柄的电阻，$\kResthree$ 是人体电阻，而 $\kResfour$ 是她的鞋的电阻。

图 21.3 显示了接在电压源上的串联的电阻器。总电阻等于各个电阻之和，这似乎是合理的，因为电流必须依次通过每一个电阻器。（这一事实对想要避免电击的人是有利的，他可以穿高电阻的橡胶底鞋来减小电流。如果其中一个电阻是通向某个用电器的、有故障的高电阻电源线，从而使工作电流减小，则这一事实就是不利的。）

为了验证串联的电阻确实相加，我们来考虑图 21.3 中每个电阻器上电功率的损失，称为电压降。

根据欧姆定律，当电流流过电阻器时，其两端的电压降 $\kV$ 由公式 $\kV = \kIcur\kRes$ 算出，其中 $\kIcur$ 等于以安培（A）为单位的电流，$\kRes$ 是以欧姆 $(Ω)$ 为单位的电阻。换一种思考方式，$\kV$ 是使电流 $\kIcur$ 流过电阻 $\kRes$ 所需的电压。

所以 $\kResone$ 两端的电压降为 $\kVone = \kIcur\kResone$，$\kRestwo$ 两端的为 $\kVtwo = \kIcur\kRestwo$，$\kResthree$ 两端的为 $\kVthree = \kIcur\kResthree$。这些电压之和等于电源的输出电压。

联系：守恒定律

串联和并联电阻表达式的推导，建立在能量守恒和电荷守恒这两条定律之上，它们指出，在任何过程中总电荷和总能量都是恒定的。这两条定律直接涉及一切电现象，将被反复用来解释各种具体效应以及电的一般行为。

由于全部电流都必须通过每一个电阻器，它就要经受每一个的电阻，所以串联的电阻就是简单地相加。

例题 21.1 · 计算电阻、电流、电压降和耗散功率：串联电路的分析

设图 21.3 中电池的输出电压为 $12.0\ \text{V}$，各电阻为 $\kResone = 1.00\ Ω$，$\kRestwo = 6.00\ Ω$，$\kResthree = 13.0\ Ω$。（a）总电阻是多少？（b）求电流。（c）计算每个电阻器上的电压降，并说明它们之和等于电源的输出电压。（d）计算每个电阻器所耗散的功率。（e）求电源的输出功率，并说明它等于各电阻器耗散的总功率。

（a）的思路与解

总电阻就是各个电阻之和，如下式所示：

$$\begin{aligned}\kRess &= \kResone + \kRestwo + \kResthree\\ &= 1.00\ Ω + 6.00\ Ω + 13.0\ Ω\\ &= 20.0\ Ω.\end{aligned}$$

（b）的思路与解

电流用欧姆定律 $\kV = \kIcur\kRes$ 求出。代入所加电压的值和总电阻，得到电路中的电流：

$$\kIcur = \frac{\kV}{\kRess} = \frac{12.0\ \text{V}}{20.0\ Ω} = 0.600\ \text{A}.$$

（c）的思路与解

电阻器上的电压，即 $\kIcur\kRes$ 压降，由欧姆定律给出。代入电流和第一个电阻的值，得到

$$\kVone = \kIcur\kResone = (0.600\ \text{A})(1.0\ Ω) = 0.600\ \text{V}.$$

同理，

$$\kVtwo = \kIcur\kRestwo = (0.600\ \text{A})(6.0\ Ω) = 3.60\ \text{V}$$

以及

$$\kVthree = \kIcur\kResthree = (0.600\ \text{A})(13.0\ Ω) = 7.80\ \text{V}.$$

（c）的讨论

三个 $\kIcur\kRes$ 压降之和为 $12.0\ \text{V}$，与预期一致：

$$\kVone + \kVtwo + \kVthree = (0.600 + 3.60 + 7.80)\ \text{V} = 12.0\ \text{V}.$$

（d）的思路与解

在直流电路中，计算电阻器所耗散的以瓦特（W）为单位的功率，最简便的方法是用焦耳定律 $\kP = \kIcur\kV$，其中 $\kP$ 是电功率。在本题中，每个电阻器中通过的都是同一个完整的电流。把欧姆定律 $\kV = \kIcur\kRes$ 代入焦耳定律，就得到第一个电阻器所耗散的功率为

$$\kPonepow = \kIcur^2\kResone = (0.600\ \text{A})^2(1.00\ Ω) = 0.360\ \text{W}.$$

同理，

$$\kPtwopow = \kIcur^2\kRestwo = (0.600\ \text{A})^2(6.00\ Ω) = 2.16\ \text{W}$$

以及

$$\kPthreepow = \kIcur^2\kResthree = (0.600\ \text{A})^2(13.0\ Ω) = 4.68\ \text{W}.$$

（d）的讨论

功率也可以用 $\kP = \kIcur\kV$ 或 $\kP = \frac{\kV^2}{\kRes}$ 来计算，其中 $\kV$ 是电阻器两端的电压降（而不是电源的完整电压）。得到的数值相同。

（e）的思路与解

计算电源的输出功率，最简便的方法是用 $\kP = \kIcur\kV$，其中 $\kV$ 是电源电压。这样得到

$$\kP = (0.600\ \text{A})(12.0\ \text{V}) = 7.20\ \text{W}.$$

（e）的讨论

请注意，各电阻器耗散的总功率也是 7.20 W，与电源输出的功率相同，这是巧合。也就是说，

$$\kPonepow + \kPtwopow + \kPthreepow = (0.360 + 2.16 + 4.68)\ \text{W} = 7.20\ \text{W}.$$

功率是单位时间内的能量（瓦特），所以能量守恒要求电源的输出功率等于各电阻器耗散的总功率。

电阻器串联的主要特点
  1. 串联电阻相加：$\kRess = \kResone + \kRestwo + \kResthree + \ldots$。
  2. 流过串联的每个电阻器的电流相同。
  3. 串联的各个电阻器并不各自得到电源的总电压，而是分担它。

电阻器的并联

图 21.4 显示了接在电压源上的并联电阻器。当每个电阻器都通过电阻可忽略的连接导线直接接到电压源上时，这些电阻器就是并联的。因此每个电阻器上所加的都是电源的完整电压。

每个电阻器所取用的电流，与它单独接在电压源上时相同（前提是该电压源没有过载）。例如，汽车的前照灯、收音机等等都是并联的，这样它们就能利用电源的完整电压，并且可以完全独立地工作。在你的住宅或任何建筑物中也是如此。（见图 21.4（b）。）

为了求出等效并联电阻 $\kResp$ 的表达式，我们来考虑流过的电流以及它们与电阻的关系。

这一关系给出的总电阻 $\kResp$ 小于各个电阻中最小的一个。（这一点将在下一个例题中看到。）当电阻器并联时，从电源流出的电流比其中任何一个单独接入时流过的都要大，因此总电阻更低。

例题 21.2 · 计算电阻、电流、耗散功率和输出功率：并联电路的分析

设图 21.4 中并联连接里电池的输出电压和电阻与前面考虑过的串联连接相同：$\kV = 12.0\ \text{V}$，$\kResone = 1.00\ Ω$，$\kRestwo = 6.00\ Ω$，$\kResthree = 13.0\ Ω$。（a）总电阻是多少？（b）求总电流。（c）计算每个电阻器中的电流，并说明它们之和等于电源输出的总电流。（d）计算每个电阻器所耗散的功率。（e）求电源的输出功率，并说明它等于各电阻器耗散的总功率。

（a）的思路与解

电阻器的并联组合的总电阻用下面的公式求出。代入已知值，得到

$$\frac{1}{\kResp} = \frac{1}{\kResone} + \frac{1}{\kRestwo} + \frac{1}{\kResthree} = \frac{1}{1.00\ Ω} + \frac{1}{6.00\ Ω} + \frac{1}{13.0\ Ω}.$$

于是，

$$\frac{1}{\kResp} = \frac{1.00}{Ω} + \frac{0.1667}{Ω} + \frac{0.07692}{Ω} = \frac{1.2436}{Ω}.$$

（注意，在这些计算中，每个中间结果都多保留了一位数字。）

我们必须把它取倒数，才能求出总电阻 $\kResp$。这样得到

$$\kResp = \frac{1}{1.2436}\ Ω = 0.8041\ Ω.$$

取正确的有效数字位数后，总电阻为 $\kResp = 0.804\ Ω.$

（a）的讨论

正如预期，$\kResp$ 小于最小的单个电阻。

（b）的思路与解

总电流可以由欧姆定律求出，把 $\kResp$ 代入作为总电阻。这样得到

$$\kIcur = \frac{\kV}{\kResp} = \frac{12.0\ \text{V}}{0.8041\ Ω} = 14.92\ \text{A}.$$

（b）的讨论

每个器件的电流 $\kIcur$ 都比同样的器件串联时大得多（见前面的例题）。含有并联连接的电路，其总电阻比串联的电阻器要小。

（c）的思路与解

各个电流很容易由欧姆定律算出，因为每个电阻器得到的都是完整的电压。于是，

$$\kIcurone = \frac{\kV}{\kResone} = \frac{12.0\ \text{V}}{1.00\ Ω} = 12.0\ \text{A}.$$

同理，

$$\kIcurtwo = \frac{\kV}{\kRestwo} = \frac{12.0\ \text{V}}{6.00\ Ω} = 2.00\ \text{A}$$

以及

$$\kIcurthree = \frac{\kV}{\kResthree} = \frac{12.0\ \text{V}}{13.0\ Ω} = 0.92\ \text{A}.$$

（c）的讨论

总电流是各个电流之和：

$$\kIcurone + \kIcurtwo + \kIcurthree = 14.92\ \text{A}.$$

这与电荷守恒是一致的。

（d）的思路与解

每个电阻器所耗散的功率可以用任何一个把功率与电流、电压和电阻联系起来的公式求出，因为这三个量都是已知的。我们用 $\kP = \frac{\kV^2}{\kRes}$，因为每个电阻器得到的都是完整的电压。于是，

$$\kPonepow = \frac{\kV^2}{\kResone} = \frac{(12.0\ \text{V})^2}{1.00\ Ω} = 144\ \text{W}.$$

同理，

$$\kPtwopow = \frac{\kV^2}{\kRestwo} = \frac{(12.0\ \text{V})^2}{6.00\ Ω} = 24.0\ \text{W}$$

以及

$$\kPthreepow = \frac{\kV^2}{\kResthree} = \frac{(12.0\ \text{V})^2}{13.0\ Ω} = 11.1\ \text{W}.$$

（d）的讨论

与串联到同一个电压源上相比，每个电阻器耗散的功率在并联时要高得多。

（e）的思路与解

总功率也可以用几种方法算出。选用 $\kP = \kIcur\kV$，并代入总电流，得到

$$\kP = \kIcur\kV = (14.92\ \text{A})(12.0\ \text{V}) = 179\ \text{W}.$$

（e）的讨论

各电阻器耗散的总功率也是 179 W：

$$\kPonepow + \kPtwopow + \kPthreepow = 144\ \text{W} + 24.0\ \text{W} + 11.1\ \text{W} = 179\ \text{W}.$$

这与能量守恒定律是一致的。

总体讨论

请注意，并联连接中的电流和功率都比同样的器件串联时大。

电阻器并联的主要特点
  1. 并联电阻由 $\frac{1}{\kResp} = \frac{1}{\kResone} + \frac{1}{\kRestwo} + \frac{1}{\kResthree} + \ldots$ 求出，并且它比组合中任何一个单独的电阻都小。
  2. 并联的每个电阻器上所加的都是电源的完整电压。（供电系统最常采用并联连接，为数不尽的用电设备提供相同的电压，并使它们能够独立工作。）
  3. 并联的电阻器并不各自得到总电流，而是分掉它。

串联与并联的组合

更复杂的电阻器连接，有时只是串联和并联的组合。这些连接很常见，尤其是在考虑导线电阻的时候。在那种情况下，导线电阻与其他并联的电阻是串联的。

用图 21.5 所示的方法，可以把串联与并联的组合化简为单个等效电阻。先把各个部分判定为串联或并联，化简为它们的等效电阻，再继续化简，直到只剩下一个电阻。这个过程更多的是费时间，而不是难。

图 21.6 所示的串联与并联电阻的最简单组合，也是最有启发性的，因为它出现在许多应用中。例如，$\kResone$ 可以是从汽车蓄电池到其用电设备的导线的电阻，而这些用电设备是并联的。$\kRestwo$ 和 $\kResthree$ 可以是起动机和一盏乘客舱灯。我们前面假定导线电阻可以忽略，但当它不可忽略时，会产生重要的影响，下一个例题将说明这一点。

例题 21.3 · 计算电阻、$\kIcur\kRes$ 压降、电流和耗散功率：串联与并联电路的组合

图 21.6 显示的是前面两个例题中的电阻器以另一种方式连接——串联与并联的组合。我们可以把 $\kResone$ 看作通向 $\kRestwo$ 和 $\kResthree$ 的导线的电阻。（a）求总电阻。（b）$\kResone$ 上的 $\kIcur\kRes$ 压降是多少？（c）求通过 $\kRestwo$ 的电流 $\kIcurtwo$。（d）$\kRestwo$ 耗散的功率是多少？

（a）的思路与解

为了求总电阻，我们注意到 $\kRestwo$ 和 $\kResthree$ 是并联的，而它们的组合 $\kResp$ 与 $\kResone$ 是串联的。因此这一组合的总（等效）电阻为

$$\kRestot = \kResone + \kResp.$$

首先，用电阻器并联的公式并代入已知值，求出 $\kResp$：

$$\frac{1}{\kResp} = \frac{1}{\kRestwo} + \frac{1}{\kResthree} = \frac{1}{6.00\ Ω} + \frac{1}{13.0\ Ω} = \frac{0.2436}{Ω}.$$

取倒数得到

$$\kResp = \frac{1}{0.2436}\ Ω = 4.11\ Ω.$$

于是总电阻为

$$\kRestot = \kResone + \kResp = 1.00\ Ω + 4.11\ Ω = 5.11\ Ω.$$

（a）的讨论

这一组合的总电阻介于纯串联值和纯并联值（分别为 $20.0\ Ω$ 和 $0.804\ Ω$）之间，这两个值是前面两个例题中同样的电阻器在两种连接下求得的。

（b）的思路与解

为了求 $\kResone$ 上的 $\kIcur\kRes$ 压降，我们注意到完整的电流 $\kIcur$ 流过 $\kResone$。因此它的 $\kIcur\kRes$ 压降为

$$\kVone = \kIcur\kResone.$$

我们必须先求出 $\kIcur$，才能算出 $\kVone$。总电流 $\kIcur$ 用整个电路的欧姆定律求出。即

$$\kIcur = \frac{\kV}{\kRestot} = \frac{12.0\ \text{V}}{5.11\ Ω} = 2.35\ \text{A}.$$

把它代入上面的表达式，得到

$$\kVone = \kIcur\kResone = (2.35\ \text{A})(1.00\ Ω) = 2.35\ \text{V}.$$

（b）的讨论

加在 $\kRestwo$ 和 $\kResthree$ 上的电压比总电压小，小的量为 $\kVone$。当导线电阻很大时，它会显著影响 $\kRestwo$ 和 $\kResthree$ 所代表的器件的工作。

（c）的思路与解

为了求通过 $\kRestwo$ 的电流，我们必须先求出加在它上面的电压。我们把这个电压称为 $\kVp$，因为它加在电阻器的并联组合上。同时加在 $\kRestwo$ 和 $\kResthree$ 上的电压减小了 $\kVone$，因此它是

$$\kVp = \kV - \kVone = 12.0\ \text{V} - 2.35\ \text{V} = 9.65\ \text{V}.$$

现在通过电阻 $\kRestwo$ 的电流 $\kIcurtwo$ 用欧姆定律求出：

$$\kIcurtwo = \frac{\kVp}{\kRestwo} = \frac{9.65\ \text{V}}{6.00\ Ω} = 1.61\ \text{A}.$$

（c）的讨论

这个电流小于前面那个并联电路例题中 $\kRestwo$ 并联到电池上时流过它的 2.00 A。

（d）的思路与解

$\kRestwo$ 所耗散的功率为

$$\kPtwopow = (\kIcurtwo)^2\kRestwo = (1.61\ \text{A})^2(6.00\ Ω) = 15.5\ \text{W}.$$

（d）的讨论

这个功率小于这个电阻器并联到 12.0 V 电源上时所耗散的 24.0 W。

导线电阻的作用

这最后一个例题的一个推论是，导线中的电阻会减小传送到电阻器的电流和功率。如果导线电阻相对较大，例如在一根旧损的（或很长的）延长线中，这种损失就可能很显著。如果取用的电流很大，导线中的 $\kIcur\kRes$ 压降也可能很显著。

例如，当你在冰箱里翻找东西、电动机起动时，冰箱灯会暂时变暗。同样，发动汽车的发动机时，你可以看到乘客舱灯变暗（不过这也可能是由电池本身内部的电阻造成的）。

在这些大电流的情形中发生的事情如图 21.7 所示。$\kResthree$ 所代表的器件具有很低的电阻，所以它一接通，就有很大的电流流过。这个增大的电流使 $\kResone$ 所代表的导线中的 $\kIcur\kRes$ 压降变大，从而降低了灯泡（即 $\kRestwo$）两端的电压，它于是明显变暗。

串联与并联电阻器的解题策略
  1. 画一幅清楚的电路图，标出所有电阻器和电压源。这一步包括列出题目的已知量，因为它们都已标在你的电路图中。
  2. 确切地找出题目中需要求的量（找出未知量）。列一张书面清单是有用的。
  3. 判定电阻器是串联、并联，还是串联与并联两者的组合。检查电路图来作出这一判断。如果同一电流必须依次通过这些电阻器，它们就是串联的。
  4. 用串联或并联连接的相应主要特点清单来求解未知量。串联有一张清单，并联有另一张。如果你的题目含有串联与并联的组合，就像本节及其例题中所做的那样，通过逐个考虑串联或并联连接的各个部分，分步化简。特别提示：求 $\kResp$ 时，取倒数必须小心。
  5. 检查答案是否合理、自洽。单位和数值结果必须合理。例如，串联总电阻应当更大，而并联总电阻应当更小。同样的器件并联时的功率应当比串联时大，等等。
