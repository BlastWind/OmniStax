RC 电路

使用闪光照相机时，给为闪光供电的电容器充电要花几秒钟。闪光发出时，电容器在不到一秒的极短时间内放电。为什么充电比放电花的时间长？这个问题，以及其他一些涉及电容器充电和放电的现象，将在本节中讨论。

RC 电路是含有一个电阻器 $\kRes$ 和一个电容器 $\kCap$ 的电路。电容器是储存电荷的电学元件。

图 21.37 显示了一个简单的 RC 电路，它采用 DC（直流电）电压源。电容器起初未充电。开关一闭合，电流就流向和流出这个起初未充电的电容器。随着电容器极板上的电荷增多，每块极板上同种电荷的排斥作用使电荷的流动受到越来越大的阻碍。

就电压而言，这是因为电容器两端的电压由 $\kVc = \kQch/\kCap$ 给出，其中 $\kQch$ 是每块极板上储存的电荷量，$\kCap$ 是电容。这个电压与电池相抗衡，从零增大，充满电时达到最大电动势。于是，电流从初始值 $\kIocur = \frac{\kemf}{\kRes}$ 减小到零，此时电容器上的电压达到与电动势相同的值。没有电流时，就没有 $\kIcur\kRes$ 电压降，因此电容器上的电压此时必定等于电压源的电动势。这也可以用基尔霍夫第二定律（回路定则）来解释，该定律在“基尔霍夫定律”中讨论过，它指出沿任意闭合回路电势变化的代数和必定为零。

初始电流为 $\kIocur = \frac{\kemf}{\kRes}$，因为全部 $\kIcur\kRes$ 电压降都在电阻上。因此，电阻越小，给定的电容器充电就越快。请注意，电压源的内阻包含在 $\kRes$ 之中，电容器和连接导线的电阻也是如此。在上述闪光照相机的情形中，当给照相机供电的电池开始耗尽时，它们的内阻增大，从而使电流减小，使做好下一次闪光准备所需的时间变长。

电容器上的电压起初为零，开始时上升得很快，因为初始电流最大。图 21.37（b）显示了电容器电压随时间（$\kt$）变化的图线，从开关在 $\kt = 0$ 时闭合开始。电压渐近地趋近电动势，因为它越接近电动势，流过的电流就越小。通过电阻器 $\kRes$ 给电容器 $\kCap$ 充电时，用微积分导出的电压随时间变化的方程为

$$\kV = \kemf\left(1 - e^{-\kt/\kRes\kCap}\right)\quad\text{(充电),}$$

其中 $\kV$ 是电容器两端的电压，电动势等于直流电压源的电动势，指数项中的 $e = 2.718\ldots$ 是自然对数的底。请注意，$\kRes\kCap$ 的单位是秒。我们定义

$$\ktauRC = \kRes\kCap,$$

其中 $\ktauRC$（希腊字母 tau）称为 RC 电路的时间常量。如前所述，较小的电阻 $\kRes$ 使电容器充电更快。这是合理的，因为通过较小的电阻的电流更大。电容器 $\kCap$ 越小，给它充电所需的时间越少，这也是合理的。这两个因素都包含在 $\ktauRC = \kRes\kCap$ 之中。

更定量地，考虑 $\kt = \ktauRC = \kRes\kCap$ 时会发生什么。此时电容器上的电压为

$$\kV = \kemf(1 - e^{-1}) = \kemf(1 - 0.368) = 0.632 \cdot \kemf.$$

这意味着，在这段时间 $\ktauRC = \kRes\kCap$ 内，电压上升到其最终值的 0.632。在接下来的时间 $\ktauRC$ 内，电压将上升剩余部分的 0.632。指数函数的特点是：最终值永远达不到，但每经过一段时间 $\ktauRC$，就达到距该值剩余部分的 0.632。因此，只需经过几倍的时间常量 $\ktauRC$，就几乎达到最终值，如图 21.37（b）中的图线所示。

电容器的放电

电容器通过电阻器放电的过程与此类似，如图 21.38 所示。起初，电流为 $\kIocur = \frac{\kVzero}{\kRes}$，由电容器上的初始电压 $\kVzero$ 驱动。随着电压降低，电流以及放电速率也随之减小，这意味着 $\kV$ 还有另一个指数公式。用微积分可得，通过电阻器 $\kRes$ 放电的电容器 $\kCap$ 上的电压 $\kV$ 为

$$\kV = \kVzero\, e^{-\kt/\kRes\kCap}\quad\text{(放电).}$$

图 21.38（b）中的图线就是这种指数式衰减的一个例子。时间常量仍然是 $\ktauRC = \kRes\kCap$。较小的电阻 $\kRes$ 使电容器在较短的时间内放电，因为电流更大。同样，较小的电容放电所需的时间更少，因为储存的电荷更少。开关闭合后的第一个时间间隔 $\ktauRC = \kRes\kCap$ 内，电压降到其初始值的 0.368，因为 $\kV = \kVzero \cdot e^{-1} = 0.368\kVzero$。

在每个相继的时间 $\ktauRC$ 内，电压都降到其前一个值的 0.368。经过几倍的 $\ktauRC$ 之后，电压变得非常接近零，如图 21.38（b）中的图线所示。

现在我们可以解释，为什么我们设想的情形中的闪光照相机充电比放电花的时间长得多：充电时的电阻明显大于放电时的电阻。电池的内阻占了充电时电阻的大部分。随着电池老化，不断增大的内阻使充电过程变得更慢。（你可能已经注意到了这一点。）

闪光的放电是通过闪光管中电阻很低的电离气体进行的，进行得非常迅速。闪光照片（如图 21.39）能够捕捉快速运动的短暂一瞬，因为闪光的持续时间可以不到一微秒。这样的闪光可以做得极其强烈。

第二次世界大战期间，夜间侦察照片是从空中拍摄的，一次闪光就能照亮超过一平方千米的敌方领土。闪光时间极短，消除了由监视飞机的运动造成的模糊。如今，强闪光灯的一个重要用途是向激光器泵入能量。短而强的闪光可以使激光器迅速获得能量，并让它以另一种形式重新发射能量。

例题 21.6 · 综合概念问题：计算电容器的大小——频闪灯

高速闪光摄影是“Doc”埃杰顿在 20 世纪 30 年代开创的，当时他是麻省理工学院的电气工程教授。你也许见过他的作品中那些惊人的照片：运动中的蜂鸟、溅落在桌上的一滴牛奶，或是穿透苹果的子弹（见图 21.39）。要使运动停住并拍下这些照片，需要一次强度很高、极短的脉冲闪光，如本节前面所提到的。

假设想要拍下一颗子弹（以 $5.0 \times 10^2\ \text{m/s}$ 的速率运动）穿过苹果的照片。闪光的持续时间与 RC 时间常量 $\ktauRC$ 有关。要使拍摄成功，若闪光管的电阻为 $10.0\ Ω$，则 RC 电路中需要多大的电容器？假设苹果是一个直径为 $8.0 \times 10^{-2}\ \text{m}$ 的球体。

思路

我们先找出所涉及的物理原理。这个例子涉及频闪灯，如上面所讨论的。图 21.38 显示了这个探测装置的电路。频闪灯的特征时间 $\ktauRC$ 由 $\ktauRC = \kRes\kCap$ 给出。

解

我们想求 $\kCap$，但不知道 $\ktauRC$。我们希望闪光只在子弹穿过苹果的时间内亮着。所以需要用到描述距离 $\kx$、速度 $\kv$ 和时间 $\kt$ 之间关系的运动学方程：

$$\kx = \kv\kt\quad\text{或}\quad \kt = \frac{\kx}{\kv}.$$

子弹的速度给定为 $5.0 \times 10^2\ \text{m/s}$，距离 $\kx$ 为 $8.0 \times 10^{-2}\ \text{m}$。于是，穿越时间为

$$\kt = \frac{\kx}{\kv} = \frac{8.0 \times 10^{-2}\ \text{m}}{5.0 \times 10^{2}\ \text{m/s}} = 1.6 \times 10^{-4}\ \text{s}.$$

我们令穿越时间 $\kt$ 的这个值等于 $\ktauRC$。因此，

$$\kCap = \frac{\kt}{\kRes} = \frac{1.6 \times 10^{-4}\ \text{s}}{10.0\ Ω} = 16\ \mu\text{F}.$$

（注：电容 $\kCap$ 通常以法拉（F）为单位测量，法拉定义为库仑每伏特。由该方程可见，$\kCap$ 也可以用秒每欧姆作单位来表示。）

讨论

闪光间隔 $160\ \mu\text{s}$（即子弹的穿越时间）如今相对容易实现。频闪灯开辟了从科学到娱乐的新天地。1963 年，沃伦委员会关于约翰·F·肯尼迪总统遇刺的报告用到了这张苹果和子弹照片中的信息，以确认只发射了一颗子弹。

用于定时的 RC 电路

RC 电路常用于定时。一个平常的例子见于现代汽车上随处可见的间歇式刮水器系统。两次刮水之间的时间是通过调节 RC 电路中的电阻来改变的。RC 电路的另一个例子见于新奇首饰、万圣节服装，以及各种带有电池供电闪烁灯的玩具。（定时电路见图 21.40。）

RC 电路用于定时的一个更为关键的用途是在人工起搏器中，它用来控制心率。心率通常由窦房结（SA 结）产生的电信号控制，窦房结位于右心房腔的壁上。这使肌肉收缩并泵出血液。有时心律不正常，心搏过快或过慢。

人工起搏器植入心脏附近，在需要时以合适的时间常量向心脏提供电信号。起搏器带有检测身体运动和呼吸的传感器，以便在运动时提高心率，满足身体对血液和氧气增加的需求。

例题 21.7 · 计算时间：心脏除颤器中的 RC 电路

心脏除颤器通过使电容器经过一名事故受害者的躯干放电，来使她复苏。图 21.38 中可以看到这个电路的简化版本。（a）如果使用 $8.00\text{-}\mu\text{F}$ 的电容器，且通过她身体的路径电阻为 $1.00 \times 10^{3}\ Ω$，时间常量是多少？（b）如果初始电压为 10.0 kV，要多长时间才能降到 $5.00 \times 10^{2}\ \text{V}$？

思路

由于电阻和电容已经给出，把它们相乘就能直接得到（a）中所求的时间常量。要求出时间，使电压降到 $5.00 \times 10^{2}\ \text{V}$，我们把初始电压反复乘以 0.368，直到得到小于或等于 $5.00 \times 10^{2}\ \text{V}$ 的电压。每乘一次，对应 $\ktauRC$ 秒的时间。

（a）的解

时间常量 $\ktauRC$ 由方程 $\ktauRC = \kRes\kCap$ 给出。代入电阻和电容的已知值（并记住法拉的单位可以表示为 $\text{s}/Ω$），得

$$\ktauRC = \kRes\kCap = (1.00 \times 10^{3}\ Ω)(8.00\ \mu\text{F}) = 8.00\ \text{ms}.$$

（b）的解

在最初的 8.00 ms 内，电压（10.0 kV）降到其初始值的 0.368。即：

$$\kV = 0.368\kVzero = 3.680 \times 10^{3}\ \text{V，当 } \kt = 8.00\ \text{ms 时}.$$

（请注意，每一步中间计算我们都多保留一位数字。）再过 8.00 ms，我们再乘以 0.368，电压为

$$\begin{aligned}\kV' &= 0.368\kV\\ &= (0.368)(3.680 \times 10^{3}\ \text{V})\\ &= 1.354 \times 10^{3}\ \text{V，当 } \kt = 16.0\ \text{ms 时}.\end{aligned}$$

同样，再过 8.00 ms，电压为

$$\begin{aligned}\kV'' &= 0.368\kV' = (0.368)(1.354 \times 10^{3}\ \text{V})\\ &= 498\ \text{V，当 } \kt = 24.0\ \text{ms 时}.\end{aligned}$$

讨论

所以，仅过了 24.0 ms，电压就降到了 498 V，即其原始值的 4.98%。这样短的时间在心脏除颤中很有用，因为短暂而强烈的电流会引起心脏短暂而有效的收缩。心脏除颤器中的实际电路比图 21.38 中的略微复杂一些，以补偿将在“磁学”中讲到的磁效应和交流效应。
