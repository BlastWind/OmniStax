干涉与噪声的消除

干涉是波的标志，所有的波都表现出相长干涉和相消干涉，与水波中所见的完全类似。事实上，证明某物“是一种波”的一种方法，就是观察干涉效应。因此，既然声音是一种波，我们就预期它会表现出干涉；我们已经提到过几种这样的效应，例如两个相近的音同时演奏时产生的拍。

图 17.21 展示了对声波干涉的一种巧妙运用，用来消除噪声。人们正在考虑把利用相消干涉的主动降噪推广到更大的范围，用于商用飞机的整个客舱。为了获得相消干涉，要进行快速的电子分析，然后引入第二个声音，其极大值和极小值与传入的噪声恰好相反。流体中的声波是压强波，与帕斯卡原理一致；来自两个不同声源的压强像普通的数一样相加和相减；也就是说，正的和负的表压强相加后得到小得多的压强，产生强度较低的声音。虽然完全的相消干涉只在最简单的条件下才有可能，但用这种技术可以把噪声级降低 30 dB 或更多。

我们还能在哪里观察到声波干涉？所有声音的共振，例如乐器中的共振，都是由相长干涉和相消干涉引起的。只有共振频率发生相长干涉，形成驻波，其余频率则发生相消干涉，因而不存在。从对着瓶口吹气发出的呜呜声，到小提琴共鸣箱的独特韵味，再到一位杰出歌手嗓音的辨识度，共振和驻波都起着至关重要的作用。

干涉

干涉是波如此基本的一个方面，以至于观察到干涉就证明了某物是一种波。光的波动性就是由显示干涉的实验确立的。类似地，当从晶体上散射的电子表现出干涉时，它们的波动性得到证实，而且与按光的某些波动特性、由对称性所作的预言恰好一致。

气柱的共振

假设我们把一支音叉拿在另一端封闭的管的一端附近，如图 17.22、图 17.23、图 17.24 和图 17.25 所示。如果音叉具有恰好合适的频率，管中的气柱就会响亮地共振，但在大多数频率下，它的振动很小。这一观察只是说明，气柱只有某些固有频率。这些图显示了在这些固有频率中最低的一个上，共振是如何形成的。一个扰动以声速沿管传下去，并在封闭端弹回。如果管具有恰好合适的长度，反射回来的声音就恰好在半个周期之后回到音叉处，并与音叉持续发出的声音发生相长干涉。入射的和反射的声音在管中形成如图所示的驻波。

波节和波腹

在管中形成的驻波在开口端有最大的空气位移（波腹），那里的运动不受约束；在封闭端则没有位移（波节），那里空气的运动被阻止。从波节到波腹的距离是四分之一波长，它等于管的长度；因此，$\klam = 4\kLlen$。在管的封闭端或靠近封闭端处引入的振动，也能产生同样的共振，如图 17.26 所示。最好把它看作气柱的一种固有振动，而不论它是如何被激起的。

基频、泛音和谐波

既然开口端可以有最大的空气位移，而封闭端没有，那么还有其他更短的波长可以在管中共振，例如图 17.27 所示的那一个。这里驻波在管中占有其波长的四分之三，即 $\kLlen = (3/4)\klamprime$，所以 $\klamprime = 4\kLlen/3$。继续这一过程，就会发现一整个系列波长更短、频率更高的声音可以在管中共振。对于任何系统中的共振，我们都使用专门的术语。最低的共振频率称为基频，所有更高的共振频率则称为泛音。所有共振频率都是基频的整数倍，它们统称为谐波。基频是一次谐波，第一泛音是二次谐波，依此类推。图 17.28 显示了一端封闭的管中的基频和前三个泛音（前四个谐波）。

基频和泛音可以以多种组合同时存在。例如，小号上的中央 C 与单簧管上的中央 C，声音截然不同，而这两种乐器都是一端封闭的管的变形。基频是相同的（而且通常最强），但泛音及其强度的搭配不同，并且可由演奏者细加调节。正是这种搭配，使各种乐器（以及人的嗓音）具有各自独特的特性，无论它们有的是气柱、弦、共鸣箱，还是鼓面。事实上，我们说话的很大一部分，是由塑造喉咙和口腔形成的腔体、并摆放舌头的位置来调节基频和泛音的组合所决定的。例如，可以使简单的共鸣腔与元音的声音共振。（见图 17.29。）男性在青春期时，喉增大，共鸣腔的形状改变，使得不同性别在说话时的主要频率有所不同。

一端封闭的管的共振频率

现在让我们在一端封闭的简单管的共振频率中寻找规律。

因为 $\kfprime = 3\kf$，所以我们把第一泛音称为三次谐波。继续这一过程，我们看到一种可以用一个表达式概括的规律。一端封闭的管的共振频率为

$$\kfn = n\frac{\kvw}{4\kLlen}\text{,}\;n = 1, 3, 5\text{,}$$

其中 $\kfone$ 是基频，$\kfthree$ 是第一泛音，依此类推。有趣的是，共振频率取决于声速，因而取决于温度。正是这种依赖关系，使得音乐家在把自己的管乐器与其他类型的乐器一起演奏之前，通常要先让管乐器达到室温。

例题 17.5 · 求基频为 128 Hz 的管的长度

（a）在空气温度为 $22.0^\circ\text{C}$ 的一天，一端封闭的管应有多大的长度，才能使它的基频为 128 Hz（中央 C 以下的 C）？

（b）它的第四泛音的频率是多少？

思路

长度 $\kLlen$ 可以由 $\kfn = n\frac{\kvw}{4\kLlen}$ 中的关系求出，但我们首先需要求出声速 $\kvw$。

（a）的解

  1. 确定已知量：
    • 基频为 128 Hz
    • 空气温度为 $22.0^\circ\text{C}$
  2. 用 $\kfn = n\frac{\kvw}{4\kLlen}$ 求基频（$n = 1$）。 $$\kfone = \frac{\kvw}{4\kLlen}$$
  3. 把这个方程对长度求解。 $$\kLlen = \frac{\kvw}{4\kfone}$$
  4. 用 $\kvw = (\text{331 m/s})\sqrt{\frac{\kTemp}{\text{273 K}}}$ 求声速。 $$\kvw = (\text{331 m/s})\sqrt{\frac{\text{295 K}}{\text{273 K}}} = \text{344 m/s}$$
  5. 把声速和频率的值代入 $\kLlen$ 的表达式。 $$\kLlen = \frac{\kvw}{4\kfone} = \frac{\text{344 m/s}}{4(\text{128 Hz})} = 0\text{.}\text{672 m}$$

（a）的讨论

许多管乐器是经过改造的管，上面有指孔、活塞和其他装置，用来改变共振气柱的长度，从而改变所奏音的频率。产生很低频率的号，例如大号，需要的管长到要盘成圈。

（b）的解

  1. 确定已知量：
    • 第一泛音的 $n = 3$
    • 第二泛音的 $n = 5$
    • 第三泛音的 $n = 7$
    • 第四泛音的 $n = 9$
  2. 把第四泛音的值代入 $\kfn = n\frac{\kvw}{4\kLlen}$。 $$f_9 = 9\frac{\kvw}{4\kLlen} = 9\kfone = \text{1.15 kHz}$$

（b）的讨论

这个泛音是否出现在简单的管或乐器中，取决于它受到怎样的激励而振动，以及其形状的细节。例如，长号通常不奏出它的基频，一般只使用泛音。

两端开口的管

另一类管是两端开口的管。例子有某些管风琴管、长笛和双簧管。两端开口的管的共振，可以用与一端封闭的管非常相似的方式来分析。两端开口的管中的气柱在两端都有最大的空气位移，如图 17.30 所示。驻波如图所示形成。

根据两端开口的管在两端都有最大空气位移这一事实，并以图 17.30 为指引，我们可以看出，两端开口的管的共振频率为：

$$\kfn = n\frac{\kvw}{2\kLlen},\;n = 1, 2, 3\text{...,}$$

其中 $\kfone$ 是基频，$\kftwo$ 是第一泛音，$\kfthree$ 是第二泛音，依此类推。注意，两端开口的管的基频是它一端封闭时的两倍。它的泛音谱也与一端封闭的管不同。因此，如果有两根管，基频相同，但一根两端开口，另一根一端封闭，那么演奏时它们听起来会不同，因为它们的泛音不同。当乐器除了所奏的主导频率之外还包含许多泛音时，音听起来更丰富。管风琴演奏者手动选择额外的谐波，来调节所奏音的音色。管风琴通常有多层键盘，因此可以为左手、右手和脚所奏的音分别设置不同的泛音谱。

实际应用：日常系统中的共振

共振出现在许多不同的系统中，包括弦、气柱和原子。共振是系统在其固有频率下的受迫振动。发生共振时，能量迅速传递给振动的系统，其振动的振幅不断增大，直到该系统不再能用胡克定律来描述。一个例子，就是某些类型的摇滚乐中有意制造的失真的声音。

乐器中的共振

管乐器利用气柱中的共振，来放大由嘴唇或振动的簧片发出的音。其他乐器也以巧妙的方式利用空气共振来放大声音。图 17.31 显示了一把小提琴和一把吉他，它们都有共鸣箱，但形状不同，因而泛音结构也不同。振动的弦发出一种声音，这种声音在共鸣箱中共振，大大放大了声音，并产生泛音，使乐器具有其独特的韵味。共鸣箱的形状越复杂，它在很宽的频率范围内共振的能力就越强。马林巴琴，如图 17.32 所示的那一架，用木条下方的罐或葫芦来放大木条的音。罐的共振可以通过加水来调节。

在讨论共振和驻波时，我们强调了声音方面的应用，但这些思想适用于任何具有波动特性的系统。例如，振动的弦实际上就在共振，并且有与气柱类似的基频和泛音。更微妙的是原子中由于其电子的波动性而产生的共振。它们的轨道可以看作驻波，驻波有基频（基态）和泛音（激发态）。令人着迷的是，波动特性竟适用于如此广泛的物理系统。
