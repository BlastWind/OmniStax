偏振

偏光太阳镜我们大多数人都很熟悉。它们有一种特殊的本领，能削弱水面或玻璃反射的光所产生的眩光（见图 27.36）。偏振片之所以有这种本领，是因为光的一种波动特性，称为偏振。什么是偏振？它是如何产生的？它有哪些用途？这些问题的答案都与光的波动性有关。

光是电磁（EM）波的一种。如前所述，电磁波是横波，由变化的电场和磁场组成，它们在垂直于传播方向的方向上振动（见图 27.37）。电场和磁场的振动各有确定的方向。偏振是指波的振动相对于波的传播方向有确定的方向这一属性。（这与讨论电荷分离时所说的极化不是同一类。）具有这种方向的波称为偏振的。对于电磁波，我们把偏振方向定义为与电场平行的方向。因此，我们可以把电场箭头看作表示偏振方向，如图 27.37 所示。

为了进一步研究这一点，请看图 27.38 中两根绳上的横波。一根绳上的振动在竖直平面内，称为竖直偏振的。另一根绳上的振动在水平面内，是水平偏振的。如果把一条竖直狭缝放在第一根绳上，波就能通过。然而，竖直狭缝会挡住水平偏振的波。对于电磁波，电场的方向类似于绳上的扰动。

非偏振光与偏振片

太阳和许多其他光源发出的波是随机偏振的（见图 27.39）。这样的光称为非偏振光，因为它由许多具有一切可能的偏振方向的波组成。偏振片材料由宝丽来公司的创始人埃德温·兰德发明，相当于对光起偏振作用的狭缝，只允许一个方向上的偏振通过。偏振片由沿一个方向排列的长分子组成。把这些分子看作许多狭缝，与振动的绳所对应的狭缝类似，我们就能理解为什么只有具有特定偏振的光才能通过。偏振片的透振方向是偏振片让电磁波的电场通过所沿的方向（见图 27.40）。

图 27.41 显示了两块偏振片对原本非偏振光的作用。第一块偏振片使光沿其透振方向偏振。当第一块和第二块偏振片的透振方向对齐（平行）时，通过第一块偏振片的全部偏振光也都能通过第二块。如果转动第二块偏振片，则只有光中与第二块偏振片透振方向平行的分量能通过。当透振方向相互垂直时，第二块不让任何光通过。

马吕斯定律

只有电磁波中与偏振片透振方向平行的分量能通过。把偏振方向与偏振片透振方向之间的夹角记为 $\ktheta$。如果电场的振幅为 $\kEf$，那么透射的那部分波的振幅为 $\kEf\;\cos\;\ktheta$（见图 27.42）。由于波的强度与其振幅的平方成正比，透射波的强度 $\kIntens$ 与入射波的强度相关联。

这里 $\kIopol$ 是偏振波在通过偏振片之前的强度。（上面的方程称为马吕斯定律。）

计算强度的减弱

例题 27.8 · 计算偏振片造成的强度减弱

偏振光的方向与偏振片的透振方向之间需要成多大的角，才能使其强度减弱 $90.0\%$？

思路

当强度减弱 $90.0\%$ 时，它为原来数值的 $10.0\%$，即 0.100 倍。也就是说，$\kIntens = 0.100\kIopol$。利用这一信息，可以用方程 $\kIntens = \kIopol\;\cos^{2}\;\ktheta$ 求出所需的角。

解

把方程 $\kIntens = \kIopol\;\cos^{2}\;\ktheta$ 对 $\cos\;\ktheta$ 求解，并代入 $\kIntens$ 与 $\kIopol$ 之间的关系，得

$$\cos\;\ktheta = \sqrt{\frac{\kIntens}{\kIopol}} = \sqrt{\frac{0.100\kIopol}{\kIopol}} = 0.3162.$$

再对 $\ktheta$ 求解，得

$$\ktheta = \cos^{-1}\;0.3162 = 71.6^\circ.$$

讨论

偏振方向与偏振片透振方向之间需要有相当大的角，才能把强度降到原来数值的 $10.0\%$。根据用偏振片做的实验，这似乎是合理的。有意思的是，在 $45^\circ$ 角时，强度减为原来数值的 $50\%$（你将在本节的“习题”中证明这一点）。请注意，$71.6^\circ$ 距离使强度减为零还差 $18.4^\circ$，而且在 $18.4^\circ$ 角时，强度减为原来数值的 $90.0\%$（你同样会在“习题”中证明这一点），这证明了对称性。

反射起偏

到现在你大概能猜到，偏光太阳镜之所以能削弱反射光的眩光，是因为那种光是偏振的。你可以自己检验这一点：把偏光太阳镜举在面前，一边转动它，一边看水面或玻璃反射的光。转动太阳镜时，你会注意到光忽亮忽暗，但不会完全变黑。这意味着反射光是部分偏振的，不能被偏振片完全挡住。

图 27.43 说明了非偏振光从一个表面反射时会发生什么。竖直偏振的光在表面处优先被折射，所以反射光留下的更多是水平偏振的。这一现象的原因超出了本书的范围，但有一个便于记忆的办法，就是把偏振方向想象成一支箭。竖直偏振就像一支垂直于表面的箭，更可能扎进去而不被反射。水平偏振就像一支侧着弹开的箭，更可能被反射。这样，透振方向竖直的太阳镜挡住的反射光，就比挡住来自其他光源的非偏振光更多。

布儒斯特定律

由于没有被反射的那部分光会被折射，偏振的程度取决于所涉及介质的折射率。可以证明，反射光在反射角 $\kthetab$ 时是完全偏振的，该角由下式给出

$$\tan\;\kthetab = \frac{n_{2}}{n_{1}},$$

其中 $n_{1}$ 是入射光和反射光传播所在的介质，$n_{2}$ 是构成反射光的界面的介质的折射率。这个方程称为布儒斯特定律，$\kthetab$ 称为布儒斯特角，它们以发现它们的 19 世纪苏格兰物理学家的名字命名。

原子尺度上的偏振片

大与小：偏振片的原子解释

偏振片有一个起狭缝作用的偏振方向，即透振方向。这条狭缝允许电场平行于该透振方向的电磁波（通常是可见光）通过。这是靠垂直于透振方向排列的长分子实现的，如图 27.44 所示。

图 27.45 说明了平行于长分子的电场分量是如何被吸收的。电磁波由振动的电场和磁场组成。电场比磁场强，对分子中的电荷施加力更有效。受影响最大的带电粒子是分子中的电子，因为电子质量很小。如果电子被迫振动，它就能从电磁波中吸收能量。这会减弱波中的场，从而降低它的强度。在长分子中，电子在平行于分子的方向上比在垂直方向上更容易振动。电子束缚在分子上，在垂直于分子的方向上运动受到更多限制。因此，电子能吸收电场有平行于分子的分量的电磁波。电子对垂直于分子的电场响应小得多，会让这些场通过。因此，偏振片的透振方向垂直于分子的长度方向。

计算反射起偏

例题 27.9 · 计算反射起偏

（a）在空气中传播的光从水面反射时，在什么角度下会完全水平偏振？（b）从玻璃反射时呢？

思路

要解这些问题，我们只需要折射率。空气的 $n_{1} = 1.00,$ 水的 $n_{2} = 1.333,$ 冕牌玻璃的 $n'_{2} = 1.520$。方程 $\tan\;\kthetab = \frac{n_{2}}{n_{1}}$ 可以直接用来求每种情形下的 $\kthetab$。

（a）的解

把已知量代入方程

$$\tan\;\kthetab = \frac{n_{2}}{n_{1}}$$

得

$$\tan\;\kthetab = \frac{n_{2}}{n_{1}} = \frac{1.333}{1.00} = 1.333.$$

对角 $\kthetab$ 求解，得

$$\kthetab = \tan^{-1}\;1.333 = 53.1^\circ.$$

（b）的解

同样，对于冕牌玻璃和空气，

$$\tan\;\ktheta'_{\text{b}} = \frac{n'_{2}}{n_{1}} = \frac{1.520}{1.00} = 1.52.$$

于是，

$$\ktheta'_{\text{b}} = \tan^{-1}\;1.52 = 56.7^\circ.$$

讨论

以这些角度反射的光，可以被一块透振方向竖直放置的优质偏振片完全挡住。水与空气的布儒斯特角和玻璃与空气的相近，所以在相似的情况下，太阳镜对从水面或玻璃反射的光同样有效。没有被反射的光折射进这些介质。所以，入射角等于布儒斯特角时，折射光会略微竖直偏振。它不会完全竖直偏振，因为只有一小部分入射光被反射，所以有相当多的水平偏振的光被折射。

散射起偏

如果你把偏光太阳镜举在面前，一边转动它，一边看蓝天，你会看到天空忽亮忽暗。这清楚地表明，被空气散射的光是部分偏振的。图 27.46 有助于说明这是怎么发生的。由于光是一种电磁横波，它使空气分子的电子在垂直于其传播方向的方向上振动。这些电子随后像小天线一样辐射。由于它们是在垂直于光线的方向上振动，所以产生的电磁辐射的偏振垂直于光线的方向。当沿垂直于原来的光线的直线观察光时，如图 27.46 所示，散射光中不可能有平行于原来的光线的偏振，因为那就要求原来的光线是纵波。沿其他方向，另一种偏振的一个分量可以投影到视线方向上，散射光就只是部分偏振的。此外，多次散射可以使光从其他方向进入你的眼睛，并可能含有不同的偏振。

天空的照片可以用偏振片压暗，这是许多摄影师用来通过对比使云显得更亮的技巧。烟或尘埃等其他粒子的散射也能使光偏振。探测散射电磁波中的偏振，可以成为确定散射源的有用分析工具。

太阳镜使用了一系列光学效应。除了偏光太阳镜之外，另一些太阳镜内嵌有彩色色素，还有一些采用增透甚至反射涂层。最近的一项进展是光致变色镜片，它们在阳光下变暗，在室内变得透明。光致变色镜片内嵌有有机微晶分子，这些分子暴露于阳光中的紫外线时会改变性质，而在没有紫外线的人工照明下则变得透明。

居家实验：偏振

找来偏光太阳镜，转动其中一副，同时保持另一副不动，观察不同的表面和物体。解释你的观察。从你看到最大强度时到看到最小强度时，角度相差多少？找一块反射玻璃表面，做同样的事。玻璃需要取向于什么角度，才能使眩光最小？

液晶和材料中的其他偏振效应

你无疑知道手表、计算器、计算机屏幕、手机、平板电视和其他无数地方都有液晶显示器（LCD），但你可能不知道它们是以偏振为基础的。液晶之所以得名，是因为它们的分子即使处在液体中也能排列整齐。液晶有一种性质：能使通过它们的光的偏振转动 $90^\circ$。此外，施加电压可以关掉这种性质，如图 27.47 所示。可以快速地、在界限分明的小区域内操控这一特性，从而产生我们在许多 LCD 设备中看到的衬度图案。

在平板 LCD 电视中，电视机背面有一个大光源。光穿过数百万个称为像素（图像元素）的微小单元，到达前面的屏幕。图 27.47（a）和（b）中显示了其中一个。每个单元有三个小格，分别带红色、蓝色或绿色滤光片，各自独立控制。当液晶两端的电压关闭时，液晶让光通过那一特定的滤光片。改变施加在液晶上的电压的大小，就能改变图像衬度。

许多晶体和溶液都能使通过它们的光的偏振面转动。这类物质称为旋光的。例如糖水、胰岛素和胶原蛋白（见图 27.48）。除了取决于物质的种类外，转动的大小和方向还取决于许多因素。其中有物质的浓度、光穿过它所经过的距离，以及光的波长。旋光性源于物质中分子的不对称形状，例如呈螺旋形。因此，测量偏振光通过物质时的转动，可以用来测量浓度，这是测定糖类的标准技术。它还能给出关于分子（例如蛋白质）的形状，以及影响其形状的因素（例如温度和 pH）的信息。

应力与双折射

玻璃和塑料受应力作用时会变得旋光；应力越大，效应越强。对复杂形状的光测应力分析，可以通过制作它们的塑料模型并透过正交偏振片观察来进行，如图 27.49 所示。显然，这一效应不仅取决于应力，还取决于波长。对波长的依赖有时也被用于艺术目的。

与偏振光有关的另一个有趣现象，是某些晶体能把一束非偏振光分成两束。这类晶体称为双折射的（见图 27.50）。分开的每一条光线都有特定的偏振。一条表现正常，称为寻常光线，而另一条不遵守斯涅耳定律，称为非寻常光线。双折射的晶体可用来由非偏振光产生偏振光束。有些双折射的材料优先吸收其中一种偏振。这类材料称为二向色性的，可以通过这种优先吸收产生偏振。偏振片和其他起偏器的工作原理，从根本上说就是这样。有兴趣的读者可以进一步探究材料中与偏振有关的众多性质。
