平均加速度

在日常交谈中，“加速”的意思是变快。汽车的油门确实能使它加速。加速度越大，在给定时间内速度的变化就越大。加速度的正式定义与这些看法一致，但包含的范围更广。

平均加速度

平均加速度是速度的变化率，

$$\kab = \frac{\kdv}{\kdt} = \frac{\kvf - \kvo}{\ktf - \kto},$$

其中 $\kab$ 是平均加速度，$\kv$ 是速度，$\kt$ 是时间。（$a$ 上方的横线表示平均加速度。）

因为加速度是以 m/s 为单位的速度除以以 s 为单位的时间，所以加速度的 SI 单位是 $\text{m/s}^2$，即米每二次方秒，或米每秒每秒，其字面意思是：每秒，速度变化多少米每秒。

加速度是矢量

回想一下，速度是矢量——既有大小又有方向。这意味着速度的变化可以是大小（即速率）的变化，也可以是方向的变化。例如，如果一辆汽车以恒定速率转弯，它就具有加速度，因为它的方向在变化。转弯越急，加速度越大。因此，无论是速度的大小变化（速率增大或减小），还是方向变化，或两者同时变化，都存在加速度。

加速度是矢量

加速度是矢量，与速度的变化量 $\kdv$ 的方向相同。由于速度是矢量，它既可以在大小上变化，也可以在方向上变化。因此，加速度是速率或方向的变化，或二者兼有。

减速度

请记住，虽然加速度的方向与速度的变化相同，但它并不总是与运动的方向相同。物体减速时，它的加速度与其运动的方向相反。这称为减速度。

减速度与负加速度

误区提醒：减速度与负加速度

减速度总是指加速度的方向与速度的方向相反。减速度总会使速率减小。然而，负加速度是在所选坐标系中沿负方向的加速度。负加速度可能是也可能不是减速度，而减速度可能被也可能不被视为负加速度。例如，请看图 2.14。

计算平均加速度

例题 2.1 · 计算加速度：赛马冲出起跑门

一匹赛马冲出起跑门，在 1.80 s 内从静止加速到正西方向 15.0 m/s 的速度。它的平均加速度是多少？

思路

首先画一幅草图，并为这个问题建立坐标系。这是一个简单的问题，但把它形象化总是有帮助的。注意，我们把东取为正，西取为负。因此，在这个问题中，我们得到的是负的速度。

我们可以这样解这个问题：根据已知信息确定 $\kdv$ 和 $\kdt$，然后直接由方程 $\kab = \frac{\kdv}{\kdt} = \frac{\kvf - \kvo}{\ktf - \kto}$ 计算平均加速度。

解

  1. 确定已知量。$\kvo = 0$，$\kvf = -15.0\ \text{m/s}$（负号表示方向向西），$\kdt = 1.80\ \text{s}$。
  2. 求速度的变化量。由于这匹马是从零变到 $-15.0\ \text{m/s}$，它的速度的变化量就等于它的末速度：$\kdv = \kvf = -15.0\ \text{m/s}$。
  3. 代入已知值（$\kdv$ 和 $\kdt$），求未知量 $\kab$。 $$\kab = \frac{\kdv}{\kdt} = \frac{-15.0\ \text{m/s}}{1.80\ \text{s}} = -8.33\ \text{m/s}^2.$$

讨论

加速度的负号表示加速度指向西。向正西、$8.33\ \text{m/s}^2$ 的加速度意味着这匹马每秒使其速度向正西增加 8.33 m/s，即 8.33 米每秒每秒，我们把它写作 $8.33\ \text{m/s}^2$。这确实是一个平均加速度，因为这趟骑行并不平稳。我们以后会看到，这样大小的加速度会要求骑手以几乎等于他的重量的力抓牢。

瞬时加速度

瞬时加速度 $\ka$，即在时间上某一特定时刻的加速度，是用与“时间、速度和速率”中讨论瞬时速度相同的过程得到的——也就是考虑一个无穷小的时间间隔。仅用代数，我们如何求瞬时加速度呢？答案是，我们选取一个能代表该运动的平均加速度。图 2.17 给出了两种截然不同的运动的瞬时加速度—时间图像。在图 2.17（a）中，加速度变化很小，整个时间间隔上的平均值与任一时刻的瞬时加速度几乎相同。在这种情形下，我们应当把这个运动当作具有等于平均值的恒定加速度来处理（这里约为 $1.8\ \text{m/s}^2$）。在图 2.17（b）中，加速度随时间变化剧烈。在这种情况下，最好考虑更小的时间间隔，并为每个间隔选取一个平均加速度。例如，我们可以考虑 0 到 1.0 s 和 1.0 到 3.0 s 这两个时间间隔内的运动，把它们看作两个独立的运动，其加速度分别为 $+3.0\ \text{m/s}^2$ 和 $-2.0\ \text{m/s}^2$。

地铁列车

接下来的几个例题考虑图 2.18 所示的地铁列车的运动。在（a）中，这列往返列车向右运动，在（b）中，它向左运动。这些例题旨在进一步说明运动的各个方面，并说明解题时所涉及的一些推理。

例题 2.2 · 计算位移：一列地铁

图 2.18 的（a）和（b）两部分所示的地铁列车的运动，其位移的大小和正负号各是多少？

思路

图中已经给出了带坐标系的示意图，所以我们不需要再画草图，但应当对它进行分析，确保我们理解它所表示的内容。要特别注意坐标系。要求位移，我们使用方程 $\kdx = \kxf - \kxo$。因为初、末位置已经给出，所以这很简单。

解

  1. 确定已知量。从图中可以看到，（a）部分有 $\kxf = 6.70\ \text{km}$ 和 $\kxo = 4.70\ \text{km}$，（b）部分有 $\kxf' = 3.75\ \text{km}$ 和 $\kxo' = 5.25\ \text{km}$。
  2. 求（a）部分的位移。 $$\kdx = \kxf - \kxo = 6.70\ \text{km} - 4.70\ \text{km} = +2.00\ \text{km}$$
  3. 求（b）部分的位移。 $$\kdx' = \kxf' - \kxo' = 3.75\ \text{km} - 5.25\ \text{km} = -1.50\ \text{km}$$

讨论

（a）中运动的方向向右，因此它的位移为正，而（b）中的运动向左，因此为负。

例题 2.3 · 比较路程与位移：一列地铁

图 2.18 中地铁列车在（a）和（b）两部分所示的运动的路程各是多少？

思路

要回答这个问题，需要想一想距离和路程的定义，以及它们与位移的关系。两个位置之间的距离定义为位移的大小，这在例题 2.2 中已经求出。路程是在两个位置之间所经路径的总长度。（见“位移”。）对于图 2.18 所示的地铁列车，路程与列车的初、末位置之间的距离相同。

解

  1. （a）部分的位移为 +2.00 km。因此，初、末位置之间的距离为 2.00 km，路程为 2.00 km。
  2. （b）部分的位移为 $-1.5\ \text{km}$。因此，初、末位置之间的距离为 1.50 km，路程为 1.50 km。

讨论

距离是标量。它有大小，但没有表示方向的正负号。

地铁列车的加速与减速

例题 2.4 · 计算加速度：加速的地铁

假设图 2.18（a）中的列车在其运动的最初 20.0 s 内从静止加速到 30.0 km/h。在这段时间间隔内，它的平均加速度是多少？

思路

此时值得画一幅简单的草图：

这个问题分三步。首先必须确定速度的变化量，然后确定时间的变化量，最后用这些值计算加速度。

解

  1. 确定已知量。$\kvo = 0$（列车从静止开始），$\kvf = 30.0\ \text{km/h}$，$\kdt = 20.0\ \text{s}$。
  2. 计算 $\kdv$。由于列车从静止开始，它的速度的变化量为 $\kdv = +30.0\ \text{km/h}$，其中正号表示速度向右。
  3. 代入已知值，求未知量 $\kab$。 $$\kab = \frac{\kdv}{\kdt} = \frac{+30.0\ \text{km/h}}{20.0\ \text{s}}$$
  4. 由于单位不统一（时间既有小时又有秒），我们需要把一切都换算成以米和秒为单位的 SI 单位。（更多指导见“物理量和单位”。） $$\kab = \left(\frac{+30\ \text{km/h}}{20.0\ \text{s}}\right)\left(\frac{10^{3}\ \text{m}}{1\ \text{km}}\right)\left(\frac{1\ \text{h}}{3600\ \text{s}}\right) = 0.417\ \text{m/s}^2$$

讨论

正号表示加速度向右。这是合理的，因为列车从静止开始，最终具有向右（同样为正）的速度。所以加速度与速度的变化量的方向相同，总是如此。

例题 2.5 · 计算加速度：减速的地铁

现在假设在其行程结束时，图 2.18（a）中的列车在 8.00 s 内从 30.0 km/h 的速率减速到停下。它在停车过程中的平均加速度是多少？

思路

在这种情况下，列车在做减速运动，它的加速度为负，因为它指向左。和上一个例题一样，我们必须求出速度的变化量和时间的变化量，然后求解加速度。

解

  1. 确定已知量。$\kvo = 30.0\ \text{km/h}$，$\kvf = 0\ \text{km/h}$（列车已停下，所以它的速度为 0），$\kdt = 8.00\ \text{s}$。
  2. 求速度的变化量 $\kdv$。 $$\kdv = \kvf - \kvo = 0 - 30.0\ \text{km/h} = -30.0\ \text{km/h}$$
  3. 代入已知量 $\kdv$ 和 $\kdt$，求 $\kab$。 $$\kab = \frac{\kdv}{\kdt} = \frac{-30.0\ \text{km/h}}{8.00\ \text{s}}$$
  4. 把单位换算成米和秒。 $$\kab = \frac{\kdv}{\kdt} = \left(\frac{-30.0\ \text{km/h}}{8.00\ \text{s}}\right)\left(\frac{10^{3}\ \text{m}}{1\ \text{km}}\right)\left(\frac{1\ \text{h}}{3600\ \text{s}}\right) = -1.04\ \text{m/s}^2.$$

讨论

负号表示加速度向左。这个正负号是合理的，因为在这个问题中列车最初具有正的速度，而负的加速度会与运动相反。同样，加速度的方向与速度的变化相同，这里为负。这个加速度可以称为减速度，因为它的方向与速度相反。

例题 2.6 · 计算平均速度：地铁

如果它走完其行程需要 5.00 min，例题 2.2 的 b 部分（下面再次给出）中列车的平均速度是多少？

思路

平均速度是位移除以时间。这里它为负，因为列车向左运动，具有负的位移。

解

  1. 确定已知量。$\kxf' = 3.75\ \text{km}$，$\kxo' = 5.25\ \text{km}$，$\kdt = 5.00\ \text{min}$。
  2. 确定位移 $\kdx'$。我们在例题 2.2 中求得 $\kdx'$ 为 $-1.5\ \text{km}$。
  3. 求平均速度。 $$\kvb = \frac{\kdx'}{\kdt} = \frac{-1.50\ \text{km}}{5.00\ \text{min}}$$
  4. 换算单位。 $$\kvb = \frac{\kdx'}{\kdt} = \left(\frac{-1.50\ \text{km}}{5.00\ \text{min}}\right)\left(\frac{60\ \text{min}}{1\ \text{h}}\right) = -18.0\ \text{km/h}$$

讨论

负的速度表示运动向左。

例题 2.7 · 计算减速度：地铁

最后，假设图 2.22 中的列车在 10.0 s 内从 20.0 km/h 的速度减速到停下。它的平均加速度是多少？

思路

让我们再画一幅草图：

和前面一样，我们必须求出速度的变化量和时间的变化量，才能计算平均加速度。

解

  1. 确定已知量。$\kvo = -20.0\ \text{km/h}$，$\kvf = 0\ \text{km/h}$，$\kdt = 10.0\ \text{s}$。
  2. 计算 $\kdv$。这里速度的变化量实际上是正的，因为 $$\kdv = \kvf - \kvo = 0 - (-20\ \text{km/h}) = +20.0\ \text{km/h}.$$
  3. 求 $\kab$。 $$\kab = \frac{\kdv}{\kdt} = \frac{+20.0\ \text{km/h}}{10.0\ \text{s}}$$
  4. 换算单位。 $$\kab = \left(\frac{+20.0\ \text{km/h}}{10.0\ \text{s}}\right)\left(\frac{10^{3}\ \text{m}}{1\ \text{km}}\right)\left(\frac{1\ \text{h}}{3600\ \text{s}}\right) = +0.556\ \text{m/s}^2$$

讨论

正号表示加速度向右。这是合理的，因为在这个问题中列车最初具有（向左的）负的速度，而正的加速度与运动相反（因此它指向右）。同样，加速度的方向与速度的变化相同，这里为正。与例题 2.5 中一样，这个加速度可以称为减速度，因为它的方向与速度相反。

正负号与方向

关于这些例题，也许最值得注意的是答案的正负号。在我们所选的坐标系中，正号表示该量向右，负号表示向左。对于位移和速度，这很容易想象。但对于加速度，就不那么明显了。大多数人把负加速度理解为物体变慢。在例题 2.7 中并非如此，那里正的加速度使负的速度变慢。关键的区别在于加速度的方向与速度相反。事实上，负加速度会增大负速度。例如，图 2.22 中向左行驶的列车在向左的加速度作用下加速。在这种情况下，$\kv$ 和 $\ka$ 都是负的。正负号给出了加速度的方向。如果加速度与速度的正负号相同，物体就在加速。如果加速度与速度的正负号相反，物体就在减速。
