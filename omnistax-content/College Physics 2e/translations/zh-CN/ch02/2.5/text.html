我们可能知道，比如一辆汽车从停车标志处驶离，其加速度越大，在给定时间内的位移就越大。但是我们还没有建立一个把加速度和位移联系起来的具体方程。在本节中，我们从已经讲过的位移、速度和加速度的定义出发，推导一些便于使用的运动学关系方程。

记号：$\kt$、$\kx$、$\kv$、$\ka$

首先，我们对记号做一些简化。把初时刻取为零，就像用秒表计时间一样，是一个很大的简化。由于时间间隔为 $\kdt = \ktf - \kto$，取 $\kto = 0$ 就意味着 $\kdt = \ktf$，即秒表上的末时刻。当初时刻取为零时，我们用下标 0 表示位置和速度的初值。也就是说，$\kxo$ 是初位置，$\kvo$ 是初速度。我们不给末值加下标。也就是说，$\kt$ 是末时刻，$\kx$ 是末位置，$\kv$ 是末速度。这样，时间间隔的表达式更简单了——现在 $\kdt = \kt$。它也简化了位移的表达式，现在是 $\kdx = \kx - \kxo$。此外，它还简化了速度的变化量的表达式，现在是 $\kdv = \kv - \kvo$。总结一下，采用简化后的记号，并把初时刻取为零，

$$\begin{aligned}\kdt &= \kt\\ \kdx &= \kx - \kxo\\ \kdv &= \kv - \kvo\end{aligned}$$

其中，在所考虑的任何运动中，下标 0 表示初值，无下标表示末值。

恒定加速度

现在我们做一个重要的假设：加速度是恒定的。这个假设使我们不必用微积分来求瞬时加速度。由于加速度恒定，平均加速度和瞬时加速度相等。也就是说，

$$\kab = \ka = \text{常量},$$

所以我们在任何时刻都用符号 $\ka$ 表示加速度。假设加速度恒定，既不会严重限制我们能够研究的情形，也不会降低我们处理的准确度。首先，在大量情形中，加速度确实是恒定的。其次，在许多其他情形中，我们可以假设一个恒定的加速度，使它等于该运动的平均加速度，从而准确地描述运动。最后，在加速度变化剧烈的运动中，例如汽车加速到最大速率然后制动直至停下，可以把这段运动分成几个部分来考虑，每一部分都有各自恒定的加速度。

由平均速度求位移

这里，平均速度为

$$\kvb = \frac{\kvo + \kv}{2}\;(\text{恒定 }\ka).$$

方程 $\kvb = \frac{\kvo + \kv}{2}$ 反映了这样一个事实：当加速度恒定时，$\kv$ 就是初、末速度的简单平均。例如，如果你把自己的速度平稳地从 30 增大到 60 km/h（即在恒定加速度下），那么在这段平稳增大的过程中，你的平均速度是 45 km/h。用方程 $\kvb = \frac{\kvo + \kv}{2}$ 来验证，可以看到

$$\kvb = \frac{\kvo + \kv}{2} = \frac{30\ \text{km/h} + 60\ \text{km/h}}{2} = 45\ \text{km/h},$$

这看起来是合乎逻辑的。

例题 2.8 · 计算位移：慢跑者跑了多远？

一名慢跑者沿着一段笔直的道路跑步，平均速度为 4.00 m/s，持续 2.00 min。若取他的初位置为零，他的末位置是多少？

思路

画一幅草图。末位置 $\kx$ 由方程给出

$$\kx = \kxo + \kvb\kt.$$

为了求 $\kx$，我们从题目的叙述中找出 $\kxo$、$\kvb$ 和 $\kt$ 的值，并把它们代入方程。

解

  1. 确定已知量。$\kvb = 4.00\ \text{m/s}$，$\kdt = 2.00\ \text{min}$，$\kxo = 0\ \text{m}$。
  2. 把已知量代入方程。 $$\kx = \kxo + \kvb\kt = 0 + (4.00\ \text{m/s})(120\ \text{s}) = 480\ \text{m}$$

讨论

速度和最终位移都是正的，这意味着它们的方向相同。

方程 $\kx = \kxo + \kvb\kt$ 让我们深入了解位移、平均速度和时间之间的关系。例如，它表明位移是平均速度的线性函数。（所谓线性函数，是指位移取决于 $\kvb$，而不是取决于 $\kvb$ 的其他次幂，比如 $\kvb^2$。画成图像时，线性函数看起来是斜率恒定的直线。）例如，在一次汽车旅行中，如果平均速度为 90 km/h，那么在给定的时间内，我们能走到的距离是平均速度为 45 km/h 时的两倍。

末速度

例题 2.9 · 计算末速度：着陆后减速的飞机

一架飞机以初速度 70.0 m/s 着陆，然后以 $1.50\ \text{m/s}^2$ 减速，持续 40.0 s。它的末速度是多少？

思路

画一幅草图。因为飞机在减速，所以我们把加速度矢量画在与速度矢量相反的方向上。

解

  1. 确定已知量。$\kvo = 70.0\ \text{m/s}$，$\ka = -1.50\ \text{m/s}^2$，$\kt = 40.0\ \text{s}$。
  2. 确定未知量。在本题中，它是末速度 $\kvf$。
  3. 确定使用哪个方程。我们可以用方程 $\kv = \kvo + \ka\kt$ 计算末速度。
  4. 代入已知量并求解。 $$\kv = \kvo + \ka\kt = 70.0\ \text{m/s} + (-1.50\ \text{m/s}^2)(40.0\ \text{s}) = 10.0\ \text{m/s}$$

讨论

末速度比初速度小得多，这正是减速时所希望的，但仍然是正的。对于喷气发动机，反向推力可以维持足够长的时间，使飞机停下来，并使它开始向后运动。这会表现为负的末速度，而本题并非如此。

方程 $\kv = \kvo + \ka\kt$ 除了在解题时有用，还让我们深入了解速度、加速度和时间之间的关系。例如，从中我们可以看出，

  • 末速度取决于加速度有多大以及持续多长时间
  • 如果加速度为零，那么末速度等于初速度 $(\kv = \kvo)$，这与预期一致（即速度是恒定的）
  • 如果 $\ka$ 为负，那么末速度小于初速度

（所有这些结论都符合我们的直觉，而且结合我们的直觉和经验来检验基本方程，以确认它们确实准确地描述了自然，总是有益的。）

建立联系：联系实际

洲际弹道导弹（ICBM）比航天飞机具有更大的平均加速度，并在飞行的头一两分钟内达到更大的速度（洲际弹道导弹的实际燃烧时间属于机密——燃烧时间短的导弹更难被敌方摧毁）。但航天飞机获得更大的末速度，因此它能够绕地球轨道运行，而不像洲际弹道导弹那样直接落回地面。航天飞机是通过加速更长的时间来做到这一点的。

速度不恒定时的末位置

例题 2.10 · 计算加速物体的位移：直线加速赛车

直线加速赛车的平均加速度可达 $26.0\ \text{m/s}^2$。假设这样一辆直线加速赛车以这一加速度从静止开始加速，持续 5.56 s。它在这段时间内行驶了多远？

思路

画一幅草图。题目要我们求位移，如果取 $\kxo$ 为零，它就是 $\kx$。（可以把它想成比赛的起跑线。起跑线可以在任何地方，但我们把它叫作 0，并相对于它来测量所有其他位置。）一旦从题目的叙述中确定了 $\kvo$、$\ka$ 和 $\kt$，我们就可以使用方程 $\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$。

解

  1. 确定已知量。从静止开始意味着 $\kvo = 0$，$\ka$ 给定为 $26.0\ \text{m/s}^2$，$\kt$ 给定为 5.56 s。
  2. 把已知量代入方程，求未知量 $\kx$： $$\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2.$$ 由于初位置和初速度都为零，它简化为 $$\kx = \tfrac{1}{2}\ka\kt^2.$$ 代入已确定的 $\ka$ 和 $\kt$ 的值，得到 $$\kx = \tfrac{1}{2}(26.0\ \text{m/s}^2)(5.56\ \text{s})^2,$$ 即得 $$\kx = 402\ \text{m}.$$

讨论

如果把 402 m 换算成英里，就会发现所行驶的距离非常接近四分之一英里，这正是直线加速赛的标准距离。所以这个答案是合理的。仅在 5.56 s 内就有令人印象深刻的位移，但顶级的直线加速赛车跑完四分之一英里所用的时间甚至比这更短。

通过研究方程 $\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$，我们还能了解到什么？我们看到：

  • 当加速度不为零时，位移取决于时间间隔的平方。在例题 2.10 中，直线加速赛车在前一半时间间隔内只行驶了总距离的四分之一
  • 如果加速度为零，那么初速度等于平均速度（$\kvo = \kvb$），而 $\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$ 变为 $\kx = \kxo + \kvo\kt$

不含时间的末速度

例题 2.11 · 计算末速度：直线加速赛车

计算例题 2.10 中直线加速赛车的末速度，不使用有关时间的信息。

思路

画一幅草图。方程 $\kv^2 = \kvo^2 + 2\ka(\kx - \kxo)$ 最适合这项任务，因为它把速度、加速度和位移联系起来，而且不需要时间信息。

解

  1. 确定已知量。因为直线加速赛车从静止开始，所以我们知道 $\kvo = 0$。然后我们注意到 $\kx - \kxo = 402\ \text{m}$（这是例题 2.10 的答案）。最后，平均加速度给定为 $\ka = 26.0\ \text{m/s}^2$。
  2. 把已知量代入方程 $\kv^2 = \kvo^2 + 2\ka(\kx - \kxo)$，求解 $\kv$。 $$\kv^2 = 0 + 2(26.0\ \text{m/s}^2)(402\ \text{m}).$$ 因此 $$\kv^2 = 2.09 \times 10^4\ \text{m}^2\text{/s}^2.$$ 为了得到 $\kv$，我们取平方根： $$\kv = \sqrt{2.09 \times 10^4\ \text{m}^2\text{/s}^2} = 145\ \text{m/s}.$$

讨论

145 m/s 约合 522 km/h，或约合 324 mi/h，但即使是这个惊人的高速，也还没有达到四分之一英里的纪录。另外请注意，平方根有两个值；我们取正值，表示速度的方向与加速度的方向相同。

研究方程 $\kv^2 = \kvo^2 + 2\ka(\kx - \kxo)$ 可以让我们对物理量之间的一般关系有更多的认识：

  • 末速度取决于加速度有多大，以及加速度作用的距离
  • 对于固定的减速度，速度为两倍的汽车并不是简单地在两倍的距离内停下来——它需要远得多的距离才能停下来。（这就是学校附近设有限速区的原因。）

把方程综合起来

在下面的例题中，我们将进一步探讨一维运动，但涉及的情形需要稍多一些代数运算。这些例题还能让我们了解解题的技巧。下面的方框便于查阅所需的方程。

运动学方程汇总（恒定 $\ka$）
$$\kx = \kxo + \kvb\kt$$ $$\kvb = \frac{\kvo + \kv}{2}$$ $$\kv = \kvo + \ka\kt$$ $$\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$$ $$\kv^2 = \kvo^2 + 2\ka(\kx - \kxo)$$

例题 2.12 · 计算位移：汽车停下来前行驶多远？

在干燥的混凝土路面上，汽车可以以 $7.00\ \text{m/s}^2$ 的减速度减速，而在潮湿的混凝土路面上，它只能以 $5.00\ \text{m/s}^2$ 减速。求使以 30.0 m/s（约 110 km/h）行驶的汽车停下来所需的距离：（a）在干燥的混凝土路面上；（b）在潮湿的混凝土路面上。（c）重复这两项计算，求从驾驶员看到交通信号灯变红的那一点起的位移，并考虑他把脚踩到刹车踏板上所需的 0.500 s 的反应时间。

思路

画一幅草图。为了确定使用哪些方程最合适，我们需要列出所有已知量，并明确我们要求解的是什么。在接下来的几个例题中，我们将明确地做到这一点，并用表格把它们突出显示出来。

（a）的解

  1. 确定已知量和要求解的量。我们知道 $\kvo = 30.0\ \text{m/s}$；$\kv = 0$；$\ka = -7.00\ \text{m/s}^2$（$\ka$ 为负，因为它的方向与速度相反）。我们取 $\kxo$ 为 0。我们要求的是位移 $\kdx$，即 $\kx - \kxo$。
  2. 确定能帮助我们解决问题的方程。最合适的方程是 $$\kv^2 = \kvo^2 + 2\ka(\kx - \kxo).$$ 这个方程最合适，因为它只含一个未知量 $\kx$。方程中所有其他变量的值我们都已知道。（还有其他方程也可以用来求 $\kx$，但它们要求我们知道制动时间 $\kt$，而这是我们不知道的。我们也可以使用它们，但会增加额外的计算。）
  3. 整理方程，求解 $\kx$。 $$\kx - \kxo = \frac{\kv^2 - \kvo^2}{2\ka}$$
  4. 代入已知值。 $$\kx - 0 = \frac{0^2 - (30.0\ \text{m/s})^2}{2(-7.00\ \text{m/s}^2)}$$ 因此， $$\kx = 64.3\ \text{m（干燥混凝土路面）}.$$

（b）的解

这一问的解法与 A 部分完全相同。唯一的区别是减速度为 $-5.00\ \text{m/s}^2$。结果是

$$x_{\text{潮湿}} = 90.0\ \text{m（潮湿混凝土路面）}.$$

（c）的解

驾驶员一旦做出反应，制动距离就与 A、B 两部分中干燥和潮湿混凝土路面的情形相同。所以，要回答这个问题，我们需要计算汽车在反应时间内行驶了多远，然后把它加到制动时间上。合理的假设是，在驾驶员的反应时间内，速度保持不变。

  1. 确定已知量和要求解的量。我们知道 $\kvb = 30.0\ \text{m/s}$；$t_{\text{反应}} = 0.500\ \text{s}$；$a_{\text{反应}} = 0$。我们取 $x_{0\text{-反应}}$ 为 0。我们要求的是 $x_{\text{反应}}$。
  2. 确定最合适的方程。$\kx = \kxo + \kvb\kt$ 很合适，因为唯一的未知量是 $\kx$，而这正是我们要求解的量。
  3. 代入已知量，解方程。 $$\kx = 0 + (30.0\ \text{m/s})(0.500\ \text{s}) = 15.0\ \text{m}.$$ 这意味着在驾驶员做出反应期间，汽车行驶了 15.0 m，使得干燥和潮湿混凝土路面这两种情形下的总位移都比他立即做出反应时多 15.0 m。
  4. 把反应时间内的位移与制动时的位移相加。 $$x_{\text{制动}} + x_{\text{反应}} = x_{\text{总}}$$
    1. 64.3 m + 15.0 m = 79.3 m（干燥时）
    2. 90.0 m + 15.0 m = 105 m（潮湿时）

讨论

本例中求得的位移，对于使一辆高速行驶的汽车停下来来说，似乎是合理的。在潮湿路面上让汽车停下来，应该比在干燥路面上花更长的时间。有趣的是，反应时间会使位移显著增大。但更重要的是解决问题的一般方法。我们先确定已知量和待求量，然后找到合适的方程。解决一个问题往往不止一种方法。本例的各个部分实际上也可以用其他方法求解，但上面给出的解法是最简短的。

例题 2.13 · 计算时间：汽车汇入车流

假设一辆汽车在一条 200 m 长的匝道上汇入高速公路车流。如果它的初速度为 10.0 m/s，且它以 $2.00\ \text{m/s}^2$ 的加速度加速，那么驶完匝道上的 200 m 需要多长时间？（这类信息可能对交通工程师有用。）

思路

画一幅草图。题目要求我们求时间 $\kt$。和前面一样，我们先确定已知量，以便选出一个方便的物理关系（也就是只含一个未知量 $\kt$ 的方程）。

解

  1. 确定已知量和要求解的量。我们知道 $\kvo = 10\ \text{m/s}$；$\ka = 2.00\ \text{m/s}^2$；$\kx = 200\ \text{m}$。
  2. 我们需要求解 $\kt$。选择最合适的方程。$\kx = \kxo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$ 最合适，因为方程中唯一的未知量就是我们需要求解的变量 $\kt$。
  3. 我们需要整理方程来求解 $\kt$。在这种情况下，先代入已知量会更容易。 $$200\ \text{m} = 0\ \text{m} + (10.0\ \text{m/s})\kt + \tfrac{1}{2}(2.00\ \text{m/s}^2)\,\kt^2$$
  4. 化简方程。米（m）这个单位出现在每一项中，所以会相互抵消。取 $\kt = t\ \text{s}$，其中 $t$ 是时间的大小，s 是单位，就可以使秒（s）这个单位也抵消。这样做之后剩下 $$200 = 10\kt + \kt^2.$$
  5. 用二次方程求根公式求解 $\kt$。 （a）整理方程，使方程的一侧为 0。 $$\kt^2 + 10\kt - 200 = 0$$ 这是一个二次方程，其形式为 $$a t^2 + b t + c = 0,$$ 其中常数为 $a = 1.00,\; b = 10.0,\; \text{和}\; c = -200$。 （b）它的解由二次方程求根公式给出： $$t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$ 这样得到 $\kt$ 的两个解，它们是 $$\kt = 10.0\ \text{和} -20.0.$$ 于是，时间为 $\kt = t$，以秒为单位，即 $$\kt = 10.0\ \text{s}\ \text{和} -20.0\ \text{s}.$$ 时间取负值是不合理的，因为这意味着事件发生在运动开始之前 20 s。我们可以舍弃这个解。因此， $$\kt = 10.0\ \text{s}.$$

讨论

只要方程中含有未知量的平方，就会有两个解。在有些问题中，两个解都有意义，而在另一些问题中，比如上面这个，只有一个解是合理的。10.0 s 这个答案对于典型的高速公路入口匝道来说似乎是合理的。
