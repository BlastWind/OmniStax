力的各种名称

力有许多名称，例如推、拉、推力、升力、重力、摩擦力和张力。按照传统，力被分成若干类，并根据其来源、传递方式或效果而得名。这些类别中最重要的几类，连同一些有趣的应用，将在本节讨论。力的更多实例将在本书后面讨论。

法向力

重力（也称引力）是一种无处不在的力，时刻都在起作用，必须被抵消才能使物体不下落。当你托住一个重物使其保持静止时，你一定会注意到，必须向上推它来支撑它的重力，如图 4.11（a）所示。但是，像桌子这样的无生命物体，是怎样支撑放在其上的物体的重力的呢，如图 4.11（b）所示？当一袋狗粮放在桌子上时，桌子在载荷作用下实际上会略微下垂。如果把载荷放在折叠牌桌上，这一点就会很明显，但即使是刚性的物体，在受到力作用时也会发生形变。除非物体的形变超过其限度，否则它会施加一个回复力，就像发生形变的弹簧（或蹦床、跳板）那样。形变越大，回复力就越大。因此，当载荷放在桌子上时，桌子会下垂，直到回复力增大到与载荷的重力一样大。此时，作用在载荷上的合外力为零。这就是载荷静止在桌子上时的情形。桌子下垂得很快，而且下垂的幅度很小，所以我们注意不到。但这与你爬上蹦床时蹦床的下垂是相似的。

我们必须得出结论：无论支撑载荷的是有生命的还是无生命的，它都必须提供一个向上的力，其大小等于载荷的重力，正如我们在前面的几个例子中所假设的那样。如果支撑载荷的力垂直于载荷与其支撑物之间的接触面，则这个力被定义为法向力，在这里用符号 $\kN$ 表示。（这不是力的单位 N。）法向（normal）一词的意思是垂直于表面。如果物体沿斜面滑动，法向力可以小于物体的重力，下一个例题中你将看到这一点。法向力甚至可以大于物体的重力，例如当你向上跳起时，或者，我们将会看到，汽车在倾斜弯道上行驶时。

常见误区：法向力（N）与牛顿（N）

在本节中，我们引入了法向力这个量，用变量 $\kN$ 表示。不要把它与牛顿的符号混淆，牛顿的符号同样是字母 N。区分这两个符号尤为重要，因为法向力（$\kN$）的单位恰好是牛顿（N）。例如，地板对椅子施加的法向力 $\kN$ 可能是 $\kN = 100\ \text{N}$。一个重要的区别是，法向力是矢量，而牛顿只是一个单位。在计算中要小心，不要混淆这些字母！随着你在物理学中继续学习，你会遇到更多变量与单位之间的相似之处。另一个例子是功（$W$）这个量与单位瓦特（W）。

斜面上的重力

例题 4.5 · 斜面上的重力：一个二维问题

请看图 4.12 中斜坡上的滑雪者。她连同装备的质量为 60.0 kg。（a）如果摩擦力可以忽略，她的加速度是多少？（b）如果已知摩擦力为 45.0 N，她的加速度是多少？（c）法向力 $\kN$ 由垂直于斜坡方向上的牛顿第二定律求得。由于 $a_{\perp} = 0$，方程变为 $\kN - \km\kg\cos(25^\circ) = 0$，于是 $\kN = \km\kg\cos(25^\circ) = (60\ \text{kg})(9.8\ \text{m/s}^2)\cos(25^\circ) = 532\ \text{N}$。

思路

这是一个二维问题，因为作用在滑雪者（所研究的系统）上的力不平行。我们在二维运动学中使用的方法在这里同样非常有效。选取一个方便的坐标系，把矢量投影到它的坐标轴上，从而得到两个相互关联的一维问题来求解。对于斜面上的运动，最方便的坐标系是一个坐标轴平行于斜坡、另一个垂直于斜坡的坐标系。（请记住，沿相互垂直的坐标轴的运动是相互独立的。）我们用符号 $\perp$ 和 $\parallel$ 分别表示垂直和平行。这样选取坐标轴会使这类问题得以简化，因为垂直于斜坡方向上没有运动，也因为摩擦力总是平行于两个物体之间的接触面。作用在系统上的仅有的外力是滑雪者的重力、摩擦力和斜坡的支持力，在图 4.12 中分别标为 $\kwgt$、$\kff$ 和 $\kN$。$\kN$ 总是垂直于斜坡，$\kff$ 平行于斜坡。但是 $\kwgt$ 不在任何一个坐标轴的方向上，所以我们采取的第一步，就是把它投影为沿所选坐标轴的分量，把 $\kwpar$ 定义为平行于斜坡的重力分量，把 $\kwperp$ 定义为垂直于斜坡的重力分量。完成这一步后，我们就可以分别考虑平行于斜坡的力和垂直于斜坡的力这两个独立的问题。

解

平行于斜坡的重力分量的大小为 $\kwpar = \kwgt\sin(25^\circ) = \km\kg\sin(25^\circ)$，垂直于斜坡的重力分量的大小为 $\kwperp = \kwgt\cos(25^\circ) = \km\kg\cos(25^\circ)$。

（a）忽略摩擦力。由于加速度平行于斜坡，我们只需考虑平行于斜坡的力。（垂直于斜坡的力之和为零，因为在该方向上没有加速度。）平行于斜坡的力是滑雪者的重力中平行于斜坡的部分 $\kwpar$ 和摩擦力 $\kff$。利用牛顿第二定律，并用下标表示平行于斜坡的量，

$$\kapar = \frac{\kFnetpar}{\km}$$

其中 $\kFnetpar = \kwpar = \km\kg\sin(25^\circ)$，这一部分假设没有摩擦力，因此

$$\kapar = \frac{\kFnetpar}{\km} = \frac{\km\kg\sin(25^\circ)}{\km} = \kg\sin(25^\circ)$$ $$(9.80\ \text{m/s}^2)(0.4226) = 4.14\ \text{m/s}^2$$

就是加速度。

（b）考虑摩擦力。现在我们有了摩擦力的给定值，并且知道它的方向平行于斜坡，阻碍接触表面之间的运动。因此，合外力现在是

$$\kFnetpar = \kwpar - \kff,$$

把它代入牛顿第二定律 $\kapar = \frac{\kFnetpar}{\km}$，得到

$$\kapar = \frac{\kFnetpar}{\km} = \frac{\kwpar - \kff}{\km} = \frac{\km\kg\sin(25^\circ) - \kff}{\km}.$$

代入已知值，得到

$$\kapar = \frac{(60.0\ \text{kg})(9.80\ \text{m/s}^2)(0.4226) - 45.0\ \text{N}}{60.0\ \text{kg}},$$

算得

$$\kapar = 3.39\ \text{m/s}^2,$$

这就是存在 45.0 N 的阻碍性摩擦力时平行于斜面的加速度。

讨论

由于摩擦力总是阻碍表面之间的运动，所以加速度在有摩擦力时比没有时小。事实上，有一个一般结论：如果斜面上的摩擦力可以忽略，那么沿斜面向下的加速度就是 $\ka = \kg\sin\ktheta$，与质量无关。这与前面讨论过的事实有关，即在没有空气阻力时，所有物体下落的加速度都相同。同样，所有物体，无论质量如何，沿无摩擦的斜面下滑的加速度都相同（如果角度相同）。法向力 $\km\kg\cos(25^\circ)$ 小于物体的重力。

把重力分解为分量

当物体静止在与水平面成角度 $\ktheta$ 的斜面上时，作用在物体上的重力被分解为两个分量：垂直于斜面的力 $\kwperp$ 和平行于斜面的力 $\kwpar$。重力的垂直力 $\kwperp$ 通常与法向力 $\kN$ 大小相等、方向相反。平行于斜面的力 $\kwpar$ 使物体沿斜面向下加速。摩擦力这种力 $\kff$ 阻碍物体的运动，所以它沿斜面向上作用。

在把物体的重力分解为分量时，一定要小心。如果斜面的角度为与水平面所成的角度 $\ktheta$，那么重力分量的大小为

$$\kwpar = \kwgt\sin(\ktheta) = \km\kg\sin(\ktheta)$$

和

$$\kwperp = \kwgt\cos(\ktheta) = \km\kg\cos(\ktheta).$$

张力

张力是沿介质长度方向的力，尤指由柔性介质（如绳或缆绳）传递的力。“张力”（tension）一词来自拉丁语中一个意为“拉伸”的词。并非巧合的是，把肌肉力传递到身体其他部位的柔韧的索状组织被称为肌腱。任何柔索，如细绳、绳、链条、钢丝或缆绳，都只能施加平行于其长度的拉力；因此，由柔索传递的力就是张力，其方向平行于该柔索。重要的是要理解，张力是柔索中的一种拉力。相比之下，请想想这句话：“你不能推一根绳子。”张力这种力沿绳的两端向外拉。

请看一个人用绳子吊着一个物体的情形，如图 4.14 所示。

绳中的张力必须等于所支撑物体的重力，我们可以用牛顿第二定律来证明这一点。如果图中5.00 kg 的物体是静止的，那么它的加速度为零，因而 $\kFnet = 0$。作用在物体上的仅有的外力是它的重力 $\kwgt$ 和绳子提供的张力 $\kTf$。

于是，对于5.00 kg 的物体（忽略绳子的质量），我们得到

$$\kTf = \km\kg = (5.00\ \text{kg})(9.80\ \text{m/s}^2) = 49.0\ \text{N}.$$

如果我们把绳子剪断并接入一根弹簧，弹簧就会伸长一段长度，对应于 49.0 N 的力，从而直接观察并测量绳中的张力这个力。

柔索常被用来绕过拐角传递力，例如在医院的牵引装置、手指关节或自行车的刹车线中。如果没有摩擦力，张力会毫无衰减地传递。只有它的方向发生改变，而且它总是平行于柔索。图 4.15（a）和（b）说明了这一点。

下垂钢丝中的张力

例题 4.6 · 钢丝中的张力有多大？

计算图 4.16 中支撑70.0 kg 的走钢丝者的钢丝中的张力。

思路

如图所示，钢丝并不是完全水平的（它不可能是！），而是在人的重力作用下弯曲了。因此，人两侧的张力都有一个向上的分量，可以支撑他的重力。与往常一样，力是矢量，用箭头形象地表示，箭头的方向与力的方向相同，长度与其大小成正比。所研究的系统是走钢丝者，作用在他身上的仅有的外力是他的重力 $\kwgt$ 以及两个张力 $\kTL$（左侧张力）和 $\kTR$（右侧张力），如图所示。忽略钢丝本身的重力是合理的。由于系统是静止的，合外力为零。现在可以用一点三角学来求张力。一个结论一开始就可以得出——从图的（b）部分可以看出，张力 $\kTL$ 和 $\kTR$ 的大小必须相等。这是因为绳中没有水平加速度，而向左和向右作用的仅有的力就是 $\kTL$ 和 $\kTR$。因此，这两个力的大小必须相等，它们才能相互抵消。

每当遇到没有任何两个矢量平行的二维矢量问题时，最简便的解法是选取一个方便的坐标系，把矢量投影到它的坐标轴上。在这个问题中，最好的坐标系是一个轴水平、另一个轴竖直。我们把水平轴称为 x 轴，把竖直轴称为 y 轴。

解

首先，我们需要把张力矢量分解为它们的水平和竖直分量。画一个新的受力图会有所帮助，图中画出作用在系统上的每个力的所有水平和竖直分量，如图 4.17 所示。

讨论

请注意，钢丝中的竖直张力起着法向力的作用，支撑着走钢丝者的重力。张力几乎是走钢丝者的 686 N 重力的六倍。由于钢丝近乎水平，它的张力的竖直分量只占钢丝中张力的一小部分。很大的水平分量的方向相反并相互抵消，所以钢丝中的张力大部分没有用来支撑走钢丝者的重力。

产生很大的张力

如果我们想产生很大的张力，只需对柔索施加一个垂直于它的力即可，如图 4.18 所示。正如我们在上一个例题中看到的，走钢丝者的重力就起着垂直于绳的力的作用。我们看到，绳中的张力与走钢丝者的重力有如下关系：

$$\kTf = \frac{\kwgt}{2\sin(\ktheta)}.$$

我们可以推广这个表达式，来描述在柔索中点处施加垂直力（$\kFperp$）时产生的张力 $\kTf$：

$$\kTf = \frac{\kFperp}{2\sin(\ktheta)}.$$

请注意，$\ktheta$ 是水平方向与弯曲的柔索之间的角。在这种情况下，当 $\ktheta$ 趋近于零时，$\kTf$ 变得非常大。即使任何柔索相对很小的重力也会使它下垂，因为如果它是水平的（即 $\ktheta = 0$ 且 $\sin\ktheta = 0$），就会产生无限大的张力。（见图 4.18。）

真实力与惯性参考系

除了已经提到的这些类型之外，力之间还有另一种区别。有些力是真实的，而另一些则不是。真实力是那些具有某种物理起源的力，例如引力。与之相对，虚拟力则是仅仅因为观察者处在加速参考系中而产生的，例如处在转动的参考系（如旋转木马）中，或者处在具有直线加速度的参考系（如正在减速的汽车）中。例如，如果一颗卫星在地球北半球上空正向正北飞行，那么在地球上的观察者看来，它似乎受到一个向西的力，而这个力没有物理起源。当然，这里实际发生的是，地球在向东自转，并在卫星下方向东运动。在地球参考系中，这看起来就像卫星受到一个向西的力，或者也可以解释为违反了牛顿第一定律（惯性定律）。惯性参考系是这样一种参考系：其中所有的力都是真实的，等价地，其中牛顿定律具有本章给出的简单形式。

地球的自转足够慢，因此地球近似是一个惯性参考系。通常必须做精密的实验才能观察到虚拟力以及与牛顿定律的微小偏离，例如刚才描述的效应。在大尺度上，例如对于天气系统和洋流的旋转，这些效应很容易观察到。

判断一个参考系是否为惯性参考系，关键因素在于它相对于已知的惯性参考系是否加速或转动。除非另有说明，本书所讨论的所有现象都是在惯性参考系中考虑的。

本节讨论的所有力都是真实力，但还有许多其他的真实力，如升力和推力，本节没有讨论。它们更为专门，没有必要讨论每一种力。然而，人们自然会问：我们在物理学中寻求的基本的简单性，在这一长串力的清单中体现在哪里？有些是否比其他的更基本？有些是否是同一种底层力的不同表现？这两个问题的答案都是肯定的，我们将在下一节（拓展专题）以及本书后面对近代物理学的讨论中看到。
