改变相而不改变温度的热量

到目前为止，我们讨论的都是由热传递引起的温度变化。如果冰熔化成液态水（即发生相变时），热传递不会引起温度变化。例如，想想在被太阳晒暖的屋顶上，水从正在熔化的冰锥上滴落的情形。反过来，制冰盒中的水在温度较低的周围环境的冷却下会结冰。

熔化固体需要能量，因为固体中分子之间的内聚键必须被拆开，分子在液体中才能以相当的动能四处运动；因此温度并不升高。同样，汽化液体也需要能量，因为液体中的分子是通过相互的吸引力发生作用的。在相变完成之前，温度没有变化。一杯起初为 $0^\circ\text{C}$ 的汽水，其温度在冰全部熔化之前一直保持 $0^\circ\text{C}$。反过来，凝固和凝结时会释放能量，通常以热能的形式释放。当分子被聚拢在一起时，内聚力做功。为了让分子保持在一起，相应的能量必须被放出（耗散） 图 14.8。

相变中涉及的能量取决于两个主要因素：键或力对的数目和强度。键的数目与分子数成正比，因而与样品的质量成正比。力的强度取决于分子的类型。使质量为 $\km$ 的样品发生相变所需的热量 $\kQh$ 由下式给出

$$\kQh = \km\kLf\ \text{(熔化/凝固),}$$ $$\kQh = \km\kLv\ \text{(汽化/凝结),}$$

其中，熔化热 $\kLf$ 和汽化热 $\kLv$ 是由实验测定的材料常量。见表 14.2。

潜热系数

潜热用 J/kg 作单位来度量。$\kLf$ 和 $\kLv$ 都取决于物质，尤其取决于前面所说的其分子力的强度。$\kLf$ 和 $\kLv$ 统称为潜热系数。它们之所以是潜的，即隐藏的，是因为在相变中，能量进入或离开一个系统，却不引起该系统的温度变化；所以实际上，这些能量是隐藏起来的。表 14.2 列出了 $\kLf$ 和 $\kLv$ 的代表性数值，以及熔点和沸点。

该表表明，相变中涉及大量的能量。例如，我们来看看要把 $0^\circ\text{C}$ 的一千克冰熔化，得到 $0^\circ\text{C}$ 的一千克水，需要多少能量。利用温度变化的方程和表 14.2 中水的数值，我们得到 $\kQh = \km\kLf = (1.0\ \text{kg})(334\ \text{kJ/kg}) = 334\ \text{kJ}$，这就是熔化一千克冰所需的能量。这是很大的能量，因为它相当于把 1 kg 液态水的温度从 $0^\circ\text{C}$ 升高到 $79.8^\circ\text{C}$ 所需的同样多的能量。使水汽化需要更多的能量；要把处于正常沸点（大气压下为 $100^\circ\text{C}$）的 1 kg 液态水变成蒸汽（水蒸气），需要 2256 kJ。这个例子表明，相变所需的能量与没有相变的温度变化所涉及的能量相比是巨大的。

把冰加热成蒸汽

为了更精确地考察相变的效应，我们来考虑向 $-20^\circ\text{C}$ 的一块冰样品中加入热量的情形（图 14.9）。冰的温度线性上升，以 $0.50\ \text{cal/g}\cdot{}^\circ\text{C}$ 的恒定速率吸收热量，直到它达到 $0^\circ\text{C}$。一旦达到这一温度，冰便开始熔化，直到全部的冰都熔化完，其间吸收 79.8 cal/g 的热量。在这次相变过程中，温度始终保持在 $0^\circ\text{C}$ 不变。全部的冰熔化后，液态水的温度上升，以 $1.00\ \text{cal/g}\cdot{}^\circ\text{C}$ 的新的恒定速率吸收热量。在 $100^\circ\text{C}$ 时，水开始沸腾，温度再次保持不变，而水在这次相变中吸收 539 cal/g 的热量。当全部液体都变成蒸汽（水蒸气）后，温度再次上升，以 $0.482\ \text{cal/g}\cdot{}^\circ\text{C}$ 的速率吸收热量。

沸点以下的蒸发

水可以在低于沸点的温度下蒸发。所需的能量比在沸点时更多，因为在低于 $100^\circ\text{C}$ 的温度下，水分子的动能小于在 $100^\circ\text{C}$ 时的动能，因而可从无规则的热运动中获得的能量更少。例如，在体温下，皮肤出汗需要输入 2428 kJ/kg 的热量，比 $100^\circ\text{C}$ 时的汽化热大约高 10%。这些热量来自皮肤，因而在炎热天气里提供了一种有效的冷却机制。高湿度会抑制蒸发，使体温可能升高，并在你的额头上留下未蒸发的汗水。

用冰块冷却汽水

例题 14.4 · 由相变计算末温：用冰块冷却汽水

用三块冰块冷却一杯 $20^\circ\text{C}$ 的汽水，汽水的质量为 $\kmsoda = 0.25\ \text{kg}$。冰的温度为 $0^\circ\text{C}$，每块冰的质量为 6.0 g。假设汽水放在泡沫塑料容器中，因此可以忽略热量损失。假设汽水与水具有相同的热容。求冰全部熔化后的末温。

思路

冰块处于 $0^\circ\text{C}$ 的熔点。热量从汽水传给冰，用于熔化。冰的熔化分两步进行：首先发生相变，固体（冰）在熔点转变为液态水，然后这些水的温度上升。熔化得到 $0^\circ\text{C}$ 的水，所以还有更多热量从汽水传给这些水，直到水加汽水这个系统达到热平衡，

$$\kQice = -\kQsoda.$$

传给冰的热量为 $\kQice = \kmice\kLf + \kmice\kcW(\kTempf - 0^\circ\text{C})$。汽水放出的热量为 $\kQsoda = \kmsoda\kcW(\kTempf - 20^\circ\text{C})$。由于没有热量损失，$\kQice = -\kQsoda$，所以

$$\kmice\kLf + \kmice\kcW(\kTempf - 0^\circ\text{C}) = -\kmsoda\kcW(\kTempf - 20^\circ\text{C}).$$

把所有含 $\kTempf$ 的项移到左边，其他项移到右边。解出未知量 $\kTempf$：

$$\kTempf = \frac{\kmsoda\kcW(20^\circ\text{C}) - \kmice\kLf}{(\kmsoda + \kmice)\kcW}.$$

解

  1. 确定已知量。冰的质量为 $\kmice = 3 \times 6.0\ \text{g} = 0.018\ \text{kg}$，汽水的质量为 $\kmsoda = 0.25\ \text{kg}$。
  2. 计算分子中的各项： $$\kmsoda\kcW(20^\circ\text{C}) = (0.25\ \text{kg})(4186\ \text{J/(kg}\cdot{}^\circ\text{C)})(20^\circ\text{C}) = 20{,}930\ \text{J}$$ 和 $$\kmice\kLf = (0.018\ \text{kg})(334{,}000\ \text{J/kg}) = 6012\ \text{J.}$$
  3. 计算分母： $$(\kmsoda + \kmice)\kcW = (0.25\ \text{kg} + 0.018\ \text{kg})(4186\ \text{J/(kg}\cdot{}^\circ\text{C)}) = 1122\ \text{J/}{}^\circ\text{C}.$$
  4. 计算末温： $$\kTempf = \frac{20{,}930\ \text{J} - 6012\ \text{J}}{1122\ \text{J/}{}^\circ\text{C}} = 13^\circ\text{C.}$$

讨论

这个例子说明了相变过程中涉及的能量之巨大。冰的质量只有水的质量的约 7%，却使汽水的温度发生了明显的变化。虽然我们假设冰处于凝固点，但这并不正确：典型的温度是 $-6^\circ\text{C}$。然而，这一修正给出的末温与我们求得的结果基本相同。你能解释为什么吗？

凝结和凝固把能量还回来

我们已经看到，汽化需要从周围环境向液体进行热传递，因此周围环境释放能量。凝结是逆过程，会使周围环境的温度升高。这种升高可能令人意外，因为我们总是把凝结与冷的物体联系在一起——例如图中的玻璃杯。然而，要使蒸气凝结，必须从正在凝结的分子中移走能量。这个能量与使相变朝相反方向（从液体到蒸气）发生所需的能量完全相同，所以可以由 $\kQh = \km\kLv$ 算出。

实际应用

液体凝固时也会释放能量。佛罗里达的果农利用这一现象，在温度接近凝固点 $(0^\circ\text{C})$ 时保护橙子。果农向果园里的植株喷水，使水凝固，热量便释放给树上生长的橙子。这样就避免了橙子内部的温度降到凝固点以下，否则会损坏果实。

升华

升华是从固相到气相的转变。你可能注意到过，雪可以凭空消失而不留一点液态水的痕迹，或者冷冻室里的冰块会消失不见。反过来也成立：霜可以在极冷的窗户上形成，而不经过液态阶段。一种常见的效果是用干冰制造“烟”，干冰就是固态二氧化碳。升华之所以发生，是因为固体的平衡蒸气压不为零。某些空气清新剂利用固体的升华把香水注入房间。樟脑丸是会升华的酚（一种有机化合物）的一个毒性较轻的例子，而有些固体，例如四氧化锇，毒性极大，必须保存在密封容器中，以防人体接触到其升华产生的蒸气。

所有的相变都涉及热量。对于固体与蒸气之间的直接转变，所需的能量由方程 $\kQh = \km\kLs$ 给出，其中 $\kLs$ 是升华热，即把 1.00 kg 物质由固相变为气相所需的能量。$\kLs$ 与 $\kLf$ 和 $\kLv$ 类似，其数值取决于物质。升华需要输入能量，所以干冰是一种有效的冷却剂，而其逆过程（即凝华）则释放能量。升华所需的能量与其他相变所需的能量具有相同的数量级。

热传递效应的解题策略

本节和上一节所介绍的内容，使我们能够计算与温度和相变有关的任意多种效应。在每种情形中，都需要先确定发生的是哪些温度变化和相变，然后应用适当的方程。请记住，热传递和功都能引起温度变化和相变。

  1. 审视情形，确定温度或相是否发生了变化。是否有热传递进入或离开系统？当是否发生相变并不明显时，你不妨先把问题当作没有相变来求解，并检查所得的温度变化。如果这一变化大到足以越过沸点或熔点，那就应当回头分步骤求解——温度变化、相变、随后的温度变化，依此类推。
  2. 确定并列出所有温度和相发生变化的物体。
  3. 准确确定问题中需要求出什么（确定未知量）。写成清单会有帮助。
  4. 列出问题中已给出的量，或可由题述推断出的量（确定已知量）。
  5. 就待求的量（未知量）解出适当的方程。如果有温度变化，所传递的热量取决于比热容（见表 14.1）；而对于相变，所传递的热量取决于潜热。见表 14.2。
  6. 把已知量连同它们的单位代入适当的方程，得出带单位的数值解。如果该过程不止一个阶段（例如温度变化之后接着发生相变），你就需要分步骤进行。
  7. 检验答案是否合理：它说得通吗？例如，要确保温度变化没有同时引起你未曾考虑的相变。
