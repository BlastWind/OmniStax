决定所传递热量的三个因素

热传递的主要效应之一是温度变化：加热使温度升高，冷却使温度降低。我们假设没有相变，并且没有对系统或由系统所做的功。实验表明，所传递的热量取决于三个因素——温度的变化、系统的质量，以及物质的种类和相。

对温度变化和质量的依赖关系很容易理解。由于一个原子或分子的（平均）动能与热力学温度成正比，系统的内能就与热力学温度以及原子或分子的数目成正比。由于所传递的热量等于内能的变化，热量就与物质的质量和温度变化成正比。所传递的热量还取决于物质的种类，例如，使温度升高所需的热量，乙醇比水少。对于同一种物质，所传递的热量还取决于相（气态、液态或固态）。

热传递与温度变化

热传递与温度变化

热传递和温度变化之间的定量关系包含了这三个因素：

$$\kQh = \km\kcspec\kdTemp,$$

其中 $\kQh$ 是热传递的符号，$\km$ 是物质的质量，$\kdTemp$ 是温度的变化。符号 $\kcspec$ 代表比热容，它取决于材料和相。比热容是使 1.00 kg 质量的物质温度改变 $1.00^\circ\text{C}$ 所需的热量。比热容 $\kcspec$ 是物质的一种属性；它的 SI 单位是 $\text{J/}(\text{kg}\cdot\text{K})$ 或 $\text{J/}(\text{kg}\cdot{}^\circ\text{C}).$ 请回想，以开尔文和摄氏度为单位时，温度变化 $(\kdTemp)$ 是相同的。如果热传递以千卡计量，那么比热容的单位是 $\text{kcal/}(\text{kg}\cdot{}^\circ\text{C}).$

比热容的数值通常必须查表，因为没有简单的方法可以算出它们。一般来说，比热容还取决于温度。表 14.1 列出了各种物质的比热容的代表性数值。除气体外，大多数物质的比热容对温度和体积的依赖都很弱。从这张表中可以看出，水的比热容是玻璃的五倍、铁的十倍，这意味着，使水的温度升高相同的量，所需的热量是玻璃的五倍；而使水的温度升高，所需的热量是铁的十倍。事实上，水的比热容是所有材料中最大的之一，这对维持地球上的生命很重要。

例题 14.1 · 计算所需的热量：加热铝锅中的水

在炉灶上用一个 0.500 kg 的铝锅加热 0.250 升水，使水温从 $20.0^\circ\text{C}$ 升到 $80.0^\circ\text{C}$。（a）需要多少热量？这些热量中有百分之几用来升高（b）锅和（c）水的温度？

思路

锅和水始终处于相同的温度。把锅放在炉灶上时，水和锅的温度升高的幅度相同。我们对给定的温度变化以及水和铝的质量，使用热传递的公式。水和铝的比热容数值在表 14.1 中给出。

解

因为水与铝处于热接触，所以锅和水的温度相同。

  1. 计算温度差： $$\kdTemp = \kTempf - \kTempi = 60.0^\circ\text{C.}$$
  2. 计算水的质量。因为水的密度是 $1000\ \text{kg/m}^3$，所以一升水的质量为 1 kg，0.250 升水的质量就是 $\km_{\text{w}} = 0.250\ \text{kg}$。
  3. 计算传给水的热量。使用表 14.1 中水的比热容： $$\kQh_{\text{w}} = \km_{\text{w}}\kcspec_{\text{w}}\kdTemp = (0.250\ \text{kg})(4186\ \text{J/(kg}\cdot{}^\circ\text{C)})(60.0^\circ\text{C}) = 62.8\ \text{kJ.}$$
  4. 计算传给铝的热量。使用表 14.1 中铝的比热容： $$\kQh_{\text{Al}} = \km_{\text{Al}}\kcspec_{\text{Al}}\kdTemp = (0.500\ \text{kg})(900\ \text{J/(kg}\cdot{}^\circ\text{C)})(60.0^\circ\text{C}) = 27.0 \times 10^{4}\ \text{J} = 27.0\ \text{kJ.}$$
  5. 比较流入锅和流入水的热量所占的百分比。首先求出所传递的热量总和： $$\kQh_{\text{Total}} = \kQh_{\text{W}} + \kQh_{\text{Al}} = 62.8\ \text{kJ} + 27.0\ \text{kJ} = 89.8\ \text{kJ.}$$

于是，用于加热锅的热量为

$$\frac{27.0\ \text{kJ}}{89.8\ \text{kJ}} \times 100\% = 30.1\%,$$

而用于加热水的热量为

$$\frac{62.8\ \text{kJ}}{89.8\ \text{kJ}} \times 100\% = 69.9\%.$$

讨论

在这个例子中，传给容器的热量占所传递热量总和的很大一部分。虽然锅的质量是水的两倍，但水的比热容却比铝的四倍还多。因此，要使水产生给定的温度变化，所需的热量是使铝锅产生同样变化所需的两倍多一点。

对物质做功所引起的温度升高

例题 14.2 · 计算对物质做功所引起的温度升高：卡车刹车在下坡行驶时过热

下坡行驶时用来控制车速的卡车刹车做功，把重力势能转化为刹车材料内能的增加（温度升高）。这种转化使重力势能不致转化为卡车的动能。问题在于，卡车的质量比吸收这部分能量的刹车材料的质量大得多，而且温度升高可能发生得太快，以致来不及有足够的热量从刹车传递到周围环境中。

计算 100 kg 刹车材料的温度升高，该材料的平均比热容为 $800\ \text{J/(kg}\cdot{}^\circ\text{C)}$，假设该材料保留了一辆 10,000 kg 的卡车下坡 75.0 m（竖直位移）、以恒定速率行驶时所释放能量的 10%。

思路

如果不踩刹车，重力势能转化为动能。踩下刹车时，重力势能转化为刹车材料的内能。我们先计算整辆卡车在下坡中损失的重力势能 $(\kM gh)$，再求出仅刹车材料产生的温度升高。

解

  1. 计算卡车下坡时重力势能的变化 $$\kM gh = (10{,}000\ \text{kg})(9.80\ \text{m/s}^2)(75.0\ \text{m}) = 7.35 \times 10^{6}\ \text{J.}$$
  2. 由所传递的热量计算温度，用 $\kQh = 0.1\kM gh$，因为第 1 步算出的能量中只有 10% 以热量的形式保留下来，并且 $$\kdTemp = \frac{\kQh}{\km\kcspec},$$

    其中 $\km$ 是刹车材料的质量。代入 $\km = 100\ \text{kg}$ 和 $\kcspec = 800\ \text{J/(kg}\cdot{}^\circ\text{C)}$，得到

    $$\kdTemp = \frac{(7.35 \times 10^{6}\ \text{J})}{(100\ \text{kg})(800\ \text{J/(kg}\cdot{}^\circ\text{C)})} = 9.2^\circ\text{C.}$$

讨论

这同一个道理，也是近来汽车混合动力技术的基础：刹车把机械能（重力势能）转化为电能（电池）。

两个物体之间传递的热量

例题 14.3 · 计算热量在两个物体之间传递后的末温：把冷水倒入热锅

假设你把 0.250 kg、$20.0^\circ\text{C}$ 的水（约一杯）倒入一个刚离开炉灶、温度为 $150^\circ\text{C}$ 的 0.500 kg 铝锅中。假设锅放在隔热垫上，并且蒸发掉的水量可以忽略。片刻之后，水和锅达到热平衡时，温度是多少？

思路

锅放在隔热垫上，所以与周围环境之间几乎没有热传递。起初锅和水不处于热平衡：锅的温度比水高。水和锅一接触，热传递就使热平衡得以恢复。因为锅与水之间的热传递进行得很快，所以蒸发掉的水的质量可以忽略，锅所失去的热量的大小等于水所得到的热量。一旦锅与水之间达到热平衡，热交换就停止。热交换可以写成 $|\kQhot| = \kQcold$。

解

  1. 用热传递的公式 $\kQh = \km\kcspec\kdTemp$，把铝锅所失去的热量用锅的质量、铝的比热容、锅的初温和末温表示出来： $$\kQhot = \kmAl\kcAl(\kTempf - 150^\circ\text{C}).$$
  2. 把水所得到的热量用水的质量、水的比热容、水的初温和末温表示出来： $$\kQcold = \kmW\kcW(\kTempf - 20.0^\circ\text{C}).$$
  3. 注意 $\kQhot < 0$，$\kQcold > 0$，并且它们之和必须为零，因为热锅所失去的热量必定等于冷水所得到的热量： $$\begin{aligned}\kQcold + \kQhot &= 0,\\ \kQcold &= -\kQhot,\\ \kmW\kcW(\kTempf - 20.0^\circ\text{C}) &= -\kmAl\kcAl(\kTempf - 150^\circ\text{C}).\end{aligned}$$
  4. 把所有含 $\kTempf$ 的项移到左边，把其余各项移到右边，解出 $\kTempf$， $$\kTempf = \frac{\kmAl\kcAl(150^\circ\text{C}) + \kmW\kcW(20.0^\circ\text{C})}{\kmAl\kcAl + \kmW\kcW},$$

    并代入数值：

    $$\begin{aligned}\kTempf &= \frac{(0.500\ \text{kg})(900\ \text{J/(kg}\cdot{}^\circ\text{C)})(150^\circ\text{C}) + (0.250\ \text{kg})(4186\ \text{J/(kg}\cdot{}^\circ\text{C)})(20.0^\circ\text{C})}{(0.500\ \text{kg})(900\ \text{J/(kg}\cdot{}^\circ\text{C)}) + (0.250\ \text{kg})(4186\ \text{J/(kg}\cdot{}^\circ\text{C)})}\\ &= \frac{88430\ \text{J}}{1496.5\ \text{J/}^\circ\text{C}}\\ &= 59.1^\circ\text{C.}\end{aligned}$$

讨论

这是一个典型的量热学问题——把两个温度不同的物体放在一起接触，它们交换热量，直到达到共同的温度。为什么末温比起 $150^\circ\text{C}$ 来，要接近 $20.0^\circ\text{C}$ 得多？原因在于，水的比热容比大多数常见物质都大，因此在给定的热传递下，水的温度变化很小。像湖泊这样的大片水体，需要大量的热量才能使其温度明显升高。这就解释了，为什么即使空气的温度变化很大，湖水的温度在一天之中仍相对保持不变。然而，水的温度在更长的时间内（例如，从夏季到冬季）确实会改变。

陆地和水升温的快慢不同

居家实验：陆地和水的温度变化

陆地和水，哪个升温更快？

研究热容的差异：

  • 把质量相等、温度相同的干沙（或土壤）和水分别放入两个小罐。（土壤或沙的平均密度约为水的 1.6 倍，所以要得到大致相等的质量，水的体积应多取 $50\%$。）
  • 用同样长的时间对二者加热（用烤箱或加热灯）。
  • 记录这两份质量的末温。
  • 现在，通过加热更长的时间，使两个罐子达到相同的温度。
  • 把罐子从热源上拿开，每隔 5 分钟测量一次它们的温度，持续约 30 分钟。

哪个样品冷却得最快？这个活动再现了形成陆风和海风的现象。
