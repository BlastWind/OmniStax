Boundary value problems

Before we tackle the Fourier series, we study the so-called boundary value problems (or endpoint problems). Consider

$$ \kxdprime + \klambda \kx = 0, \quad \kx(a) = 0, \quad \kx(b) = 0, $$

for some constant $\klambda$, where $\kx(t)$ is defined for $t$ in the interval $[a,b]$. Previously we specified the value of the solution and its derivative at a single point. Now we specify the value of the solution at two different points. As $\kx=0$ is a solution, existence of solutions is not a problem. Uniqueness of solutions is another issue. The general solution to $\kxdprime + \klambda \kx = 0$ has two arbitrary constants. It is, therefore, natural (but wrong) to believe that requiring two conditions guarantees a unique solution.

Example 4.1.1

Take $\klambda = 1$, $a=0$, $b=\pi$. That is,

$$ \kxdprime + \kx = 0, \quad \kx(0) = 0, \quad \kx(\pi) = 0. $$

Then $\kx = \sin t$ is another solution (besides $\kx=0$) satisfying both boundary conditions. There are more. Write down the general solution of the differential equation, which is $\kx= A \cos t + B \sin t$. The condition $\kx(0) = 0$ forces $A=0$. Letting $\kx(\pi) = 0$ does not give us any more information, as $\kx = B \sin t$ already satisfies both boundary conditions. Hence, there are infinitely many solutions of the form $\kx = B \sin t$, where $B$ is an arbitrary constant.

Example 4.1.2

On the other hand, consider $\klambda = 2$. That is,

$$ \kxdprime + 2 \kx = 0, \quad \kx(0) = 0, \quad \kx(\pi) = 0. $$

Then the general solution is $\kx= A \cos \bigl( \sqrt{2}\,t\bigr) + B \sin \bigl( \sqrt{2}\,t\bigr)$. Letting $\kx(0) = 0$ still forces $A = 0$. We apply the second condition to find $0=\kx(\pi) = B \sin \bigl( \sqrt{2}\,\pi\bigr)$. As $\sin \bigl( \sqrt{2}\,\pi\bigr) \neq 0$, we obtain $B = 0$. Therefore, $\kx=0$ is the unique solution to this problem.

What is going on? We will be interested in finding which constants $\klambda$ allow a nonzero solution, and we will be interested in finding those solutions. This problem is an analogue of finding eigenvalues and eigenvectors of matrices.

Eigenvalue problems

For basic Fourier series theory, we will need the following three eigenvalue problems:

$$ \kxdprime + \klambda \kx = 0, \quad \kx(a) = 0, \quad \kx(b) = 0 , \tag{4.1}$$
$$ \kxdprime + \klambda \kx = 0, \quad \kxprime(a) = 0, \quad \kxprime(b) = 0 , \tag{4.2}$$

and

$$ \kxdprime + \klambda \kx = 0, \quad \kx(a) = \kx(b), \quad \kxprime(a) = \kxprime(b) . \tag{4.3}$$

A number $\klambda$ is called an eigenvalue of (4.1) (resp. (4.2) or (4.3)) if and only if there exists a nonzero (not identically zero) solution to (4.1) (resp. (4.2) or (4.3)) given that specific $\klambda$. A nonzero solution is called a corresponding eigenfunction. We will consider more general equations and boundary conditions, but we will postpone this until chapter 5.

Note the similarity to eigenvalues and eigenvectors of matrices. The similarity is not just coincidental. If we think of the equations as differential operators, then we are doing the same exact thing. Think of a function $\kx(t)$ as a vector with infinitely many components (one for each $t$). Let $L = -\frac{d^2}{{dt}^2}$ be the linear operator. Then the eigenvalue/eigenfunction pair should be $\klambda$ and nonzero $\kx$ such that $L\kx = \klambda \kx$. In other words, we are looking for nonzero functions $\kx$ satisfying certain endpoint conditions that solve $(L- \klambda)\kx = 0$. A lot of the formalism from linear algebra still applies here, though we will not pursue this line of reasoning too far.

Example 4.1.3

Find the eigenvalues and eigenfunctions of

$$ \kxdprime + \klambda \kx = 0, \quad \kx(0) = 0, \quad \kx(\pi) = 0 . $$

We have to handle the cases $\klambda > 0$, $\klambda = 0$, and $\klambda < 0$ separately. First, suppose that $\klambda > 0$. Then the general solution to $\kxdprime+\klambda \kx = 0$ is

$$ \kx = A \cos \bigl( \sqrt{\klambda}\, t\bigr) + B \sin \bigl( \sqrt{\klambda}\, t\bigr). $$

The condition $\kx(0) = 0$ implies immediately $A = 0$. Next

$$ 0 = \kx(\pi) = B \sin \bigl( \sqrt{\klambda}\, \pi \bigr) . $$

If $B$ is zero, then $\kx$ is not a nonzero solution. So to get a nonzero solution, we must have that $\sin \bigl( \sqrt{\klambda}\, \pi\bigr) = 0$. Hence, $\sqrt{\klambda}\, \pi$ must be an integer multiple of $\pi$. In other words, $\sqrt{\klambda} = k$ for a positive integer $k$. Hence, the positive eigenvalues are $k^2$ for all integers $k \geq 1$. Corresponding eigenfunctions can be taken as $\kx=\sin (k t)$. Just like for eigenvectors, constant multiples of an eigenfunction are also eigenfunctions, so we only need to pick one.

Now, suppose that $\klambda = 0$. In this case, the equation is $\kxdprime = 0$, and its general solution is $\kx = At + B$. The condition $\kx(0) = 0$ implies that $B=0$, and $\kx(\pi) = 0$ implies that $A = 0$. This means that $\klambda = 0$ is not an eigenvalue.

Finally, suppose that $\klambda < 0$. In this case, we have the general solution

$$ \kx = A \cosh \bigl( \sqrt{-\klambda}\, t\bigr) + B \sinh \bigl( \sqrt{-\klambda}\, t \bigr) . $$

Letting $\kx(0) = 0$ implies that $A = 0$ (recall $\cosh 0 = 1$ and $\sinh 0 = 0$). So our solution must be $\kx = B \sinh \bigl( \sqrt{-\klambda}\, t \bigr)$ and satisfy $\kx(\pi) = 0$. This is only possible if $B$ is zero. Why? Because $\sinh \xi$ is only zero when $\xi=0$. You should plot $\sinh$ to see this fact. We can also see this from the definition of $\sinh$. We get $0 = \sinh \xi = \frac{e^\xi - e^{-\xi}}{2}$. Hence $e^\xi = e^{-\xi}$, which implies $\xi = -\xi$ and that is only true if $\xi=0$. So there are no negative eigenvalues.

In summary, the eigenvalues and corresponding eigenfunctions are

$$ \klambdak = k^2 \qquad \text{with an eigenfunction} \qquad \kxk = \sin (k t) \qquad \text{for all integers } k \geq 1 . $$

Example 4.1.4

Compute the eigenvalues and eigenfunctions of

$$ \kxdprime + \klambda \kx = 0, \quad \kxprime(0) = 0, \quad \kxprime(\pi) = 0 . $$

Again we have to handle the cases $\klambda > 0$, $\klambda = 0$, $\klambda < 0$ separately. First suppose that $\klambda > 0$. The general solution to $\kxdprime+\klambda \kx = 0$ is $\kx = A \cos \bigl( \sqrt{\klambda}\, t\bigr) + B \sin \bigl( \sqrt{\klambda}\, t\bigr)$. So

$$ \kxprime = -A\sqrt{\klambda}\, \sin \bigl( \sqrt{\klambda}\, t\bigr) + B\sqrt{\klambda}\, \cos \bigl(\sqrt{\klambda}\, t\bigr) . $$

The condition $\kxprime(0) = 0$ implies immediately $B = 0$. Next

$$ 0 = \kxprime(\pi) = -A\sqrt{\klambda}\, \sin \bigl( \sqrt{\klambda}\, \pi\bigr) . $$

Again $A$ cannot be zero if $\klambda$ is to be an eigenvalue, and $\sin \bigl( \sqrt{\klambda}\, \pi\bigr)$ is only zero if $\sqrt{\klambda} = k$ for a positive integer $k$. Hence, the positive eigenvalues are again $k^2$ for all integers $k \geq 1$. And the corresponding eigenfunctions can be taken as $\kx=\cos (k t)$.

Now suppose that $\klambda = 0$. In this case, the equation is $\kxdprime = 0$ and the general solution is $\kx = At + B$ so $\kxprime = A$. The condition $\kxprime(0) = 0$ implies that $A=0$. The condition $\kxprime(\pi) = 0$ also implies $A=0$. Hence $B$ could be anything (let us take it to be 1). So $\klambda = 0$ is an eigenvalue and $\kx=1$ is a corresponding eigenfunction.

Finally, let $\klambda < 0$. In this case, the general solution is $\kx = A \cosh \bigl( \sqrt{-\klambda}\, t\bigr) + B \sinh \bigl( \sqrt{-\klambda}\, t\bigr)$ and

$$ \kxprime = A\sqrt{-\klambda}\, \sinh \bigl( \sqrt{-\klambda}\, t\bigr) + B\sqrt{-\klambda}\, \cosh \bigl( \sqrt{-\klambda}\, t \bigr) . $$

We have already seen (with roles of $A$ and $B$ switched) that for this expression to be zero at $t=0$ and $t=\pi$, we must have $A=B=0$. Hence, there are no negative eigenvalues.

In summary, the eigenvalues and corresponding eigenfunctions are

$$ \klambdak = k^2 \qquad \text{with an eigenfunction} \qquad \kxk = \cos (k t) \qquad \text{for all integers } k \geq 1 , $$

and there is another eigenvalue

$$ \klambdazero = 0 \qquad \text{with an eigenfunction} \qquad \kx_0 = 1. $$

The following problem is the one that leads to the general Fourier series.

Example 4.1.5

Compute the eigenvalues and eigenfunctions of

$$ \kxdprime + \klambda \kx = 0, \quad \kx(-\pi) = \kx(\pi), \quad \kxprime(-\pi) = \kxprime(\pi) . $$

We have not specified the values or the derivatives at the endpoints, but rather that they are the same at the beginning and at the end of the interval.

We skip $\klambda < 0$. The computations are the same as before, and again we find that there are no negative eigenvalues.

For $\klambda = 0$, the general solution is $\kx = At + B$. The condition $\kx(-\pi) = \kx(\pi)$ implies that $A=0$ ($A\pi + B = -A\pi +B$ implies $A=0$). The second condition $\kxprime(-\pi) = \kxprime(\pi)$ says nothing about $B$ and hence $\klambda=0$ is an eigenvalue with a corresponding eigenfunction $\kx=1$.

For $\klambda > 0$ we get that $\kx = A \cos \bigl( \sqrt{\klambda}\, t \bigr) + B \sin \bigl( \sqrt{\klambda}\, t\bigr)$. Now

$$ \underbrace{A \cos \bigl(-\sqrt{\klambda}\, \pi\bigr) + B \sin \bigl(-\sqrt{\klambda}\, \pi\bigr)}_{\kx(-\pi)} = \underbrace{A \cos \bigl( \sqrt{\klambda}\, \pi \bigr) + B \sin \bigl( \sqrt{\klambda}\, \pi\bigr)}_{\kx(\pi)} . $$

We remember that $\cos (- \theta) = \cos (\theta)$ and $\sin (-\theta) = - \sin (\theta)$. Therefore,

$$ A \cos \bigl(\sqrt{\klambda}\, \pi\bigr) - B \sin \bigl( \sqrt{\klambda}\, \pi\bigr) = A \cos \bigl(\sqrt{\klambda}\, \pi\bigr) + B \sin \bigl( \sqrt{\klambda}\, \pi\bigr). $$

Hence either $B=0$ or $\sin \bigl( \sqrt{\klambda}\, \pi\bigr) = 0$. Similarly (exercise), if we differentiate $\kx$ and plug in the second condition, we find that $A=0$ or $\sin \bigl( \sqrt{\klambda}\, \pi\bigr) = 0$. Therefore, unless we want $A$ and $B$ to both be zero (which we do not), we must have $\sin \bigl( \sqrt{\klambda}\, \pi \bigr) = 0$. Hence, $\sqrt{\klambda}$ is an integer and the eigenvalues are yet again $\klambda = k^2$ for an integer $k \geq 1$. In this case, however, $\kx = A \cos (k t) + B \sin (k t)$ is an eigenfunction for any $A$ and any $B$. So we have two linearly independent eigenfunctions $\sin (kt)$ and $\cos (kt)$. Remember that for a matrix, we can also have two eigenvectors corresponding to a single eigenvalue if the eigenvalue is repeated.

In summary, the eigenvalues and corresponding eigenfunctions are

$$ \begin{align*} & \klambdak = k^2 & & \text{with eigenfunctions} & & \cos (k t) \quad \text{and}\quad \sin (k t) & & \text{for all integers } k \geq 1 , \\ & \klambdazero = 0 & & \text{with an eigenfunction} & & \kx_0 = 1. \end{align*} $$

Orthogonality of eigenfunctions

Something that will be very useful in the next section is the orthogonality property of the eigenfunctions. This is an analogue of the following fact about eigenvectors of a matrix. A matrix is called symmetric if $A = A^T$ (it is equal to its transpose). Eigenvectors for two distinct eigenvalues of a symmetric matrix are orthogonal. The differential operators we are dealing with act much like a symmetric matrix. We, therefore, get the following theorem.

Theorem 4.1.1

Suppose that $\kxone(t)$ and $\kxtwo(t)$ are two eigenfunctions of the problem (4.1), (4.2), or (4.3) for two different eigenvalues $\klambdaone$ and $\klambdatwo$. Then they are orthogonal in the sense that

$$ \int_a^b \kxone(t) \kxtwo(t) \,dt = 0 . $$

The terminology comes from the fact that the integral is a type of inner product. We will expand on this in the next section. The theorem has a very short, elegant, and illuminating proof so we give it here. First, we have the following two equations.

The last equality holds because of the boundary conditions. For example, if we consider (4.1) we have $\kxone(a) = \kxone(b) = \kxtwo(a) = \kxtwo(b) = 0$ and so $\kxtwoprime \kxone - \kxtwo \kxoneprime$ is zero at both $a$ and $b$. As $\klambdaone \neq \klambdatwo$, the theorem follows.

The function $\sin (n t)$ is an eigenfunction for the problem $\kxdprime+\klambda \kx = 0$, $\kx(0) = 0$, $\kx(\pi) = 0$. Hence for positive integers $n$ and $m$, we have the integrals

$$ \int_{0}^\pi \sin (mt) \sin (nt) \,dt = 0 , \quad \text{when } m \neq n. $$

Similarly, still assuming that $m$ and $n$ are positive integers,

$$ \int_{0}^\pi \cos (mt) \cos (nt) \,dt = 0 , \quad \text{when } m \neq n, \qquad \text{and} \qquad \int_{0}^\pi \cos (nt) \,dt = 0 . $$

Finally, we also get

$$ \int_{-\pi}^\pi \sin (mt) \sin (nt) \,dt = 0 , \quad \text{when } m \neq n, \qquad \text{and} \qquad \int_{-\pi}^\pi \sin (nt) \,dt = 0 , $$ $$ \int_{-\pi}^\pi \cos (mt) \cos (nt) \,dt = 0 , \quad \text{when } m \neq n, \qquad \text{and} \qquad \int_{-\pi}^\pi \cos (nt) \,dt = 0 , $$

and

$$ \int_{-\pi}^\pi \cos (mt) \sin (nt) \,dt = 0 \qquad \text{(even if $m=n$).} $$

Fredholm alternative

We now touch on a very useful theorem in the theory of differential equations. The theorem holds in a more general setting than we are going to state it, but for our purposes the following statement is sufficient. We will give a slightly more general version in chapter 5.

Theorem 4.1.2

Fredholm alternative

Exactly one of the following statements holds. Either

$$ \kxdprime + \klambda \kx = 0, \quad \kx(a) = 0, \quad \kx(b) = 0 \tag{4.4}$$

has a nonzero solution, or

$$ \kxdprime + \klambda \kx = \kf(t), \quad \kx(a) = 0, \quad \kx(b) = 0 \tag{4.5}$$

has a unique solution for every function $\kf$ continuous on $[a,b]$.

The theorem is also true for the other types of boundary conditions we considered. The theorem means that if $\klambda$ is not an eigenvalue, the nonhomogeneous equation (4.5) has a unique solution for every right-hand side. On the other hand, if $\klambda$ is an eigenvalue, then (4.5) need not have a solution for every $\kf$, and furthermore, even if it happens to have a solution, the solution is not unique.

We also want to reinforce the idea here that linear differential operators have much in common with matrices. So it is no surprise that there is a finite-dimensional version of Fredholm alternative for matrices as well. Let $A$ be an $n \times n$ matrix. The Fredholm alternative then states that either $(A-\klambda I) \vec{x} = \vec{0}$ has a nontrivial solution, or $(A-\klambda I) \vec{x} = \vec{b}$ has a unique solution for every $\vec{b}$.

A lot of intuition from linear algebra can be applied to linear differential operators, but one must be careful of course. For example, one difference we have already seen is that in general a differential operator will have infinitely many eigenvalues, while a matrix has only finitely many.

Application

Let us consider a physical application of an endpoint problem. Suppose we have a tightly stretched quickly spinning elastic string or rope of uniform linear density $\rho$, for example in $\mathrm{kg}/\mathrm{m}$. Let us put this problem into the $xy$-plane and both $x$ and $\ky$ are in meters. The $x$-axis represents the position on the string. The string rotates at angular velocity $\komega$, in $\mathrm{radians}/\mathrm{s}$. Imagine that the whole $xy$-plane rotates at angular velocity $\komega$. This way, the string stays in this $xy$-plane and $\ky$ measures its deflection from the equilibrium position, $\ky=0$, on the $x$-axis. Hence the graph of $\ky$ gives the shape of the string. We consider an ideal string with no volume, just a mathematical curve. We suppose the tension on the string is a constant $T$ in Newtons. Assuming that the deflection is small, we can use Newton’s second law (let us skip the derivation) to get the equation

$$ T \kydprime + \rho \komega^2 \ky = 0 . $$

To check the units, notice that the units of $\kydprime$ are $\mathrm{m}/\mathrm{m^2}$, as the derivative is in terms of $x$.

Let $L$ be the length of the string (in meters) and the string is fixed at both endpoints. Hence, $\ky(0) = 0$ and $\ky(L) = 0$. See Figure 4.1.

We rewrite the equation as $\kydprime + \frac{\rho \komega^2}{T} \ky = 0$. The setup is similar to Example 4.1.3, except for the interval length being $L$ instead of $\pi$. We are looking for eigenvalues of $\kydprime + \klambda \ky = 0, \ky(0) = 0, \ky(L) = 0$ where $\klambda = \frac{\rho \komega^2}{T}$. As before, there are no nonpositive eigenvalues. With $\klambda > 0$, the general solution to the equation is $\ky = A \cos \bigl( \sqrt{\klambda} \,x \bigr) + B \sin \bigl( \sqrt{\klambda} \,x \bigr)$. The condition $\ky(0) = 0$ implies that $A = 0$ as before. The condition $\ky(L) = 0$ implies that $\sin \bigl( \sqrt{\klambda} \, L\bigr) = 0$ and hence $\sqrt{\klambda} \, L = k \pi$ for some integer $k > 0$, so

$$ \frac{\rho \komega^2}{T} = \klambda = \frac{k^2 \pi^2}{L^2} . $$

What does this say about the shape of the string? It says that for all parameters $\rho$, $\komega$, $T$ not satisfying the equation above, the string is in the equilibrium position, $\ky=0$. When $\frac{\rho \komega^2}{T} = \frac{k^2 \pi^2}{L^2}$, then the string will “pop out” some distance $B$. We cannot compute $B$ with the information we have.

Let us assume that $\rho$ and $T$ are fixed and we are changing $\komega$. For most values of $\komega$, the string is in the equilibrium state. When the angular velocity $\komega$ hits a value $\komega = \frac{k \pi \sqrt{T}}{L\sqrt{\rho}}$, then the string pops out and has the shape of a sine wave crossing the $x$-axis $k-1$ times between the endpoints. For example, at $k=1$, the string does not cross the $x$-axis and the shape looks like in Figure 4.1. On the other hand, when $k=3$ the string crosses the $x$-axis 2 times, see Figure 4.2. When $\komega$ changes again, the string returns to the equilibrium position. The higher the angular velocity, the more times it crosses the $x$-axis when it is popped out.

For another example, if you have a spinning jump rope (then $k=1$ as it is completely “popped out”) and you pull on the ends to increase the tension, then the velocity also increases for the rope to stay “popped out”.
