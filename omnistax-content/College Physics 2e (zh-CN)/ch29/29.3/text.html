电离辐射

光子是电磁辐射的量子。它的能量由 $\kE = h\kf$ 给出，并与该辐射的频率 $\kf$ 和波长 $\klam$ 通过下式相联系：

$$\kE = h\kf = \frac{h\kc}{\klam}\;\text{(光子的能量),}$$

其中 $\kE$ 是单个光子的能量，$\kc$ 是光速。在处理微小系统时，以 eV 为单位的能量往往很有用。注意，在这些单位中，普朗克常量为

$$h = 4.14\times 10^{-15}\;\text{eV}\cdot\text{s}.$$

由于许多波长是以纳米（nm）为单位给出的，所以知道下面这一关系也很有用：

$$h\kc = 1240\;\text{eV}\cdot\text{nm}.$$

这些关系会使许多计算稍微容易一些。

所有电磁辐射都由光子组成。图 29.9 给出了电磁波谱的各个区域，它们按波长、频率和光子能量绘制。在本书前面讨论 UV、X 射线和 $\gamma$ 射线的一些特性时，曾经提到过光子的特性；其中第一种的频率正好从可见光谱中紫光的上方开始。当时指出，这几类电磁辐射的特性与可见光大不相同。现在我们可以看到，这些性质之所以产生，是因为光子能量在高频率处更大。

光子以单个量子的方式起作用，与单个电子、原子、分子等相互作用。因此，光子所携带的能量对它所产生的效应至关重要。表 29.1 以 eV 为单位列出了代表性的亚微观能量。当我们把图 29.9 中电磁波谱上的光子能量与表中的能量相比较时，就能看出各种效应如何随电磁辐射的类型而变化。

γ 射线和 X 射线

γ 射线是一种来自原子核和宇宙的电磁辐射，其频率可以是电磁波谱中最高的，因而其光子能量也是最高的。例如，频率 $\kf = 10^{21}\;\text{Hz}$ 的 $\gamma$ 射线光子具有能量 $\kE = h\kf = 6.63\times 10^{-13}\;\text{J} = 4.14\;\text{MeV}.$ 这一能量足以使数千个原子和分子电离，因为每次电离只需要 10 至 1000 eV。事实上，$\gamma$ 射线是电离辐射的一种，X 射线和 UV 也是，因为它们在吸收它们的材料中产生电离。由于能产生如此多的电离，单个 $\gamma$ 射线光子就能对生物组织造成严重损伤，杀死细胞，或损害细胞正常增殖的能力。细胞增殖受到扰乱时，结果可能是癌症，这是已知的暴露于电离辐射的后果之一。由于癌细胞在快速增殖，它们对电离辐射所造成的扰乱格外敏感。这意味着，电离辐射既有用于癌症治疗的积极用途，也有引发癌症的风险。

较高的光子能量还使 $\gamma$ 射线能够穿透材料，因为与单个原子或分子的一次碰撞不大可能吸收 $\gamma$ 射线的全部能量。这使得 $\gamma$ 射线可以用作探针，它们有时也用于医学成像。X 射线，如图 29.9 所示，与 $\gamma$ 射线范围的低频端重叠。由于 X 射线的能量为 keV 量级及以上，单个 X 射线光子同样能产生大量电离。在较低的光子能量下，X 射线的穿透力不如 $\gamma$ 射线，危险性也略小。X 射线非常适合用于医学成像，这是它们最常见的用途，而这一点在 1895 年德国物理学家 W. C. 伦琴（1845–1923）发现它们时就立即被认识到了。（见图 29.10。）发现后不到一年，X 射线（一度称为伦琴射线）就被用于医学诊断。伦琴因发现 X 射线而获得 1901 年诺贝尔奖。

联系：能量守恒

我们再一次发现，能量守恒让我们只需考虑能量所采取的初始形式和最终形式，而不必对中间步骤作详细计算。例题 29.2 的求解只考虑了能量的初始形式和最终形式。

在管中产生 X 射线

$\gamma$ 射线起源于核衰变，而 X 射线则由图 29.11 所示的过程产生。在真空管中，被热灯丝通过热骚动发射出来的电子经高电压加速，从电势能中获得动能。当它们撞击阳极时，电子把它们的动能转化为多种形式，包括热能。但是，由于被加速的电荷会辐射电磁波，又由于电子是各自单独起作用的，因此也会产生光子。这些 X 射线光子中有一些获得了电子的动能。被加速的电子起源于阴极，所以这种管称为阴极射线管（CRT），它们的各种型号可见于较老的电视和计算机屏幕，以及 X 射线机中。

例题 29.2 · X 射线光子能量与 X 射线管电压

求在像图 29.11 中那样的 CRT 里，被 50.0 kV 的电势差加速的电子所产生的 X 射线光子的最大能量（以 eV 为单位）。

思路

电子撞击 CRT 的阳极时，可以把它们的全部动能交给单个光子。（这有点像光电效应的逆过程。）电子的动能来自电势能。因此，我们可以直接令最大光子能量等于电势能，即 $h\kf = \kq\kV.$（我们不必从头到尾逐步计算，只要知道起始的全部能量 $\kq\kV$ 都转化成了最终形式 $h\kf.$）

解

最大光子能量为 $h\kf = \kq\kV$，其中 $\kq$ 是电子的电荷，$\kV$ 是加速电压。因此，

$$h\kf = (1.60\times 10^{-19}\;\text{C})(50.0\times 10^{3}\;\text{V}).$$

根据电子伏的定义，我们知道 $1\;\text{eV} = 1.60\times 10^{-19}\;\text{J}$，其中 $1\;\text{J} = 1\;\text{C}\cdot\text{V}.$ 合并各因子并把能量换算为 eV，得

$$h\kf = (50.0\times 10^{3})(1.60\times 10^{-19}\;\text{C}\cdot\text{V})\left(\frac{1\;\text{eV}}{1.60\times 10^{-19}\;\text{C}\cdot\text{V}}\right) = (50.0\times 10^{3})(1\;\text{eV}) = 50.0\;\text{keV}.$$

讨论

这个例题得出的结果可以应用于许多类似的情形。如果你让单个元电荷（例如电子的电荷）通过以伏特表示的电势加速，那么它以 eV 为单位的能量在数值上与该电势相同。因此，50.0 kV 的电势产生 50.0 keV 的电子，这些电子又可以产生光子，其最大能量为 50 keV。同样，X 射线管中 100 kV 的电势最多可以产生 100 keV 的 X 射线光子。许多 X 射线管的电压是可调的，因此可以产生各种能量的 X 射线，它们的能量不同，穿透本领也就不同。

X 射线谱

图 29.12 给出了从 X 射线管得到的 X 射线谱。这个谱有两个鲜明的特征。第一，平滑的分布来自电子在阳极材料中被减速。这样的曲线是通过探测大量光子得到的，而且很明显，最大能量是不太可能出现的。这种减速过程产生的辐射称为轫致辐射（德语意为制动辐射）。第二个特征是谱中存在尖锐的峰；这些峰称为特征 X 射线，因为它们是阳极材料的特征。特征 X 射线来自某一类阳极材料所特有的原子激发。它们类似于原子光谱中的谱线，这意味着原子的能级是量子化的。离散的原子光谱和特征 X 射线等现象将在“原子物理学”中作进一步探讨。

紫外辐射

紫外辐射（约 4 eV 至 300 eV）与 X 射线的能量范围的低端重叠，但 UV 的能量通常更低。UV 来自原子的退激发，这些原子可以是高温固体或气体的一部分。这些原子可以通过多种过程被赋予能量，之后再以 UV 的形式释放出来，这些过程包括放电、核爆炸、热骚动和暴露于 X 射线。UV 光子具有足以使原子和分子电离的能量，这使得它的效应不同于可见光。因此，UV 具有一些与 $\gamma$ 射线和 X 射线相同的生物学效应。例如，它能引起皮肤癌，并用于消毒。主要区别在于，要破坏细胞增殖或杀死一个细菌，需要若干个 UV 光子，而单个 $\gamma$ 射线光子和 X 射线光子就能造成同样的损伤。但由于 UV 确实具有改变分子的能量，它能做到可见光做不到的事。UV 有益的一面是，它能触发皮肤中维生素 D 的生成，而可见光每个光子的能量不足以改变触发这一生成过程的分子。婴儿黄疸的治疗方法是让婴儿暴露于 UV 之下（并做好眼部防护），称为光疗法，人们认为其有益效果与它有助于防止血液中可能有毒的胆红素堆积的能力有关。

例题 29.3 · 紫外辐射的光子能量与效应

短波长的 UV 有时称为真空紫外，因为它会被空气强烈吸收，必须在真空中研究。求 100 nm 的真空紫外的光子能量（以 eV 为单位），并估算它能使多少个分子电离或分裂。

思路

利用公式 $\kE = h\kf$ 和适当的常量，我们可以求出光子能量，并将它与表 29.1 中的能量信息作比较。

解

光子的能量由下式给出

$$\kE = h\kf = \frac{h\kc}{\klam}.$$

利用 $h\kc = 1240\;\text{eV}\cdot\text{nm},$ 可得

$$\kE = \frac{h\kc}{\klam} = \frac{1240\;\text{eV}\cdot\text{nm}}{100\;\text{nm}} = 12.4\;\text{eV}.$$

讨论

根据表 29.1，这个光子能量也许能使原子或分子电离，而且它大约就是拆散一个束缚较紧的分子所需的能量，因为这类分子的结合能约为 10 eV。这个光子能量可以破坏大约十二个束缚较弱的分子。由于光子能量高，UV 会破坏与之相互作用的原子和分子。一个好的结果是，除波长最长的 UV 之外，其余的 UV 都被强烈吸收，并且很容易被太阳镜挡住。事实上，太阳发出的 UV 大部分被高层大气中的一层薄薄的臭氧吸收，从而保护了地球上敏感的生物。氯氟烃等化学物质的加入对臭氧层造成的破坏，削弱了这种对我们的保护。

可见光

可见光从红到紫的光子能量范围分别为 1.63 至 3.26 eV（留给本章的习题去验证）。这些能量与原子和分子中外层电子壳层之间的能量具有相同的数量级。这意味着这些光子可以被原子和分子吸收。单个光子实际上就能刺激视网膜，例如通过改变某个受体分子，该分子随后触发神经冲动。光子只能被恰好具有相应量子化的能量间隔的原子和分子吸收或发射。例如，如果一个红光光子的频率为 $\kf$，遇到一个能量间隔 $\kdE,$ 等于 $h\kf,$ 的分子，那么该光子就可以被吸收。紫色的花吸收红光而反射紫光；这意味着受体分子的能级之间没有等于紫光光子的能量的能量间隔，但对红光存在能量间隔。

可见光谱两端的光在特性上有一些明显差异，这些差异是由光子能量造成的。红光的光子能量不足以使大多数黑白胶片感光，因此它被用来照明冲洗这类胶片的暗室。由于紫光的光子能量较高，吸收紫光的染料往往比不吸收紫光的染料褪色更快。（见图 29.13。）找个时间看看商店橱窗里一些褪了色的彩色海报，你会注意到，蓝色和紫色是最后褪去的。这是因为其他染料，例如红色和绿色染料，会吸收蓝光和紫光的光子，这些光子较高的能量会拆散它们束缚较弱的分子。（染料和 DNA 中那样的复杂分子往往束缚较弱。）蓝色和紫色的染料反射这些颜色的光，因此不吸收这些能量更高的光子，所以分子受到的损伤较小。

透明材料（例如某些玻璃）不吸收任何可见光，因为原子或分子中没有能够吸收这种光的能量间隔。由于单个光子与单个原子相互作用，几乎不可能让两个光子同时被吸收而达到一个很大的能量间隔。由于光子能量较低，可见光有时能穿过好几千米厚的物质，而 UV、X 射线和 $\gamma$ 射线等较高的频率则被吸收，因为它们具有足以使该材料电离的光子能量。

例题 29.4 · 一只典型的灯泡每秒产生多少个光子？

假设一只 100 W 灯泡输出能量的 10.0% 在可见光范围内（这对白炽灯泡是典型的），平均波长为 580 nm，求每秒发射的可见光子数。

思路

功率是单位时间内的能量，因此，如果我们能求出每个光子的能量，就能确定每秒的光子数。最好用焦耳来计算，因为功率是以瓦特给出的，而瓦特就是每秒多少焦耳。

解

产生可见光的功率是 100 W 的 10.0%，即 10.0 J/s。平均可见光光子的能量可通过把给定的平均波长代入公式求得

$$\kE = \frac{h\kc}{\klam}.$$

由此得到

$$\kE = \frac{(6.63\times 10^{-34}\;\text{J}\cdot\text{s})(3.00\times 10^{8}\;\text{m/s})}{580\times 10^{-9}\;\text{m}} = 3.43\times 10^{-19}\;\text{J}.$$

因此，每秒的可见光子数为

$$\text{光子/s} = \frac{10.0\;\text{J/s}}{3.43\times 10^{-19}\;\text{J/光子}} = 2.92\times 10^{19}\;\text{光子/s}.$$

讨论

每秒如此惊人的光子数，证实了单个光子在人类的日常经验中是微不足道的。它也证实了对应原理——在宏观尺度上，量子化变得基本上是连续的，或者说是经典的。最后，一只 100 W 的灯泡发射出如此多的光子，以至于在几千米之外用肉眼就能看到它。

低能光子

红外辐射（IR）的光子能量比可见光还要低，不能显著地改变原子和分子。IR 可以被原子和分子吸收和发射，尤其是在间距很小的态之间。例如，水对 IR 的吸收极强，因为水分子有许多态，这些态之间相隔的能量，其量级为 $10^{-5}\;\text{eV}$ 至 $10^{-2}\;\text{eV},$ 完全处于 IR 和微波的能量范围之内。这就是为什么在 IR 范围内，皮肤几乎是漆黑的，发射率接近 1——皮肤中的水分子有许多态，能吸收很宽范围的 IR 光子能量。并非所有分子都具有这种性质。例如，空气对许多 IR 频率几乎是透明的。

微波是电子电路所能产生的最高频率，尽管它们也可以自然产生。因此，微波与 IR 相似，只是没有延伸到那么高的频率。水和其他分子中存在着与微波具有相同频率和能量的态，典型值约为 $10^{-5}\;\text{eV}.$ 这是食物比许多其他材料更强烈地吸收微波的原因之一，也使微波炉成为把能量直接输入食物的一种高效方式。

IR 和微波的光子能量都非常低，因此，IR 或微波要实现任何显著的能量传递（例如用加热灯给自己取暖，或在微波炉里烤比萨），都需要巨大数量的光子参与。可见光、IR、微波以及所有更低的频率都不能由单个光子产生电离，通常也不具有较高频率所带来的危害。当可见光、IR 或微波辐射确实有危害时，例如微波诱发白内障，这种危害来自巨大数量的光子共同作用（而不是来自光子的累积，例如弱 UV 灭菌）。可见光、IR 或微波辐射的负面效应可以是热效应，任何热源都能产生。但有一点不同：在非常高的强度下，光子共同作用能产生很强的电场和磁场。这样的电磁场（EMF）实际上能使材料电离。

误区提醒：高压输电线

尽管有些人认为居住在高压输电线附近对健康有害，但对这些输电线所产生的瞬态场效应的持续研究表明，其强度不足以造成损害。人口统计学研究也没有显示出不良影响与高压输电线之间有显著的相关性。美国物理学会在 20 多年前发布了一份关于输电线场的报告，此后的更多研究也没有显示出癌症与输电线场之间存在一致的、显著的联系。

要探测频率低于微波频率的单个光子，几乎是不可能的，因为它们的光子能量太低。但这些光子是存在的。连续的电磁波可以建模为光子。在低频率下，电磁波通常被当作随时间和位置变化的电场和磁场来处理，没有可辨别的量子化。这是涉及巨大数量光子的情形中对应原理的又一个例子。
