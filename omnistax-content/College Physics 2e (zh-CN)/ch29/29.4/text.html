光子动量的测量

我们称为光子的电磁辐射量子，其性质类似于我们能看见的粒子，例如沙粒。光子在碰撞或被吸收时是作为一个整体起作用的，而不是作为一个扩展的波。有质量的量子，如电子，也表现得像宏观粒子——这是我们所预期的，因为它们是物质的最小单元。粒子既携带能量，也携带动量。尽管光子没有质量，但长期以来就有证据表明电磁辐射携带动量。（麦克斯韦等研究电磁波的人曾预言它们会携带动量。）现在，光子确实具有动量已是确立的事实。事实上，光子动量是由光电效应提示的，在光电效应中，光子把电子从物质中撞出。图 29.14 展示了光子动量的宏观证据。

图 29.14 展示了一颗有两条显著尾巴的彗星。大多数人不知道的是，这些尾巴总是指向背离太阳的方向，而不是拖在彗星后面（就像小波皮的羊的尾巴那样）。彗尾由从彗星本体蒸发出来的气体和尘埃，以及电离气体组成。当光子从尘埃粒子上散射时，尘埃粒子反冲着远离太阳。显然，光子沿着其运动的方向（背离太阳）携带动量，并且在碰撞中，这些动量有一部分转移给了尘埃粒子。蓝色尾巴中的气体原子和分子，受到的影响主要来自其他的辐射粒子，例如从太阳射出的质子和电子，而不是光子的动量。

联系：动量守恒

动量不仅在物理学的所有领域中守恒，而且发现所有种类的粒子都具有动量。我们预期有质量的粒子具有动量，但现在我们看到，包括光子在内的无质量粒子也携带动量。

动量在量子力学中守恒，正如它在相对论和经典物理学中守恒一样。关于这一点，最早的一些直接实验证据来自物质中电子对 X 射线光子的散射，这被称为康普顿散射，以美国物理学家阿瑟·H·康普顿（1892–1962）的名字命名。1923 年前后，康普顿观察到，从材料上散射的 X 射线具有减小的能量，并正确地将此分析为是由光子被电子散射所致。这一现象可以当作两个粒子之间的碰撞来处理——一个光子和材料中一个静止的电子。能量和动量在碰撞中守恒。（见图 29.15）他因发现这种散射而于 1929 年获得诺贝尔奖，这种散射现在称为康普顿效应，因为它帮助证明了光子动量由下式给出

$$\kp = \frac{h}{\klam},$$

其中 $h$ 是普朗克常量，$\klam$ 是光子波长。（注意，以 $\kp = \gamma \km \ku$ 给出的相对论动量只对有质量的粒子成立。）

我们可以看出，光子动量很小，因为 $\kp = h/\klam$，而 $h$ 非常小。正因为如此，我们通常观察不到光子动量。当光从我们的镜子上反射时，镜子并不会反冲（也许卡通片里除外）。康普顿之所以看到了光子动量的效应，是因为他观察的是 X 射线，它们的波长小而动量相对较大，与最轻的粒子——电子——相互作用。

例题 29.5 · 电子与光子动量的比较

（a）计算一个可见光光子的动量，该光子的波长为 500 nm。（b）求具有相同动量的一个电子的速度。（c）该电子的能量是多少？它与该光子的能量相比如何？

思路

求光子动量只是直接应用其定义：$\kp = \frac{h}{\klam}$。如果我们发现光子动量很小，那么就可以假定具有相同动量的一个电子是非相对论性的，这样就容易用经典公式求出它的速度和动能。

（a）的解

光子动量由下面的方程给出：

$$\kp = \frac{h}{\klam}.$$

代入所给的光子波长，得到

$$\kp = \frac{6.63\times 10^{-34}\;\text{J}\cdot\text{s}}{500\times 10^{-9}\;\text{m}} = 1.33\times 10^{-27}\;\text{kg}\cdot\text{m/s}.$$

（b）的解

由于这个动量确实很小，我们将用经典表达式 $\kp = \km\kv$ 来求具有这个动量的一个电子的速度。解出 $\kv$ 并代入电子的质量的已知值，得到

$$\kv = \frac{\kp}{\km} = \frac{1.33\times 10^{-27}\;\text{kg}\cdot\text{m/s}}{9.11\times 10^{-31}\;\text{kg}} = 1460\;\text{m/s} \approx 1460\;\text{m/s}.$$

（c）的解

电子具有动能，经典地由下式给出

$$\kKEe = \frac{1}{2}\km\kv^{2}.$$

因此，

$$\kKEe = \frac{1}{2}(9.11\times 10^{-3}\;\text{kg})(1455\;\text{m/s})^{2} = 9.64\times 10^{-25}\;\text{J}.$$

乘以 $(1\;\text{eV})/(1.602\times 10^{-19}\;\text{J})$ 将其换算为 eV，得到

$$\kKEe = 6.02\times 10^{-6}\;\text{eV}.$$

光子能量 $\kE$ 为

$$\kE = \frac{h\kc}{\klam} = \frac{1240\;\text{eV}\cdot\text{nm}}{500\;\text{nm}} = 2.48\;\text{eV},$$

这大约要大五个数量级。

讨论

光子动量确实很小。即使它们的数量极其庞大，它们携带的总动量也很小。具有相同动量的一个电子有 1460 m/s 的速度，这显然是非相对论性的。质量更大而动量相同的粒子，其速度会更小。这一点可由下述事实得到证实：要使电子具有与光子相同的动量，所需的能量要少得多。但在量子力学尺度上，特别是对于与小质量相互作用的高能光子，光子动量是显著的。即使在大尺度上，只要它们足够多，并且没有什么东西阻止物质缓慢地反冲，光子动量也能产生效应。彗尾就是一个例子，此外还有人提议建造太阳帆，它们用巨大的低质量镜子（由镀铝 Mylar 制成）来反射阳光。在太空的真空中，这些镜子会逐渐反冲，实际上可以把航天器在太阳系中从一处送到另一处。（见图 29.16。）

光子的相对论动量

光子动量 $\kp$ 与光子能量 $\kE$ 之间存在一种关系，它与前面给出的粒子相对论性总能量的关系 $\kE^{2} = (\kp\kc)^{2} + (\km\kc^{2})^{2}$ 是一致的。我们知道光子的 $\km$ 为零，但 $\kp$ 不为零，所以 $\kE^{2} = (\kp\kc)^{2} + (\km\kc^{2})^{2}$ 可以化简。

这与实验测定的结果以及上面的讨论一致。因此，$\kp = \kE/\kc$ 等价于康普顿的结果 $\kp = h/\klam$。关于光子能量与动量之间关系的进一步验证，见例题 29.6。

光子探测器

到目前为止所讨论的几乎所有探测系统——眼睛、照相底板、显微镜中的光电倍增管，以及 CCD 照相机——都依赖于光子与灵敏区域相互作用时的类粒子性质。这会引起一个变化，这个变化或者被级联放大，或者无数个点被记录下来，形成我们所探测到的图像。这些探测器用于生物医学成像系统，而且目前仍在研究如何提高接收光子的效率，特别是通过冷却探测系统和减少热效应。

例题 29.6 · 光子的能量与动量

证明对于例题 29.5 中所考虑的光子，$\kp = \kE/\kc$ 成立。

思路

我们取例题 29.5 中求得的能量 $\kE$，将它除以光速，看看是否得到与之前相同的动量。

解

已知该光子的能量为 2.48 eV，将其换算为焦耳，得到

$$\kp = \frac{\kE}{\kc} = \frac{(2.48\;\text{eV})(1.60\times 10^{-19}\;\text{J/eV})}{3.00\times 10^{8}\;\text{m/s}} = 1.33\times 10^{-27}\;\text{kg}\cdot\text{m/s}.$$

讨论

这个动量值与之前求得的相同（注意，在所有计算中都使用未舍入的数值，以避免哪怕很小的舍入误差），这是对关系式 $\kp = \kE/\kc$ 的预期验证。这也意味着由 $\kE^{2} = (\kp\kc)^{2} + (\km\kc)^{2}$ 给出的能量、动量和质量之间的关系，对物质和光子都适用。再次注意，即使 $\km$ 为零，$\kp$ 也不为零。

解题建议

注意，常量 $h = 4.14\times 10^{-15}\;\text{eV}\cdot\text{s}$ 和 $h\kc = 1240\;\text{eV}\cdot\text{nm}$ 的这些形式，可能对本节的习题特别有用。
