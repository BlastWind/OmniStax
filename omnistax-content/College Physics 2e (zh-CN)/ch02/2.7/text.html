落体构成了一类有趣的运动问题。例如，要估算竖直矿井的深度，可以向井中投下一块石块，并听石块撞到井底的声音。把迄今为止建立的运动学知识应用于落体，我们就可以考察一些有趣的情形，并在此过程中对重力有较多的了解。

重力与自由落体运动

关于落体，最引人注目也最出人意料的事实是：如果空气阻力和摩擦力可以忽略，那么在给定的地点，所有物体都以相同的恒定加速度向地心下落，与它们的质量无关。这一由实验测定的事实出人意料，因为我们早已习惯了空气阻力和摩擦力的影响，以致预期轻的物体比重的物体下落得慢。

在现实世界中，空气阻力可以使较轻的物体比大小相同的较重物体下落得慢。同时释放的网球会比硬棒球后落地。（如果高度不大，可能难以观察到这种差别。）空气阻力阻碍物体在空气中的运动，而物体之间的摩擦力——例如衣服与洗衣滑槽之间，或石头与它落入的水池之间——也阻碍它们之间的运动。在这最初几章的理想情形中，不受空气阻力或摩擦力影响而下落的物体被定义为做自由落体运动。

重力加速度

重力使物体向地心下落。因此，自由落体的加速度称为重力加速度。重力加速度是恒定的，这意味着，对于任何空气阻力和摩擦力可以忽略的落体，我们都可以应用运动学方程。这为我们打开了一大类有趣的情形。重力加速度非常重要，因此它的大小有自己专用的符号 $\kg$。在地球上任何给定的地点它都是恒定的，其平均值为

$$\kg = 9.80\ \text{m/s}^2.$$

虽然 $\kg$ 的值随纬度、海拔、地下地质构造和当地地形而在 $9.78\ \text{m/s}^2$ 到 $9.83\ \text{m/s}^2$ 之间变化，但除非另有说明，本教材将使用平均值 $9.80\ \text{m/s}^2$。重力加速度的方向是向下（朝向地心）。事实上，正是它的方向定义了我们所说的竖直方向。请注意，运动学方程中的加速度 $\ka$ 取 $+\kg$ 还是 $-\kg$，取决于我们如何定义坐标系。如果我们把向上的方向定义为正，那么 $\ka = -\kg = -9.80\ \text{m/s}^2$；如果把向下的方向定义为正，那么 $\ka = \kg = 9.80\ \text{m/s}^2$。

涉及重力的一维运动

观察涉及重力的运动的基本特征，最好的办法是从最简单的情形入手，再逐步过渡到较复杂的情形。因此，我们先考虑没有空气阻力或摩擦力的直上直下的运动。这些假设意味着速度（如果有的话）是竖直的。如果物体是被释放的，我们知道初速度为零。物体一旦脱离了握持或抛出它的任何东西，就在做自由落体运动。在这种情况下，运动是一维的，其恒定加速度的大小为 $\kg$。我们还将用符号 $\ky$ 表示竖直位移，用 $\kx$ 表示水平位移。

落体运动的运动学方程（加速度 = −$\kg$）
$$\kv = \kvo - \kg\kt$$ $$\ky = \kyo + \kvo\kt - \tfrac{1}{2}\kg\kt^2$$ $$\kv^2 = \kvo^2 - 2\kg(\ky - \kyo)$$

向上抛出的石块

例题 2.14 · 计算落体的位置和速度：向上抛出的石块

一个站在高崖边缘的人把一块石块以 13.0 m/s 的初速度竖直向上抛出。石块落回地面的途中，它恰好没有碰到悬崖边缘。忽略空气阻力的影响，计算石块在它被抛出后 1.00 s、2.00 s 和 3.00 s 时的位置和速度。

思路

画一幅草图。

我们要求的是不同时刻的位置 $\ky$。取初位置 $\kyo$ 为零是合理的。这个问题涉及一维运动，其方向是竖直的。我们用正负号表示方向，向上为正，向下为负。由于向上为正，而石块是向上抛出的，所以初速度也必须为正。重力加速度是向下的，所以 $\ka$ 为负。初速度和重力加速度的正负号必须相反，这一点至关重要。正负号相反表明，重力加速度阻碍最初的运动，并将使它减慢，最终使它反向。

由于要求我们给出位置和速度在三个时刻的值，我们把它们记作 $\ky_1$ 和 $\kv_1$；$\ky_2$ 和 $\kv_2$；以及 $\ky_3$ 和 $\kv_3$。

求位置

$\ky_1$

  1. 确定已知量。我们知道 $\kyo = 0$；$\kvo = 13.0\ \text{m/s}$；$\ka = -\kg = -9.80\ \text{m/s}^2$；以及 $\kt = 1.00\ \text{s}$。
  2. 确定最适用的方程。我们将使用 $\ky = \kyo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$，因为它只包含一个未知量 $\ky$（这里是 $\ky_1$），也就是我们要求的值。
  3. 代入已知值，求解 $\ky_1$。 $$\ky_1 = 0 + (13.0\ \text{m/s})(1.00\ \text{s}) + \tfrac{1}{2}(-9.80\ \text{m/s}^2)(1.00\ \text{s})^2 = 8.10\ \text{m}$$

讨论

在 $\kt = 1.00$ s 时，石块位于其起点上方 8.10 m 处，因为 $\ky_1 > \kyo$。它可能在向上运动，也可能在向下运动；要判断是哪一种，唯一的办法是计算 $\kv_1$，看它是正还是负。

求速度

$\kv_1$

  1. 确定已知量。我们知道 $\kyo = 0$；$\kvo = 13.0\ \text{m/s}$；$\ka = -\kg = -9.80\ \text{m/s}^2$；以及 $\kt = 1.00\ \text{s}$。我们还从上面的解中知道 $\ky_1 = 8.10\ \text{m}$。
  2. 确定最适用的方程。最直接的是 $\kv = \kvo - \kg\kt$（由 $\kv = \kvo + \ka\kt$ 得出，其中 $\ka = \text{重力加速度} = -\kg$）。
  3. 代入已知量并求解。 $$\kv_1 = \kvo - \kg\kt = 13.0\ \text{m/s} - (9.80\ \text{m/s}^2)(1.00\ \text{s}) = 3.20\ \text{m/s}$$

讨论

$\kv_1$ 为正值，意味着石块在 $\kt = 1.00\ \text{s}$ 时仍在向上运动。不过，正如预期的那样，它已经从其原来的 13.0 m/s 减慢了。

求其余时刻

计算 $\kt = 2.00\ \text{s}$ 和 $3.00\ \text{s}$ 时位置和速度的步骤与上面相同。结果汇总于表 2.1，并在图 2.39 中表示出来。

讨论

对这些结果的解释很重要。在 1.00 s 时，因为 $\ky_1$ 和 $\kv_1$ 都为正，石块位于其起点上方并向上运动。在 2.00 s 时，石块仍在其起点上方，但负速度表示它正在向下运动。在 3.00 s 时，$\ky_3$ 和 $\kv_3$ 都为负，表示石块位于其起点下方并继续向下运动。请注意，当石块处于其最高点（在 1.33 s 时）时，其速度为零，但其加速度仍为 $-9.80\ \text{m/s}^2$。它的加速度在整个行程中都是 $-9.80\ \text{m/s}^2$——无论是它向上运动，还是它向下运动时。请注意，$\ky$ 的值是石块的位置（或位移），而不是总路程。最后请注意，自由落体运动既适用于向上的运动，也适用于向下的运动。两者具有相同的加速度——重力加速度，它在整个过程中保持不变。例如，在著名的“呕吐彗星”失重飞机上训练的航天员，在向上和向下的弧线飞行中都经历自由落体运动，我们将在后面更详细地讨论。

建立联系：居家实验——反应时间

可以做一个简单的实验来测定你的反应时间。让一位朋友把一把直尺握在你的拇指和食指之间，两指相隔约 1 cm。记下直尺上正好位于你两指之间的刻度。让朋友出其不意地放开直尺，你试着用两指把它夹住。记下直尺上新的读数。假设加速度就是重力加速度，计算你的反应时间。如果你的脚从油门踏板移到刹车踏板所用的时间是这个反应时间的两倍，那么在一辆以 30 m/s 行驶的汽车里，你会前进多远？

向下抛出的石块

例题 2.15 · 计算落体的速度：向下抛出的石块

如果悬崖上的那个人不是把石块竖直向上抛，而是竖直向下抛，会发生什么？为了探讨这个问题，请计算：当它处于起点下方 5.10 m 处，并且是以 13.0 m/s 的初速率向下抛出时，石块的速度。

思路

画一幅草图。

由于向上为正，石块的末位置将为负，因为它最终处于 $\kyo = 0$ 的起点下方。同样，初速度是向下的，因此为负，重力加速度也是如此。我们预期末速度为负，因为石块将继续向下运动。

解

  1. 确定已知量。$\kyo = 0$；$\ky_1 = -5.10\ \text{m}$；$\kvo = -13.0\ \text{m/s}$；$\ka = -\kg = -9.80\ \text{m/s}^2$。
  2. 选择能使问题最容易求解的运动学方程。方程 $\kv^2 = \kvo^2 + 2\ka(\ky - \kyo)$ 很合适，因为其中唯一的未知量是 $\kv$。（我们将把 $\ky_1$ 代入 $\ky$。）
  3. 代入已知值 $$\kv^2 = (-13.0\ \text{m/s})^2 + 2(-9.80\ \text{m/s}^2)(-5.10\ \text{m} - 0\ \text{m}) = 268.96\ \text{m}^2\text{/s}^2,$$ 其中我们保留了额外的有效数字，因为这是中间结果。 开平方，并注意到平方根可正可负，得 $$\kv = \pm 16.4\ \text{m/s}.$$ 取负根，表示石块仍在向下运动。因此， $$\kv = -16.4\ \text{m/s}.$$

讨论

请注意，这恰好就是石块在它以相同的初速率被竖直向上抛出时，在这个位置所具有的同一个速度。（见例题 2.14 和图 2.41（a）。）这并非巧合。因为在这个问题中我们只考虑重力加速度，所以落体的速率只取决于它的初速率和它相对于起点的竖直位置。例如，如果当初速度为 13.0 m/s 竖直向上时，使用例题 2.14 中的方法，计算石块在起点上方 8.10 m 的高度处的速度，会得到 $\pm 3.20\ \text{m/s}$ 的结果。这里两个正负号都有意义；正值出现在石块位于 8.10 m 处并向上运动时，负值出现在石块位于 8.10 m 处并正在落回时。它的速率相同，但方向相反。

换一种看法是这样的：在例题 2.14 中，石块以 $13.0\ \text{m/s}$ 的初速度向上抛出。它上升，然后落回。当它的位置在它回落途中为 $\ky = 0$ 时，它的速度为 $-13.0\ \text{m/s}$。也就是说，它在其下行途中与在其上行途中具有相同的速率。于是我们预期，它在位置 $\ky = -5.10\ \text{m}$ 处的速度都相同，无论是把它以 $+13.0\ \text{m/s}$ 向上抛出，还是把它以 $-13.0\ \text{m/s}$ 向下抛出。石块在其从 $\ky = 0$ 下行途中的速度是相同的，无论开始时它是被向上抛出还是向下抛出，只要它最初被抛出时的速率相同。

由落体数据求 g

例题 2.16 · 由落体数据求 g

地球上的重力加速度因地而异，取决于地形（例如，你是在山上还是在山谷里）和地下地质（你脚下是铁矿石那样的致密岩石，还是盐那样的轻质岩石。）精确的重力加速度可以由入门物理学实验课程中取得的数据算出。让一个物体（通常是一个金属球，其空气阻力可以忽略）落下，测量它落过已知距离所用的时间。例如，见图 2.42。如果在测量下落的距离和时间间隔时足够仔细，这种方法可以得到非常精确的结果。

假设球下落 1.0000 m 用时 0.45173 s。假设球不受空气阻力影响，这个地点的精确的重力加速度是多少？

思路

画一幅草图。

我们需要求解加速度 $\ka$。请注意，在这种情况下，位移是向下的，因此为负，加速度也是如此。

解

  1. 确定已知量。$\kyo = 0$；$\ky = -1.0000\ \text{m}$；$\kt = 0.45173$；$\kvo = 0$。
  2. 选择能让你利用已知值求解 $\ka$ 的方程。 $$\ky = \kyo + \kvo\kt + \tfrac{1}{2}\ka\kt^2$$
  3. 将 0 代入 $\kvo$，并整理方程以求解 $\ka$。将 0 代入 $\kvo$ 得 $$\ky = \kyo + \tfrac{1}{2}\ka\kt^2.$$ 解出 $\ka$ 得 $$\ka = \frac{2(\ky - \kyo)}{\kt^2}.$$
  4. 代入已知值得 $$\ka = \frac{2(-1.0000\ \text{m} - 0)}{(0.45173\ \text{s})^2} = -9.8010\ \text{m/s}^2,$$ 所以，由于按我们选定的方向有 $\ka = -\kg$， $$\kg = 9.8010\ \text{m/s}^2.$$

讨论

$\ka$ 为负值，表明重力加速度是向下的，这与预期相符。我们预期该值在平均值 $9.80\ \text{m/s}^2$ 附近，所以 $9.8010\ \text{m/s}^2$ 是合理的。由于代入计算的数据相当精确，$\kg$ 的这个值比平均值 $9.80\ \text{m/s}^2$ 更精确；它代表当地的重力加速度值。
