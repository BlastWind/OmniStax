相互垂直的力的合成：驳船所受的阻力

牛顿运动定律有许多有趣的应用，本节再介绍其中的几个。它们还有助于说明物理学的一些更深层的微妙之处，并有助于培养解题技能。

例题 4.7 · 驳船受到的阻力

假设两艘拖船以不同的角度推一艘驳船，如图 4.21 所示。第一艘拖船沿 x 方向施加 $2.7\times 10^{5}\ \text{N}$ 的力，第二艘拖船沿 y 方向施加 $3.6\times 10^{5}\ \text{N}$ 的力。

如果驳船的质量为 $5.0\times 10^{6}\ \text{kg}$，并且观测到它沿图示方向的加速度为 $7.5\times 10^{-2}\ \text{m/s}^{2}$，那么水对驳船的、阻碍运动的阻力是多大？（注：阻力是流体（如空气或水）施加的一种摩擦力。阻力阻碍物体的运动。）

思路

加速度和外加力的方向和大小已在图 4.21（a） 中给出。我们把拖船对驳船的总力定义为 $\kFa$，于是有：

$$\kFa = \kFx + \kFy$$

由于驳船是平底的，水的阻力 $\kFD$ 的方向将与 $\kFa$ 相反，如图 4.21（b） 的受力图所示。这里所研究的系统是驳船，因为已知它所受的力以及它的加速度。我们的思路是先求出外加合力 $\kFa$ 的大小和方向，然后应用牛顿第二定律求阻力 $\kFD$。

解

由于 $\kFx$ 和 $\kFy$ 相互垂直，$\kFa$ 的大小和方向很容易求得。首先，合矢量的大小由勾股定理给出：

$$\begin{aligned}\kFa &= \sqrt{\kFx^{2} + \kFy^{2}}\\ \kFa &= \sqrt{(2.7\times 10^{5}\ \text{N})^{2} + (3.6\times 10^{5}\ \text{N})^{2}} = 4.5\times 10^{5}\ \text{N}.\end{aligned}$$

角度由下式给出

$$\begin{aligned}\ktheta &= \tan^{-1}\!\left(\frac{\kFy}{\kFx}\right)\\ \ktheta &= \tan^{-1}\!\left(\frac{3.6\times 10^{5}\ \text{N}}{2.7\times 10^{5}\ \text{N}}\right) = 53^\circ,\end{aligned}$$

根据牛顿第一定律，我们知道它与加速度的方向相同。$\kFD$ 的方向与 $\kFa$ 相反，因为它的作用是减缓加速度。因此，合外力的方向与 $\kFa$ 相同，但其大小略小于 $\kFa$。现在这个问题成了一维问题。由图 4.21（b） 可以看出

$$\kFnet = \kFa - \kFD.$$

但牛顿第二定律指出

$$\kFnet = \km\ka.$$

因此，

$$\kFa - \kFD = \km\ka.$$

由此可以用已知量求出水的阻力 $\kFD$ 的大小：

$$\kFD = \kFa - \km\ka.$$

代入已知数值，得到

$$\kFD = (4.5\times 10^{5}\ \text{N}) - (5.0\times 10^{6}\ \text{kg})(7.5\times 10^{-2}\ \text{m/s}^{2}) = 7.5\times 10^{4}\ \text{N}.$$

$\kFD$ 的方向已确定为与 $\kFa$ 的方向相反，即处于西偏南 $53^\circ$ 的角度。

讨论

本例中所用的数值，对一艘中等大小的驳船来说是合理的。用拖船确实很难获得更大的加速度，而且为了避免驳船撞上码头，低速是理想的。对于设计良好的船体，低速时的阻力相对较小，这与本例的结果一致，其中 $\kFD$ 小于该船的重力的 1/600。

成不同角度的两根钢丝

在前面走钢丝者的例子中，我们注意到，支撑一个物体的钢丝中的张力相等，只是因为两侧的角度相等。请看下面这个例子，其中角度并不相等；它涉及稍多一点的三角学。

例题 4.8 · 不同角度下的不同张力

考虑如图 4.22 所示悬挂在两根钢丝下的交通信号灯（质量 15.0 kg）。求每根钢丝中的张力，忽略钢丝的质量。

思路

所研究的系统是交通信号灯，它的受力图如图 4.22（c） 所示。所涉及的三个力不平行，因此必须把它们投影到一个坐标系上。最方便的坐标系是一条轴竖直、一条轴水平，矢量在其上的投影画在图的（d）部分。这个问题中有两个未知量（$\kTone$ 和 $\kTtwo$），所以需要两个方程来求它们。这两个方程来自沿竖直轴和水平轴应用牛顿第二定律，并注意到每条轴上的合外力都为零，因为加速度为零。

解

首先考虑水平轴，即 x 轴：

$$\kFnetx = \kTtwox - \kTonex = 0.$$

因此，正如你可能预料到的，

$$\kTonex = \kTtwox.$$

这给出 $\kTone$ 与 $\kTtwo$ 之间的如下关系：

$$\kTone\cos(30^\circ) = \kTtwo\cos(45^\circ).$$

因此，

$$\kTtwo = (1.225)\kTone.$$

注意，在这种情形下 $\kTone$ 和 $\kTtwo$ 并不相等，因为两侧的角度并不相等。$\kTtwo$ 最终大于 $\kTone$ 是合理的，因为它比 $\kTone$ 更接近竖直方向施加。

现在考虑沿竖直轴即 y 轴的力的分量：

$$\kFnety = \kToney + \kTtwoy - \kwgt = 0.$$

这意味着

$$\kToney + \kTtwoy = \kwgt.$$

代入竖直分量的表达式，得到

$$\kTone\sin(30^\circ) + \kTtwo\sin(45^\circ) = \kwgt.$$

这个方程中有两个未知量，但代入用 $\kTone$ 表示 $\kTtwo$ 的表达式后，就化为一个含一个未知量的方程：

$$\kTone(0.500) + (1.225\kTone)(0.707) = \kwgt = \km\kg,$$

由此得到

$$(1.366)\kTone = (15.0\ \text{kg})(9.80\ \text{m/s}^{2}).$$

解这最后一个方程，得到 $\kTone$ 的大小为

$$\kTone = 108\ \text{N}.$$

最后，利用上面求得的二者之间的关系 $\kTtwo = 1.225\,\kTone$，确定 $\kTtwo$ 的大小。这样我们得到

$$\kTtwo = 132\ \text{N}.$$

讨论

如果两根钢丝都更接近水平，两个张力都会更大；当且仅当两侧的角度相同时（如前面走钢丝者的例子中那样），它们才会相等。

电梯中体重秤的示数

体重秤是作用在物体上的法向力的一个绝佳例子。它给出的是一个定量读数，说明为了支撑物体的重力，它必须向上推多大的力。但是，你能预测出，如果你在乘电梯时站在体重秤上，刻度盘上会看到什么吗？电梯启动上升时，你会看到大于你的重力的数值吗？电梯以恒定速率上升时呢：秤的示数还会比你静止时的重力大吗？请看下面这个例子。

例题 4.9 · 电梯中体重秤的示数是多少？

图 4.23 显示一位 75.0 kg 的男子（重力约为 165 lb）站在电梯里的体重秤上。计算秤的示数：（a）电梯以 $1.20\ \text{m/s}^{2}$ 的加速度向上加速时，（b）电梯以 1 m/s 的恒定速率向上运动时。

思路

如果秤是准确的，它的示数将等于 $\kFp$，即人向下压它的力的大小。图 4.23（a） 显示了作用在电梯、秤和人上的众多力。它使这个一维问题看起来，比选人作为所研究的系统并像图 4.23（b） 那样画出受力图要艰巨得多。用牛顿定律分析受力图，可以得出本例（a）、（b）两问的答案，以及可能出现的其他一些问题的答案。作用在人身上的力只有他的重力 $\kwgt$ 和秤的向上的力 $\kFs$。根据牛顿第三定律，$\kFp$ 和 $\kFs$ 的大小相等、方向相反，所以我们需要求出 $\kFs$，才能知道秤的示数。我们可以像往常一样，应用牛顿第二定律来做到这一点。

我们没有对加速度作任何假设，因此这个解对本题中的加速度之外的各种加速度也应当成立。

（a）的解

在这一问中，$\ka = 1.20\ \text{m/s}^{2}$，因此

$$\kFs = (75.0\ \text{kg})(1.20\ \text{m/s}^{2}) + (75.0\ \text{kg})(9.80\ \text{m/s}^{2}),$$

得到

$$\kFs = 825\ \text{N}.$$

（a）的讨论

这大约是 185 lb。如果他静止不动，秤会显示多少？由于他的加速度将为零，秤的力将等于他的重力：

$$\begin{aligned}\kFnet &= \km\ka = 0 = \kFs - \kwgt\\ \kFs &= \kwgt = \km\kg\\ \kFs &= (75.0\ \text{kg})(9.80\ \text{m/s}^{2})\\ \kFs &= 735\ \text{N.}\end{aligned}$$

所以，电梯里的秤的示数大于他的735 N（165 lb）的重力。这意味着秤向上推人的力大于他的重力，它必须如此，才能使他向上加速。显然，电梯的加速度越大，秤的示数就越大，这与你在快速加速和缓慢加速的电梯中的感觉是一致的。

（b）的解

现在，当电梯达到恒定的向上速度时会怎样？秤的示数还会比他的重力大吗？对于任何恒定的速度——向上、向下或静止——加速度都为零，因为 $\ka = \frac{\kdv}{\kdt}$，而 $\kdv = 0$。

因此，

$$\kFs = \km\ka + \km\kg = 0 + \km\kg.$$

现在

$$\kFs = (75.0\ \text{kg})(9.80\ \text{m/s}^{2}),$$

由此得到

$$\kFs = 735\ \text{N}.$$

（b）的讨论

秤的示数是 735 N，等于人的重力。只要电梯的恒定速度——向上运动、向下运动或静止——情况都是如此。

如前面所提到的，上一个例题的解也适用于向下加速的电梯。电梯向下加速时，$\ka$ 为负，秤的示数小于人的重力，直到达到恒定的向下速度，这时秤的示数又变得等于人的重力。如果电梯处于自由落体运动，以 $\kg$ 向下加速，那么秤的示数将为零，人将看起来是失重的。

综合概念：牛顿运动定律与运动学

物理学在应用于涉及的物理原理不止一小组的一般情形时，最有趣也最有力。牛顿运动定律还可以与本书前面讨论过的其他概念相结合，来解决运动问题。例如，力产生加速度，这是运动学的一个课题，因而前面各章与此相关。在处理涉及各种类型的力、加速度、速度和/或位置的问题时，请按下面的步骤来处理：

解题策略

步骤 1。 确定涉及哪些物理原理。列出已知量和待求量，可以让你确定所涉及的原理。

步骤 2。 运用本书中概述的策略来解题。如果针对具体主题有这类策略，你应当参考它们。你也应当参考本书中论述某个具体主题的各节。下面的例题说明了如何把这些策略应用于一道综合概念题。

例题 4.10 · 足球运动员要达到最大速率必须施加多大的力？

一名足球运动员从静止开始向前加速，在 2.50 s 内达到 8.00 m/s 的速度。（a）他的平均加速度是多少？（b）他为达到这一加速度，对地面向后施加了多大的平均力？该运动员的质量为 70.0 kg，空气阻力可以忽略。

思路

要解一道综合概念题，我们必须首先确定所涉及的物理原理，并确定它们所在的章。本例的（a）问考虑的是沿直线的加速度。这是运动学的一个课题。（b）问涉及力，这是本章中的动力学的一个课题。

下面对例题各部分的解，说明了具体的解题策略是如何应用的。这些策略包括确定已知量和未知量、检验答案是否合理，等等。

（a）的解

已知初速度和末速度（零和向前 8.00 m/s）；因此，速度的变化量为 $\kdv = 8.00\ \text{m/s}$。已知时间间隔，所以 $\kdt = 2.50\ \text{s}$。未知量是加速度，可以由它的定义求得：

$$\ka = \frac{\kdv}{\kdt}.$$

代入已知数值，得到

$$\begin{aligned}\ka &= \frac{8.00\ \text{m/s}}{2.50\ \text{s}}\\ &= 3.20\ \text{m/s}^{2}.\end{aligned}$$

（a）的讨论

对于一名状态良好的运动员，这是一个可以达到的加速度。

（b）的解

这里要求的是运动员为达到这一向前加速度而向后施加的平均力。忽略空气阻力，它的大小将等于作用在运动员身上的合外力，因为正是这个力使他产生加速度。既然我们现在知道运动员的加速度，并且已知他的质量，就可以用牛顿第二定律求出所施加的力。即，

$$\kFnet = \km\ka.$$

代入 $\km$ 和 $\ka$ 的已知值，得到

$$\begin{aligned}\kFnet &= (70.0\ \text{kg})(3.20\ \text{m/s}^{2})\\ &= 224\ \text{N}.\end{aligned}$$

（b）的讨论

这大约是 50 磅，是一个合理的平均力。

这个例题说明了如何把解题策略应用于包含不同章节主题的情形。第一步是确定问题所涉及的物理原理。第二步是用熟悉的解题策略求解未知量。这些策略贯穿全书，许多例题展示了如何把它们用于单个主题。你会发现，这些针对综合概念题的技巧，在物理学课程之外的物理学应用中也很有用，比如在你的职业中、在其他科学学科中，以及在日常生活中。下面的习题将培养你广泛应用物理原理的技能。
