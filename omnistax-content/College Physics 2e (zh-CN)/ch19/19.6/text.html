几个电容器，一个等效电容

在各种应用中，可以把几个电容器连接在一起。电容器的多种连接，其作用就像单个等效电容器。这个等效单个电容器的总电容既取决于各个电容器，也取决于它们的连接方式。有两种简单而常见的连接方式，称为串联和并联，我们可以很容易地算出它们的总电容。某些更复杂的连接也可以归结为串联与并联的组合。

串联电容

图 19.20(a) 表示串联的三个电容器，并加有一个电压。与任何电容器一样，这个组合的电容通过 $\kCap = \frac{\kQch}{\kV}$ 与电荷和电压相联系。

请注意，在图 19.20 中，当加上电压 $\kV$ 时，大小为 $\kQch$ 的异号电荷流向原本不带电的电容器组合的两侧。电荷守恒要求在各个电容器的极板上产生大小相等的电荷，因为在这些原本电中性的器件中，电荷只是被分离开。最终的结果是，这个组合类似于单个电容器，其有效极板间距大于各个电容器单独的极板间距。（见图 19.20(b)。）较大的极板间距意味着较小的电容。电容器的串联连接有一个普遍的特点：总电容小于其中任何一个单独的电容。

通过考虑图 19.20 所示各个电容器两端的电压，我们可以求出总电容的表达式。

这里的“...”表示该表达式对任意个串联的电容器都成立。这种形式的表达式得到的总电容 $\kCS$ 总是小于任何一个单独的电容 $\kCone$、$\kCtwo$、...，下一个例题将说明这一点。

串联的总电容

串联的总电容：

$$\frac{1}{\kCS} = \frac{1}{\kCone} + \frac{1}{\kCtwo} + \frac{1}{\kCthree} + \text{.}\text{.}\text{.}$$

例题 19.9 · 串联电容是多少？

求三个串联的电容器的总电容，已知它们各自的电容分别为 1.000、5.000 和 8.000 $\text{\mu F}$。

思路

根据所给的信息，利用串联电容的公式，就可以求出总电容。

解

把所给的电容代入 $\frac{1}{\kCS}$ 的表达式，得 $\frac{1}{\kCS} = \frac{1}{\kCone} + \frac{1}{\kCtwo} + \frac{1}{\kCthree}$。

$$\frac{1}{\kCS} = \frac{1}{1\text{.}\text{000 }\mu\text{F}} + \frac{1}{5\text{.}\text{000 }\mu\text{F}} + \frac{1}{8\text{.}\text{000 }\mu\text{F}} = \frac{1\text{.}\text{325}}{\text{}\mu\text{F}}$$

取倒数求 $\kCS$，得 $\kCS = \frac{\text{\mu F}}{1\text{.}\text{325}} = 0\text{.}\text{755 \mu F}$。

讨论

串联总电容 $\kCS$ 小于最小的单个电容，正如前面所说。在电容器的串联连接中，总和小于各部分。事实上，它比其中任何一个都小。请注意，有时可以通过求最小公分母来解上面这样的方程，而且更方便；在这个例子中（只显示整数运算），最小公分母是 40。于是，

$$\frac{1}{\kCS} = \frac{\text{40}}{\text{40 }\mu\text{F}} + \frac{8}{\text{40 }\mu\text{F}} + \frac{5}{\text{40 }\mu\text{F}} = \frac{\text{53}}{\text{40 }\mu\text{F}},$$

所以

$$\kCS = \frac{\text{40 }\mu\text{F}}{\text{53}} = 0\text{.}\text{755 }\mu\text{F}.$$

并联的电容器

图 19.21(a) 表示并联的三个电容器，并加有一个电压。这里的总电容比串联的情形更容易求。为了求等效总电容 $\kCp$，我们首先注意到，每个电容器两端的电压都是 $\kV$，与电源的电压相同，因为它们通过导体直接与电源相连。（导体是等势体，因此各个电容器两端的电压与电压源两端的相同。）于是，各个电容器上具有相同的电荷，就像它们单独接到电压源上时一样。

并联时的总电容就是各个电容之和。（同样，“...”表示该表达式对任意个并联的电容器都成立。）因此，例如，如果上面例题中的电容器是并联的，那么它们的电容就将是

$$\kCp = 1\text{.}\text{000 }\mu\text{F} + 5\text{.}\text{000 }\mu\text{F} + 8\text{.}\text{000 }\mu\text{F} = \text{14}\text{.}000\ \text{}\mu\text{F}.$$

并联连接的等效电容器具有更大的等效极板面积，因此具有较大的电容，如图 19.21(b) 所示。

并联的总电容

并联的总电容：

$$\kCp = \kCone + \kCtwo + \kCthree + \text{.}\text{.}\text{.}$$

同一电路中的串联与并联

更复杂的电容器连接有时可以是串联与并联的组合。（见图 19.22。）要求这类组合的总电容，我们先辨认出串联和并联的部分，算出它们的电容，再求出总电容。

例题 19.10 · 串联与并联混合的电容

求图 19.22 所示的电容器组合的总电容。假设图 19.22 中的电容已知到三个小数位（$\kCone = 1.000\ \text{\mu F}$，$\kCtwo = 5.000\ \text{\mu F}$，$\kCthree = 8.000\ \text{\mu F}$），并把答案修约到三个小数位。

思路

为了求总电容，我们先辨认哪些电容器是串联的，哪些是并联的。电容器 $\kCone$ 和 $\kCtwo$ 是串联的。它们的组合在图中标为 $\kCS$，与 $\kCthree$ 并联。

解

因为 $\kCone$ 和 $\kCtwo$ 是串联的，所以它们的总电容由 $\frac{1}{\kCS} = \frac{1}{\kCone} + \frac{1}{\kCtwo} + \frac{1}{\kCthree}$ 给出。把它们的值代入方程，得

$$\frac{1}{\kCS} = \frac{1}{\kCone} + \frac{1}{\kCtwo} = \frac{1}{1\text{.}\text{000}\;\mu\text{F}} + \frac{1}{5\text{.}\text{000}\;\mu\text{F}} = \frac{1\text{.}\text{200}}{\mu\text{F}}.$$

取倒数，得

$$\kCS = 0\text{.}\text{833 }\mu\text{F}.$$

这个等效串联电容与第三个电容器并联；因此，总电容是二者之和

$$\begin{aligned}\kCtot &= \kCS + \kCthree\\ &= 0.833\;\mu\text{F} + 8.000\;\mu\text{F}\\ &= 8.833\;\mu\text{F}.\end{aligned}$$

讨论

这种把电容器的组合逐段分析、直到得出总电容的方法，可以用于更大的电容器组合。
