听觉与可听频率范围

人耳的范围和灵敏度都非常惊人。它能给我们提供大量简单的信息——例如音调、响度和方向。而且，根据它的输入，我们能察觉音乐的品质和说话时情感的细微差别。我们的听觉与声音的物理性质有什么关系，听觉机制又是如何工作的？

听觉是对声音的知觉。（知觉通常被定义为通过感官而获得的觉察，这是对生物体内较高层次过程的一种典型的循环定义。）正常人的听觉涵盖从 20 到 20,000 Hz 的频率，范围相当可观。低于 20 Hz 的声音称为次声，而高于 20,000 Hz 的则是超声。耳朵感知不到这两者，不过次声有时可以作为振动被感觉到。当我们确实听到低频振动时，例如跳板的声音，我们之所以能听到一次次单独的振动，只是因为每一次振动中都含有较高频率的声音。其他动物的听觉范围与人类不同。狗能听到高达 30,000 Hz 的声音，而蝙蝠和海豚能听到高达 100,000 Hz 的声音。你可能已经注意到，狗会对犬笛的声音作出反应，这种哨子发出的声音超出了人类听觉的范围。已知大象会对低于 20 Hz 的频率作出反应。

音调与相对音感

对频率的知觉称为音调。我们大多数人都具有出色的相对音感，这意味着我们能分辨一个声音的频率与另一个是否不同。一般来说，如果两个声音的频率相差 0.3% 或更多，我们就能区分它们。例如，500.0 和 501.5 Hz 的差别是明显的。音调知觉与频率直接相关，不太受强度等其他物理量的影响。音乐中的音是大多数乐器都能产生的特定声音，在西方音乐中各有特定的名称。音的组合构成音乐。有些人只要听一听，就能辨认出音乐中的音，例如升 A、C 或降 E。这种不常见的能力称为绝对音感。

响度与强度范围

耳朵对低强度的声音非常灵敏。可听的最低强度，即阈值，约为 $10^{-12}\ \text{W/m}^2$，即 0 dB。强度高出多达 $10^{12}$ 倍的声音也能被短暂地忍受。很少有测量仪器能够在一万亿倍的范围内进行观测。对强度的知觉称为响度。在给定的频率下，能够分辨约 1 dB 的差别，而 3 dB 的变化很容易被察觉。但响度并不只与强度有关。频率对一个声音听起来有多响有很大影响。耳朵对2000 到 5000 Hz 范围内的频率灵敏度最高，所以这个范围内的声音被感知得比，比如说，500 或 10,000 Hz 的声音更响，即使它们都具有相同的强度。声音在听觉范围的高频和低频两端附近听起来更不响，因为耳朵在这些频率上更不灵敏。表 17.4 给出了人的某些听觉知觉对物理量的依赖关系。

音色、音质与音

小提琴演奏中央 C 时，没有人会把它错认成钢琴演奏的同一个音。原因在于每种乐器都会产生一组独特的频率和强度。我们把对这些频率和强度组合的知觉称为音质，或者更常见地称为声音的音色。把音色知觉与物理量联系起来，比响度或音调知觉更困难。音色更具主观性。人们用沉闷、明亮、温暖、冰冷、纯净和丰富等词来描述一个声音的音色。所以对音色的考虑把我们带入知觉心理学的领域，在那里，大脑中较高层次的过程占主导地位。对于声音的其他知觉，例如音乐和噪声，也是如此。我们不再深入探讨它们；相反，我们将集中讨论响度知觉的问题。

方与等响曲线

一种叫作“方”的单位用来以数值表示响度。方与分贝不同，因为方是响度知觉的单位，而分贝是物理强度的单位。图 17.34 显示了对于听力正常的人，响度与强度（或声强级）和频率的关系。这些曲线是等响曲线。每条曲线都标有以方为单位的响度。沿某一条曲线的任何声音，普通人都会感知为同样响。这些曲线是让大量的人比较不同频率和不同声强级的声音的响度而测定的。在1000 Hz 的频率下，取方在数值上等于分贝。下面的例题有助于说明如何使用这张图：

讨论

这些答案与从图 17.34 中提取的所有信息一样，都有若干方或若干分贝的不确定度，部分是由于内插的困难，但主要与等响曲线本身的不确定度有关。

对图 17.34 作进一步考察，可以发现关于人的听觉的一些有趣事实。首先，低于 0 方曲线的声音，大多数人是感知不到的。因此，例如，40 dB 的 60 Hz 声音是听不见的。0 方曲线代表正常听觉的阈值。我们能听到一些声强级低于 0 dB 的声音。例如，3 dB、5000 Hz 的声音是可以听到的，因为它位于 0 方曲线之上。响度曲线在大约 2000 到 5000 Hz 之间都有凹处。这些凹处意味着耳朵对该范围内的频率最灵敏。例如，4000 Hz 处 15 dB 的声音的响度为 20 方，与 1000 Hz 处 20 dB 的声音相同。曲线在频率范围的两端上升，表明在这些频率上需要声强级更大的声音，才会被感知得与中等频率上一样响。例如，10,000 Hz 的声音必须有 30 dB 的声强级，才会显得与 1000 Hz 处 20 dB 的声音一样响。高于 120 方的声音既会引起疼痛，也会造成损伤。

听力损失、语音区与听力图

我们并不经常用到全部的听觉范围。对于高于 8000 Hz 的频率尤其如此，这些频率在环境中很少见，对于听懂交谈或欣赏音乐也是不必要的。事实上，丧失了听到如此高频率的能力的人，通常要到接受测试后才会意识到自己的损失。图 17.35 中的阴影区域是大多数交谈声音所处的频率和强度区域。曲线表示 40 和 60 方的听力损失会产生什么影响。在所有频率上都有 40 方的听力损失，仍然可以让人听懂交谈，尽管听起来会很轻。在所有频率上都有 60 方损失的人，只能听到最低的频率，除非语音比正常情况响得多，否则无法听懂语音。即便如此，语音也可能显得含混不清，因为较高的频率没有被很好地感知。交谈的语音区还有性别的成分，即女性的声音通常以较高的频率为特征。所以有 60 方听力障碍的人，可能难以听懂女性的正常交谈。

听力测试在一定范围的频率上进行，通常是 250 到 8000 Hz，其结果可以用听力图以图形方式显示，如图 17.36 所示。听阈是以 dB 为单位、相对于正常阈值来测量的，所以正常听觉在所有频率上都记录为 0 dB。噪声引起的听力损失通常在4000 Hz 的频率附近出现凹处，与引起损失的频率无关，并且常常影响双耳。最常见的听力损失形式随年龄而来，称为老年性聋（presbycusis）——字面意思是“老年的耳朵”。这种损失在较高的频率上越来越严重，会妨碍音乐欣赏和语音识别。

听觉机制

听觉机制

听觉机制涉及一些有趣的物理学。撞击我们耳朵的声波是一种压强波。耳朵是一种换能器，把声波转换成电神经冲动，其方式比传声器复杂得多，但与之类似。图 17.37 显示了耳的大体解剖结构，它分为三部分：外耳或外耳道；中耳，从鼓膜延伸到耳蜗；以及内耳，即耳蜗本身。我们通常称为耳朵的这个身体部位，在专业上称为耳郭。

外耳，即外耳道，把声音传送到凹进去、受到保护的鼓膜。外耳道中的空气柱发生共振，这在一定程度上造成了耳朵对 2000 到 5000 Hz 范围内的声音的灵敏度。中耳把声音转换成机械振动，并把这些振动施加到耳蜗上。中耳的杠杆系统接收由声压变化作用在鼓膜上的力，将它放大，并经由前庭窗传给内耳，在耳蜗中产生压强波，其大小约为撞击鼓膜的压强波的 40 倍。（见图 17.38。）中耳中的两块肌肉（图中未画出）保护内耳免受非常强烈的声音的伤害。它们在几毫秒内对强烈的声音作出反应，并减小传到耳蜗的力。这种保护性反应也可以由你自己的声音触发，所以，例如开枪时哼唱，可以减轻噪声造成的损伤。

图 17.39 更详细地显示了中耳和内耳。压强波穿过耳蜗时，使盖膜振动，摩擦纤毛（称为毛细胞），纤毛刺激神经，神经把电信号送到大脑。该膜在不同频率下于不同的位置共振，高频率刺激近端的神经，低频率刺激远端的神经。耳蜗的完整工作过程仍未被理解，但已知有若干把信息送往大脑的机制参与其中。对于低于约 1000 Hz 的声音，神经发送的信号与声音具有相同的频率。对于高于约 1000 Hz 的频率，神经通过位置来表示频率。纤毛有一定的结构，神经细胞之间也有连接，在信息送往大脑之前先进行信号处理。强度信息部分地由神经信号的数目和成串的信号来表示。大脑对耳蜗神经信号进行处理，以提供额外的信息，例如声源方向（依据对来自双耳的声音的时间和强度的比较）。更高层次的处理产生许多细微之处，例如音乐欣赏。

听力损失可能由中耳或内耳的问题引起。中耳的传导性听力损失，可以通过让声振动经由颅骨传到耳蜗而得到部分克服。为此目的的助听器通常压在耳后的骨头上，而不是像许多助听器那样，只是放大送入外耳道的声音。耳蜗中神经的损伤是不可修复的，但放大可以部分地予以补偿。放大有造成进一步损伤的风险。耳蜗中另一种常见的故障是纤毛受损或丧失，但神经仍保持功能。直接刺激神经的人工耳蜗现在已经可以获得，并被广泛接受。使用中的植入体超过 100,000 个，成人和儿童的数量大致相当。

人工耳蜗是澳大利亚墨尔本的格雷姆·克拉克在 20 世纪 70 年代为他失聪的父亲而首创的。该植入体由三个外部部件和两个内部部件组成。外部部件是：用来拾取声音并将其转换成电信号的传声器，用来选择某些频率的言语处理器，以及通过电磁感应把信号传送到内部部件的发射器。内部部件由固定在皮肤下方骨中的接收器/发射器和盘绕穿过耳蜗的约 24 个电极组成的阵列构成；接收器/发射器把信号转换成电脉冲，并通过一根内部电缆把它们送到耳蜗和该阵列。这些电极再把脉冲直接送入大脑。电极基本上是模拟纤毛。
