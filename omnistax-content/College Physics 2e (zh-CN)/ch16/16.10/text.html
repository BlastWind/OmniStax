叠加与干涉

大多数波看起来并不那么简单。它们看起来更像图 16.32 中的波，而不像“波”一节中所讨论的那种简单水波。（简单的波可以由简谐振动产生，因而具有正弦形状。）复杂的波更有趣，甚至很美，但看上去令人生畏。大多数波之所以显得复杂，是因为它们由几列简单的波相加而成。幸运的是，波相加的规则相当简单。

当两列或多列波到达同一点时，它们会彼此叠加。更确切地说，波的扰动在汇合时会叠加——这一现象称为叠加。每个扰动都对应一个力，而力是相加的。如果这些扰动沿同一直线，那么合成波就是各列波扰动的简单相加，也就是说，它们的振幅相加。图 16.33 和图 16.34 说明了两种特殊情形下的叠加，这两种情形的结果都很简单。

图 16.33 表示两列相同的波恰好同相到达同一点。两列波的波峰精确对齐，波谷也是如此。这种叠加产生完全相长干涉。由于扰动相加，完全相长干涉所产生的波，其振幅是单个波的两倍，但波长相同。

图 16.34 表示两列相同的波恰好反相到达——也就是波峰与波谷精确对齐——产生完全相消干涉。由于在这种叠加中扰动的方向相反，完全相消干涉所得的合成振幅为零——两列波完全抵消。

完全相长干涉和完全相消干涉确实会出现，但它们要求相同的波精确对齐。大多数波的叠加产生的是相长干涉与相消干涉的组合，并且会随位置和时间而变化。例如，立体声音响发出的声音，可能在一处很响，在另一处却很轻。响度变化意味着声波在不同位置上部分相长、部分相消地相加。立体声音响至少有两个扬声器产生声波，而且波还会被墙壁反射。所有这些波都会叠加。声音随时间由相长变为相消的一个例子，是静止不动的乘客听到的喷气式飞机发动机合在一起的啸叫声。由于两台发动机的声音随时间由相长变为相消，合在一起的声音的音量可以忽高忽低。这些例子说的都是相似的波。

图 16.35 所示是两列不相似的波的叠加的一个例子。这里，扰动同样有加有减，产生一个看起来更复杂的波。

驻波

有时波似乎并不移动，而只是在原地振动。例如，在冰箱里的一杯牛奶的表面上，就能看到不动的波。冰箱电动机的振动在牛奶上产生波，这些波上下振动，却似乎不会在液面上移动。这些波是由两列或多列运动的波叠加而成的，如图 16.36 所示，那是沿相反方向运动的两列相同的波。这两列波相互穿过，经过时它们的扰动相加。如果两列波的振幅和波长相同，它们就在相长干涉和相消干涉之间交替。合成波看上去像是静立在原地的波，因此称为驻波。玻璃杯中牛奶上的波就是驻波的一个例子。还有其他的驻波，如吉他弦上和风琴管中的驻波。就这杯牛奶而言，产生驻波的两列波可能来自杯壁的反射。

仔细考察地震，可以找到适合产生共振、驻波以及相长干涉和相消干涉的条件的证据。一座建筑可能在数秒内受到振动，驱动频率与建筑振动的固有频率相匹配——产生共振，结果一座建筑倒塌，而相邻的建筑却安然无恙。常常是某一高度的建筑被摧毁，而另一些更高的建筑却完好无损。建筑的高度符合为该特定高度建立驻波的条件。随着地震波沿地球表面传播并在较致密的岩石上反射，在某些点上会出现相长干涉。常常是离震中较近的区域没有受损，而较远的区域却遭到破坏。

驻波也见于乐器的弦上，它们是由波在弦的两端反射形成的。图 16.37 和图 16.38 表示在两端固定的弦上可以产生的三种驻波。波节是弦不运动的点；更一般地说，波节是驻波中波的扰动为零之处。弦的固定端也必定是波节，因为弦在那里不能运动。“波腹”一词用来表示驻波中振幅最大的位置。弦上驻波的频率与扰动在弦上的传播速率 $\kvw$ 有关。波长 $\klam$ 由弦被固定的两点之间的距离决定。

最低的频率称为基频，因而对应最长的波长，可见它是 $\klamone = 2\kLlen$。所以，基频为 $\kfone = \kvw/\klamone = \kvw/2\kLlen$。这时，泛音或谐波是基频的倍数。如图 16.38 所示，由于 $\klamtwo = \kLlen$，一次谐波很容易算出。于是 $\kftwo = \kvw/\klamtwo = \kvw/\kLlen = 2\kfone$。同样，$\kfthree = 3\kfone$，依此类推。所有这些频率都可以通过调节弦中的张力来改变。张力越大，$\kvw$ 越大，频率越高。任何观察过弦乐器调音的人，对这一点都很熟悉。我们将在后面的章节中看到，驻波对许多共振现象至关重要，例如弦乐器的共鸣箱。

拍

同时敲击钢琴上相邻的两个琴键，会产生一种颤动的混合音，通常被认为令人不悦。罪魁祸首是两列频率相近但不相同的波的叠加。另一个例子常常出现在喷气式飞机上，尤其是双发动机的那种，在滑行的时候。发动机合在一起的声音的响度忽高忽低。出现这种变化的响度，是因为声波的频率相近但不相同。钢琴那不和谐的颤音和喷气发动机噪声起伏的响度，都是由于两列波时而同相、时而反相，相长干涉和相消干涉交替出现。图 16.39 用图形说明了这一点。

两列频率相近的波的叠加所得的波，其频率是这两个频率的平均值。这列波的振幅会起伏，也就是拍，其频率称为拍频。我们可以通过把两列波在数学上相加来确定拍频。注意，在空间中的一点，波可以表示为

$$\kx = \kX\cos\left(\frac{2\pi\kt}{\kT}\right) = \kX\cos(2\pi\kf\kt),$$

其中 $\kf = 1/\kT$ 是波的频率。把两列频率不同而振幅相同的波相加，得到合成波

$$\kx = \kxone + \kxtwo.$$

更具体地说，

$$\kx = \kX\cos(2\pi\kfone\kt) + \kX\cos(2\pi\kftwo\kt).$$

利用三角恒等式，可以证明

$$\kx = 2\kX\cos(\pi\kfB\kt)\cos(2\pi\kfave\kt),$$

其中

$$\kfB = \lvert\kfone - \kftwo\rvert$$

是拍频，$\kfave$ 是 $\kfone$ 和 $\kftwo$ 的平均值。这些结果表明，合成波具有所叠加的两列波的两倍振幅和平均频率，但它的总振幅还以拍频 $\kfB$ 起伏。表达式中的第一个余弦项实际上使振幅忽大忽小。第二个余弦项是频率为 $\kfave$ 的波。这一结果对所有类型的波都成立。不过，如果是声波，只要两个频率相近，那么我们听到的就是一个平均频率，它按拍频变响变轻（或发出颤音）。

建立职业联系

钢琴调音师在工作中经常使用拍。把一个音与音叉比较时，他们倾听拍，并调整琴弦，直到拍消失（降为零频率）。例如，如果音叉的频率为 $\text{256}\;\text{Hz}$，并且每秒听到两拍，那么另一个频率是 $\text{254}$ 或 $\text{258}\;\text{Hz}$。多数琴键会敲击多根弦，这些弦实际上被调到频率几乎相同，产生缓慢的拍，使音色更丰满。十二弦吉他和曼陀林也是用拍来调音的。

虽然拍在可听的声音中有时令人烦恼，但我们将发现拍有许多应用。观察拍是比较相近频率的一种非常有用的方法。拍的应用看似相去甚远，例如超声成像和雷达测速点。
