The description on which both groups converged begins with the most general form of the master equation,

$$\frac{d\krhoS}{d\kt} = \frac{1}{i\hbar}[\kH_S, \krhoS] + \mathcal{L}(\krhoS), \tag{6.1}$$

where the Liouvillian operator can be expressed as

$$\mathcal{L}(\krhoS) = -\sum_k \frac{\kgammak}{2}\left(\kchatk^\dagger\kchatk\krhoS + \krhoS\kchatk^\dagger\kchatk - 2\kchatk\krhoS\kchatk^\dagger\right). \tag{6.2}$$

It can be shown that Eq. (6.1) is the most general form for a master equation allowed by physics, and it has the added advantage that it is notationally compact. Since it is the most general form, it must contain the master equation we derived by assuming a certain kind of environment. To see this, identify the (in principle arbitrary) operators $\kchatk$ with

$$\hat{c}_{2k} = \sqrt{\knbar+1}\,\hat{S}_k \tag{6.3}$$
$$\hat{c}_{2k+1} = \sqrt{\knbar}\,\hat{S}_k^\dagger, \tag{6.4}$$

in which case both the decay and absorption terms are included in Eq. (6.1).

Combining Eq. (6.1) with the definition for $\mathcal{L}(\krhoS)$, and expanding $\krhoS = \sum_\alpha p_\alpha|\kpsi_\alpha\rangle\langle\kpsi_\alpha|$, we can rewrite the master equation in a suggestive form.

The first two terms can be rewritten in terms of an effective Hamiltonian,

$$\kHeff = \kH_S - i\hbar\sum_k \frac{\kgammak}{2}\kchatk^\dagger\kchatk. \tag{6.7}$$

This form for the first two terms resembles the master equation for a pure state evolving according to $\kHeff$; the final term we will interpret as a “quantum jump” operator which changes $|\kpsi_\alpha\rangle$ into another state $|\phi_{k,\alpha}\rangle = \kchatk|\kpsi_\alpha\rangle$ with some probability.

The Schrodinger equation corresponding to the first two terms of Eq. (6.8) is

$$i\hbar\frac{d}{d\kt}|\kpsi_\alpha\rangle = \kHeff|\kpsi_\alpha\rangle, \tag{6.9}$$

and since we are interested in using Eq. (6.8) to describe a stochastic evolution, we will write it in discrete time,

$$|\kpsi_\alpha(\kt+\delta\kt)\rangle = \left(1 + \frac{\kHeff\delta\kt}{i\hbar}\right)|\kpsi_\alpha(\kt)\rangle. \tag{6.10}$$

Note that $|\tilde{\kpsi}_\alpha(\kt+\delta\kt)\rangle$ is not normalized because the effective Hamiltonian is not Hermitian.

To simplify notation, we define

$$\kdeltapk = \delta\kt\,\kgammak\langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle \tag{6.14}$$
$$\kdeltap = \delta\kt\sum_k \kgammak\langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle. \tag{6.15}$$

We now know the proper normalization for the state at time $\kt+\delta\kt$:

$$|\tilde{\kpsi}_\alpha(\kt+\delta\kt)\rangle = \frac{1 + \kHeff\delta\kt/i\hbar}{\sqrt{1-\kdeltap}}|\kpsi_\alpha(\kt)\rangle. \tag{6.17}$$

This normalized state corresponds the state of a system evolving solely under the influence of the first two terms in the master equation, i.e. a system which has never jumped into one of the $|\phi_{k,\alpha}\rangle$.

The “quantum jump” states $|\phi_{k,\alpha}\rangle$ are not normalized either, since

$$\langle\phi_{k,\alpha}|\phi_{k,\alpha}\rangle = \langle\kpsi_\alpha|\kchatk^\dagger\kchatk|\kpsi_\alpha\rangle = \frac{\kdeltapk}{\kgammak\delta\kt}. \tag{6.18}$$

Again, we will define a normalized state

$$|\tilde{\phi}_{k,\alpha}\rangle = \sqrt{\frac{\kgammak\delta\kt}{\kdeltapk}}|\phi_{k,\alpha}\rangle \tag{6.19}$$

to explicitly keep track of probability conservation.

Like the Schrodinger equation, the master equation may be written for discrete times $\delta\kt$.

By rewriting the master equation in this form, we can use a probability interpretation to gain intuition – and develop numerics – for the resulting system dynamics. Eq. (6.21) has two terms, which lead to two possible outcomes after a time $\delta\kt$ :

(1) with probability $(1-\kdeltap)$, the system evolves according to $\kHeff$, and remains in state $|\tilde{\kpsi}_\alpha\rangle$.

(2) with probability $\kdeltap$, the system jumps into another state; in particular it jumps into state $|\tilde{\phi}_{k,\alpha}\rangle$ with probability $\kdeltapk$.

This statistical picture of a state vector evolution provides a clear procedure for simulation which only requires computation of the state vector (rather than density matrix) elements. A sample algorithm is summarized in Table (6.1).

Table 6.1Monte Carlo Procedure
(1) Pick initial state $|\kpsi_\alpha\rangle$
(2) Pick a random number r
(3) For an appropriate time interval $\delta\kt$, calculate $\kdeltap$. If $\kdeltap < r$, replace $|\kpsi_\alpha\rangle$ by $(1 - i\delta\kt\kHeff/\hbar)|\kpsi_\alpha\rangle/\sqrt{1-\kdeltap}$. If $\sum_{k=1}^{K}\kdeltapk \leq r < \sum_{k=1}^{K+1}\kdeltapk$, replace $|\kpsi_\alpha\rangle$ by $|\tilde{\phi}_{k,\alpha}\rangle$
(4) Repeat steps (2) and (3) for the desired length of time.
(5) Repeat steps (1-4) N times to generate a distribution of outcomes.
(6) If necessary, repeat steps (1-5) for all possible initial states $|\kpsi_\alpha\rangle$.
(7) Density matrix evolution: $\krhoS(\kt) = \sum_\alpha p_\alpha|\kpsi_\alpha(\kt)\rangle\langle\kpsi_\alpha(\kt)|/N$.
