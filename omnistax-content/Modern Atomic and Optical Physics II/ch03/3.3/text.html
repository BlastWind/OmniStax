We will use the density operator as a tool to aid derivation of an efficient description for an open system interacting with its environment. To understand how the reduced density operator evolves in time, consider first its evolution with a Hamiltonian $\kHS$ acting only on the system.

Suppose now that there is some coupling between the system and the environment described by an interaction Hamiltonian $\kHSR$. The dynamics will become quite a bit more involved, since even if the system and environment start out independent of one another, the initial product state $|\kpsi_S\rangle \otimes |\kpsi_R\rangle$ will evolve under the influence of $\kHSR$ into a state which cannot in general be factored into independent system and environment states. The system and environment are then said to be entangled.

As an illustration we return to the example of an atom spontaneously emitting a photon into the vacuum. If the atom starts out in a superposition state, $|\kpsi_0\rangle = (\kcone|1\rangle + \kctwo|2\rangle) \otimes |0\rangle$, at time ${\kt}$ it will be in a state $|\kpsi({\kt})\rangle = \kcone|1\rangle \otimes |0\rangle + \kctwo({\kt})|2\rangle \otimes |0\rangle + \sum_k \kck({\kt})|1\rangle \otimes |1_k\rangle$ which can no longer be written as a direct product of atomic and electromagnetic states. The elements of the atomic reduced density matrix can then be calculated in terms of the decay rate $\kgamma$.

Note that the off-diagonal elements decay at half the rate of the excited state population. This is characteristic of interactions which conserve energy.

3.3.1 General formalism

The total Hamiltonian may be represented as a sum of three terms,

$$\kH = \kHS + \kHR + \kHSR. \tag{3.27}$$

The first term only affects system degrees of freedom and the second only affects the reservoir while the third contains products of system operators with reservoir operators.

Each of the three terms contributes differently. The system Hamiltonian has the same effect it would have in the absence of the reservoir. The reservoir Hamiltonian has no net effect on $\krhoS$ because the trace is invariant under cyclic permutations of the reservoir operators, so the commutator must vanish. The interaction Hamiltonian, however, involves both system and reservoir operators and requires special treatment. Although we have obtained the equation of motion as a general result, no further progress can be made without specifying at least some of the properties of the interaction Hamiltonian and the reservoir itself.

3.3.2 Properties of the environment

Different environments can have qualitatively different impacts on the system with which they interact. To illustrate typical reservoir properties, we consider the example of a spin in a fluctuating magnetic field, where the interaction Hamiltonian is

$$\kHSR = \hbar \kft({\kt})\hat{S}_z. \tag{3.32}$$

This Hamiltonian corresponds to an energy splitting $\hbar \kft({\kt})$ between the spin states $|1\rangle, |2\rangle$, where $\hat{S}_z = (|2\rangle\langle 2| - |1\rangle\langle 1|)/2$. We will consider the case when $\kft({\kt})$ represents a random field. This model is applicable to a variety of physical systems, for example an electron spin in a (randomly fluctuating) bath of nuclear spins. Starting from the Hamiltonian, we can formally derive the operator describing unitary evolution of the spin

$$\hat{U} = e^{i\int_0^{\kt} \kft({\kt}')d{\kt}'\hat{S}_z}, \tag{3.33}$$

from which we can calculate the time dependence of any expectation value. In particular, we will be interested in $\langle\hat{S}_+\rangle$, which correspnds to the off-diagonal element of the spin density matrix ($\hat{S}_+ = |2\rangle\langle 1|$). This operator picks up a phase from the energy splitting in the Hamiltonian, so its time dependence is

$$\langle\hat{S}_+\rangle = \langle e^{i\int_0^{\kt} \kft({\kt}')d{\kt}'}\hat{S}_+(0)\rangle, \tag{3.34}$$

which depends on the moments of the random variable $\kft({\kt})$.

Random variables

The fluctuating energy splitting $\hbar \kft({\kt})$ represents a time dependent random process, also known as a random variable. At each point in time, $\kft({\kt})$ is characterized by some probability distribution, and we need to know something about this probability distribution to predict the average effect that $\kft({\kt})$ has on the operator we are calculating. In particular, we will want to know the following properties of the probability distribution:

(1) The first moment is the expectation value $\langle \kft({\kt})\rangle$. Typically, we will be interested in so-called “stationary processes”, for which $\langle \kft({\kt})\rangle = \langle\kft\rangle$ is constant. We can then define

$$\kft({\kt}) = \langle\kft\rangle + \delta \kft({\kt}), \tag{3.35}$$

where $\langle\delta \kft({\kt})\rangle = 0$.

(2) The variance of the random process $\langle\delta \kft({\kt})\delta \kft({\kt}')\rangle \neq 0$ describes the typical extent of the deviations of $\kft({\kt})$ from its average value.

(3) The correlation time $\ktauc$ represents the timescale on which $\kft({\kt})$ changes. It is related to the time dependence of the variance; in particular, the variance $\langle\delta \kft({\kt})\delta \kft({\kt}')\rangle$ is nearly constant for $|{\kt} - {\kt}'| < \ktauc$.

For arbitrary probability distributions, we would in principle need to specify an infinite number of higher order moments. However, in what follows we will typically deal with “Gaussian” probability distributions. For a Gaussian probability distribution, knowledge of the mean and the variance is sufficient to specify all higher order moments because they factorize pairwise:

$$\langle\delta \kft({\kt}_1)\delta \kft({\kt}_2)\ldots\delta \kft({\kt}_n)\rangle = \sum\langle\delta \kft({\kt}_1)\delta \kft({\kt}_2)\rangle\langle\delta \kft({\kt}_3)\ldots\rangle, \tag{3.36}$$

where the sum is taken over all distinct groupings into pairwise and single expectation values. In particular, we should notice that for $\langle\delta\kft\rangle = 0$, all odd-order moments vanish.

Correlation time

For the example we are considering (the spin in a fluctuating field $\kft({\kt})$), we will distinguish two important limits:

(1) ${\kt} < \ktauc$

In this case, we examine the system on timescales which are much shorter than the timescale over which the environment changes. Each time that we examine the system (for example, running an experiment on it), we will find that the spin precesses around the $\hat{z}$ axis at a rate $\kft({\kt} < \ktauc)$ which is random in value but fixed over the duration of the evolution. Every realization will have a different value of $\kft({\kt})$, so on average we would find that $\langle\bar{\hat{S}}_+\rangle = 0$. However, this dephasing is in some sense reversible. If you know what $\kft({\kt})$ is for each experiment, you can compensate for it. For example, you could perform a spin echo experiment, wherein you reverse the orientation of the spin halfway through its evolution, so that the net precession vanishes. Consequently we refer to this first situation as “reversible evolution.”

(2) ${\kt} \gg \ktauc$.

For times long compared to the correlation time, spin echo techniques fail. There is simply no way to recover a history of the evolution and undo the damage done by the fluctuating environment. The ensemble average $\langle\bar{\hat{S}}_+\rangle = 0$ again vanishes, but in a way that is fundamentally irreversible. This situation corresponds to a reservoir which has a short memory time. Such a reservoir is known as a “Markovian environment” because it can be described by a Markov process (a random process with an infinitely short correlation time). In atomic physics and quantum optics, most environments are nearly Markovian, so we will focus on techniques for understanding the effects of a Markovian reservoir.

3.3.3 Density operator method for a Markovian reservoir

By limiting the system and reservoir to certain kinds of interactions relevant to atomic physics and quantum optics, we can develop a framework for analyzing open systems. In particular, we will consider environments which have a very short correlation time, so that the system is only influenced by the instantaneous state of the reservoir.

Again, we will assume $\kH = \kHS + \kHR + \kHSR$. The interaction term $\kHS R$ is the most relevant part. To focus on it we will work in the interaction picture, which is found by transforming according to the unitary operator

$$\hat{U} = e^{i(\kHR + \kHS){\kt}/\hbar}. \tag{3.37}$$

In the interaction picture (denoted by tildes), the relevant operators are

$$\krhotilde = e^{i(\kHR + \kHS){\kt}/\hbar}\krhohat e^{-i(\kHR + \kHS){\kt}/\hbar} \tag{3.38}$$
$$\kHtilde_{SR} = e^{i(\kHR + \kHS){\kt}/\hbar}\kHSR e^{-i(\kHR + \kHS){\kt}/\hbar}. \tag{3.39}$$

The unitary transformation automatically accounts for the free evolution of the system and reservoir, so that the only remaining dynamics are due to the interactions, i.e.

$$\frac{d}{d{\kt}}\krhotilde = \frac{1}{i\hbar}[\kHtilde_{SR}, \krhotilde]. \tag{3.40}$$

Our analysis requires that the interaction be a bilinear product of system and reservoir operators,

$$\kHSR = \kShat\hat{R}^\dagger + \hat{R}\kShat^\dagger, \tag{3.41}$$

where $\kShat$ ($\hat{R}$) is a general system (reservoir) operator. In practice, the interaction Hamiltonian may have a sum over such terms: the analysis proceeds in exactly the same manner, and the effects may be accounted for by considering each term of the sum separately and summing at the end. In the interaction picture, we will represent the Hamiltonian by

$$\kHtilde_{SR} = \kShat\kFR({\kt})^\dagger + \kFR({\kt})\kShat^\dagger, \tag{3.42}$$

where all the time dependence is explicitly included in the reservoir operator $\kFR({\kt})$.

For example, consider the Hamiltonian for a single atom interacting with the radiation field in the Schrodinger picture,

$$\kHSR = \underbrace{-\sum_j\hbar \kg_j\hat{a}_j}_{\hat{R}}\underbrace{|2\rangle\langle 1|}_{\kShat^\dagger} - \sum_j\hbar \kg_j^*\hat{a}_j^\dagger|1\rangle\langle 2|, \tag{3.43}$$

where we can identify the system and reservoir operators appropriate to our more general form of the interaction. Likewise, in the interaction picture the Hamiltonian includes the phase factors associated with free evolution of the system and reservoir:

$$\kHtilde_{SR} = \underbrace{-\sum_j\hbar \kg_j\hat{a}_j e^{-i(\knu_j - \komega){\kt}}}_{\kFR({\kt})}\underbrace{|2\rangle\langle 1|}_{\kShat^\dagger} - \sum_j\hbar \kg_j^*\hat{a}_j^\dagger e^{i(\knu_j - \komega){\kt}}|1\rangle\langle 2|, \tag{3.44}$$

and we incorporate these phase factors into the new reservoir operator $\kFR({\kt})$.

In addition to the specified form for the interaction given by Eq. (3.42), our analysis requires two assumptions regarding the nature of the reservoir itself, namely

(1) The reservoir is large (so it is not affected by the system)

(2) The reservoir has a broad bandwidth (so its correlation time is very short).

The first assumption indicates that the reservoir state is not significantly affected by its interaction with the system. Consequently for our analysis we may take the reservoir to be in a stationary (time-independent) state, for example a statistical mixture at some temperature T. The second assumption implies that the correlation time $\ktauc \sim (1/\text{bandwidth})$ for the reservoir is short; in particular, we require that $\ktauc$ be much smaller than the typical timescale $\ktauS$ on which the system evolves. These assumptions together constitute the “Born-Markov Approximation”, and a reservoir which satisfies them is called Markovian.

The effect of the reservoir on the system can be simplified by averaging over a timescale $\kDeltat$ which is in between the correlation time and characteristic system evolution time, $\ktauc \ll \kDeltat \ll \ktauS$. This approach is akin to perturbation theory in $\ktauc/\ktauS$, and will provide equations of motion for the system reduced density operator which are valid for times greater than $\kDeltat$.

To proceed we must now make yet another assumption: the initial state is factorizable,

$$\krhotilde({\kt}) = \krhotilde_S({\kt}) \otimes \krhotilde_R({\kt}). \tag{3.49}$$

For times shortly thereafter, ${\kt} < {\kt}' < {\kt} + \kDeltat$, the total density operator is approximately factorizable with some small correction,

$$\krhotilde({\kt}') \approx \krhotilde_S({\kt}) \otimes \krhotilde_R({\kt}) + \krhotilde_{corr}({\kt}, {\kt}'). \tag{3.50}$$

Provided that $\kDeltat \ll \ktauS$, we can neglect $\krhotilde_{corr}$ in the RHS of Eq. (3.48) to leading order, replacing the total density operator by the product of a system and reservoir density operator.

Using the explicit forms for $\kHtilde_{SR}({\kt})$ and $\krhotilde({\kt})$, we will now examine the two terms in Eq. (3.48). The first term, $\Delta\krhotilde_S^{(1)}$, has a straightforward effect on the system.

Since the reservoir is large and does not change much under the influence of the system, $\langle\kFR({\kt}')^\dagger\rangle$ is essentially a constant. The effect of the first term may thereby be interpreted an addition to the system Hamiltonian, $\kHS + \kHS'$. In many cases including the atom-field interaction, $\langle\kFR({\kt}')^\dagger\rangle = 0$, and the first term vanishes altogether.

The second term, $\Delta\krhotilde_S^{(2)}$, is responsible for the nontrivial effects of the reservoir.

We will evaluate it in terms of two-time correlation functions of the reservoir operators, defined by

$$g^{--}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')\kFR({\kt}'')\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')\krhotilde_R\kFR({\kt}')] \tag{3.58}$$
$$g^{+-}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')^\dagger\kFR({\kt}'')\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')\krhotilde_R\kFR({\kt}')^\dagger] \tag{3.59}$$
$$g^{-+}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')\kFR({\kt}'')^\dagger\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')^\dagger\krhotilde_R\kFR({\kt}')] \tag{3.60}$$
$$g^{++}({\kt}', {\kt}'') = \mathrm{Tr}_R[\kFR({\kt}')^\dagger\kFR({\kt}'')^\dagger\krhotilde_R] = \mathrm{Tr}_R[\kFR({\kt}'')^\dagger\krhotilde_R\kFR({\kt}')^\dagger], \tag{3.61}$$

where the second line when we cyclically permute reservoir operators.

As an example, we can explicitly evaluate one of these correlators for an environment formed by the radiation field.

The two time correlation function now depends only on the difference in time, ${\kt}'' - {\kt}' = \tau$, and it is a sharply peaked function of $\tau$ whose width corresponds to the reservoir correlation time $\ktauc$. In the limit that the radiation field volume $\kV \to \infty$, $\ktauc \to 0$, we recover the Wigner-Weisskopf approximation for which the correlator is a delta function in time. Note that for the radiation field, $g^{--} = g^{++} = 0$, and $g^{-+}$ is the same as $g^{+-}$ with $\langle\hat{a}_j^\dagger\hat{a}_j\rangle$ replaced by $\langle\hat{a}_j\hat{a}_j^\dagger\rangle = \langle\hat{a}_j^\dagger\hat{a}_j\rangle + 1$.

This result is known as the “master equation”, and it provides an essential tool for studying the evolution of open systems coupled to Markovian reservoirs. This formalism provides a method to properly treat non-unitary behavior in the system of interest. It can be seen, for example, that Eq. (3.78) preserves the trace of the density matrix ($\mathrm{Tr}\ \dot{\rho} = 0$). While Eq. (3.78) describes a two-level atom interacting with a thermal state of the electromagnetic field, we note that it is possible to derive master equations for other types of interactions as well, e.g., a harmonic oscillator interacting with an environment of other harmonic oscillators.
