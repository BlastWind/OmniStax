Many functions have the property that their graphs can be traced with a pencil without lifting the pencil from the page. Such functions are called continuous. Other functions have points at which a break in the graph occurs, but satisfy this property over intervals contained in their domains. They are continuous on these intervals and are said to have a discontinuity at a point where a break occurs.

We begin our investigation of continuity by exploring what it means for a function to have continuity at a point. Intuitively, a function is continuous at a particular point if there is no break in its graph at that point.

Continuity at a Point

Before we look at a formal definition of what it means for a function to be continuous at a point, let’s consider various functions that fail to meet our intuitive notion of what it means to be continuous at a point. We then create a list of conditions that prevent such failures.

Our first function of interest is shown in Figure 2.32. We see that the graph of $\kf(x)$ has a hole at a. In fact, $\kf(a)$ is undefined. At the very least, for $\kf(x)$ to be continuous at a, we need the following condition:

$$\text{i.}\;\kf(a)\;\text{is defined.}$$

However, as we see in Figure 2.33, this condition alone is insufficient to guarantee continuity at the point a. Although $\kf(a)$ is defined, the function has a gap at a. In this example, the gap exists because $\lim_{x\to a}\kf(x)$ does not exist. We must add another condition for continuity at a—namely,

$$\text{ii.}\;\lim_{x\to a}\kf(x)\;\text{exists.}$$

However, as we see in Figure 2.34, these two conditions by themselves do not guarantee continuity at a point. The function in this figure satisfies both of our first two conditions, but is still not continuous at a. We must add a third condition to our list:

$$\text{iii.}\;\lim_{x\to a}\kf(x)=\kf(a).$$

Now we put our list of conditions together and form a definition of continuity at a point.

Definition

A function $\kf(x)$ is continuous at a point a if and only if the following three conditions are satisfied:

  1. $\kf(a)$ is defined
  2. $\lim_{x\to a}\kf(x)$ exists
  3. $\lim_{x\to a}\kf(x)=\kf(a)$

A function is discontinuous at a point a if it fails to be continuous at a.

The following procedure can be used to analyze the continuity of a function at a point using this definition.

Problem-Solving Strategy

Determining Continuity at a Point

  1. Check to see if $\kf(a)$ is defined. If $\kf(a)$ is undefined, we need go no further. The function is not continuous at a. If $\kf(a)$ is defined, continue to step 2.
  2. Compute $\lim_{x\to a}\kf(x).$ In some cases, we may need to do this by first computing $\lim_{x\to a^{-}}\kf(x)$ and $\lim_{x\to a^{+}}\kf(x).$ If $\lim_{x\to a}\kf(x)$ does not exist (that is, it is not a real number), then the function is not continuous at a and the problem is solved. If $\lim_{x\to a}\kf(x)$ exists, then continue to step 3.
  3. Compare $\kf(a)$ and $\lim_{x\to a}\kf(x).$ If $\lim_{x\to a}\kf(x)\ne\kf(a),$ then the function is not continuous at a. If $\lim_{x\to a}\kf(x)=\kf(a),$ then the function is continuous at a.

The next three examples demonstrate how to apply this definition to determine whether a function is continuous at a given point. These examples illustrate situations in which each of the conditions for continuity in the definition succeed or fail.

Example 2.26 · Determining Continuity at a Point, Condition 1

Using the definition, determine whether the function $\kf(x)=(x^{2}-4)/(x-2)$ is continuous at $x=2.$ Justify the conclusion.

Solution

Let’s begin by trying to calculate $\kf(2).$ We can see that $\kf(2)=0/0,$ which is undefined. Therefore, $\kf(x)=\dfrac{x^{2}-4}{x-2}$ is discontinuous at 2 because $\kf(2)$ is undefined. The graph of $\kf(x)$ is shown in Figure 2.35.

Example 2.27 · Determining Continuity at a Point, Condition 2

Using the definition, determine whether the function $\kf(x)=\begin{cases}-x^{2}+4 & \text{if}\;x\le 3\\ 4x-8 & \text{if}\;x\gt 3\end{cases}$ is continuous at $x=3.$ Justify the conclusion.

Solution

Let’s begin by trying to calculate $\kf(3).$

$$\kf(3)=-(3^{2})+4=-5.$$

Thus, $\kf(3)$ is defined. Next, we calculate $\lim_{x\to 3}\kf(x).$ To do this, we must compute $\lim_{x\to 3^{-}}\kf(x)$ and $\lim_{x\to 3^{+}}\kf(x)\text{:}$

$$\lim_{x\to 3^{-}}\kf(x)=-(3^{2})+4=-5$$

and

$$\lim_{x\to 3^{+}}\kf(x)=4(3)-8=4.$$

Therefore, $\lim_{x\to 3}\kf(x)$ does not exist. Thus, $\kf(x)$ is not continuous at 3. The graph of $\kf(x)$ is shown in Figure 2.36.

Example 2.28 · Determining Continuity at a Point, Condition 3

Using the definition, determine whether the function $\kf(x)=\begin{cases}\dfrac{\sin x}{x} & \text{if}\;x\ne 0\\ 1 & \text{if}\;x=0\end{cases}$ is continuous at $x=0.$

Solution

First, observe that

$$\kf(0)=1.$$

Next,

$$\lim_{x\to 0}\kf(x)=\lim_{x\to 0}\frac{\sin x}{x}=1.$$

Last, compare $\kf(0)$ and $\lim_{x\to 0}\kf(x).$ We see that

$$\kf(0)=1=\lim_{x\to 0}\kf(x).$$

Since all three of the conditions in the definition of continuity are satisfied, $\kf(x)$ is continuous at $x=0.$

By applying the definition of continuity and previously established theorems concerning the evaluation of limits, we can state the following theorem.

Theorem

Continuity of Polynomials and Rational Functions

Polynomials and rational functions are continuous at every point in their domains.

Proof

Previously, we showed that if $p(x)$ and $q(x)$ are polynomials, $\lim_{x\to a}p(x)=p(a)$ for every polynomial $p(x)$ and $\lim_{x\to a}\dfrac{p(x)}{q(x)}=\dfrac{p(a)}{q(a)}$ as long as $q(a)\ne 0.$ Therefore, polynomials and rational functions are continuous on their domains.

□

We now apply Continuity of Polynomials and Rational Functions to determine the points at which a given rational function is continuous.

Example 2.29 · Continuity of a Rational Function

For what values of x is $\kf(x)=\dfrac{x+1}{x-5}$ continuous?

Solution

The rational function $\kf(x)=\dfrac{x+1}{x-5}$ is continuous for every value of x except $x=5.$

Types of Discontinuities

As we have seen in Example 2.26 and Example 2.27, discontinuities take on several different appearances. We classify the types of discontinuities we have seen thus far as removable discontinuities, infinite discontinuities, or jump discontinuities. Intuitively, a removable discontinuity is a discontinuity for which there is a hole in the graph, a jump discontinuity is a noninfinite discontinuity for which the sections of the function do not meet up, and an infinite discontinuity is a discontinuity located at a vertical asymptote. Figure 2.37 illustrates the differences in these types of discontinuities. Although these terms provide a handy way of describing three common types of discontinuities, keep in mind that not all discontinuities fit neatly into these categories.

These three discontinuities are formally defined as follows:

Definition

If $\kf(x)$ is discontinuous at a, then

  1. $\kf$ has a removable discontinuity at a if $\lim_{x\to a}\kf(x)$ exists. (Note: When we state that $\lim_{x\to a}\kf(x)$ exists, we mean that $\lim_{x\to a}\kf(x)=\kL,$ where $\kL$ is a real number.)
  2. $\kf$ has a jump discontinuity at a if $\lim_{x\to a^{-}}\kf(x)$ and $\lim_{x\to a^{+}}\kf(x)$ both exist, but $\lim_{x\to a^{-}}\kf(x)\ne\lim_{x\to a^{+}}\kf(x).$ (Note: When we state that $\lim_{x\to a^{-}}\kf(x)$ and $\lim_{x\to a^{+}}\kf(x)$ both exist, we mean that both are real-valued and that neither take on the values $\pm\infty.$)
  3. $\kf$ has an infinite discontinuity at a if $\lim_{x\to a^{-}}\kf(x)=\pm\infty$ and/or $\lim_{x\to a^{+}}\kf(x)=\pm\infty.$

Example 2.30 · Classifying a Discontinuity

In Example 2.26, we showed that $\kf(x)=\dfrac{x^{2}-4}{x-2}$ is discontinuous at $x=2.$ Classify this discontinuity as removable, jump, or infinite.

Solution

To classify the discontinuity at 2 we must evaluate $\lim_{x\to 2}\kf(x)\text{:}$

$$\begin{aligned}\lim_{x\to 2}\kf(x)&=\lim_{x\to 2}\frac{x^{2}-4}{x-2}\\&=\lim_{x\to 2}\frac{(x-2)(x+2)}{x-2}\\&=\lim_{x\to 2}(x+2)\\&=4.\end{aligned}$$

Since $\kf$ is discontinuous at 2 and $\lim_{x\to 2}\kf(x)$ exists, $\kf$ has a removable discontinuity at $x=2.$

Example 2.31 · Classifying a Discontinuity

In Example 2.27, we showed that $\kf(x)=\begin{cases}-x^{2}+4 & \text{if}\;x\le 3\\ 4x-8 & \text{if}\;x\gt 3\end{cases}$ is discontinuous at $x=3.$ Classify this discontinuity as removable, jump, or infinite.

Solution

Earlier, we showed that $\kf$ is discontinuous at 3 because $\lim_{x\to 3}\kf(x)$ does not exist. However, since $\lim_{x\to 3^{-}}\kf(x)=-5$ and $\lim_{x\to 3^{+}}\kf(x)=4$ both exist, we conclude that the function has a jump discontinuity at 3.

Example 2.32 · Classifying a Discontinuity

Determine whether $\kf(x)=\dfrac{x+2}{x+1}$ is continuous at −1. If the function is discontinuous at −1, classify the discontinuity as removable, jump, or infinite.

Solution

The function value $\kf(-1)$ is undefined. Therefore, the function is not continuous at −1. To determine the type of discontinuity, we must determine the limit at −1. We see that $\lim_{x\to -1^{-}}\dfrac{x+2}{x+1}=-\infty$ and $\lim_{x\to -1^{+}}\dfrac{x+2}{x+1}=+\infty.$ Therefore, the function has an infinite discontinuity at −1.

Continuity over an Interval

Now that we have explored the concept of continuity at a point, we extend that idea to continuity over an interval. As we develop this idea for different types of intervals, it may be useful to keep in mind the intuitive idea that a function is continuous over an interval if we can use a pencil to trace the function between any two points in the interval without lifting the pencil from the paper. In preparation for defining continuity on an interval, we begin by looking at the definition of what it means for a function to be continuous from the right at a point and continuous from the left at a point.

Continuity from the Right and from the Left

A function $\kf(x)$ is said to be continuous from the right at a if $\lim_{x\to a^{+}}\kf(x)=\kf(a).$

A function $\kf(x)$ is said to be continuous from the left at a if $\lim_{x\to a^{-}}\kf(x)=\kf(a).$

A function is continuous over an open interval if it is continuous at every point in the interval. A function $\kf(x)$ is continuous over a closed interval of the form $[a,b]$ if it is continuous at every point in $(a,b)$ and is continuous from the right at a and is continuous from the left at b. Analogously, a function $\kf(x)$ is continuous over an interval of the form $(a,b]$ if it is continuous over $(a,b)$ and is continuous from the left at b. Continuity over other types of intervals are defined in a similar fashion.

Requiring that $\lim_{x\to a^{+}}\kf(x)=\kf(a)$ and $\lim_{x\to b^{-}}\kf(x)=\kf(b)$ ensures that we can trace the graph of the function from the point $(a,\kf(a))$ to the point $(b,\kf(b))$ without lifting the pencil. If, for example, $\lim_{x\to a^{+}}\kf(x)\ne\kf(a),$ we would need to lift our pencil to jump from $\kf(a)$ to the graph of the rest of the function over $(a,b]$.

Example 2.33 · Continuity on an Interval

State the interval(s) over which the function $\kf(x)=\dfrac{x-1}{x^{2}+2x}$ is continuous.

Solution

Since $\kf(x)=\dfrac{x-1}{x^{2}+2x}$ is a rational function, it is continuous at every point in its domain. The domain of $\kf(x)$ is the set $(-\infty,-2)\cup(-2,0)\cup(0,+\infty)$. Thus, $\kf(x)$ is continuous over each of the intervals $(-\infty,-2),(-2,0),$ and $(0,+\infty)$.

Example 2.34 · Continuity over an Interval

State the interval(s) over which the function $\kf(x)=\sqrt{4-x^{2}}$ is continuous.

Solution

From the limit laws, we know that $\lim_{x\to a}\sqrt{4-x^{2}}=\sqrt{4-a^{2}}$ for all values of a in $(-2,2)$. We also know that $\lim_{x\to -2^{+}}\sqrt{4-x^{2}}=0$ exists and $\lim_{x\to 2^{-}}\sqrt{4-x^{2}}=0$ exists. Therefore, $\kf(x)$ is continuous over the interval $[-2,2]$.

The Composite Function Theorem allows us to expand our ability to compute limits. In particular, this theorem ultimately allows us to demonstrate that trigonometric functions are continuous over their domains.

Theorem

Composite Function Theorem

If $\kf(x)$ is continuous at $\kL$ and $\lim_{x\to a}\kg(x)=\kL,$ then

$$\lim_{x\to a}\kf(\kg(x))=\kf\left(\lim_{x\to a}\kg(x)\right)=\kf(\kL).$$

Before we move on to Example 2.35, recall that earlier, in the section on limit laws, we showed $\lim_{x\to 0}\cos x=1=\cos(0).$ Consequently, we know that $\kf(x)=\cos x$ is continuous at 0. In Example 2.35 we see how to combine this result with the composite function theorem.

Example 2.35 · Limit of a Composite Cosine Function

Evaluate $\lim_{x\to\pi/2}\cos\left(x-\dfrac{\pi}{2}\right).$

Solution

The given function is a composite of $\cos x$ and $x-\dfrac{\pi}{2}.$ Since $\lim_{x\to\pi/2}\left(x-\dfrac{\pi}{2}\right)=0$ and $\cos x$ is continuous at 0, we may apply the composite function theorem. Thus,

$$\lim_{x\to\pi/2}\cos\left(x-\frac{\pi}{2}\right)=\cos\left(\lim_{x\to\pi/2}\left(x-\frac{\pi}{2}\right)\right)=\cos(0)=1.$$

The proof of the next theorem uses the composite function theorem as well as the continuity of $\kf(x)=\sin x$ and $\kg(x)=\cos x$ at the point 0 to show that trigonometric functions are continuous over their entire domains.

Theorem

Continuity of Trigonometric Functions

Trigonometric functions are continuous over their entire domains.

Proof

We begin by demonstrating that $\cos x$ is continuous at every real number. To do this, we must show that $\lim_{x\to a}\cos x=\cos a$ for all values of a.

$$\begin{array}{lllll}\lim_{x\to a}\cos x&=\lim_{x\to a}\cos((x-a)+a)&&&\text{rewrite}\;x=x-a+a\\&=\lim_{x\to a}(\cos(x-a)\cos a-\sin(x-a)\sin a)&&&\text{apply the identity for the cosine of the sum of two angles}\\&=\cos\left(\lim_{x\to a}(x-a)\right)\cos a-\sin\left(\lim_{x\to a}(x-a)\right)\sin a&&&\lim_{x\to a}(x-a)=0,\;\text{and}\;\sin x\;\text{and}\;\cos x\;\text{are continuous at 0}\\&=\cos(0)\cos a-\sin(0)\sin a&&&\text{evaluate cos(0) and sin(0) and simplify}\\&=1\cdot\cos a-0\cdot\sin a=\cos a.\end{array}$$

The proof that $\sin x$ is continuous at every real number is analogous. Because the remaining trigonometric functions may be expressed in terms of $\sin x$ and $\cos x,$ their continuity follows from the quotient limit law.

□

As you can see, the composite function theorem is invaluable in demonstrating the continuity of trigonometric functions. As we continue our study of calculus, we revisit this theorem many times.

The Intermediate Value Theorem

Functions that are continuous over intervals of the form $[a,b],$ where a and b are real numbers, exhibit many useful properties. Throughout our study of calculus, we will encounter many powerful theorems concerning such functions. The first of these theorems is the Intermediate Value Theorem.

Theorem

The Intermediate Value Theorem

Let $\kf$ be continuous over a closed, bounded interval $[a,b].$ If $z$ is any real number between $\kf(a)$ and $\kf(b),$ then there is a number $c$ in $[a,b]$ satisfying $\kf(c)=z$ in Figure 2.38.

Example 2.36 · Application of the Intermediate Value Theorem

Show that $\kf(x)=x-\cos x$ has at least one zero.

Solution

Since $\kf(x)=x-\cos x$ is continuous over $(-\infty,+\infty),$ it is continuous over any closed interval of the form $[a,b].$ If you can find an interval $[a,b]$ such that $\kf(a)$ and $\kf(b)$ have opposite signs, you can use the Intermediate Value Theorem to conclude there must be a real number $c$ in $(a,b)$ that satisfies $\kf(c)=0.$ Note that

$$\kf(0)=0-\cos(0)=-1\lt 0$$

and

$$\kf\left(\frac{\pi}{2}\right)=\frac{\pi}{2}-\cos\frac{\pi}{2}=\frac{\pi}{2}\gt 0.$$

Using the Intermediate Value Theorem, we can see that there must be a real number $c$ in $[0,\pi/2]$ that satisfies $\kf(c)=0.$ Therefore, $\kf(x)=x-\cos x$ has at least one zero.

Example 2.37 · When Can You Apply the Intermediate Value Theorem?

If $\kf(x)$ is continuous over $[0,2],$ $\kf(0)\gt 0$ and $\kf(2)\gt 0,$ can we use the Intermediate Value Theorem to conclude that $\kf(x)$ has no zeros in the interval $[0,2]$? Explain.

Solution

No. The Intermediate Value Theorem only allows us to conclude that we can find a value between $\kf(0)$ and $\kf(2);$ it doesn’t allow us to conclude that we can’t find other values. To see this more clearly, consider the function $\kf(x)=(x-1)^{2}.$ It satisfies $\kf(0)=1\gt 0,\ \kf(2)=1\gt 0,$ and $\kf(1)=0.$

Example 2.38 · When Can You Apply the Intermediate Value Theorem?

For $\kf(x)=1/x,$ $\kf(-1)=-1\lt 0$ and $\kf(1)=1\gt 0.$ Can we conclude that $\kf(x)$ has a zero in the interval $[-1,1]$?

Solution

No. The function is not continuous over $[-1,1].$ The Intermediate Value Theorem does not apply here.
