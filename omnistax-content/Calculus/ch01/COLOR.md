# Chapter 1 colour plan

Prepared 2026-10-12 with `config.md`. It refines the book's `COLOR.md` for what this chapter draws; root rules 7 and 22 hold, and nothing here invents a hue.

## What the chapter colours

`function` is the chapter's category (config 21): every function symbol the text names (f, g, s(t), f⁻¹), every named class of function (a linear, polynomial, rational, trigonometric, exponential, logarithmic, hyperbolic function and their inverses) where a mention names it, and every curve that is the graph of one. Two others appear a few times: `derivative` for the slope m of a line (1.2) and the tangent line to eˣ at 0 (1.5, Figure 1.45); `limit` for the value a function approaches at infinity and its horizontal asymptote (1.2, "Behavior at Infinity"). No fact and no convention: the opener and the two photographs keep their own colours.

## Rules the sections keep

- In ink: the variables x, y, t, θ; the points and numbers a, b, c, h, the coordinates; the degree n and the coefficients aₙ, …, a₀; the parameters A, B, C, α of a transformed sine; the constants e and π; the domain D and range R, which are sets; a zero, an intercept and an interval.
- A relation that is not a function (the sideways curve of Figure 1.8(b)) is drawn in ink: it is not a value of the category.
- A referent's curve wears its referent colour, a single curve its category's; f⁻¹ beside f is a referent of the graph, not a variant.
- A function written only as a value ("f(5) = 16") is ink; the function symbol in it wears `function`.
