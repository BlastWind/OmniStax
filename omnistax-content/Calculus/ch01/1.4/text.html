An inverse function reverses the operation done by a particular function. In other words, whatever a function does, the inverse function undoes it. In this section, we define an inverse function formally and state the necessary conditions for an inverse function to exist. We examine how to find an inverse function and study the relationship between the graph of a function and the graph of its inverse. Then we apply these ideas to define and discuss properties of the inverse trigonometric functions.

Existence of an Inverse Function

We begin with an example. Given a function $\kf$ and an output $y=\kf(x),$ we are often interested in finding what value or values $x$ were mapped to $y$ by $\kf.$ For example, consider the function $\kf(x)=x^{3}+4.$ Since any output $y=x^{3}+4,$ we can solve this equation for $x$ to find that the input is $x=\sqrt[3]{y-4}.$ This equation defines $x$ as a function of $y.$ Denoting this function as $\kfinv,$ and writing $x=\kfinv(y)=\sqrt[3]{y-4},$ we see that for any $x$ in the domain of $\kf,\ \kfinv(\kf(x))=\kfinv(x^{3}+4)=x.$ Thus, this new function, $\kfinv,$ “undid” what the original function $\kf$ did. A function with this property is called the inverse function of the original function.

Definition

Given a function $\kf$ with domain $\kD$ and range $\kR,$ its inverse function (if it exists) is the function $\kfinv$ with domain $\kR$ and range $\kD$ such that $\kfinv(y)=x$ if $\kf(x)=y.$ In other words, for a function $\kf$ and its inverse $\kfinv,$

$$\kfinv(\kf(x))=x\;\text{for all}\;x\;\text{in}\;\kD,\;\text{and}\;\kf(\kfinv(y))=y\;\text{for all}\;y\;\text{in}\;\kR.\tag{1.11}$$

Note that $\kfinv$ is read as “f inverse.” Here, the $-1$ is not used as an exponent and $\kfinv(x)\ne 1/\kf(x).$ Figure 1.37 shows the relationship between the domain and range of $\kf$ and the domain and range of $\kfinv.$

Recall that a function has exactly one output for each input. Therefore, to define an inverse function, we need to map each input to exactly one output. For example, let’s try to find the inverse function for $\kf(x)=x^{2}.$ Solving the equation $y=x^{2}$ for $x,$ we arrive at the equation $x=\pm\sqrt{y}.$ This equation does not describe $x$ as a function of $y$ because there are two solutions to this equation for every $y\gt 0.$ The problem with trying to find an inverse function for $\kf(x)=x^{2}$ is that two inputs are sent to the same output for each output $y\gt 0.$ The function $\kf(x)=x^{3}+4$ discussed earlier did not have this problem. For that function, each input was sent to a different output. A function that sends each input to a different output is called a one-to-one function.

Definition

We say a $\kf$ is a one-to-one function if $\kf(x_{1})\ne \kf(x_{2})$ when $x_{1}\ne x_{2}.$

One way to determine whether a function is one-to-one is by looking at its graph. If a function is one-to-one, then no two inputs can be sent to the same output. Therefore, if we draw a horizontal line anywhere in the $xy$-plane, according to the horizontal line test, it cannot intersect the graph more than once. We note that the horizontal line test is different from the vertical line test. The vertical line test determines whether a graph is the graph of a function. The horizontal line test determines whether a function is one-to-one (Figure 1.38).

Rule

Horizontal Line Test

A function $\kf$ is one-to-one if and only if every horizontal line intersects the graph of $\kf$ no more than once.

Finding a Function’s Inverse

We can now consider one-to-one functions and show how to find their inverses. Recall that a function maps elements in the domain of $\kf$ to elements in the range of $\kf.$ The inverse function maps each element from the range of $\kf$ back to its corresponding element from the domain of $\kf.$ Therefore, to find the inverse function of a one-to-one function $\kf,$ given any $y$ in the range of $\kf,$ we need to determine which $x$ in the domain of $\kf$ satisfies $\kf(x)=y.$ Since $\kf$ is one-to-one, there is exactly one such value $x.$ We can find that value $x$ by solving the equation $\kf(x)=y$ for $x.$ Doing so, we are able to write $x$ as a function of $y$ where the domain of this function is the range of $\kf$ and the range of this new function is the domain of $\kf.$ Consequently, this function is the inverse of $\kf,$ and we write $x=\kfinv(y).$ Since we typically use the variable $x$ to denote the independent variable and $y$ to denote the dependent variable, we often interchange the roles of $x$ and $y,$ and write $y=\kfinv(x).$ Representing the inverse function in this way is also helpful later when we graph a function $\kf$ and its inverse $\kfinv$ on the same axes.

Problem-Solving Strategy

Finding an Inverse Function

  1. Solve the equation $y=\kf(x)$ for $x.$
  2. Interchange the variables $x$ and $y$ and write $y=\kfinv(x).$

Example 1.29 · Finding an Inverse Function

Find the inverse for the function $\kf(x)=3x-4.$ State the domain and range of the inverse function. Verify that $\kfinv(\kf(x))=x.$

Solution

Follow the steps outlined in the strategy.

Step 1. If $y=3x-4,$ then $3x=y+4$ and $x=\frac{1}{3}y+\frac{4}{3}.$

Step 2. Rewrite as $y=\frac{1}{3}x+\frac{4}{3}$ and let $y=\kfinv(x).$

Therefore, $\kfinv(x)=\frac{1}{3}x+\frac{4}{3}.$

Since the domain of $\kf$ is $(-\infty,\infty)$, the range of $\kfinv$ is $(-\infty,\infty)$. Since the range of $\kf$ is $(-\infty,\infty)$, the domain of $\kfinv$ is $(-\infty,\infty)$.

You can verify that $\kfinv(\kf(x))=x$ by writing

$$\kfinv(\kf(x))=\kfinv(3x-4)=\frac{1}{3}(3x-4)+\frac{4}{3}=x-\frac{4}{3}+\frac{4}{3}=x.$$

Note that for $\kfinv(x)$ to be the inverse of $\kf(x),$ both $\kfinv(\kf(x))=x$ and $\kf(\kfinv(x))=x$ for all x in the domain of the inside function.

Restricting Domains

As we have seen, $\kf(x)=x^{2}$ does not have an inverse function because it is not one-to-one. However, we can choose a subset of the domain of $\kf$ such that the function is one-to-one. This subset is called a restricted domain. By restricting the domain of $\kf,$ we can define a new function $\kg$ such that the domain of $\kg$ is the restricted domain of $\kf$ and $\kg(x)=\kf(x)$ for all $x$ in the domain of $\kg.$ Then we can define an inverse function for $\kg$ on that domain. For example, since $\kf(x)=x^{2}$ is one-to-one on the interval $[0,\infty)$, we can define a new function $\kg$ such that the domain of $\kg$ is $[0,\infty)$ and $\kg(x)=x^{2}$ for all $x$ in its domain. Since $\kg$ is a one-to-one function, it has an inverse function, given by the formula $\kg^{-1}(x)=\sqrt{x}.$ On the other hand, the function $\kf(x)=x^{2}$ is also one-to-one on the domain $(-\infty,0]$. Therefore, we could also define a new function $\kh$ such that the domain of $\kh$ is $(-\infty,0]$ and $\kh(x)=x^{2}$ for all $x$ in the domain of $\kh.$ Then $\kh$ is a one-to-one function and must also have an inverse. Its inverse is given by the formula $\kh^{-1}(x)=-\sqrt{x}$ (Figure 1.40).

Example 1.31 · Restricting the Domain

Consider the function $\kf(x)=(x+1)^{2}.$

  1. Sketch the graph of $\kf$ and use the horizontal line test to show that $\kf$ is not one-to-one.
  2. Show that $\kf$ is one-to-one on the restricted domain $[-1,\infty)$. Determine the domain and range for the inverse of $\kf$ on this restricted domain and find a formula for $\kfinv.$

Solution

  1. The graph of $\kf$ is the graph of $y=x^{2}$ shifted left $1$ unit. Since there exists a horizontal line intersecting the graph more than once, $\kf$ is not one-to-one.
  2. On the interval $[-1,\infty)$, $\kf$ is one-to-one.

    The domain and range of $\kfinv$ are given by the range and domain of $\kf,$ respectively. Therefore, the domain of $\kfinv$ is $[0,\infty)$ and the range of $\kfinv$ is $[-1,\infty)$. To find a formula for $\kfinv,$ solve the equation $y=(x+1)^{2}$ for $x.$ If $y=(x+1)^{2},$ then $x=-1\pm\sqrt{y}.$ Since we are restricting the domain to the interval where $x\ge -1,$ we need $\pm\sqrt{y}\ge 0.$ Therefore, $x=-1+\sqrt{y}.$ Interchanging $x$ and $y,$ we write $y=-1+\sqrt{x}$ and conclude that $\kfinv(x)=-1+\sqrt{x}.$

Inverse Trigonometric Functions

The six basic trigonometric functions are periodic, and therefore they are not one-to-one. However, if we restrict the domain of a trigonometric function to an interval where it is one-to-one, we can define its inverse. Consider the sine function (Figure 1.34). The sine function is one-to-one on an infinite number of intervals, but the standard convention is to restrict the domain to the interval $[-\frac{\pi}{2},\frac{\pi}{2}]$. By doing so, we define the inverse sine function on the domain $[-1,1]$ such that for any $x$ in the interval $[-1,1]$, the inverse sine function tells us which angle $\ktheta$ in the interval $[-\frac{\pi}{2},\frac{\pi}{2}]$ satisfies $\sin\ktheta=x.$ Similarly, we can restrict the domains of the other trigonometric functions to define inverse trigonometric functions, which are functions that tell us which angle in a certain interval has a specified trigonometric value.

Definition

The inverse sine function, denoted $\sin^{-1}$ or arcsin, and the inverse cosine function, denoted $\cos^{-1}$ or arccos, are defined on the domain $\kD=\{x\mid -1\le x\le 1\}$ as follows:

$$\begin{array}{l}\sin^{-1}(x)=y\;\text{if and only if}\;\sin(y)=x\;\text{and}\;-\frac{\pi}{2}\le y\le \frac{\pi}{2};\\ \cos^{-1}(x)=y\;\text{if and only if}\;\cos(y)=x\;\text{and}\;0\le y\le \pi.\end{array}\tag{1.12}$$

The inverse tangent function, denoted $\tan^{-1}$ or arctan, and inverse cotangent function, denoted $\cot^{-1}$ or arccot, are defined on the domain $\kD=\{x\mid -\infty\lt x\lt \infty\}$ as follows:

$$\begin{array}{l}\tan^{-1}(x)=y\;\text{if and only if}\;\tan(y)=x\;\text{and}\;-\frac{\pi}{2}\lt y\lt \frac{\pi}{2};\\ \cot^{-1}(x)=y\;\text{if and only if}\;\cot(y)=x\;\text{and}\;0\lt y\lt \pi.\end{array}\tag{1.13}$$

The inverse cosecant function, denoted $\csc^{-1}$ or arccsc, and inverse secant function, denoted $\sec^{-1}$ or arcsec, are defined on the domain $\kD=\{x\mid |x|\ge 1\}$ as follows:

$$\begin{array}{l}\csc^{-1}(x)=y\;\text{if and only if}\;\csc(y)=x\;\text{and}\;-\frac{\pi}{2}\le y\le \frac{\pi}{2},\ y\ne 0;\\ \sec^{-1}(x)=y\;\text{if and only if}\;\sec(y)=x\;\text{and}\;0\le y\le \pi,\ y\ne \pi/2.\end{array}\tag{1.14}$$

To graph the inverse trigonometric functions, we use the graphs of the trigonometric functions restricted to the domains defined earlier and reflect the graphs about the line $y=x$ (Figure 1.41).

When evaluating an inverse trigonometric function, the output is an angle. For example, to evaluate $\cos^{-1}\left(\frac{1}{2}\right),$ we need to find an angle $\ktheta$ such that $\cos\ktheta=\frac{1}{2}.$ Clearly, many angles have this property. However, given the definition of $\cos^{-1},$ we need the angle $\ktheta$ that not only solves this equation, but also lies in the interval $[0,\pi]$. We conclude that $\cos^{-1}\left(\frac{1}{2}\right)=\frac{\pi}{3}.$

We now consider a composition of a trigonometric function and its inverse. For example, consider the two expressions $\sin\left(\sin^{-1}\left(\frac{\sqrt{2}}{2}\right)\right)$ and $\sin^{-1}(\sin(\pi)).$ For the first one, we simplify as follows:

$$\sin\left(\sin^{-1}\left(\frac{\sqrt{2}}{2}\right)\right)=\sin\left(\frac{\pi}{4}\right)=\frac{\sqrt{2}}{2}.$$

For the second one, we have

$$\sin^{-1}(\sin(\pi))=\sin^{-1}(0)=0.$$

The inverse function is supposed to “undo” the original function, so why isn’t $\sin^{-1}(\sin(\pi))=\pi?$ Recalling our definition of inverse functions, a function $\kf$ and its inverse $\kfinv$ satisfy the conditions $\kf(\kfinv(y))=y$ for all $y$ in the domain of $\kfinv$ and $\kfinv(\kf(x))=x$ for all $x$ in the domain of $\kf,$ so what happened here? The issue is that the inverse sine function, $\sin^{-1},$ is the inverse of the restricted sine function defined on the domain $[-\frac{\pi}{2},\frac{\pi}{2}]$. Therefore, for $x$ in the interval $[-\frac{\pi}{2},\frac{\pi}{2}]$, it is true that $\sin^{-1}(\sin x)=x.$ However, for values of $x$ outside this interval, the equation does not hold, even though $\sin^{-1}(\sin x)$ is defined for all real numbers $x.$

What about $\sin(\sin^{-1}y)?$ Does that have a similar issue? The answer is no. Since the domain of $\sin^{-1}$ is the interval $[-1,1]$, we conclude that $\sin(\sin^{-1}y)=y$ if $-1\le y\le 1$ and the expression is not defined for other values of $y.$ To summarize,

$$\sin(\sin^{-1}y)=y\;\text{if}\;-1\le y\le 1$$

and

$$\sin^{-1}(\sin x)=x\;\text{if}\;-\frac{\pi}{2}\le x\le \frac{\pi}{2}.$$

Similarly, for the cosine function,

$$\cos(\cos^{-1}y)=y\;\text{if}\;-1\le y\le 1$$

and

$$\cos^{-1}(\cos x)=x\;\text{if}\;0\le x\le \pi.$$

Similar properties hold for the other trigonometric functions and their inverses.

Example 1.32 · Evaluating Expressions Involving Inverse Trigonometric Functions

Evaluate each of the following expressions.

  1. $\sin^{-1}\left(-\frac{\sqrt{3}}{2}\right)$
  2. $\tan\left(\tan^{-1}\left(-\frac{1}{\sqrt{3}}\right)\right)$
  3. $\cos^{-1}\left(\cos\left(\frac{5\pi}{4}\right)\right)$
  4. $\sin^{-1}\left(\cos\left(\frac{2\pi}{3}\right)\right)$

Solution

  1. Evaluating $\sin^{-1}(-\sqrt{3}/2)$ is equivalent to finding the angle $\ktheta$ such that $\sin\ktheta=-\sqrt{3}/2$ and $-\pi/2\le\ktheta\le\pi/2.$ The angle $\ktheta=-\pi/3$ satisfies these two conditions. Therefore, $\sin^{-1}(-\sqrt{3}/2)=-\pi/3.$
  2. First we use the fact that $\tan^{-1}(-1/\sqrt{3})=-\pi/6.$ Then $\tan(-\pi/6)=-1/\sqrt{3}.$ Therefore, $\tan(\tan^{-1}(-1/\sqrt{3}))=-1/\sqrt{3}.$
  3. To evaluate $\cos^{-1}(\cos(5\pi/4)),$ first use the fact that $\cos(5\pi/4)=-\sqrt{2}/2.$ Then we need to find the angle $\ktheta$ such that $\cos(\ktheta)=-\sqrt{2}/2$ and $0\le\ktheta\le\pi.$ Since $3\pi/4$ satisfies both these conditions, we have $\cos^{-1}(\cos(5\pi/4))=\cos^{-1}(-\sqrt{2}/2)=3\pi/4.$
  4. Since $\cos(2\pi/3)=-1/2,$ we need to evaluate $\sin^{-1}(-1/2).$ That is, we need to find the angle $\ktheta$ such that $\sin(\ktheta)=-1/2$ and $-\pi/2\le\ktheta\le\pi/2.$ Since $-\pi/6$ satisfies both these conditions, we can conclude that $\sin^{-1}(\cos(2\pi/3))=\sin^{-1}(-1/2)=-\pi/6.$
