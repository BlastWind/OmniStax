We have shown how to use the first and second derivatives of a function to describe the shape of a graph. To graph a function $\kf$ defined on an unbounded domain, we also need to know the behavior of $\kf$ as $x\to \pm \infty.$ In this section, we define limits at infinity and show how these limits affect the graph of a function. At the end of this section, we outline a strategy for graphing an arbitrary function $\kf.$

Limits at Infinity

We begin by examining what it means for a function to have a finite limit at infinity. Then we study the idea of a function with an infinite limit at infinity. Back in Introduction to Functions and Graphs, we looked at vertical asymptotes; in this section we deal with horizontal and oblique asymptotes.

Limits at Infinity and Horizontal Asymptotes

Recall that $\lim_{x\to a}\kf(x)=\kL$ means $\kf(x)$ becomes arbitrarily close to $\kL$ as long as $x$ is sufficiently close to $a.$ We can extend this idea to limits at infinity. For example, consider the function $\kf(x)=2+\frac{1}{x}.$ As can be seen graphically in Figure 4.40 and numerically in Table 4.2, as the values of $x$ get larger, the values of $\kf(x)$ approach $2.$ We say the limit as $x$ approaches $\infty$ of $\kf(x)$ is $2$ and write $\lim_{x\to \infty}\kf(x)=2.$ Similarly, for $x\lt 0,$ as the values $|x|$ get larger, the values of $\kf(x)$ approaches $2.$ We say the limit as $x$ approaches $-\infty$ of $\kf(x)$ is $2$ and write $\lim_{x\to-\infty}\kf(x)=2.$

$2+\frac{1}{x}$$2.1$$2.01$$2.001$$2.0001$
$x$$-10$$-100$$-1000$$-10,000$
$2+\frac{1}{x}$$1.9$$1.99$$1.999$$1.9999$

More generally, for any function $\kf,$ we say the limit as $x\to \infty$ of $\kf(x)$ is $\kL$ if $\kf(x)$ becomes arbitrarily close to $\kL$ as long as $x$ is sufficiently large. In that case, we write $\lim_{x\to \infty}\kf(x)=\kL.$ Similarly, we say the limit as $x\to-\infty$ of $\kf(x)$ is $\kL$ if $\kf(x)$ becomes arbitrarily close to $\kL$ as long as $x\lt 0$ and $|x|$ is sufficiently large. In that case, we write $\lim_{x\to-\infty}\kf(x)=\kL.$ We now look at the definition of a function having a limit at infinity.

Definition

(Informal) If the values of $\kf(x)$ become arbitrarily close to $\kL$ as $x$ becomes sufficiently large, we say the function $\kf$ has a limit at infinity and write

$$\lim_{x\to \infty}\kf(x)=\kL.$$

If the values of $\kf(x)$ becomes arbitrarily close to $\kL$ for $x\lt 0$ as $|x|$ becomes sufficiently large, we say that the function $\kf$ has a limit at negative infinity and write

$$\lim_{x\to-\infty}\kf(x)=\kL.$$

If the values $\kf(x)$ are getting arbitrarily close to some finite value $\kL$ as $x\to \infty$ or $x\to-\infty,$ the graph of $\kf$ approaches the line $y=\kL.$ In that case, the line $y=\kL$ is a horizontal asymptote of $\kf$ (Figure 4.41). For example, for the function $\kf(x)=\frac{1}{x},$ since $\lim_{x\to \infty}\kf(x)=0,$ the line $y=0$ is a horizontal asymptote of $\kf(x)=\frac{1}{x}.$

Definition

If $\lim_{x\to \infty}\kf(x)=\kL$ or $\lim_{x\to-\infty}\kf(x)=\kL,$ we say the line $y=\kL$ is a horizontal asymptote of $\kf.$

A function cannot cross a vertical asymptote because the graph must approach infinity (or $-\infty)$ from at least one direction as $x$ approaches the vertical asymptote. However, a function may cross a horizontal asymptote. In fact, a function may cross a horizontal asymptote an unlimited number of times. For example, the function $\kf(x)=\frac{(\cos x)}{x}+1$ shown in Figure 4.42 intersects the horizontal asymptote $y=1$ an infinite number of times as it oscillates around the asymptote with ever-decreasing amplitude.

The algebraic limit laws and squeeze theorem we introduced in Introduction to Limits also apply to limits at infinity. We illustrate how to use these laws to compute several limits at infinity.

Example 4.21 · Computing Limits at Infinity

For each of the following functions $\kf,$ evaluate $\lim_{x\to \infty}\kf(x)$ and $\lim_{x\to-\infty}\kf(x).$ Determine the horizontal asymptote(s) for $\kf.$

a. $\kf(x)=5-\frac{2}{{x}^{2}}$

b. $\kf(x)=\frac{\sin x}{x}$

c. $\kf(x)={\tan}^{-1}(x)$

Solution

a. Using the algebraic limit laws, we have $\lim_{x\to \infty}(5-\frac{2}{{x}^{2}})=\lim_{x\to \infty}5-2(\lim_{x\to \infty}\frac{1}{x}).(\lim_{x\to \infty}\frac{1}{x})=5-2\cdot 0=5.$

Similarly, $\lim_{x\to-\infty}\kf(x)=5.$

Therefore, $\kf(x)=5-\frac{2}{{x}^{2}}$ has a horizontal asymptote of $y=5$ and $\kf$ approaches this horizontal asymptote as $x\to \pm \infty$ as shown in the following graph.

b. Since $-1\le \sin x\le 1$ for all $x,$ we have

$$\frac{-1}{x}\le \frac{\sin x}{x}\le \frac{1}{x}$$

for all $x\ne 0.$ Also, since

$$\lim_{x\to \infty}\frac{-1}{x}=0=\lim_{x\to \infty}\frac{1}{x},$$

we can apply the squeeze theorem to conclude that

$$\lim_{x\to \infty}\frac{\sin x}{x}=0.$$

Similarly,

$$\lim_{x\to-\infty}\frac{\sin x}{x}=0.$$

Thus, $\kf(x)=\frac{\sin x}{x}$ has a horizontal asymptote of $y=0$ and $\kf(x)$ approaches this horizontal asymptote as $x\to \pm \infty$ as shown in the following graph.

c. To evaluate $\lim_{x\to \infty}{\tan}^{-1}(x)$ and $\lim_{x\to-\infty}{\tan}^{-1}(x),$ we first consider the graph of $y=\tan (x)$ over the interval $(-\pi /2,\pi /2)$ as shown in the following graph.

Since

$$\lim_{x\to {(\pi /2)}^{-}}\tan x=\infty,$$

it follows that

$$\lim_{x\to \infty}{\tan}^{-1}(x)=\frac{\pi}{2}.$$

Similarly, since

$$\lim_{x\to {(-\pi /2)}^{+}}\tan x=-\infty,$$

it follows that

$$\lim_{x\to-\infty}{\tan}^{-1}(x)=-\frac{\pi}{2}.$$

As a result, $y=\frac{\pi}{2}$ and $y=-\frac{\pi}{2}$ are horizontal asymptotes of $\kf(x)={\tan}^{-1}(x)$ as shown in the following graph.

Infinite Limits at Infinity

Sometimes the values of a function $\kf$ become arbitrarily large as $x\to \infty$ (or as $x\to-\infty).$ In this case, we write $\lim_{x\to \infty}\kf(x)=\infty$ (or $\lim_{x\to-\infty}\kf(x)=\infty).$ On the other hand, if the values of $\kf$ are negative but become arbitrarily large in magnitude as $x\to \infty$ (or as $x\to-\infty),$ we write $\lim_{x\to \infty}\kf(x)=-\infty$ (or $\lim_{x\to-\infty}\kf(x)=-\infty).$

For example, consider the function $\kf(x)={x}^{3}.$ As seen in Table 4.3 and Figure 4.47, as $x\to \infty$ the values $\kf(x)$ become arbitrarily large. Therefore, $\lim_{x\to \infty}{x}^{3}=\infty.$ On the other hand, as $x\to-\infty,$ the values of $\kf(x)={x}^{3}$ are negative but become arbitrarily large in magnitude. Consequently, $\lim_{x\to-\infty}{x}^{3}=-\infty.$

${x}^{3}$$1000$$8000$$125,000$$1,000,000$$1,000,000,000$
$x$$-10$$-20$$-50$$-100$$-1000$
${x}^{3}$$-1000$$-8000$$-125,000$$-1,000,000$$-1,000,000,000$
Definition

(Informal) We say a function $\kf$ has an infinite limit at infinity and write

$$\lim_{x\to \infty}\kf(x)=\infty.$$

if $\kf(x)$ becomes arbitrarily large for $x$ sufficiently large. We say a function has a negative infinite limit at infinity and write

$$\lim_{x\to \infty}\kf(x)=-\infty.$$

if $\kf(x)\lt 0$ and $|\kf(x)|$ becomes arbitrarily large for $x$ sufficiently large. Similarly, we can define infinite limits as $x\to-\infty.$

Formal Definitions

Earlier, we used the terms arbitrarily close, arbitrarily large, and sufficiently large to define limits at infinity informally. Although these terms provide accurate descriptions of limits at infinity, they are not precise mathematically. Here are more formal definitions of limits at infinity. We then look at how to use these definitions to prove results involving limits at infinity.

Definition

(Formal) We say a function $\kf$ has a limit at infinity, if there exists a real number $\kL$ such that for all $\varepsilon \gt 0,$ there exists $N\gt 0$ such that

$$|\kf(x)-\kL|\lt \varepsilon$$

for all $x\gt N.$ In that case, we write

$$\lim_{x\to \infty}\kf(x)=\kL$$

(see Figure 4.48).

We say a function $\kf$ has a limit at negative infinity if there exists a real number $\kL$ such that for all $\varepsilon \gt 0,$ there exists $N\lt 0$ such that

$$|\kf(x)-\kL|\lt \varepsilon$$

for all $x\lt N.$ In that case, we write

$$\lim_{x\to-\infty}\kf(x)=\kL.$$

Earlier in this section, we used graphical evidence in Figure 4.40 and numerical evidence in Table 4.2 to conclude that $\lim_{x\to \infty}(2+\frac{1}{x})=2.$ Here we use the formal definition of limit at infinity to prove this result rigorously.

Example 4.22 · A Finite Limit at Infinity Example

Use the formal definition of limit at infinity to prove that $\lim_{x\to \infty}(2+\frac{1}{x})=2.$

Solution

Let $\varepsilon \gt 0.$ Let $N=\frac{1}{\varepsilon}.$ Therefore, for all $x\gt N,$ we have

$$|2+\frac{1}{x}-2|=|\frac{1}{x}|=\frac{1}{x}\lt \frac{1}{N}=\varepsilon \text{.}$$

We now turn our attention to a more precise definition for an infinite limit at infinity.

Definition

(Formal) We say a function $\kf$ has an infinite limit at infinity and write

$$\lim_{x\to \infty}\kf(x)=\infty$$

if for all $M\gt 0,$ there exists an $N\gt 0$ such that

$$\kf(x)\gt M$$

for all $x\gt N$ (see Figure 4.49).

We say a function has a negative infinite limit at infinity and write

$$\lim_{x\to \infty}\kf(x)=-\infty$$

if for all $M\lt 0,$ there exists an $N\gt 0$ such that

$$\kf(x)\lt M$$

for all $x\gt N.$

Similarly we can define limits as $x\to-\infty.$

Earlier, we used graphical evidence (Figure 4.47) and numerical evidence (Table 4.3) to conclude that $\lim_{x\to \infty}{x}^{3}=\infty.$ Here we use the formal definition of infinite limit at infinity to prove that result.

Example 4.23 · An Infinite Limit at Infinity

Use the formal definition of infinite limit at infinity to prove that $\lim_{x\to \infty}{x}^{3}=\infty.$

Solution

Let $M\gt 0.$ Let $N=\sqrt[3]{M}.$ Then, for all $x\gt N,$ we have

$${x}^{3}\gt {N}^{3}={(\sqrt[3]{M})}^{3}=M.$$

Therefore, $\lim_{x\to \infty}{x}^{3}=\infty.$

End Behavior

The behavior of a function as $x\to \pm \infty$ is called the function’s end behavior. At each of the function’s ends, the function could exhibit one of the following types of behavior:

  1. The function $\kf(x)$ approaches a horizontal asymptote $y=\kL.$
  2. The function $\kf(x)\to \infty$ or $\kf(x)\to-\infty.$
  3. The function does not approach a finite limit, nor does it approach $\infty$ or $-\infty.$ In this case, the function may have some oscillatory behavior.

Let’s consider several classes of functions here and look at the different types of end behaviors for these functions.

End Behavior for Polynomial Functions

Consider the power function $\kf(x)={x}^{n}$ where $n$ is a positive integer. From Figure 4.50 and Figure 4.51, we see that

$$\lim_{x\to \infty}{x}^{n}=\infty;n=1,2,3\text{,\ldots}$$

and

$$\lim_{x\to-\infty}{x}^{n}=\{\begin{array}{l}\infty;n=2,4,6\text{,\ldots} \\-\infty;n=1,3,5\text{,\ldots}\end{array}.$$

Using these facts, it is not difficult to evaluate $\lim_{x\to \infty}c{x}^{n}$ and $\lim_{x\to-\infty}c{x}^{n},$ where $c$ is any constant and $n$ is a positive integer. If $c\gt 0,$ the graph of $y=c{x}^{n}$ is a vertical stretch or compression of $y={x}^{n},$ and therefore

$$\lim_{x\to \infty}c{x}^{n}=\lim_{x\to \infty}{x}^{n}\;\text{and}\;\lim_{x\to-\infty}c{x}^{n}=\lim_{x\to-\infty}{x}^{n}\;\text{if}\;c\gt 0.$$

If $c\lt 0,$ the graph of $y=c{x}^{n}$ is a vertical stretch or compression combined with a reflection about the $x$-axis, and therefore

$$\lim_{x\to \infty}c{x}^{n}=-\lim_{x\to \infty}{x}^{n}\;\text{and}\;\lim_{x\to-\infty}c{x}^{n}=-\lim_{x\to-\infty}{x}^{n}\;\text{if}\;c\lt 0.$$

If $c=0,y=c{x}^{n}=0,$ in which case $\lim_{x\to \infty}c{x}^{n}=0=\lim_{x\to-\infty}c{x}^{n}.$

Example 4.24 · Limits at Infinity for Power Functions

For each function $\kf,$ evaluate $\lim_{x\to \infty}\kf(x)$ and $\lim_{x\to-\infty}\kf(x).$

a. $\kf(x)=-5{x}^{3}$

b. $\kf(x)=2{x}^{4}$

Solution

a. Since the coefficient of ${x}^{3}$ is $-5,$ the graph of $\kf(x)=-5{x}^{3}$ involves a vertical stretch and reflection of the graph of $y={x}^{3}$ about the $x$-axis. Therefore, $\lim_{x\to \infty}(-5{x}^{3})=-\infty$ and $\lim_{x\to-\infty}(-5{x}^{3})=\infty.$

b. Since the coefficient of ${x}^{4}$ is $2,$ the graph of $\kf(x)=2{x}^{4}$ is a vertical stretch of the graph of $y={x}^{4}.$ Therefore, $\lim_{x\to \infty}2{x}^{4}=\infty$ and $\lim_{x\to-\infty}2{x}^{4}=\infty.$

We now look at how the limits at infinity for power functions can be used to determine $\lim_{x\to \pm \infty}\kf(x)$ for any polynomial function $\kf.$ Consider a polynomial function

$$\kf(x)={a}_{n}{x}^{n}+{a}_{n-1}{x}^{n-1}+\ldots+{a}_{1}x+{a}_{0}$$

of degree $n\ge 1$ so that ${a}_{n}\ne 0.$ Factoring, we see that

$$\kf(x)={a}_{n}{x}^{n}(1+\frac{{a}_{n-1}}{{a}_{n}}\;\frac{1}{x}+\ldots+\frac{{a}_{1}}{{a}_{n}}\;\frac{1}{{x}^{n-1}}+\frac{{a}_{0}}{{a}_{n}}\frac{1}{{x}^{n}}).$$

As $x\to \pm \infty,$ all the terms inside the parentheses approach zero except the first term. We conclude that

$$\lim_{x\to \pm \infty}\kf(x)=\lim_{x\to \pm \infty}{a}_{n}{x}^{n}.$$

For example, the function $\kf(x)=5{x}^{3}-3{x}^{2}+4$ behaves like $\kg(x)=5{x}^{3}$ as $x\to \pm \infty$ as shown in Figure 4.52 and Table 4.4.

End Behavior for Algebraic Functions

The end behavior for rational functions and functions involving radicals is a little more complicated than for polynomials. In Example 4.25, we show that the limits at infinity of a rational function $\kf(x)=\frac{p(x)}{q(x)}$ depend on the relationship between the degree of the numerator and the degree of the denominator. To evaluate the limits at infinity for a rational function, we divide the numerator and denominator by the highest power of $x$ appearing in the denominator. This determines which term in the overall expression dominates the behavior of the function at large values of $x.$

Example 4.25 · Determining End Behavior for Rational Functions

For each of the following functions, determine the limits as $x\to \infty$ and $x\to-\infty.$ Then, use this information to describe the end behavior of the function.

a. $\kf(x)=\frac{3x-1}{2x+5}$ (Note: The degree of the numerator and the denominator are the same.)

b. $\kf(x)=\frac{3{x}^{2}+2x}{4{x}^{3}-5x+7}$ (Note: The degree of numerator is less than the degree of the denominator.)

c. $\kf(x)=\frac{3{x}^{2}+4x}{x+2}$ (Note: The degree of numerator is greater than the degree of the denominator.)

Solution

a. The highest power of $x$ in the denominator is $x.$ Therefore, dividing the numerator and denominator by $x$ and applying the algebraic limit laws, we see that

$$\begin{array}{rl}\lim_{x\to \pm \infty}\frac{3x-1}{2x+5} &=\lim_{x\to \pm \infty}\frac{3-1/x}{2+5/x} \\ &=\frac{\lim_{x\to \pm \infty}(3-1/x)}{\lim_{x\to \pm \infty}(2+5/x)} \\ &=\frac{\lim_{x\to \pm \infty}3-\lim_{x\to \pm \infty}1/x}{\lim_{x\to \pm \infty}2+\lim_{x\to \pm \infty}5/x} \\ &=\frac{3-0}{2+0}=\frac{3}{2}.\end{array}$$

Since $\lim_{x\to \pm \infty}\kf(x)=\frac{3}{2},$ we know that $y=\frac{3}{2}$ is a horizontal asymptote for this function as shown in the following graph.

b. Since the largest power of $x$ appearing in the denominator is ${x}^{3},$ divide the numerator and denominator by ${x}^{3}.$ After doing so and applying algebraic limit laws, we obtain

$$\lim_{x\to \pm \infty}\frac{3{x}^{2}+2x}{4{x}^{3}-5x+7}=\lim_{x\to \pm \infty}\frac{3/x+2/{x}^{2}}{4-5/{x}^{2}+7/{x}^{3}}=\frac{3(0)+2(0)}{4-5(0)+7(0)}=0.$$

Therefore $\kf$ has a horizontal asymptote of $y=0$ as shown in the following graph.

c. Dividing the numerator and denominator by $x,$ we have

$$\lim_{x\to \pm \infty}\frac{3{x}^{2}+4x}{x+2}=\lim_{x\to \pm \infty}\frac{3x+4}{1+2/x}.$$

As $x\to \pm \infty,$ the denominator approaches $1.$ As $x\to \infty,$ the numerator approaches $+\infty.$ As $x\to-\infty,$ the numerator approaches $-\infty.$ Therefore $\lim_{x\to \infty}\kf(x)=\infty,$ whereas $\lim_{x\to-\infty}\kf(x)=-\infty$ as shown in the following figure.

Before proceeding, consider the graph of $\kf(x)=\frac{(3{x}^{2}+4x)}{(x+2)}$ shown in Figure 4.56. As $x\to \infty$ and $x\to-\infty,$ the graph of $\kf$ appears almost linear. Although $\kf$ is certainly not a linear function, we now investigate why the graph of $\kf$ seems to be approaching a linear function. First, using long division of polynomials, we can write

$$\kf(x)=\frac{3{x}^{2}+4x}{x+2}=3x-2+\frac{4}{x+2}.$$

Since $\frac{4}{(x+2)}\to 0$ as $x\to \pm \infty,$ we conclude that

$$\lim_{x\to \pm \infty}(\kf(x)-(3x-2))=\lim_{x\to \pm \infty}\frac{4}{x+2}=0.$$

Therefore, the graph of $\kf$ approaches the line $y=3x-2$ as $x\to \pm \infty.$ This line is known as an oblique asymptote for $\kf$ (Figure 4.56).

We can summarize the results of Example 4.25 to make the following conclusion regarding end behavior for rational functions. Consider a rational function

$$\kf(x)=\frac{p(x)}{q(x)}=\frac{{a}_{n}{x}^{n}+{a}_{n-1}{x}^{n-1}+\ldots+{a}_{1}x+{a}_{0}}{{b}_{m}{x}^{m}+{b}_{m-1}{x}^{m-1}+\ldots+{b}_{1}x+{b}_{0}},$$

where ${a}_{n}\ne 0\;\text{and}\;{b}_{m}\ne 0.$

  1. If the degree of the numerator is the same as the degree of the denominator $(n=m),$ then $\kf$ has a horizontal asymptote of $y={a}_{n}/{b}_{m}$ as $x\to \pm \infty.$
  2. If the degree of the numerator is less than the degree of the denominator $(n\lt m),$ then $\kf$ has a horizontal asymptote of $y=0$ as $x\to \pm \infty.$
  3. If the degree of the numerator is greater than the degree of the denominator $(n\gt m),$ then $\kf$ does not have a horizontal asymptote. The limits at infinity are either positive or negative infinity, depending on the signs of the leading terms. In addition, using long division, the function can be rewritten as
$$\kf(x)=\frac{p(x)}{q(x)}=\kg(x)+\frac{r(x)}{q(x)},$$

where the degree of $r(x)$ is less than the degree of $q(x).$ As a result, $\lim_{x\to \pm \infty}r(x)/q(x)=0.$ Therefore, the values of $[\kf(x)-\kg(x)]$ approach zero as $x\to \pm \infty.$ If the degree of $p(x)$ is exactly one more than the degree of $q(x)$ $(n=m+1),$ the function $\kg(x)$ is a linear function. In this case, we call $\kg(x)$ an oblique asymptote.

Now let’s consider the end behavior for functions involving a radical.

Example 4.26 · Determining End Behavior for a Function Involving a Radical

Find the limits as $x\to \infty$ and $x\to-\infty$ for $\kf(x)=\frac{3x-2}{\sqrt{4{x}^{2}+5}}$ and describe the end behavior of $\kf.$

Solution

Let’s use the same strategy as we did for rational functions: divide the numerator and denominator by a power of $x.$ To determine the appropriate power of $x,$ consider the expression $\sqrt{4{x}^{2}+5}$ in the denominator. Since

$$\sqrt{4{x}^{2}+5}\approx \sqrt{4{x}^{2}}=2|x|$$

for large values of $x$ in effect $x$ appears just to the first power in the denominator. Therefore, we divide the numerator and denominator by $|x|.$ Then, using the fact that $|x|=x$ for $x\gt 0,$ $|x|=-x$ for $x\lt 0,$ and $|x|=\sqrt{{x}^{2}}$ for all $x,$ we calculate the limits as follows:

$$\begin{array}{rll}\lim_{x\to \infty}\frac{3x-2}{\sqrt{4{x}^{2}+5}} &= & \lim_{x\to \infty}\frac{(1/|x|)(3x-2)}{(1/|x|)\sqrt{4{x}^{2}+5}} \\ &= & \lim_{x\to \infty}\frac{(1/x)(3x-2)}{\sqrt{(1/{x}^{2})(4{x}^{2}+5)}} \\ &= & \lim_{x\to \infty}\frac{3-2/x}{\sqrt{4+5/{x}^{2}}}=\frac{3}{\sqrt{4}}=\frac{3}{2} \\ \lim_{x\to-\infty}\frac{3x-2}{\sqrt{4{x}^{2}+5}} &= & \lim_{x\to-\infty}\frac{(1/|x|)(3x-2)}{(1/|x|)\sqrt{4{x}^{2}+5}} \\ &= & \lim_{x\to-\infty}\frac{(-1/x)(3x-2)}{\sqrt{(1/{x}^{2})(4{x}^{2}+5)}} \\ &= & \lim_{x\to-\infty}\frac{-3+2/x}{\sqrt{4+5/{x}^{2}}}=\frac{-3}{\sqrt{4}}=\frac{-3}{2}.\end{array}$$

Therefore, $\kf(x)$ approaches the horizontal asymptote $y=\frac{3}{2}$ as $x\to \infty$ and the horizontal asymptote $y=-\frac{3}{2}$ as $x\to-\infty$ as shown in the following graph.

The six basic trigonometric functions are periodic and do not approach a finite limit as $x\to \pm \infty.$ For example, $\sin x$ oscillates between $1\;\text{and}\;-1$ (Figure 4.58). The tangent function, $\tan (x)$, has an infinite number of vertical asymptotes as $x\to \pm \infty;$ therefore, it does not approach a finite limit nor does it approach $\pm \infty$ as $x\to \pm \infty$ as shown in Figure 4.59.

Recall that for any base $b\gt 0,b\ne 1,$ the function $y={b}^{x}$ is an exponential function with domain $(-\infty,\infty)$ and range $(0,\infty).$ If $b\gt 1,y={b}^{x}$ is increasing over $(-\infty,\infty).$ If $0\lt b\lt 1,$ $y={b}^{x}$ is decreasing over $(-\infty,\infty).$ For the natural exponential function $\kf(x)={e}^{x},$ $e\approx 2.718\gt 1.$ Therefore, $\kf(x)={e}^{x}$ is increasing on $(-\infty,\infty)$ and the range is $(0,\infty).$ The exponential function $\kf(x)={e}^{x}$ approaches $\infty$ as $x\to \infty$ and approaches $0$ as $x\to-\infty$ as shown in Table 4.5 and Figure 4.60.

Example 4.27 · Determining End Behavior for a Transcendental Function

Find the limits as $x\to \infty$ and $x\to-\infty$ for $\kf(x)=\frac{(2+3{e}^{x})}{(7-5{e}^{x})}$ and describe the end behavior of $\kf.$

Solution

To find the limit as $x\to \infty,$ divide the numerator and denominator by ${e}^{x}:$

$$\begin{array}{rl}\lim_{x\to \infty}\kf(x) &=\lim_{x\to \infty}\frac{2+3{e}^{x}}{7-5{e}^{x}} \\ &=\lim_{x\to \infty}\frac{(2/{e}^{x})+3}{(7/{e}^{x})-5}.\end{array}$$

As shown in Figure 4.60, ${e}^{x}\to \infty$ as $x\to \infty.$ Therefore,

$$\lim_{x\to \infty}\frac{2}{{e}^{x}}=0=\lim_{x\to \infty}\frac{7}{{e}^{x}}.$$

We conclude that $\lim_{x\to \infty}\kf(x)=-\frac{3}{5},$ and the graph of $\kf$ approaches the horizontal asymptote $y=-\frac{3}{5}$ as $x\to \infty.$ To find the limit as $x\to-\infty,$ use the fact that ${e}^{x}\to 0$ as $x\to-\infty$ to conclude that $\lim_{x\to \infty}\kf(x)=\frac{2}{7},$ and therefore the graph of approaches the horizontal asymptote $y=\frac{2}{7}$ as $x\to-\infty.$

Guidelines for Drawing the Graph of a Function

We now have enough analytical tools to draw graphs of a wide variety of algebraic and transcendental functions. Before showing how to graph specific functions, let’s look at a general strategy to use when graphing any function.

Problem-Solving Strategy

Drawing the Graph of a Function

Given a function $\kf,$ use the following steps to sketch a graph of $\kf:$

  1. Determine the domain of the function.
  2. Locate the $x$- and $y$-intercepts.
  3. Evaluate $\lim_{x\to \infty}\kf(x)$ and $\lim_{x\to-\infty}\kf(x)$ to determine the end behavior. If either of these limits is a finite number $\kL,$ then $y=\kL$ is a horizontal asymptote. If either of these limits is $\infty$ or $-\infty,$ determine whether $\kf$ has an oblique asymptote. If $\kf$ is a rational function such that $\kf(x)=\frac{p(x)}{q(x)},$ where the degree of the numerator is greater than the degree of the denominator, then $\kf$ can be written as
$$\kf(x)=\frac{p(x)}{q(x)}=\kg(x)+\frac{r(x)}{q(x)},$$

where the degree of $r(x)$ is less than the degree of $q(x).$ The values of $\kf(x)$ approach the values of $\kg(x)$ as $x\to \pm \infty.$ If $\kg(x)$ is a linear function, it is known as an oblique asymptote.

  1. Determine whether $\kf$ has any vertical asymptotes.
  2. Calculate $\kfprime.$ Find all critical points and determine the intervals where $\kf$ is increasing and where $\kf$ is decreasing. Determine whether $\kf$ has any local extrema.
  3. Calculate $\kfdprime.$ Determine the intervals where $\kf$ is concave up and where $\kf$ is concave down. Use this information to determine whether $\kf$ has any inflection points. The second derivative can also be used as an alternate means to determine or verify that $\kf$ has a local extremum at a critical point.

Now let’s use this strategy to graph several different functions. We start by graphing a polynomial function.

Example 4.28 · Sketching a Graph of a Polynomial

Sketch a graph of $\kf(x)={(x-1)}^{2}(x+2).$

Solution

Step 1. Since $\kf$ is a polynomial, the domain is the set of all real numbers.

Step 2. When $x=0,\kf(x)=2.$ Therefore, the $y$-intercept is $(0,2).$ To find the $x$-intercepts, we need to solve the equation ${(x-1)}^{2}(x+2)=0,$ gives us the $x$-intercepts $(1,0)$ and $(-2,0)$

Step 3. We need to evaluate the end behavior of $\kf.$ As $x\to \infty,$ ${(x-1)}^{2}\to \infty$ and $(x+2)\to \infty.$ Therefore, $\lim_{x\to \infty}\kf(x)=\infty.$ As $x\to-\infty,$ ${(x-1)}^{2}\to \infty$ and $(x+2)\to-\infty.$ Therefore, $\lim_{x\to-\infty}\kf(x)=-\infty.$ To get even more information about the end behavior of $\kf,$ we can multiply the factors of $\kf.$ When doing so, we see that

$$\kf(x)={(x-1)}^{2}(x+2)={x}^{3}-3x+2.$$

Since the leading term of $\kf$ is ${x}^{3},$ we conclude that $\kf$ behaves like $y={x}^{3}$ as $x\to \pm \infty.$

Step 4. Since $\kf$ is a polynomial function, it does not have any vertical asymptotes.

Step 5. The first derivative of $\kf$ is

$$\kfprime(x)=3{x}^{2}-3.$$

Therefore, $\kf$ has two critical points: $x=1,-1.$ Divide the interval $(-\infty,\infty)$ into the three smaller intervals: $(-\infty,-1),$ $(-1,1),$ and $(1,\infty).$ Then, choose test points $x=-2,$ $x=0,$ and $x=2$ from these intervals and evaluate the sign of $\kfprime(x)$ at each of these test points, as shown in the following table.

IntervalTest PointSign of Derivative $\kfprime(x)=3{x}^{2}-3=3(x-1)(x+1)$Conclusion
$(-\infty,-1)$$x=-2$$(+)(-)(-)=+$$\kf$ is increasing.
$(-1,1)$$x=0$$(+)(-)(+)=-$$\kf$ is decreasing.
$(1,\infty)$$x=2$$(+)(+)(+)=+$$\kf$ is increasing.

From the table, we see that $\kf$ has a local maximum at $x=-1$ and a local minimum at $x=1.$ Evaluating $\kf(x)$ at those two points, we find that the local maximum value is $\kf(-1)=4$ and the local minimum value is $\kf(1)=0.$

Step 6. The second derivative of $\kf$ is

$$\kfdprime(x)=6x.$$

The second derivative is zero at $x=0.$ Therefore, to determine the concavity of $\kf,$ divide the interval $(-\infty,\infty)$ into the smaller intervals $(-\infty,0)$ and $(0,\infty),$ and choose test points $x=-1$ and $x=1$ to determine the concavity of $\kf$ on each of these smaller intervals as shown in the following table.

$(-\infty,0)$$x=-1$$-$$\kf$ is concave down.

We note that the information in the preceding table confirms the fact, found in step $5,$ that $\kf$ has a local maximum at $x=-1$ and a local minimum at $x=1.$ In addition, the information found in step $5$—namely, $\kf$ has a local maximum at $x=-1$ and a local minimum at $x=1,$ and $\kfprime(x)=0$ at those points—combined with the fact that $\kfdprime$ changes sign only at $x=0$ confirms the results found in step $6$ on the concavity of $\kf.$

Combining this information, we arrive at the graph of $\kf(x)={(x-1)}^{2}(x+2)$ shown in the following graph.

Example 4.29 · Sketching a Rational Function

Sketch the graph of $\kf(x)=\frac{{x}^{2}}{(1-{x}^{2})}\text{.}$

Solution

Step 1. The function $\kf$ is defined as long as the denominator is not zero. Therefore, the domain is the set of all real numbers $x$ except $x=\pm 1.$

Step 2. Find the intercepts. If $x=0,$ then $\kf(x)=0,$ so $0$ is an intercept. If $y=0,$ then $\frac{{x}^{2}}{(1-{x}^{2})}=0,$ which implies $x=0.$ Therefore, $(0,0)$ is the only intercept.

Step 3. Evaluate the limits at infinity. Since $\kf$ is a rational function, divide the numerator and denominator by the highest power in the denominator: ${x}^{2}.$ We obtain

$$\lim_{x\to \pm \infty}\frac{{x}^{2}}{1-{x}^{2}}=\lim_{x\to \pm \infty}\frac{1}{\frac{1}{{x}^{2}}-1}=-1.$$

Therefore, $\kf$ has a horizontal asymptote of $y=-1$ as $x\to \infty$ and $x\to-\infty.$

Step 4. To determine whether $\kf$ has any vertical asymptotes, first check to see whether the denominator has any zeroes. We find the denominator is zero when $x=\pm 1.$ To determine whether the lines $x=1$ or $x=-1$ are vertical asymptotes of $\kf,$ evaluate $\lim_{x\to 1}\kf(x)$ and $\lim_{x\to-1}\kf(x).$ By looking at each one-sided limit as $x\to 1,$ we see that

$$\lim_{x\to {1}^{+}}\frac{{x}^{2}}{1-{x}^{2}}=-\infty \;\text{and}\;\lim_{x\to {1}^{-}}\frac{{x}^{2}}{1-{x}^{2}}=\infty.$$

In addition, by looking at each one-sided limit as $x\to-1,$ we find that

$$\lim_{x\to-{1}^{+}}\frac{{x}^{2}}{1-{x}^{2}}=\infty \;\text{and}\;\lim_{x\to-{1}^{-}}\frac{{x}^{2}}{1-{x}^{2}}=-\infty.$$

Step 5. Calculate the first derivative:

$$\kfprime(x)=\frac{(1-{x}^{2})(2x)-{x}^{2}(-2x)}{{(1-{x}^{2})}^{2}}=\frac{2x}{{(1-{x}^{2})}^{2}}.$$

Critical points occur at points $x$ where $\kfprime(x)=0$ or $\kfprime(x)$ is undefined. We see that $\kfprime(x)=0$ when $x=0.$ The derivative $\kfprime$ is not undefined at any point in the domain of $\kf.$ However, $x=\pm 1$ are not in the domain of $\kf.$ Therefore, to determine where $\kf$ is increasing and where $\kf$ is decreasing, divide the interval $(-\infty,\infty)$ into four smaller intervals: $(-\infty,-1),$ $(-1,0),$ $(0,1),$ and $(1,\infty),$ and choose a test point in each interval to determine the sign of $\kfprime(x)$ in each of these intervals. The values $x=-2,$ $x=-\frac{1}{2},$ $x=\frac{1}{2},$ and $x=2$ are good choices for test points as shown in the following table.

IntervalTest PointSign of $\kfprime(x)=\frac{2x}{{(1-{x}^{2})}^{2}}$Conclusion
$(-\infty,-1)$$x=-2$$-/+=-$$\kf$ is decreasing.
$(-1,0)$$x=-1/2$$-/+=-$$\kf$ is decreasing.
$(0,1)$$x=1/2$$+/+=+$$\kf$ is increasing.
$(1,\infty)$$x=2$$+/+=+$$\kf$ is increasing.

From this analysis, we conclude that $\kf$ has a local minimum at $x=0$ but no local maximum.

Step 6. Calculate the second derivative:

$$\begin{array}{rr}\kfdprime(x) &=\frac{{(1-{x}^{2})}^{2}(2)-2x(2(1-{x}^{2})(-2x))}{{(1-{x}^{2})}^{4}} \\ &=\frac{(1-{x}^{2})[2(1-{x}^{2})+8{x}^{2}]}{{(1-{x}^{2})}^{4}} \\ &=\frac{2(1-{x}^{2})+8{x}^{2}}{{(1-{x}^{2})}^{3}} \\ &=\frac{6{x}^{2}+2}{{(1-{x}^{2})}^{3}}.\end{array}$$

To determine the intervals where $\kf$ is concave up and where $\kf$ is concave down, we first need to find all points $x$ where $\kfdprime(x)=0$ or $\kfdprime(x)$ is undefined. Since the numerator $6{x}^{2}+2\ne 0$ for any $x,$ $\kfdprime(x)$ is never zero. Furthermore, $\kfdprime$ is not undefined for any $x$ in the domain of $\kf.$ However, as discussed earlier, $x=\pm 1$ are not in the domain of $\kf.$ Therefore, to determine the concavity of $\kf,$ we divide the interval $(-\infty,\infty)$ into the three smaller intervals $(-\infty,-1),$ $(-1,-1),$ and $(1,\infty),$ and choose a test point in each of these intervals to evaluate the sign of $\kfdprime(x).$ in each of these intervals. The values $x=-2,$ $x=0,$ and $x=2$ are possible test points as shown in the following table.

IntervalTest PointSign of $\kfdprime(x)=\frac{6{x}^{2}+2}{{(1-{x}^{2})}^{3}}$Conclusion
$(-\infty,-1)$$x=-2$$+/-=-$$\kf$ is concave down.
$(-1,-1)$$x=0$$+/+=+$$\kf$ is concave up.
$(1,\infty)$$x=2$$+/-=-$$\kf$ is concave down.

Combining all this information, we arrive at the graph of $\kf$ shown below. Note that, although $\kf$ changes concavity at $x=-1$ and $x=1,$ there are no inflection points at either of these places because $\kf$ is not continuous at $x=-1$ or $x=1.$

Example 4.30 · Sketching a Rational Function with an Oblique Asymptote

Sketch the graph of $\kf(x)=\frac{{x}^{2}}{(x-1)}$

Solution

Step 1. The domain of $\kf$ is the set of all real numbers $x$ except $x=1.$

Step 2. Find the intercepts. We can see that when $x=0,$ $\kf(x)=0,$ so $(0,0)$ is the only intercept.

Step 3. Evaluate the limits at infinity. Since the degree of the numerator is one more than the degree of the denominator, $\kf$ must have an oblique asymptote. To find the oblique asymptote, use long division of polynomials to write

$$\kf(x)=\frac{{x}^{2}}{x-1}=x+1+\frac{1}{x-1}.$$

Since $1/(x-1)\to 0$ as $x\to \pm \infty,$ $\kf(x)$ approaches the line $y=x+1$ as $x\to \pm \infty.$ The line $y=x+1$ is an oblique asymptote for $\kf.$

Step 4. To check for vertical asymptotes, look at where the denominator is zero. Here the denominator is zero at $x=1.$ Looking at both one-sided limits as $x\to 1,$ we find

$$\lim_{x\to {1}^{+}}\frac{{x}^{2}}{x-1}=\infty \;\text{and}\;\lim_{x\to {1}^{-}}\frac{{x}^{2}}{x-1}=-\infty.$$

Therefore, $x=1$ is a vertical asymptote, and we have determined the behavior of $\kf$ as $x$ approaches $1$ from the right and the left.

Step 5. Calculate the first derivative:

$$\kfprime(x)=\frac{(x-1)(2x)-{x}^{2}(1)}{{(x-1)}^{2}}=\frac{{x}^{2}-2x}{{(x-1)}^{2}}.$$

We have $\kfprime(x)=0$ when ${x}^{2}-2x=x(x-2)=0.$ Therefore, $x=0$ and $x=2$ are critical points. Since $\kf$ is undefined at $x=1,$ we need to divide the interval $(-\infty,\infty)$ into the smaller intervals $(-\infty,0),$ $(0,1),$ $(1,2),$ and $(2,\infty),$ and choose a test point from each interval to evaluate the sign of $\kfprime(x)$ in each of these smaller intervals. For example, let $x=-1,$ $x=\frac{1}{2},$ $x=\frac{3}{2},$ and $x=3$ be the test points as shown in the following table.

IntervalTest PointSign of $\kfprime(x)=\frac{{x}^{2}-2x}{{(x-1)}^{2}}=\frac{x(x-2)}{{(x-1)}^{2}}$Conclusion
$(-\infty,0)$$x=-1$$(-)(-)/+=+$$\kf$ is increasing.
$(0,1)$$x=1/2$$(+)(-)/+=-$$\kf$ is decreasing.
$(1,2)$$x=3/2$$(+)(-)/+=-$$\kf$ is decreasing.
$(2,\infty)$$x=3$$(+)(+)/+=+$$\kf$ is increasing.

From this table, we see that $\kf$ has a local maximum at $x=0$ and a local minimum at $x=2.$ The value of $\kf$ at the local maximum is $\kf(0)=0$ and the value of $\kf$ at the local minimum is $\kf(2)=4.$ Therefore, $(0,0)$ and $(2,4)$ are important points on the graph.

Step 6. Calculate the second derivative:

$$\begin{array}{rl}\kfdprime(x) &=\frac{{(x-1)}^{2}(2x-2)-({x}^{2}-2x)(2(x-1))}{{(x-1)}^{4}} \\ &=\frac{(x-1)[(x-1)(2x-2)-2({x}^{2}-2x)]}{{(x-1)}^{4}} \\ &=\frac{(x-1)(2x-2)-2({x}^{2}-2x)}{{(x-1)}^{3}} \\ &=\frac{2{x}^{2}-4x+2-(2{x}^{2}-4x)}{{(x-1)}^{3}} \\ &=\frac{2}{{(x-1)}^{3}}.\end{array}$$

We see that $\kfdprime(x)$ is never zero or undefined for $x$ in the domain of $\kf.$ Since $\kf$ is undefined at $x=1,$ to check concavity we just divide the interval $(-\infty,\infty)$ into the two smaller intervals $(-\infty,1)$ and $(1,\infty),$ and choose a test point from each interval to evaluate the sign of $\kfdprime(x)$ in each of these intervals. The values $x=0$ and $x=2$ are possible test points as shown in the following table.

IntervalTest PointSign of $\kfdprime(x)=\frac{2}{{(x-1)}^{3}}$Conclusion
$(-\infty,1)$$x=0$$+/-=-$$\kf$ is concave down.
$(1,\infty)$$x=2$$+/+=+$$\kf$ is concave up.

From the information gathered, we arrive at the following graph for $\kf.$

Example 4.31 · Sketching the Graph of a Function with a Cusp

Sketch a graph of $\kf(x)={(x-1)}^{2/3}.$

Solution

Step 1. Since the cube-root function is defined for all real numbers $x$ and ${(x-1)}^{2/3}={(\sqrt[3]{x-1})}^{2},$ the domain of $\kf$ is all real numbers.

Step 2: To find the $y$-intercept, evaluate $\kf(0).$ Since $\kf(0)=1,$ the $y$-intercept is $(0,1).$ To find the $x$-intercept, solve ${(x-1)}^{2/3}=0.$ The solution of this equation is $x=1,$ so the $x$-intercept is $(1,0).$

Step 3: Since $\lim_{x\to \pm \infty}{(x-1)}^{2/3}=\infty,$ the function continues to grow without bound as $x\to \infty$ and $x\to-\infty.$

Step 4: The function has no vertical asymptotes.

Step 5: To determine where $\kf$ is increasing or decreasing, calculate $\kfprime.$ We find

$$\kfprime(x)=\frac{2}{3}{(x-1)}^{-1/3}=\frac{2}{3{(x-1)}^{1/3}}.$$

This function is not zero anywhere, but it is undefined when $x=1.$ Therefore, the only critical point is $x=1.$ Divide the interval $(-\infty,\infty)$ into the smaller intervals $(-\infty,1)$ and $(1,\infty),$ and choose test points in each of these intervals to determine the sign of $\kfprime(x)$ in each of these smaller intervals. Let $x=0$ and $x=2$ be the test points as shown in the following table.

IntervalTest PointSign of $\kfprime(x)=\frac{2}{3{(x-1)}^{1/3}}$Conclusion
$(-\infty,1)$$x=0$$+/-=-$$\kf$ is decreasing.
$(1,\infty)$$x=2$$+/+=+$$\kf$ is increasing.

We conclude that $\kf$ has a local minimum at $x=1.$ Evaluating $\kf$ at $x=1,$ we find that the value of $\kf$ at the local minimum is zero. Note that $\kfprime(1)$ is undefined, so to determine the behavior of the function at this critical point, we need to examine $\lim_{x\to 1}\kfprime(x).$ Looking at the one-sided limits, we have

$$\lim_{x\to {1}^{+}}\frac{2}{3{(x-1)}^{1/3}}=\infty \;\text{and}\;\lim_{x\to {1}^{-}}\frac{2}{3{(x-1)}^{1/3}}=-\infty.$$

Therefore, $\kf$ has a cusp at $x=1.$

Step 6: To determine concavity, we calculate the second derivative of $\kf:$

$$\kfdprime(x)=-\frac{2}{9}{(x-1)}^{-4/3}=\frac{-2}{9{(x-1)}^{4/3}}.$$

We find that $\kfdprime(x)$ is defined for all $x,$ but is undefined when $x=1.$ Therefore, divide the interval $(-\infty,\infty)$ into the smaller intervals $(-\infty,1)$ and $(1,\infty),$ and choose test points to evaluate the sign of $\kfdprime(x)$ in each of these intervals. As we did earlier, let $x=0$ and $x=2$ be test points as shown in the following table.

IntervalTest PointSign of $\kfdprime(x)=\frac{-2}{9{(x-1)}^{4/3}}$Conclusion
$(-\infty,1)$$x=0$$-/+=-$$\kf$ is concave down.
$(1,\infty)$$x=2$$-/+=-$$\kf$ is concave down.

From this table, we conclude that $\kf$ is concave down everywhere. Combining all of this information, we arrive at the following graph for $\kf.$
