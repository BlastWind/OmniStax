Earlier in this chapter we stated that if a function $\kf$ has a local extremum at a point $c,$ then $c$ must be a critical point of $\kf.$ However, a function is not guaranteed to have a local extremum at a critical point. For example, $\kf(x)={x}^{3}$ has a critical point at $x=0$ since $\kfprime(x)=3{x}^{2}$ is zero at $x=0,$ but $\kf$ does not have a local extremum at $x=0.$ Using the results from the previous section, we are now able to determine whether a critical point of a function actually corresponds to a local extreme value. In this section, we also see how the second derivative provides information about the shape of a graph by describing whether the graph of a function curves upward or curves downward.

The First Derivative Test

Corollary $3$ of the Mean Value Theorem showed that if the derivative of a function is positive over an interval $\kI$ then the function is increasing over $\kI.$ On the other hand, if the derivative of the function is negative over an interval $\kI,$ then the function is decreasing over $\kI$ as shown in the following figure.

A continuous function $\kf$ has a local maximum at point $c$ if and only if $\kf$ switches from increasing to decreasing at point $c.$ Similarly, $\kf$ has a local minimum at $c$ if and only if $\kf$ switches from decreasing to increasing at $c.$ If $\kf$ is a continuous function over an interval $\kI$ containing $c$ and differentiable over $\kI,$ except possibly at $c,$ the only way $\kf$ can switch from increasing to decreasing (or vice versa) at point $c$ is if $\kfprime$ changes sign as $x$ increases through $c.$ If $\kf$ is differentiable at $c,$ the only way that $\kfprime$ can change sign as $x$ increases through $c$ is if $\kfprime(c)=0.$ Therefore, for a function $\kf$ that is continuous over an interval $\kI$ containing $c$ and differentiable over $\kI,$ except possibly at $c,$ the only way $\kf$ can switch from increasing to decreasing (or vice versa) is if $\kfprime(c)=0$ or $\kfprime(c)$ is undefined. Consequently, to locate local extrema for a function $\kf,$ we look for points $c$ in the domain of $\kf$ such that $\kfprime(c)=0$ or $\kfprime(c)$ is undefined. Recall that such points are called critical points of $\kf.$

Note that $\kf$ need not have local extrema at a critical point. The critical points are candidates for local extrema only. In Figure 4.31, we show that if a continuous function $\kf$ has a local extremum, it must occur at a critical point, but a function may not have a local extremum at a critical point. We show that if $\kf$ has a local extremum at a critical point, then the sign of $\kfprime$ switches as $x$ increases through that point.

Using Figure 4.31, we summarize the main results regarding local extrema.

  • If a continuous function $\kf$ has a local extremum, it must occur at a critical point $c.$
  • The function has a local extremum at the critical point $c$ if and only if the derivative $\kfprime$ switches sign as $x$ increases through $c.$
  • Therefore, to test whether a function has a local extremum at a critical point $c,$ we must determine the sign of $\kfprime(x)$ to the left and right of $c.$

This result is known as the first derivative test.

Theorem

First Derivative Test

Suppose that $\kf$ is a continuous function over an interval $\kI$ containing a critical point $c.$ If $\kf$ is differentiable over $\kI,$ except possibly at point $c,$ then $\kf(c)$ satisfies one of the following descriptions:

  1. If $\kfprime$ changes sign from positive when $x\lt c$ to negative when $x\gt c,$ then $\kf(c)$ is a local maximum of $\kf.$
  2. If $\kfprime$ changes sign from negative when $x\lt c$ to positive when $x\gt c,$ then $\kf(c)$ is a local minimum of $\kf.$
  3. If $\kfprime$ has the same sign for $x\lt c$ and $x\gt c,$ then $\kf(c)$ is neither a local maximum nor a local minimum of $\kf.$

We can summarize the first derivative test as a strategy for locating local extrema.

Problem-Solving Strategy

Using the First Derivative Test

Consider a function $\kf$ that is continuous over an interval $\kI.$

  1. Find all critical points of $\kf$ and divide the interval $\kI$ into smaller intervals using the critical points as endpoints.

  2. Analyze the sign of $\kfprime$ in each of the subintervals. If $\kfprime$ is continuous over a given subinterval (which is typically the case), then the sign of $\kfprime$ in that subinterval does not change and, therefore, can be determined by choosing an arbitrary test point $x$ in that subinterval and by evaluating the sign of $\kfprime$ at that test point. Use the sign analysis to determine whether $\kf$ is increasing or decreasing over that interval.

    Note: If $\kfprime$ is not continuous throughout $\kI$, then include points of discontinuity along with critical points as endpoints when dividing $\kI$ into subintervals.

  3. Use First Derivative Test and the results of step $2$ to determine whether $\kf$ has a local maximum, a local minimum, or neither at each of the critical points.

Now let’s look at how to use this strategy to locate all local extrema for particular functions.

Concavity and Points of Inflection

We now know how to determine where a function is increasing or decreasing. However, there is another issue to consider regarding the shape of the graph of a function. If the graph curves, does it curve upward or curve downward? This notion is called the concavity of the function.

Figure 4.34(a) shows a function $\kf$ with a graph that curves upward. As $x$ increases, the slope of the tangent line increases. Thus, since the derivative increases as $x$ increases, $\kfprime$ is an increasing function. We say this function $\kf$ is concave up. Figure 4.34(b) shows a function $\kf$ that curves downward. As $x$ increases, the slope of the tangent line decreases. Since the derivative decreases as $x$ increases, $\kfprime$ is a decreasing function. We say this function $\kf$ is concave down.

Definition

Let $\kf$ be a function that is differentiable over an open interval $\kI.$ If $\kfprime$ is increasing over $\kI,$ we say $\kf$ is concave up over $\kI.$ If $\kfprime$ is decreasing over $\kI,$ we say $\kf$ is concave down over $\kI.$

In general, without having the graph of a function $\kf,$ how can we determine its concavity? By definition, a function $\kf$ is concave up if $\kfprime$ is increasing. From Corollary $3,$ we know that if $\kfprime$ is a differentiable function, then $\kfprime$ is increasing if its derivative $\kfdprime(x)\gt 0.$ Therefore, a function $\kf$ that is twice differentiable is concave up when $\kfdprime(x)\gt 0.$ Similarly, a function $\kf$ is concave down if $\kfprime$ is decreasing. We know that a differentiable function $\kfprime$ is decreasing if its derivative $\kfdprime(x)\lt 0.$ Therefore, a twice-differentiable function $\kf$ is concave down when $\kfdprime(x)\lt 0.$ Applying this logic is known as the concavity test.

Theorem

Test for Concavity

Let $\kf$ be a function that is twice differentiable over an interval $\kI.$

  1. If $\kfdprime(x)\gt 0$ for all $x\in \kI,$ then $\kf$ is concave up over $\kI.$
  2. If $\kfdprime(x)\lt 0$ for all $x\in \kI,$ then $\kf$ is concave down over $\kI.$

We conclude that we can determine the concavity of a function $\kf$ by looking at the second derivative of $\kf.$ In addition, we observe that a function $\kf$ can switch concavity (Figure 4.35). However, a continuous function can switch concavity only at a point $x$ if $\kfdprime(x)=0$ or $\kfdprime(x)$ is undefined. Consequently, to determine the intervals where a function $\kf$ is concave up and concave down, we look for those values of $x$ where $\kfdprime(x)=0$ or $\kfdprime(x)$ is undefined. When we have determined these points, we divide the domain of $\kf$ into smaller intervals and determine the sign of $\kfdprime$ over each of these smaller intervals. If $\kfdprime$ changes sign as we pass through a point $x,$ then $\kf$ changes concavity. It is important to remember that a function $\kf$ may not change concavity at a point $x$ even if $\kfdprime(x)=0$ or $\kfdprime(x)$ is undefined. If, however, $\kf$ does change concavity at a point $a$ and $\kf$ is continuous at $a,$ we say the point $(a,\kf(a))$ is an inflection point of $\kf.$

Definition

If $\kf$ is continuous at $a$ and $\kf$ changes concavity at $a,$ the point $(a,\kf(a))$ is an inflection point of $\kf.$

The Second Derivative Test

The first derivative test provides an analytical tool for finding local extrema, but the second derivative can also be used to locate extreme values. Using the second derivative can sometimes be a simpler method than using the first derivative.

We know that if a continuous function has local extrema, it must occur at a critical point. However, a function need not have local extrema at a critical point. Here we examine how the second derivative test can be used to determine whether a function has a local extremum at a critical point. Let $\kf$ be a twice-differentiable function such that $\kfprime(a)=0$ and $\kfdprime$ is continuous over an open interval $\kI$ containing $a.$ Suppose $\kfdprime(a)\lt 0.$ Since $\kfdprime$ is continuous over $\kI,$ $\kfdprime(x)\lt 0$ for all $x\in \kI$ (Figure 4.38). Then, by Corollary $3,$ $\kfprime$ is a decreasing function over $\kI.$ Since $\kfprime(a)=0,$ we conclude that for all $x\in \kI,\kfprime(x)\gt 0$ if $x\lt a$ and $\kfprime(x)\lt 0$ if $x\gt a.$ Therefore, by the first derivative test, $\kf$ has a local maximum at $x=a.$ On the other hand, suppose there exists a point $b$ such that $\kfprime(b)=0$ but $\kfdprime(b)\gt 0.$ Since $\kfdprime$ is continuous over an open interval $\kI$ containing $b,$ then $\kfdprime(x)\gt 0$ for all $x\in \kI$ (Figure 4.38). Then, by Corollary $3,\kfprime$ is an increasing function over $\kI.$ Since $\kfprime(b)=0,$ we conclude that for all $x\in \kI,$ $\kfprime(x)\lt 0$ if $x\lt b$ and $\kfprime(x)\gt 0$ if $x\gt b.$ Therefore, by the first derivative test, $\kf$ has a local minimum at $x=b.$

Theorem

Second Derivative Test

Suppose $\kfprime(c)=0,\kfdprime$ is continuous over an interval containing $c.$

  1. If $\kfdprime(c)\gt 0,$ then $\kf$ has a local minimum at $c.$
  2. If $\kfdprime(c)\lt 0,$ then $\kf$ has a local maximum at $c.$
  3. If $\kfdprime(c)=0,$ then the test is inconclusive.

Note that for case iii. when $\kfdprime(c)=0,$ then $\kf$ may have a local maximum, local minimum, or neither at $c.$ For example, the functions $\kf(x)={x}^{3},$ $\kf(x)={x}^{4},$ and $\kf(x)=-{x}^{4}$ all have critical points at $x=0.$ In each case, the second derivative is zero at $x=0.$ However, the function $\kf(x)={x}^{4}$ has a local minimum at $x=0$ whereas the function $\kf(x)=-{x}^{4}$ has a local maximum at $x,$ and the function $\kf(x)={x}^{3}$ does not have a local extremum at $x=0.$

Let’s now look at how to use the second derivative test to determine whether $\kf$ has a local maximum or local minimum at a critical point $c$ where $\kfprime(c)=0.$
